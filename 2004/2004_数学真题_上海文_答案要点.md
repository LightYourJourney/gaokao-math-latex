**17．**

**答案：U/PENDING**

原卷不等式 $|z_1 - z_2| < |z_1|$ 经化简为 $(a - 4)^2 < -3$，在实数范围内无解（$a \in \varnothing$ / 不存在实数 $a$ 满足条件）。部分外部资料疑原式为 $\left|\dfrac{z_1}{z_2}\right| < |z_1| \iff a \ne 2$。因原卷字面无解，保留 U/PENDING。

**18．**

**答案：$x = 8 - 4\sqrt{2} \approx 2.343\text{ m},\; y = 2\sqrt{2} \approx 2.828\text{ m}$**

**19．**

**（1）答案：$(-\infty, -1) \cup [1, +\infty)$**

**（2）答案：U/PENDING**

题干定义 $g(x)$ 的定义域为 $D$，但在小问（2）中提问条件作 $B \subseteq A$，未在题面定义集合 $B$。若按题意将 $B$ 理解为 $g(x)$ 的定义域 $D$，则可解得实数 $a$ 的取值范围为 $(-\infty, -2] \cup \left[\dfrac{1}{2}, 1\right)$。

**21．**

**（1）证明要点**：设正三棱锥底面边长为 $1$，侧棱长为 $a$，截面相似比为 $k \in (0, 1)$。由棱台与棱锥棱长和相等得 $3 + 3k + 3(1 - k)a = 3 + 3a \implies 3ka = 3k \implies a = 1$。故所有棱长均相等，为正四面体。

**（2）答案：$\arccos\dfrac{\sqrt{6}}{3}$（或 $\arcsin\dfrac{\sqrt{3}}{3}$、$\arctan\dfrac{\sqrt{2}}{2}$）**

**（3）答案：存在，构造各棱长均为 $\dfrac{1}{2}$、底面相邻两边夹角为 $\alpha = \arcsin(8V)$ 的直平行六面体**

**22．**

**（1）答案：$(3\sqrt{10}, 3)$（或 $(3\sqrt{10}, -3)$、$(-3\sqrt{10}, 3)$、$(-3\sqrt{10}, -3)$）**

**（2）证明要点**：在抛物线 $y^2 = 2px$ 上，点 $P_k$ 满足 $a_k = |OP_k|^2 = x_k^2 + y_k^2 = x_k^2 + 2px_k$。则 $(x_k + p)^2 = x_k^2 + 2px_k + p^2 = a_k + p^2$。因 $\{a_k\}$ 为等差数列，故 $\{(x_k + p)^2\}$ 亦为公差为 $d$ 的等差数列。

**（3）答案：$\dfrac{n(a^2 + b^2)}{2}$**
