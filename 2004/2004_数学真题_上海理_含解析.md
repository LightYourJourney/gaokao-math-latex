### 第 1 题

**题目**：

若 $\tan\alpha = \dfrac{1}{2}$，则 $\tan\left(\alpha + \dfrac{\pi}{4}\right) = \underline{\qquad}$。

**解析**

由两角和的正切公式：

$$
\tan\left(\alpha + \dfrac{\pi}{4}\right) = \dfrac{\tan\alpha + \tan\frac{\pi}{4}}{1 - \tan\alpha \tan\frac{\pi}{4}} = \dfrac{\frac{1}{2} + 1}{1 - \frac{1}{2}\times 1} = \dfrac{3/2}{1/2} = 3。
$$

**答案：$3$**

### 第 2 题

**题目**：

设抛物线的顶点坐标为 $(2, 0)$，准线方程为 $x = -1$，则它的焦点坐标为 $\underline{\qquad}$。

**解析**

抛物线的顶点坐标为 $(2, 0)$，准线方程为 $x = -1$。
准线到顶点的距离为 $2 - (-1) = 3$。因准线垂直于 $x$ 轴且位于顶点左侧，故抛物线开口向右，对称轴为 $x$ 轴，焦点位于顶点向右平移 $3$ 个单位处，坐标为 $(2 + 3, 0) = (5, 0)$。

**答案：$(5, 0)$**

### 第 3 题

**题目**：

设集合 $A = \{5, \log_2(a + 3)\}$，集合 $B = \{a, b\}$。若 $A \cap B = \{2\}$，则 $A \cup B = \underline{\qquad}$。

**解析**

已知集合 $A = \{5, \log_2(a + 3)\}$，集合 $B = \{a, b\}$，且 $A \cap B = \{2\}$。
由 $2 \in A$ 且 $5 \ne 2$，必有 $\log_2(a + 3) = 2$，解得 $a + 3 = 4 \implies a = 1$。
又 $2 \in B = \{1, b\}$，故必有 $b = 2$。
此时 $A = \{5, 2\}$，$B = \{1, 2\}$，因此

$$
A \cup B = \{1, 2, 5\}。
$$

**答案：$\{1, 2, 5\}$**

### 第 4 题

**题目**：

设等比数列 $\{a_n\}$（$n \in \mathbf{N}$）的公比 $q = -\dfrac{1}{2}$，且 $\displaystyle\lim_{n\to\infty}(a_1 + a_3 + a_5 + \cdots + a_{2n-1}) = \dfrac{8}{3}$，则 $a_1 = \underline{\qquad}$。

**解析**

设等比数列 $\{a_n\}$ 的公比为 $q = -\dfrac{1}{2}$。
奇数项数列 $a_1, a_3, a_5, \cdots, a_{2n-1}$ 亦构成等比数列，首项为 $a_1$，公比为 $q^2 = \left(-\dfrac{1}{2}\right)^2 = \dfrac{1}{4}$。
由于公比绝对值 $|q^2| = \dfrac{1}{4} < 1$，其无穷项和收敛：

$$
\lim_{n\to\infty}(a_1 + a_3 + \cdots + a_{2n-1}) = \dfrac{a_1}{1 - q^2} = \dfrac{a_1}{1 - \frac{1}{4}} = \dfrac{4}{3}a_1。
$$

已知该极限值为 $\dfrac{8}{3}$，得 $\dfrac{4}{3}a_1 = \dfrac{8}{3} \implies a_1 = 2$。

**答案：$2$**

### 第 5 题

**题目**：

设奇函数 $f(x)$ 的定义域为 $[-5, 5]$。若当 $x \in [0, 5]$ 时，$f(x)$ 的图象如右图，则不等式 $f(x) < 0$ 的解是 $\underline{\qquad}$。

[原卷第 5 题函数图象待矢量重绘：含坐标轴，原点 $O$，$x$ 轴标注点 $2, 5$，$y$ 轴标注曲线 $y = f(x)$，图象在 $[0, 2]$ 凸向上方穿过 $(2, 0)$，在 $(2, 5]$ 下凸，端点 $x = 5$ 处引虚线垂足。]

**解析**

因为 $f(x)$ 是定义在 $[-5, 5]$ 上的奇函数，其图象关于原点对称，且 $f(0) = 0$。
观察原卷图象：当 $x \in [0, 5]$ 时，$f(2) = 0$，且
- 当 $x \in (0, 2)$ 时，$f(x) > 0$；
- 当 $x \in (2, 5]$ 时，$f(x) < 0$。

根据奇函数性质 $f(-x) = -f(x)$：
- 当 $x \in (-2, 0)$ 时，$-x \in (0, 2)$，故 $f(x) = -f(-x) < 0$；
- 当 $x \in [-5, -2)$ 时，$-x \in (2, 5]$，故 $f(x) = -f(-x) > 0$；
- 当 $x = 0$ 或 $x = \pm 2$ 时，$f(x) = 0$。

综上，不等式 $f(x) < 0$ 的解集为 $(-2, 0) \cup (2, 5]$。

**答案：$(-2, 0) \cup (2, 5]$**

### 第 6 题

**题目**：

已知点 $A(1, -2)$，若向量 $\overrightarrow{AB}$ 与 $\vec{a} = (2, 3)$ 同向，$|\overrightarrow{AB}| = 2\sqrt{13}$，则点 $B$ 的坐标为 $\underline{\qquad}$。

**解析**

已知向量 $\vec{a} = (2, 3)$，其模长 $|\vec{a}| = \sqrt{2^2 + 3^2} = \sqrt{13}$。
因为向量 $\overrightarrow{AB}$ 与 $\vec{a}$ 同向，可设 $\overrightarrow{AB} = \lambda \vec{a}$（$\lambda > 0$）。
由 $|\overrightarrow{AB}| = \lambda |\vec{a}| = \lambda\sqrt{13} = 2\sqrt{13}$，解得 $\lambda = 2$。
故 $\overrightarrow{AB} = 2(2, 3) = (4, 6)$。
已知点 $A(1, -2)$，设点 $B(x_B, y_B)$，则

$$
(x_B - 1, y_B - (-2)) = (4, 6) \implies x_B = 1 + 4 = 5,\; y_B = -2 + 6 = 4。
$$

故点 $B$ 的坐标为 $(5, 4)$。

**答案：$(5, 4)$**

### 第 7 题

**题目**：

在极坐标系中，点 $M\left(4, \dfrac{\pi}{3}\right)$ 到直线 $l: \rho(2\cos\theta + \sin\theta) = 4$ 的距离 $d = \underline{\qquad}$。

**解析**

直线方程化为直角坐标：
由 $\rho(2\cos\theta + \sin\theta) = 4 \iff 2\rho\cos\theta + \rho\sin\theta = 4$，
代入 $x = \rho\cos\theta, y = \rho\sin\theta$，得直角坐标方程为

$$
2x + y - 4 = 0。
$$

点 $M\left(4, \dfrac{\pi}{3}\right)$ 的直角坐标为：

$$
x_M = 4\cos\dfrac{\pi}{3} = 4 \times \dfrac{1}{2} = 2,\quad y_M = 4\sin\dfrac{\pi}{3} = 4 \times \dfrac{\sqrt{3}}{2} = 2\sqrt{3}。
$$

即 $M(2, 2\sqrt{3})$。
由点到直线的距离公式：

$$
d = \dfrac{|2x_M + y_M - 4|}{\sqrt{2^2 + 1^2}} = \dfrac{|2(2) + 2\sqrt{3} - 4|}{\sqrt{5}} = \dfrac{2\sqrt{3}}{\sqrt{5}} = \dfrac{2\sqrt{15}}{5}。
$$

**答案：$\dfrac{2\sqrt{15}}{5}$**

### 第 8 题

**题目**：

圆心在直线 $2x - y - 7 = 0$ 上的圆 $C$ 与 $y$ 轴交于两点 $A(0, -4)$，$B(0, -2)$，则圆 $C$ 的方程为 $\underline{\qquad}$。

**解析**

圆 $C$ 与 $y$ 轴交于两点 $A(0, -4)$、$B(0, -2)$，则弦 $AB$ 的中点为 $(0, -3)$。
因为弦 $AB$ 在 $y$ 轴上，其垂直平分线为水平直线 $y = -3$。
圆心必在该垂直平分线上，设圆心坐标为 $(x_0, -3)$。
又圆心在直线 $2x - y - 7 = 0$ 上，代入得

$$
2x_0 - (-3) - 7 = 0 \implies 2x_0 - 4 = 0 \implies x_0 = 2。
$$

故圆心坐标为 $(2, -3)$。
半径平方为圆心到点 $B(0, -2)$ 的距离平方：

$$
r^2 = (2 - 0)^2 + (-3 - (-2))^2 = 4 + 1 = 5。
$$

因此圆 $C$ 的方程为 $(x - 2)^2 + (y + 3)^2 = 5$。

**答案：$(x - 2)^2 + (y + 3)^2 = 5$**

### 第 9 题

**题目**：

若在二项式 $(x + 1)^{10}$ 的展开式中任取一项，则该项的系数为奇数的概率是 $\underline{\qquad}$。（结果用分数表示）

**解析**

二项式 $(x + 1)^{10}$ 展开式共有 $11$ 项，第 $k + 1$ 项的系数为组合数 $\mathrm{C}_{10}^k$（$k = 0, 1, 2, \cdots, 10$）。
各项系数依次为：
- $\mathrm{C}_{10}^0 = 1$（奇）
- $\mathrm{C}_{10}^1 = 10$（偶）
- $\mathrm{C}_{10}^2 = 45$（奇）
- $\mathrm{C}_{10}^3 = 120$（偶）
- $\mathrm{C}_{10}^4 = 210$（偶）
- $\mathrm{C}_{10}^5 = 252$（偶）
- $\mathrm{C}_{10}^6 = 210$（偶）
- $\mathrm{C}_{10}^7 = 120$（偶）
- $\mathrm{C}_{10}^8 = 45$（奇）
- $\mathrm{C}_{10}^9 = 10$（偶）
- $\mathrm{C}_{10}^{10} = 1$（奇）

其中系数为奇数的项共有 $4$ 项（对应 $k = 0, 2, 8, 10$）。
（亦可由卢卡斯定理判定：$10 = (1010)_2$，$k$ 的二进制各位不超过 $10$ 的对应位，满足条件的 $k$ 有 $2^2 = 4$ 个）。
因此任取一项系数为奇数的概率为

$$
P = \dfrac{4}{11}。
$$

**答案：$\dfrac{4}{11}$**

### 第 10 题

**题目**：

若函数 $f(x) = a|x - b| + 2$ 在 $[0, +\infty)$ 上为增函数，则实数 $a$、$b$ 的取值范围是 $\underline{\qquad}$。

**解析**

函数 $f(x) = a|x - b| + 2$。
当 $a = 0$ 时，$f(x) \equiv 2$ 为常数函数，不是增函数，故 $a \ne 0$。
函数 $y = |x - b|$ 在 $(-\infty, b]$ 上递减，在 $[b, +\infty)$ 上递增。
- 若 $a < 0$：$f(x)$ 在 $[b, +\infty)$ 上单调递减，不可能在 $[0, +\infty)$ 上递增；
- 若 $a > 0$：$f(x)$ 在 $[b, +\infty)$ 上单调递增，在 $(-\infty, b]$ 上单调递减。

要使 $f(x)$ 在 $[0, +\infty)$ 上为增函数，单调递增区间 $[b, +\infty)$ 必须包含区间 $[0, +\infty)$，即要求 $b \leqslant 0$。
综上，实数 $a$、$b$ 的取值范围是 $a > 0,\; b \leqslant 0$。

**答案：$a > 0,\; b \leqslant 0$**

### 第 12 题

**题目**：

若干个能唯一确定一个数列的量称为该数列的“基本量”。设 $\{a_n\}$ 是公比为 $q$ 的无穷等比数列，下列 $\{a_n\}$ 的四组量中，一定能成为该数列“基本量”的是第 $\underline{\qquad}$ 组。（写出所有符合要求的组号）

① $S_1$ 与 $S_2$；② $a_2$ 与 $S_3$；③ $a_1$ 与 $a_n$；④ $q$ 与 $a_n$。

其中 $n$ 为大于 1 的整数，$S_n$ 为 $\{a_n\}$ 的前 $n$ 项和。

**解析**

设无穷等比数列 $\{a_n\}$ 的首项为 $a_1$（$a_1 \ne 0$），公比为 $q$（$q \ne 0$）。若一组量能唯一确定一组实数对 $(a_1, q)$，则能唯一确定该等比数列。
- ① $S_1 = a_1$，$S_2 = a_1 + a_1 q = a_1(1 + q)$。因为等比数列 $a_1 \ne 0$，由 $S_1$ 可唯一确定 $a_1$，进而 $q = \dfrac{S_2}{S_1} - 1$ 唯一确定，故 ① 是一组基本量；
- ② $a_2 = a_1 q$，$S_3 = a_1(1 + q + q^2)$。消去 $a_1$ 得 $\dfrac{a_2}{q}(1 + q + q^2) = S_3 \implies a_2 q^2 + (a_2 - S_3)q + a_2 = 0$。此方程关于 $q$ 一般有两个不相等的实数解（例如 $a_2 = 2, S_3 = 7$ 时得 $q = 2$ 或 $q = \dfrac{1}{2}$），不能唯一确定数列，故 ② 不是基本量；
- ③ $a_1$ 与 $a_n = a_1 q^{n-1}$。当 $n$ 为大于 1 的奇数时，$n - 1$ 为正偶数，$q^{n-1} = \dfrac{a_n}{a_1} > 0$ 会解得互为相反数的两个 $q$ 值，不能唯一确定数列，故 ③ 不是基本量；
- ④ $q$ 与 $a_n = a_1 q^{n-1}$。由于公比 $q$ 给出（且 $q \ne 0$），可唯一解出 $a_1 = \dfrac{a_n}{q^{n-1}}$，从而 $a_1$ 和 $q$ 均唯一确定，故 ④ 是一组基本量。

综上，符合要求的组号是 ①④。

**答案：①④**

### 第 13 题

**题目**：

在下列关于直线 $l$、$m$ 与平面 $\alpha$、$\beta$ 的命题中，真命题是（\qquad）

(A) 若 $l \subset \beta$ 且 $\alpha \perp \beta$，则 $l \perp \alpha$

(B) 若 $l \perp \beta$ 且 $\alpha \parallel \beta$，则 $l \perp \alpha$

(C) 若 $l \perp \beta$ 且 $\alpha \perp \beta$，则 $l \parallel \alpha$

(D) 若 $\alpha \cap \beta = m$ 且 $l \parallel m$，则 $l \parallel \alpha$

**解析**

- 对于 (A)：若 $l \subset \beta$ 且 $\alpha \perp \beta$，直线 $l$ 只有垂直于交线时才垂直于 $\alpha$，否则不垂直，故 (A) 为假命题；
- 对于 (B)：由面面平行的性质，垂直于两个平行平面中一个平面的直线必垂直于另一个平面，故 (B) 为真命题；
- 对于 (C)：若 $l \perp \beta$ 且 $\alpha \perp \beta$，直线 $l$ 可以平行于平面 $\alpha$，也可以在平面 $\alpha$ 内，故 (C) 为假命题；
- 对于 (D)：若 $\alpha \cap \beta = m$ 且 $l \parallel m$，$l$ 可以在平面 $\alpha$ 内，故 (D) 为假命题。

故选 B。

**答案：B**

### 第 14 题

**题目**：

三角方程 $2\sin\left(\dfrac{\pi}{2} - x\right) = 1$ 的解集为（\qquad）

(A) $\left\{x \mathrel{}\middle|\mathrel{} x = 2k\pi + \dfrac{\pi}{3},\ k \in \mathbf{Z}\right\}$

(B) $\left\{x \mathrel{}\middle|\mathrel{} x = 2k\pi + \dfrac{5\pi}{3},\ k \in \mathbf{Z}\right\}$

(C) $\left\{x \mathrel{}\middle|\mathrel{} x = 2k\pi \pm \dfrac{\pi}{3},\ k \in \mathbf{Z}\right\}$

(D) $\left\{x \mathrel{}\middle|\mathrel{} x = k\pi + (-1)^k,\ k \in \mathbf{Z}\right\}$

**解析**

方程 $2\sin\left(\dfrac{\pi}{2} - x\right) = 1$。
由诱导公式 $\sin\left(\dfrac{\pi}{2} - x\right) = \cos x$，方程化为

$$
2\cos x = 1 \iff \cos x = \dfrac{1}{2}。
$$

在区间 $[0, 2\pi)$ 内，方程的解为 $x = \dfrac{\pi}{3}$ 或 $x = \dfrac{5\pi}{3} = -\dfrac{\pi}{3} + 2\pi$。
故通解集为

$$
\left\{x \mathrel{}\middle|\mathrel{} x = 2k\pi \pm \dfrac{\pi}{3},\ k \in \mathbf{Z}\right\}。
$$

故选 C。
（注：原卷选项 (D) 印载字面为 $x = k\pi + (-1)^k$，漏印项系原卷排版笔误，忠实照录）。

**答案：C**

### 第 15 题

**题目**：

若函数 $y = f(x)$ 的图象可由函数 $y = \lg(x + 1)$ 的图象绕坐标原点 $O$ 逆时针旋转 $\dfrac{\pi}{2}$ 得到，则 $f(x) = $（\qquad）

(A) $10^{-x} - 1$

(B) $10^x - 1$

(C) $1 - 10^{-x}$

(D) $1 - 10^x$

**解析**

设点 $P(x, y)$ 为函数 $y = f(x)$ 图象上的任意一点。
根据题意，$y = f(x)$ 的图象是由 $y = \lg(x + 1)$ 的图象绕原点逆时针旋转 $\dfrac{\pi}{2}$ 得到的，
因此将点 $P(x, y)$ 绕原点顺时针旋转 $\dfrac{\pi}{2}$（即旋转角为 $-\dfrac{\pi}{2}$），必落在原函数 $y = \lg(x + 1)$ 的图象上。
由平面坐标旋转公式：

$$
x_0 = x\cos\left(-\dfrac{\pi}{2}\right) - y\sin\left(-\dfrac{\pi}{2}\right) = y,
$$
$$
y_0 = x\sin\left(-\dfrac{\pi}{2}\right) + y\cos\left(-\dfrac{\pi}{2}\right) = -x。
$$

点 $(x_0, y_0) = (y, -x)$ 满足方程 $y_0 = \lg(x_0 + 1)$，即

$$
-x = \lg(y + 1) \iff y + 1 = 10^{-x} \iff y = 10^{-x} - 1。
$$

故 $f(x) = 10^{-x} - 1$。
故选 A。

**答案：A**

### 第 16 题

**题目**：

某地 2004 年第一季度应聘和招聘人数排行榜前 5 个行业的情况列表如下

| 行业名称 | 计算机 | 机械 | 营销 | 物流 | 贸易 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 应聘人数 | 215830 | 200250 | 154676 | 74570 | 65280 |

| 行业名称 | 计算机 | 营销 | 机械 | 建筑 | 化工 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 招聘人数 | 124620 | 102935 | 89115 | 76516 | 70436 |

若用同一行业中应聘人数与招聘人数比值的大小来衡量该行业的就业情况，则根据表中数据，就业形势一定是（\qquad）

(A) 计算机行业好于化工行业

(B) 建筑行业好于物流行业

(C) 机械行业最紧张

(D) 营销行业比贸易行业紧张

**解析**

指标定义为：$\text{比值} = \dfrac{\text{应聘人数}}{\text{招聘人数}}$，比值越小就业形势越好，比值越大就业形势越紧张。
根据表格前 5 名数据：
- 计算机：应聘 $215830$，招聘 $124620$，比值约为 $\dfrac{215830}{124620} \approx 1.732$；
- 机械：应聘 $200250$，招聘 $89115$，比值约为 $\dfrac{200250}{89115} \approx 2.247$；
- 营销：应聘 $154676$，招聘 $102935$，比值约为 $\dfrac{154676}{102935} \approx 1.503$；
- 物流：应聘 $74570$，招聘未进入前 5（即招聘人数 $< 70436$），故其比值 $> \dfrac{74570}{70436} \approx 1.059$；
- 建筑：招聘 $76516$，应聘未进入前 5（即应聘人数 $< 65280$），故其比值 $< \dfrac{65280}{76516} \approx 0.853$；
- 化工：招聘 $70436$，应聘未进入前 5（即应聘人数 $< 65280$），故其比值 $< \dfrac{65280}{70436} \approx 0.927$。

分析各选项：
- 对 (A)：计算机比值 $\approx 1.732$，化工比值 $< 0.927$，化工比值小于计算机，化工好于计算机，故 (A) 错；
- 对 (B)：建筑比值 $< 0.853$，物流比值 $> 1.059$，建筑比值确定严格小于物流比值，故建筑行业就业形势一定好于物流行业，(B) 成立；

### 第 17 题

**题目**：

已知复数 $z_1$ 满足 $(1 + \mathrm{i})z_1 = -1 + 5\mathrm{i}$，$z_2 = a - 2 - \mathrm{i}$，其中 $\mathrm{i}$ 为虚数单位，$a \in \mathbf{R}$，若 $|z_1 - \overline{z_2}| < |z_1|$，求 $a$ 的取值范围。

$$

$$

又 $z_2 = a - 2 - \mathrm{i}$（$a \in \mathbf{R}$），其共轭复数为

\overline{z_2} = a - 2 + \mathrm{i}。
$$

故

z_1 - \overline{z_2} = (2 + 3\mathrm{i}) - (a - 2 + \mathrm{i}) = (4 - a) + 2\mathrm{i}。

$$

$$

### 第 18 题

**题目**：

某单位用木料制作如图所示的框架，框架的下部是边长分别为 $x$、$y$（单位：$\mathrm{m}$）的矩形，上部是等腰直角三角形。要求框架围成的总面积 $8\text{ cm}^2$。问 $x$、$y$ 分别为多少（精确到 $0.001\text{ m}$）时用料最省？

依题意，框架上部为以 $x$ 为斜边的等腰直角三角形，斜边上的高为 $\dfrac{x}{2}$，腰长为 $\dfrac{\sqrt{2}}{2}x$。

$$
S = xy + \dfrac{1}{2}x \cdot \dfrac{x}{2} = xy + \dfrac{1}{4}x^2 = 8。
$$

由 $S = 8$ 解得

$$
y = \dfrac{8 - \frac{1}{4}x^2}{x} = \dfrac{8}{x} - \dfrac{1}{4}x。
$$

因为 $y > 0$，所以 $8 - \dfrac{1}{4}x^2 > 0 \implies 0 < x < 4\sqrt{2}$。

$$

将 $y = \dfrac{8}{x} - \dfrac{1}{4}x$ 代入得

$$
L = 2\left(\dfrac{8}{x} - \dfrac{1}{4}x\right) + (2 + \sqrt{2})x = \dfrac{16}{x} + \left(\dfrac{3}{2} + \sqrt{2}\right)x。
$$

注意到 $\dfrac{3}{2} + \sqrt{2} = \dfrac{3 + 2\sqrt{2}}{2} = \dfrac{(\sqrt{2} + 1)^2}{2}$。
由于 $x > 0$，由基本不等式：

$$
L \geqslant 2\sqrt{\dfrac{16}{x} \cdot \dfrac{(\sqrt{2} + 1)^2}{2}x} = 2 \times 4 \times \dfrac{\sqrt{2} + 1}{\sqrt{2}} = 8 + 4\sqrt{2}。
$$

当且仅当 $\dfrac{16}{x} = \dfrac{(\sqrt{2} + 1)^2}{2}x$ 时等号成立，即

$$
x^2 = \dfrac{32}{(\sqrt{2} + 1)^2} = 32(\sqrt{2} - 1)^2 = 32(3 - 2\sqrt{2}) = 96 - 64\sqrt{2}。

### 第 19 题

**题目**：

记函数 $f(x) = \sqrt{2 - \dfrac{x + 3}{x + 1}}$ 的定义域为 $A$，$g(x) = \lg[(x - a - 1)(2a - x)]$（$a < 1$）的定义域为 $D$。

(1) 求 $A$；

(2) 若 $B \subseteq A$，求实数 $a$ 的取值范围。

**解析**

#### （1）求集合 $A$

由题设，函数 $f(x) = \sqrt{2 - \dfrac{x + 3}{x + 1}}$ 有意义，需满足

$$
2 - \dfrac{x + 3}{x + 1} \geqslant 0 \iff \dfrac{2(x + 1) - (x + 3)}{x + 1} \geqslant 0 \iff \dfrac{x - 1}{x + 1} \geqslant 0 \text{ 且 } x + 1 \ne 0。
$$

这等价于 $(x - 1)(x + 1) \geqslant 0$ 且 $x \ne -1$。
解此不等式得 $x < -1$ 或 $x \geqslant 1$。
故集合 $A = (-\infty, -1) \cup [1, +\infty)$。

#### （2）求实数 $a$ 的取值范围

> **存疑说明**：题干中定义函数 $g(x)$ 的定义域为集合 $D$，而在小问（2）中提问条件作“若 $B \subseteq A$”，题面通篇未定义集合 $B$。因集合符号脱节，原题存疑，保留 U/PENDING。

若依据题意将 $B$ 视作函数 $g(x)$ 的定义域 $D$ 求解：
要使 $g(x) = \lg[(x - a - 1)(2a - x)]$ 有意义，需

$$
(x - a - 1)(2a - x) > 0 \iff (x - (a + 1))(x - 2a) < 0。
$$

由已知 $a < 1$，得 $(a + 1) - 2a = 1 - a > 0$，即 $a + 1 > 2a$。
因此不等式的解集为开区间 $(2a, a + 1)$，即定义域 $D = (2a, a + 1)$。
若 $D \subseteq A = (-\infty, -1) \cup [1, +\infty)$，由于开区间 $(2a, a + 1)$ 是连通区间，它必须完全落在 $(-\infty, -1)$ 或 $[1, +\infty)$ 之中：
- 情形一：$(2a, a + 1) \subseteq (-\infty, -1)$，只需右端点 $a + 1 \leqslant -1 \iff a \leqslant -2$；结合 $a < 1$ 得 $a \leqslant -2$；
- 情形二：$(2a, a + 1) \subseteq [1, +\infty)$，只需左端点 $2a \geqslant 1 \iff a \geqslant \dfrac{1}{2}$；结合已知 $a < 1$ 得 $\dfrac{1}{2} \leqslant a < 1$。

综上，按 $D \subseteq A$ 理解，实数 $a$ 的取值范围为 $(-\infty, -2] \cup \left[\dfrac{1}{2}, 1\right)$。

**答案（1）：$(-\infty, -1) \cup [1, +\infty)$**

**答案（2）：U/PENDING**

### 第 20 题

**题目**：

已知二次函数 $y = f_1(x)$ 的图象以原点为顶点且过点 $(1, 1)$，反比例函数 $y = f_2(x)$ 的图象与直线 $y = x$ 的两个交点间距离为 8，$f(x) = f_1(x) + f_2(x)$。

(1) 求函数 $f(x)$ 的表达式；

(2) 证明：当 $a > 3$ 时，关于 $x$ 的方程 $f(x) = f(a)$ 有三个实数解。

**解析**

#### （1）求函数 $f(x)$ 的表达式

设二次函数 $f_1(x) = k_1 x^2$。因其图象过点 $(1, 1)$，代入得 $1 = k_1(1)^2 \implies k_1 = 1$，故 $f_1(x) = x^2$。
设反比例函数 $f_2(x) = \dfrac{k_2}{x}$（$k_2 \ne 0$）。
将 $y = \dfrac{k_2}{x}$ 与直线 $y = x$ 联立，得 $x^2 = k_2$。
由于有两个交点，必有 $k_2 > 0$。两交点坐标分别为 $(\sqrt{k_2}, \sqrt{k_2})$ 和 $(-\sqrt{k_2}, -\sqrt{k_2})$。
两交点间的距离为

$$
\sqrt{(\sqrt{k_2} - (-\sqrt{k_2}))^2 + (\sqrt{k_2} - (-\sqrt{k_2}))^2} = \sqrt{(2\sqrt{k_2})^2 + (2\sqrt{k_2})^2} = \sqrt{8k_2}。
$$

已知距离为 $8$，故 $\sqrt{8k_2} = 8 \implies 8k_2 = 64 \implies k_2 = 8$。
所以 $f_2(x) = \dfrac{8}{x}$。
因此函数 $f(x) = f_1(x) + f_2(x) = x^2 + \dfrac{8}{x}$。

#### （2）证明方程 $f(x) = f(a)$ 有三个实数解

证明：关于 $x$ 的方程 $f(x) = f(a)$ 即

$$
x^2 + \dfrac{8}{x} = a^2 + \dfrac{8}{a} \quad (x \ne 0)。
$$

移项整理：

$$
(x^2 - a^2) + \left(\dfrac{8}{x} - \dfrac{8}{a}\right) = 0 \iff (x - a)(x + a) - \dfrac{8(x - a)}{ax} = 0。
$$

提取公因式 $(x - a)$ 得

$$
(x - a)\left(x + a - \dfrac{8}{ax}\right) = 0 \iff (x - a)\cdot \dfrac{ax^2 + a^2 x - 8}{ax} = 0。
$$

由于 $a > 3$，且定义域要求 $x \ne 0$，方程等价于

$$
x - a = 0 \quad \text{或} \quad ax^2 + a^2 x - 8 = 0。
$$

显然 $x = a$ 是方程的一个实数解。
考察二次方程 $ax^2 + a^2 x - 8 = 0$：
判别式为 $\Delta = (a^2)^2 - 4(a)(-8) = a^4 + 32a$。
因为 $a > 3$，所以 $a > 0$ 且 $a^3 + 32 > 0$，故 $\Delta = a(a^3 + 32) > 0$ 恒成立。
因此该二次方程必有两个互不相等的实数根 $x_1, x_2$。
又常数项与二次项系数之比为 $-\dfrac{8}{a} \ne 0$，故 $x_1 \ne 0, x_2 \ne 0$。
检验 $x = a$ 是否可能为该二次方程的根：
将 $x = a$ 代入二次多项式得 $a(a^2) + a^2(a) - 8 = 2a^3 - 8$。
当 $a > 3$ 时，$2a^3 - 8 > 2(3^3) - 8 = 46 > 0$，故 $x = a$ 不是该二次方程的根。
因此 $x_1, x_2, a$ 是三个互不相等的实数解。
综上所述，当 $a > 3$ 时，方程 $f(x) = f(a)$ 恰有三个实数解。

**答案（1）：$f(x) = x^2 + \dfrac{8}{x}$**

**答案（2）：证明见解析**

在椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）上，任意一点 $P(x, y)$ 满足

$$
y^2 = b^2\left(1 - \dfrac{x^2}{a^2}\right) = b^2 - \dfrac{b^2}{a^2}x^2。
$$

故点 $P$ 到原点的距离平方为

$$
|OP|^2 = x^2 + y^2 = b^2 + \dfrac{a^2 - b^2}{a^2}x^2。
$$

因为 $0 \leqslant x^2 \leqslant a^2$ 且 $a > b > 0$，所以 $|OP|^2 \in [b^2, a^2]$。
已知点 $P_1(a, 0)$ 在椭圆上，首项 $a_1 = |OP_1|^2 = a^2$ 达到曲线上的最大模方。
数列 $\{a_k\}$ 为公差 $d \ne 0$ 的等差数列，各项均须满足 $b^2 \leqslant a_k \leqslant a^2$。
若 $d > 0$，则 $a_2 = a^2 + d > a^2$，超出范围，不可能；
因此必有 $d < 0$。
当 $d < 0$ 时，数列单调递减，最小项为 $a_n = a^2 + (n - 1)d$。
要使点 $P_1, P_2, \cdots, P_n$ 均在椭圆上，必须且只需

$$
a_n \geqslant b^2 \iff a^2 + (n - 1)d \geqslant b^2 \iff d \geqslant -\dfrac{a^2 - b^2}{n - 1}。
$$

前 $n$ 项和为

$$
S_n = na_1 + \dfrac{n(n - 1)}{2}d = na^2 + \dfrac{n(n - 1)}{2}d。
$$

因为 $\dfrac{n(n - 1)}{2} > 0$，当 $d$ 取允许范围内的最小值 $d_{\min} = -\dfrac{a^2 - b^2}{n - 1}$ 时，$S_n$ 取得最小值：

$$
S_{n,\min} = na^2 + \dfrac{n(n - 1)}{2}\left(-\dfrac{a^2 - b^2}{n - 1}\right) = na^2 - \dfrac{n(a^2 - b^2)}{2} = \dfrac{n(a^2 + b^2)}{2}。
$$

故 $S_n$ 的最小值为 $\dfrac{n(a^2 + b^2)}{2}$。

#### （3）二次曲线与点存在的充要条件及理由

选定抛物线 $C: y^2 = 2px$（$p > 0$），取顶点 $P_1(0, 0)$。
此时 $a_1 = |OP_1|^2 = 0$。
对于抛物线上的任意点 $P(x, y)$，有 $y^2 = 2px$（$x \geqslant 0$），
其到原点的距离平方为

$$
g(x) = |OP|^2 = x^2 + y^2 = x^2 + 2px。
$$

因为 $p > 0$，$g(x)$ 在 $[0, +\infty)$ 上严格单调递增，且值域为 $[0, +\infty)$。
数列 $\{a_k\}$ 是公差为 $d$ 的等差数列，首项 $a_1 = 0$，故通项为 $a_k = (k - 1)d$（$k = 1, 2, \cdots, n$）。
符合条件的点 $P_1, P_2, \cdots, P_n$ 存在的充要条件为：$d > 0$。
理由如下：
- **必要性**：若符合条件的点 $P_1, \cdots, P_n$ 存在，则对每个 $k \geqslant 2$，点 $P_k$ 对应模方 $a_k = (k - 1)d$ 必须在函数 $g(x)$ 的值域 $[0, +\infty)$ 内。由题设公差 $d \ne 0$，若 $d < 0$，则当 $k = 2$ 时 $a_2 = d < 0$，不在值域内，无法在曲线上取点；因此必有 $d > 0$。
- **充分性**：若 $d > 0$，则对任意 $k \in \{1, 2, \cdots, n\}$，有 $a_k = (k - 1)d \geqslant 0$。由函数 $g(x) = x^2 + 2px$ 在 $[0, +\infty)$ 上的连续性与严格单调递增性，方程 $x^2 + 2px - a_k = 0$ 在 $[0, +\infty)$ 上存在唯一的非负实数解：
  $$x_k = -p + \sqrt{p^2 + a_k} = -p + \sqrt{p^2 + (k - 1)d} \geqslant 0。$$
  再取 $y_k = \sqrt{2px_k}$，则点 $P_k(x_k, y_k)$ 满足 $y_k^2 = 2px_k$（在抛物线上），且 $|OP_k|^2 = x_k^2 + y_k^2 = a_k$。因此符合条件的点 $P_1, P_2, \cdots, P_n$ 均存在。
综上所述，$d > 0$ 是符合条件的点存在的充要条件。

**答案（1）：U/PENDING**

**答案（2）：$\dfrac{n(a^2 + b^2)}{2}$**

**答案（3）：选抛物线 $C: y^2 = 2px$（$p > 0$），取 $P_1(0, 0)$ 时，充要条件为 $d > 0$**
