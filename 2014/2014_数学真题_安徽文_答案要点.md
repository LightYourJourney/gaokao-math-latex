## 逐题答案

**1．**
**答案**：D。$\mathrm i^3=-\mathrm i$，$\dfrac{2\mathrm i}{1+\mathrm i}=\mathrm i(1-\mathrm i)=1+\mathrm i$，相加得 $1$。

**2．**
**答案**：C。全称命题的否定是特称命题，同时把结论“$\geqslant0$”改为“$<0$”。

**3．**
**答案**：A。抛物线化为 $x^2=4y$，$2p=4$，故准线为 $y=-1$。

**4．**
**答案**：B。$z$ 依次取 $2,3,5,8,13,21,34,55$，$55>50$ 时输出。

**5．**
**答案**：B。$a=\log_37\in(1,2)$，$b=2^{1.1}>2$，$c=0.8^{3.1}\in(0,1)$，故 $c<a<b$。

**6．**
**答案**：D。设斜率为 $k$，圆心到 $l$ 的距离 $\leqslant1$ 给出 $0\leqslant k\leqslant\sqrt3$，倾斜角属 $\left[0,\dfrac\pi3\right]$。

**7．**
**答案**：C。$f(x)=\sqrt2\sin\left(2x+\dfrac\pi4\right)$，平移后相位为 $\dfrac\pi4-2\varphi$，关于 $y$ 轴对称需 $\dfrac\pi4-2\varphi=\dfrac\pi2+k\pi$，最小正值 $\varphi=\dfrac{3\pi}8$。

**8．**
**答案**：A。该多面体是棱长 $2$ 的正方体挖去两个三侧棱两两垂直且长均为 $1$ 的四面体（正方体一角的角块），$8-2\times\dfrac16=\dfrac{23}3$。

**9．**
**答案**：D。最小值在折点取得，$|a-2|=3$ 或 $\left|1-\dfrac a2\right|=3$，逐一代回检验得 $a=-4$ 或 $a=8$。

**10．**
**答案**：B。三类配对的值依次为 $8|\boldsymbol a|^2\cos\theta$、$(5+4\cos\theta)|\boldsymbol a|^2$、$10|\boldsymbol a|^2$，最小者为 $8|\boldsymbol a|^2\cos\theta=4|\boldsymbol a|^2$，故 $\cos\theta=\dfrac12$。

**11．**
**答案**：$\dfrac{27}8$。$\left(\dfrac{16}{81}\right)^{-\frac34}=\left(\dfrac32\right)^3=\dfrac{27}8$，两个对数之和为 $\log_31=0$。

**12．**
**答案**：$\dfrac14$。每一步所得的垂线段与上一条之比恒为 $\dfrac{\sqrt2}2$，$a_7=2\left(\dfrac{\sqrt2}2\right)^6=\dfrac14$。

**13．**
**答案**：$4$。三条边界两两交于 $(0,2)$，$(2,0)$，$(8,-2)$，用行列式计算得面积 $\dfrac12\times8=4$。

**14．**
**答案**：$\dfrac5{16}$。$f\left(\dfrac{29}4\right)=f\left(-\dfrac34\right)=-\dfrac3{16}$，$f\left(\dfrac{41}6\right)=f\left(-\dfrac76\right)=-\sin\dfrac{7\pi}6=\dfrac12$。

**15．**
**答案**：①③。①中 $x^3$、③中 $\sin x-x$ 在 $P$ 两侧变号；②的 $x=-1$ 不是切线，④中 $\tan x-x$ 两侧同号，⑤中 $\ln x-(x-1)\leqslant0$ 只在单侧。

**16．**
**答案**：$\cos A=\dfrac13$，$a=2\sqrt2$；或 $\cos A=-\dfrac13$，$a=2\sqrt3$。由 $S=\dfrac12bc\sin A$ 得 $\sin A=\dfrac{2\sqrt2}3$，故 $\cos A=\pm\dfrac13$，再用余弦定理。

**17．**

**（1）答案**：$90$。按女生占比 $\dfrac{4500}{15000}=\dfrac3{10}$ 分层，$300\times\dfrac3{10}=90$。

**（2）答案**：$0.75$。后四组频率之和为 $2\times(0.150+0.125+0.075+0.025)=0.75$。

**（3）答案**：列联表为男生超过 $4$ 小时 $165$ 人、不超过 $45$ 人，女生分别为 $60$ 人与 $30$ 人；$K^2=\dfrac{100}{21}\approx4.762>3.841$，有 $95\%$ 的把握认为有关。

**18．**

**（1）证明**：两边同除以 $n(n+1)$ 得 $\dfrac{a_{n+1}}{n+1}-\dfrac{a_n}{n}=1$，首项 $\dfrac{a_1}1=1$，故该数列是公差为 $1$ 的等差数列。

**（2）答案**：$S_n=\dfrac{(2n-1)3^{n+1}+3}4$。由（1）得 $a_n=n^2$，$b_n=n\cdot3^n$，用错位相减法求和。

**19．**

**（1）证明**：由 $BC\parallel$ 平面 $GEFH$ 及 $BC\subset$ 平面 $PBC$ 得 $GH\parallel BC$；又 $EF$ 是平面 $GEFH$ 与底面 $ABCD$ 的交线，$BC\parallel$ 底面得 $EF\parallel BC$，故 $GH\parallel EF$。

**（2）答案**：$18$。底面中心到各顶点距离 $4\sqrt2$，由侧棱 $2\sqrt{17}$ 得高 $6$；截面为梯形，$EF=8$，$GH=4$，高 $3$，面积 $\dfrac{8+4}2\times3=18$。

**20．**

**（1）答案**：记 $x_1=\dfrac{-1-\sqrt{4+3a}}3$，$x_2=\dfrac{-1+\sqrt{4+3a}}3$；减区间为 $(-\infty,x_1)$、$(x_2,+\infty)$，增区间为 $(x_1,x_2)$。

**（2）答案**：最大值点：$0<a<4$ 时为 $x=\dfrac{\sqrt{4+3a}-1}3$，$a\geqslant4$ 时为 $x=1$；最小值点：$0<a<1$ 时为 $x=1$，$a=1$ 时为 $x=0$ 或 $x=1$，$a>1$ 时为 $x=0$。

**21．**

**（1）答案**：$5$。由 $|AB|=4$ 与 $|AF_1|=3|BF_1|$ 得 $|AF_1|=3$；周长给出 $|AF_2|+|BF_2|=12$，而两者分别为 $2a-3$ 与 $2a-1$，解得 $a=4$，$|AF_2|=5$。

**（2）答案**：$\dfrac{\sqrt2}2$。记 $|BF_1|=m$，由两个三角形余弦定理与 $|AF_1|=3m$ 得 $\cos\angle AF_1F_2=\dfrac a{2c}$、$m=\dfrac{2(a^2-c^2)}{3a}$，再对 $\triangle ABF_2$ 用余弦定理，得 $4e^4-12e^2+5=0$，取 $e<1$ 得 $e=\dfrac{\sqrt2}2$。
