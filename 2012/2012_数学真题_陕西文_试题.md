# 2012 年普通高等学校招生考试（陕西卷文）

## 一、选择题

**1．** 集合 $M=\{x\mid\lg x>0\}$，$N=\{x\mid x^2\leqslant4\}$，则 $M\cap N=$（　　）

（A）$(1,2)$；（B）$[1,2)$；（C）$(1,2]$；（D）$[1,2]$。

**2．** 下列函数中，既是奇函数又是增函数的为（　　）

（A）$y=x+1$；（B）$y=-x^3$；（C）$y=\dfrac1x$；（D）$y=x|x|$。

**3．** 对某商店一个月内每天的顾客人数进行了统计，得到样本的茎叶图（如图所示），则该样本的中位数、众数、极差分别是（　　）

| 十位 | 个位 |
| --- | --- |
| $1$ | $2$ $5$ |
| $2$ | $0$ $2$ $3$ $3$ |
| $3$ | $1$ $2$ $4$ $4$ $8$ $9$ |
| $4$ | $5$ $5$ $5$ $7$ $7$ $8$ $8$ $9$ |
| $5$ | $0$ $0$ $1$ $1$ $4$ $7$ $9$ |
| $6$ | $1$ $7$ $8$ |

（A）$46,45,56$；（B）$46,45,53$；（C）$47,45,56$；（D）$45,47,53$。

**4．** 设 $a$，$b\in\mathbf R$，$\mathrm i$ 是虚数单位，则「$ab=0$」是「复数 $a+\dfrac b{\mathrm i}$ 为纯虚数」的（　　）

（A）充分不必要条件；（B）必要不充分条件；（C）充分必要条件；（D）既不充分也不必要条件。

**5．** 如图是计算某年级 $500$ 名学生期末考试（满分为 $100$ 分）及格率 $q$ 的程序框图，则图中空白框内应填入（　　）

（A）$q=\dfrac NM$；（B）$q=\dfrac MN$；（C）$q=\dfrac N{M+N}$；（D）$q=\dfrac M{M+N}$。

**6．** 已知圆 $C:x^2+y^2-4x=0$，$l$ 是过点 $P(3,0)$ 的直线，则（　　）

（A）$l$ 与 $C$ 相交；（B）$l$ 与 $C$ 相切；（C）$l$ 与 $C$ 相离；（D）以上三个选项均有可能。

**7．** 设向量 $\boldsymbol a=(1,\cos\theta)$ 与 $\boldsymbol b=(-1,2\cos\theta)$ 垂直，则 $\cos2\theta$ 等于（　　）

（A）$\dfrac{\sqrt2}2$；（B）$\dfrac12$；（C）$0$；（D）$-1$。

**8．** 将正方体（如图 1 所示）截去两个三棱锥，得到图 2 所示的几何体，则该几何体的左视图为（　　）

**9．** 设函数 $f(x)=\dfrac2x+\ln x$，则（　　）

（A）$x=\dfrac12$ 为 $f(x)$ 的极大值点；（B）$x=\dfrac12$ 为 $f(x)$ 的极小值点；

（C）$x=2$ 为 $f(x)$ 的极大值点；（D）$x=2$ 为 $f(x)$ 的极小值点。

**10．** 小王从甲地到乙地往返的时速分别为 $a$ 和 $b$（$a<b$），其全程的平均时速为 $v$，则（　　）

（A）$a<v<\sqrt{ab}$；（B）$v=\sqrt{ab}$；（C）$\sqrt{ab}<v<\dfrac{a+b}2$；（D）$v=\dfrac{a+b}2$。

## 二、填空题

**11．** 设函数 $f(x)=\begin{cases}\sqrt x,&x\geqslant0,\\ \left(\dfrac12\right)^x,&x<0,\end{cases}$ 则 $f(f(-4))=$______。

**12．** 观察下列不等式：
$$1+\frac1{2^2}<\frac32,\qquad1+\frac1{2^2}+\frac1{3^2}<\frac53,\qquad1+\frac1{2^2}+\frac1{3^2}+\frac1{4^2}<\frac74,\ \cdots$$
照此规律，第五个不等式为______。

**13．** 在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 所对应的边长分别为 $a$，$b$，$c$，若 $a=2$，$B=\dfrac\pi6$，$c=2\sqrt3$，则 $b=$______。

## 三、解答题

**16．** 已知等比数列 $\{a_n\}$ 的公比为 $q=-\dfrac12$。

（1） 若 $a_3=\dfrac14$，求数列 $\{a_n\}$ 的前 $n$ 项和；

（2） 证明：对任意 $k\in\mathbf N_+$，$a_k$，$a_{k+2}$，$a_{k+1}$ 成等差数列。

**17．** 函数 $f(x)=A\sin\left(\omega x-\dfrac\pi6\right)+1$（$A>0$，$\omega>0$）的最大值为 $3$，其图象相邻两条对称轴之间的距离为 $\dfrac\pi2$。

（1） 求函数 $f(x)$ 的解析式；

（2） 设 $\alpha\in\left(0,\dfrac\pi2\right)$，$f\left(\dfrac\alpha2\right)=2$，求 $\alpha$ 的值。

**18．** 直三棱柱 $ABC-A_1B_1C_1$ 中，$AB=AA_1$，$\angle CAB=\dfrac\pi2$。

（1） 证明：$CB_1\perp BA_1$；

（2） 已知 $AB=2$，$BC=\sqrt5$，求三棱锥 $C_1-ABA_1$ 的体积。

[第18题图：直三棱柱](../docs/exams/2012_陕西卷_文科/figures/f2012_shaanxi_arts_q18_prism.tex)

**19．** 假设甲乙两种品牌的同类产品在某地区市场上销售量相等，为了解他们的使用寿命，现从两种品牌的产品中分别随机抽取 $100$ 个进行测试，结果统计如下：

[第19题图：两个频率分布直方图](../docs/exams/2012_陕西卷_文科/figures/f2012_shaanxi_arts_q19_histograms.tex)

（1） 估计甲品牌产品寿命小于 $200$ 小时的概率；

（2） 这两种品牌产品中，某个产品已使用了 $200$ 小时，试估计该产品是甲品牌的概率。

**20．** 已知椭圆 $C_1:\dfrac{x^2}4+y^2=1$，椭圆 $C_2$ 以 $C_1$ 的长轴为短轴，且与 $C_1$ 有相同的离心率。

（1） 求椭圆 $C_2$ 的方程；

（2） 设 $O$ 为坐标原点，点 $A$，$B$ 分别在椭圆 $C_1$ 和 $C_2$ 上，$\overrightarrow{OB}=2\overrightarrow{OA}$，求直线 $AB$ 的方程。

**21．** 设函数 $f_n(x)=x^n+bx+c$（$n\in\mathbf N_+$，$b$，$c\in\mathbf R$）。

（1） 设 $n\geqslant2$，$b=1$，$c=-1$，证明：$f_n(x)$ 在区间 $\left(\dfrac12,1\right)$ 内存在唯一零点；

（2） 设 $n$ 为偶数，$|f(-1)|\leqslant1$，$|f(1)|\leqslant1$，求 $b+3c$ 的最小值和最大值；

（3） 设 $n=2$，若对任意 $x_1$，$x_2\in[-1,1]$，有 $|f_2(x_1)-f_2(x_2)|\leqslant4$，求 $b$ 的取值范围。
