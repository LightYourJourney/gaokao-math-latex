### 4．
- **推导**：
  原方程为 $\dfrac{M_1}{(R+r)^2} + \dfrac{M_2}{r^2} = (R+r)\dfrac{M_1}{R^3}$。
  设 $\alpha = \dfrac{r}{R} \implies r = \alpha R$。
  方程变形为：
  $\dfrac{M_1}{R^2 (1+\alpha)^2} + \dfrac{M_2}{\alpha^2 R^2} = \dfrac{M_1}{R^2} (1+\alpha)$。
  同除以 $\dfrac{M_1}{R^2}$ 并移项：
  $\dfrac{M_2}{M_1}\dfrac{1}{\alpha^2} = (1+\alpha) - \dfrac{1}{(1+\alpha)^2} = \dfrac{(1+\alpha)^3 - 1}{(1+\alpha)^2} = \dfrac{3\alpha + 3\alpha^2 + \alpha^3}{(1+\alpha)^2}$。
  两边同乘 $\alpha^2$：
  $\dfrac{M_2}{M_1} = \dfrac{3\alpha^3 + 3\alpha^4 + \alpha^5}{(1+\alpha)^2}$。
  利用题目近似条件 $\dfrac{3\alpha^3 + 3\alpha^4 + \alpha^5}{(1+\alpha)^2} \approx 3\alpha^3$：
  $3\alpha^3 \approx \dfrac{M_2}{M_1} \implies \alpha \approx \sqrt[3]{\dfrac{M_2}{3M_1}}$。
  因此 $r = \alpha R \approx \sqrt[3]{\dfrac{M_2}{3M_1}} R$。
- **结论**：D。

### 12．
- **推导**：

  当 $t \in (0, 1]$ 时，$f(t) = t(t-1) = \left(t - \dfrac{1}{2}\right)^2 - \dfrac{1}{4}$，最小值为 $-\dfrac{1}{4}$。

  $(x-2)(x-3) \geqslant -\dfrac{2}{9} \iff x^2 - 5x + \dfrac{56}{9} \geqslant 0 \iff \left(x - \dfrac{7}{3}\right)\left(x - \dfrac{8}{3}\right) \geqslant 0$。

### 20．
- **推导**：
  (1) 定义域为 $(0, 1) \cup (1, +\infty)$。
  $f'(x) = \dfrac{1}{x} + \dfrac{2}{(x-1)^2}$。
  当 $x \in (0, 1) \cup (1, +\infty)$ 时，$f'(x) > 0$ 恒成立。
  因此 $f(x)$ 在 $(0, 1)$ 和 $(1, +\infty)$ 上均严格单调递增。

  在 $(1, +\infty)$ 上，$x \to 1^+$ 时 $f(x) \to -\infty$，$x \to +\infty$ 时 $f(x) \to +\infty$，存在且仅有 1 个零点。
  故 $f(x)$ 有且仅有两个零点。
  (2) 设 $x_0$ 为零点，则 $\ln x_0 = \dfrac{x_0+1}{x_0-1}$。
  曲线 $y = \ln x$ 在点 $A(x_0, \ln x_0)$ 处的切线为 $y - \ln x_0 = \dfrac{1}{x_0}(x - x_0) \implies y = \dfrac{1}{x_0}x + \dfrac{2}{x_0-1}$。

  因此该切线也是曲线 $y = \mathrm{e}^x$ 的切线。
- **结论**：(1) 递增区间为 $(0, 1)$ 和 $(1, +\infty)$，两个零点；(2) 见推导。

  点 $P$ 在线段 $OM$ 上要求 $0 \leqslant \rho \leqslant \rho_M \iff 0 \leqslant 4\cos\theta \leqslant 4\sin\theta$。

  由 $\cos\theta \leqslant \sin\theta$ 得 $\tan\theta \geqslant 1 \implies \theta \geqslant \dfrac{\pi}{4}$。
  因此 $\theta \in \left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$。
  $P$ 点轨迹的极坐标方程为 $\rho = 4\cos\theta$ $\left(\dfrac{\pi}{4} \leqslant \theta \leqslant \dfrac{\pi}{2}\right)$。
- **结论**：(1) $\rho_0 = 2\sqrt{3}$；$\rho\cos\left(\theta - \dfrac{\pi}{3}\right) = 2$；(2) $\rho = 4\cos\theta$ $\left(\dfrac{\pi}{4} \leqslant \theta \leqslant \dfrac{\pi}{2}\right)$。

### 23．
- **推导**：
  $f(x) = |x - a|x + |x - 2|(x - a)$。
  (1) 当 $a = 1$ 时，$f(x) = |x - 1|x + |x - 2|(x - 1)$。
  当 $x \geqslant 1$ 时，$f(x) = (x - 1)(x + |x - 2|)$。因为 $x \geqslant 1$ 时 $x + |x - 2| > 0$ 恒成立，故 $f(x) < 0 \iff x - 1 < 0$，无解；
  当 $x < 1$ 时，$f(x) = (x - 1)(|x - 2| - x) = 2(x - 1)(1 - x) = -2(x - 1)^2 < 0$ 恒成立。
  故不等式的解集为 $\{x \mid x < 1\}$。
  (2) 严格核查原卷字面条件：原卷印为 $x \in (-\infty, 1]$。
  当 $x = 1$ 时，$f(1) = |1 - a| + (1 - a)$。
  若 $a \geqslant 1$，则 $|1 - a| = a - 1 \implies f(1) = (a - 1) + (1 - a) = 0$；
  若 $a < 1$，则 $|1 - a| = 1 - a \implies f(1) = 2(1 - a) > 0$。
  因此对任意实数 $a$ 均有 $f(1) \geqslant 0$，不可能严格小于 0。按原卷字面条件，符合题意的 $a$ 不存在（空集 $\varnothing$）。
  补充勘误说明：若原题排印有误，实际定义区间为开区间 $x \in (-\infty, 1)$（或不等式为 $f(x) \leqslant 0$）：
  当 $x \in (-\infty, 1)$ 时，$x < a$ 且 $x < 2$，此时 $f(x) = 2(a - x)(x - 1)$。
  因 $x - 1 < 0$，需 $a - x > 0$ 恒成立 $\iff a \geqslant 1$。
- **结论**：(1) $\{x \mid x < 1\}$；(2) 按原卷字面条件无解（$\varnothing$）；若勘误为开区间 $x \in (-\infty, 1)$，则 $a$ 的取值范围为 $[1, +\infty)$。
