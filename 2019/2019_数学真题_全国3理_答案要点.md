**17．** **答案：**
(1) $a = 0.35, b = 0.10$;  
(2) 甲离子残留百分比的平均值估计值为 $4.05$, 乙离子残留百分比的平均值估计值为 $6$.

**18．** **答案：**
(1) $B = \dfrac{\pi}{3}$;  
(2) $\triangle ABC$ 面积的取值范围为 $\left(\dfrac{\sqrt{3}}{8}, \dfrac{\sqrt{3}}{2}\right)$.

**19．** **答案：**
(1) 证明见解析;  
(2) 二面角 $B - CG - A$ 的大小为 $30^\circ$ (或 $\dfrac{\pi}{6}$).

**20．** **答案：**
(1) 若 $a \leqslant 0$, $f(x)$ 在 $\mathbb{R}$ 上单调递增;  
若 $a > 0$, $f(x)$ 在 $(-\infty, 0)$ 和 $\left(\dfrac{a}{3}, +\infty\right)$ 单调递增, 在 $\left(0, \dfrac{a}{3}\right)$ 单调递减;  
(2) 存在, $a = 0, b = -1$ 或 $a = 4, b = 1$.

**21．** **答案：**
(1) 证明见解析, 直线 $AB$ 恒过定点 $\left(0, \dfrac{1}{2}\right)$;  
(2) 四边形 $ADBE$ 的面积为 $3$ 或 $4\sqrt{2}$.

**22．** **答案：**
(1) $M_1: \rho = 2\cos\theta\ (0 \leqslant \theta \leqslant \dfrac{\pi}{4})$, $M_2: \rho = 2\sin\theta\ (\dfrac{\pi}{4} \leqslant \theta \leqslant \dfrac{3\pi}{4})$, $M_3: \rho = -2\cos\theta\ (\dfrac{3\pi}{4} \leqslant \theta \leqslant \pi)$;  
(2) $P$ 的极坐标为 $\left(\sqrt{3}, \dfrac{\pi}{6}\right)$, $\left(\sqrt{3}, \dfrac{\pi}{3}\right)$, $\left(\sqrt{3}, \dfrac{2\pi}{3}\right)$, $\left(\sqrt{3}, \dfrac{5\pi}{6}\right)$.

**23．** **答案：**
(1) 最小值为 $\dfrac{4}{3}$;  
(2) 证明见解析.
