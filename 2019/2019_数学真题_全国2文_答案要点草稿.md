### 5．
- **推导**：
  设甲、乙、丙三人的成绩分别为 $x_甲, x_乙, x_丙$，且互不相同。
  只有一人预测正确。
  甲说：“$x_甲 > x_乙$”；
  乙说：“$x_丙 > x_乙$ 且 $x_丙 > x_甲$”；
  丙说：“$x_丙 > x_乙$”。
  若乙预测正确，则必定有 $x_丙 > x_乙$，此时丙也预测正确，出现两人正确，与“只有一个人预测正确”矛盾。故乙必预测错误。
  因此只能是甲正确或丙正确：
  - 若丙正确，则甲错误，有 $x_丙 > x_乙$ 且 $x_甲 < x_乙$，推出 $x_丙 > x_乙 > x_甲$。此时丙比甲和乙都高，乙的预测也成立，矛盾。
  - 若甲正确，则乙、丙均错误。甲正确 $\implies x_甲 > x_乙$；丙错误 $\implies x_丙 < x_乙$。
  综合得 $x_甲 > x_乙 > x_丙$。此时乙说“丙最高”为假，符合题意。
  成绩由高到低次序为甲、乙、丙。
- **结论**：A。

- **推导**：

  $\triangle POF_2$ 为等边三角形，边长为 $|OF_2| = c$。

### 21．
- **推导**：
  $f(x) = (x - 1)\ln x - x - 1$，定义域为 $(0, +\infty)$。
  求导得 $f'(x) = \ln x + \dfrac{x-1}{x} - 1 = \ln x - \dfrac{1}{x}$。
  (1) 令 $g(x) = f'(x) = \ln x - \dfrac{1}{x}$。
  在 $(0, +\infty)$ 上，$\ln x$ 与 $-\dfrac{1}{x}$ 均严格单调递增，故 $g(x)$ 严格单调递增。
  又 $g(1) = -1 < 0$，$g(\mathrm{e}) = 1 - \dfrac{1}{\mathrm{e}} > 0$。
  由零点存在定理，$g(x)$ 在 $(1, \mathrm{e})$ 内存在唯一零点 $x_0$，满足 $\ln x_0 = \dfrac{1}{x_0}$。
  当 $x \in (0, x_0)$ 时，$f'(x) < 0$，$f(x)$ 单调递减；
  当 $x \in (x_0, +\infty)$ 时，$f'(x) > 0$，$f(x)$ 单调递增。
  因此 $x_0$ 是 $f(x)$ 唯一的极值点（极小值点）。
  (2) 对任意 $x > 0$，
  $f(\dfrac{1}{x}) = (\dfrac{1}{x}-1)\ln(\dfrac{1}{x}) - \dfrac{1}{x} - 1 = \dfrac{1-x}{x}(-\ln x) - \dfrac{1}{x} - 1 = \dfrac{(x-1)\ln x - x - 1}{x} = \dfrac{f(x)}{x}$。
  若 $x$ 是 $f(x) = 0$ 的实根，则 $f(\dfrac{1}{x}) = \dfrac{f(x)}{x} = 0$，即 $\dfrac{1}{x}$ 也是方程的实根。
  在极小值点 $x_0$ 处，$f(x_0) = (x_0 - 1)\dfrac{1}{x_0} - x_0 - 1 = -(x_0 + \dfrac{1}{x_0}) < -2 < 0$。
  当 $x > x_0$ 时，$f(x)$ 单调递增，且 $f(\mathrm{e}^2) = (\mathrm{e}^2 - 1) \times 2 - \mathrm{e}^2 - 1 = \mathrm{e}^2 - 3 > 0$。
  由零点存在定理，$f(x)$ 在 $(x_0, +\infty)$ 上有且仅有一个实根 $x_1$（满足 $x_1 > x_0 > 1$）。
  令 $x_2 = \dfrac{1}{x_1}$，则 $0 < x_2 < 1 < x_0$，且 $f(x_2) = 0$。
  由 $f(x)$ 在 $(0, x_0)$ 上单调递减，故 $x_2$ 是 $(0, x_0)$ 上唯一的实根。
  综上，$f(x) = 0$ 有且仅有两个实根，且两个实根互为倒数。
- **结论**：见证明。

  (2) 设点 $P$ 极坐标为 $(\rho, \theta)$。
  因为点 $P$ 在线段 $OM$ 上，所以点 $P$ 的极角 $\theta = \theta_0$，且 $0 \leqslant \rho \leqslant \rho_0$。
  在直角 $\triangle OAP$ 中，$\angle APO = 90^\circ, OA = 4$，故 $\rho = 4\cos\theta$。
  因为 $\rho > 0$，所以 $\cos\theta > 0$。
  又 $M(\rho_0, \theta)$ 在 $C: \rho = 4\sin\theta$ 上，且 $\rho_0 > 0$，故 $\sin\theta > 0$。因此 $\theta \in (0, \dfrac{\pi}{2})$。
  由 $P$ 在线段 $OM$ 上，必有 $\rho \leqslant \rho_0 \implies 4\cos\theta \leqslant 4\sin\theta \implies \tan\theta \geqslant 1$。
  结合 $\theta \in (0, \dfrac{\pi}{2})$，得 $\dfrac{\pi}{4} \leqslant \theta < \dfrac{\pi}{2}$。
  当 $\theta = \dfrac{\pi}{2}$ 时，$\rho = 0$，$P$ 与原点重合，符合极限位置。
  因此点 $P$ 轨迹的极坐标方程为 $\rho = 4\cos\theta$（$\dfrac{\pi}{4} \leqslant \theta \leqslant \dfrac{\pi}{2}$）。
- **结论**：(1) $\rho_0 = 2\sqrt{3}$，$l$ 极坐标方程为 $\rho\cos(\theta - \dfrac{\pi}{3}) = 2$；(2) $\rho = 4\cos\theta$（$\dfrac{\pi}{4} \leqslant \theta \leqslant \dfrac{\pi}{2}$）。

### 23．
- **推导**：
  (1) 当 $a = 1$ 时，$f(x) = |x - 1|x + |x - 2|(x - 1)$。
  分区间讨论：
  - 当 $x < 1$ 时，$f(x) = -(x-1)x + (2-x)(x-1) = (x-1)(-2x+2) = -2(x-1)^2$。因为 $x < 1$ 时 $(x-1)^2 > 0$，故 $f(x) < 0$ 恒成立；
  - 当 $x = 1$ 时，$f(1) = 0$，$0 < 0$ 不成立；
  - 当 $1 < x < 2$ 时，$f(x) = (x-1)x + (2-x)(x-1) = 2(x-1) > 0$，不满足；
  - 当 $x \geqslant 2$ 时，$f(x) = (x-1)x + (x-2)(x-1) = 2(x-1)^2 > 0$，不满足。
  综上，不等式 $f(x) < 0$ 的解集为 $\{x \mid x < 1\}$。
  (2) 关键设问核验：
  原卷字面条件为“$x \in (-\infty, 1]$ 时，$f(x) < 0$”。
  在端点 $x = 1$ 处：$f(1) = |1 - a| \times 1 + |1 - 2|(1 - a) = |1 - a| + (1 - a)$。
  对任意实数 $a$，恒有 $|1 - a| \geqslant -(1 - a)$，因此 $f(1) \geqslant 0$ 恒成立，不可能严格小于 0。
  故在原卷字面条件下，无实数 $a$ 满足条件，解集为 $\varnothing$。
  若按命题逻辑将闭区间修正为开区间 $x \in (-\infty, 1)$：
  当 $x < 1$ 时，$x < 2 \implies |x - 2| = 2 - x$。
  - 若 $a \geqslant 1$，则对任意 $x < 1$ 均有 $x < a$，故 $|x - a| = a - x$。
    $f(x) = (a - x)x + (2 - x)(x - a) = (a - x)[x - (2 - x)] = 2(a - x)(x - 1)$。
    因为 $a \geqslant 1 > x$，所以 $a - x > 0$；又 $x - 1 < 0$，故 $f(x) < 0$ 恒成立；
  - 若 $a < 1$，当 $x \in (a, 1)$ 时，$x > a$，此时 $|x - a| = x - a$。
    $f(x) = (x - a)x + (2 - x)(x - a) = 2(x - a) > 0$，不满足条件。
  因此修正后解为 $a \geqslant 1$。
- **结论**：(1) $\{x \mid x < 1\}$；(2) 原卷字面闭区间下无解（$\varnothing$）；若修正为开区间 $x \in (-\infty, 1)$，则 $a$ 的取值范围为 $[1, +\infty)$。
