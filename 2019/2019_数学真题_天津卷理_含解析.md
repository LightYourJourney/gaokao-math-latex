## 一、选择题

### 第 1 题

**题目**：

设集合 $A = \{-1, 1, 2, 3, 5\}$, $B = \{2, 3, 4\}$, $C = \{x \in \mathbb{R} \mid 1 \leqslant x < 3\}$, 则 $(A \cap C) \cup B =$（ ）。

(A) $\{2\}$　(B) $\{2, 3\}$　(C) $\{-1, 2, 3\}$　(D) $\{1, 2, 3, 4\}$

**解析**

由集合交集与并集的定义：
已知 $A = \{-1, 1, 2, 3, 5\}$, $C = \{x \in \mathbb{R} \mid 1 \leqslant x < 3\}$,
则 $A \cap C = \{1, 2\}$.
进而由集合 $B = \{2, 3, 4\}$, 计算并集得：
$$(A \cap C) \cup B = \{1, 2\} \cup \{2, 3, 4\} = \{1, 2, 3, 4\}.$$
故选 **D**。

**答案：D**

### 第 2 题

**题目**：

设变量 $x, y$ 满足约束条件
$$
\begin{cases}
x + y - 2 \leqslant 0, \\
x - y + 2 \geqslant 0, \\
x \geqslant -1, \\
y \geqslant -1,
\end{cases}
$$
则目标函数 $z = -4x + y$ 的最大值为（ ）。

(A) $2$　(B) $3$　(C) $5$　(D) $6$

**解析**

绘制不等式组表示的平面可行域：
不等式组为
$$
\begin{cases}
x + y - 2 \leqslant 0, \\
x - y + 2 \geqslant 0, \\
x \geqslant -1, \\
y \geqslant -1.
\end{cases}
$$
其边界直线交点构成四边形凸多边形区域，各顶点坐标分别为：
- 直线 $x = -1$ 与 $y = -1$ 的交点为 $(-1, -1)$；
- 直线 $x = -1$ 与 $x - y + 2 = 0$ 的交点为 $(-1, 1)$；
- 直线 $x + y - 2 = 0$ 与 $x - y + 2 = 0$ 的交点为 $(0, 2)$；
- 直线 $x + y - 2 = 0$ 与 $y = -1$ 的交点为 $(3, -1)$。
将各顶点代入目标函数 $z = -4x + y$：
- 代入 $(-1, -1)$ 得 $z = -4(-1) + (-1) = 3$；
- 代入 $(-1, 1)$ 得 $z = -4(-1) + 1 = 5$；
- 代入 $(0, 2)$ 得 $z = -4(0) + 2 = 2$；
- 代入 $(3, -1)$ 得 $z = -4(3) + (-1) = -13$。
比较可知，$z$ 的最大值为 $5$，在点 $(-1, 1)$ 处取得。
故选 **C**。

**答案：C**

### 第 3 题

**题目**：

设 $x \in \mathbb{R}$, 则“$x^2 - 5x < 0$”是“$|x - 1| < 1$”的（ ）。

(A) 充分而不必要条件　(B) 必要而不充分条件  
(C) 充要条件　(D) 既不充分也不必要条件

**解析**

解一元二次不等式：
$$x^2 - 5x < 0 \iff x(x - 5) < 0 \iff 0 < x < 5.$$
解绝对值不等式：
$$|x - 1| < 1 \iff -1 < x - 1 < 1 \iff 0 < x < 2.$$
因为 $(0, 2) \subsetneq (0, 5)$，所以由 $|x - 1| < 1$ 可以推出 $x^2 - 5x < 0$；
但反之由 $x^2 - 5x < 0$ 推不出 $|x - 1| < 1$（例如取 $x = 3$ 时满足 $x^2 - 5x < 0$，但 $|3 - 1| = 2 \not< 1$）。
因此，“$x^2 - 5x < 0$”是“$|x - 1| < 1$”的必要而不充分条件。
故选 **B**。

**答案：B**

### 第 4 题

**题目**：

阅读如图的程序框图, 运行相应的程序, 输出 $S$ 的值为（ ）。

[TikZ 图稿：第 4 题](../math-gaokao-latex/2019_天津卷_理科/figures/q4.tikz.tex)

(A) $5$　(B) $8$　(C) $24$　(D) $29$

按照程序框图逐步追踪变量的变化过程：
- 初始时，$i = 1, S = 0$；
- 判断 $i$ 为偶数：$1$ 为奇数，走“否”分支，计算
  $$S = S + i = 0 + 1 = 1,$$

- 判断 $i$ 为偶数：$2$ 为偶数，走“是”分支，计算

### 第 5 题

**题目**：

已知抛物线 $y^2 = 4x$ 的焦点为 $F$, 准线为 $l$. 若 $l$ 与双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ ($a > 0, b > 0$) 的两条渐近线分别交于点 $A$ 和点 $B$, 且 $|AB| = 4|OF|$ ($O$ 为原点), 则双曲线的离心率为（ ）。

(A) $\sqrt{2}$　(B) $\sqrt{3}$　(C) $2$　(D) $\sqrt{5}$

**解析**

抛物线 $y^2 = 4x$ 的焦准距参数 $p = 2$，焦点为 $F(1, 0)$，原点到焦点的距离 $|OF| = 1$，准线 $l$ 的方程为 $x = -1$。
双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ 的两条渐近线方程为 $y = \pm \dfrac{b}{a} x$。
准线 $l: x = -1$ 与两条渐近线分别交于点 $A\left(-1, \dfrac{b}{a}\right)$ 和 $B\left(-1, -\dfrac{b}{a}\right)$。
线段 $AB$ 的长度为：
$$|AB| = \left|\frac{b}{a} - \left(-\frac{b}{a}\right)\right| = \frac{2b}{a}.$$
已知 $|AB| = 4|OF| = 4$，代入得：
$$\frac{2b}{a} = 4 \implies \frac{b}{a} = 2.$$
由双曲线离心率公式：
$$e = \sqrt{1 + \left(\frac{b}{a}\right)^2} = \sqrt{1 + 2^2} = \sqrt{5}.$$
故选 **D**。

**答案：D**

### 第 6 题

**题目**：

已知 $a = \log_5 2$, $b = \log_{0.5} 0.2$, $c = 0.5^{0.2}$, 则 $a, b, c$ 的大小关系为（ ）。

(A) $a < c < b$　(B) $a < b < c$　(C) $b < c < a$　(D) $c < a < b$

**解析**

分别估算 $a, b, c$ 的数值范围：
- 对于 $a = \log_5 2$：因为 $1 < 2 < \sqrt{5}$，且以 $5$ 为底的对数函数在 $(0, +\infty)$ 上单调递增，所以
  $$0 = \log_5 1 < a < \log_5 \sqrt{5} = \frac{1}{2};$$
- 对于 $b = \log_{0.5} 0.2$：利用换底公式，
  $$b = \frac{\lg 0.2}{\lg 0.5} = \frac{\lg\frac{1}{5}}{\lg\frac{1}{2}} = \frac{-\lg 5}{-\lg 2} = \log_2 5.$$
  因为 $4 < 5 < 8$，所以 $2 = \log_2 4 < b < \log_2 8 = 3$；
- 对于 $c = 0.5^{0.2}$：底数 $0.5 \in (0, 1)$，指数函数 $y = 0.5^x$ 在 $\mathbb{R}$ 上单调递减。
  因为 $0 < 0.2 < 1$，所以
  $$\frac{1}{2} = 0.5^1 < c < 0.5^0 = 1.$$
综合上述结果，$a \in \left(0, \dfrac{1}{2}\right)$，$c \in \left(\dfrac{1}{2}, 1\right)$，$b \in (2, 3)$，因此 $a < c < b$。
故选 **A**。

**答案：A**

### 第 7 题

**题目**：

已知函数 $f(x) = A \sin(\omega x + \varphi)$ ($A > 0, \omega > 0, |\varphi| < \pi$) 是奇函数, 将 $y = f(x)$ 的图象上所有点的横坐标伸长到原来的 $2$ 倍 (纵坐标不变), 所得图象对应的函数为 $g(x)$. 若 $g(x)$ 的最小正周期为 $2\pi$, 且 $g\left(\dfrac{\pi}{4}\right) = \sqrt{2}$, 则 $f\left(\dfrac{3\pi}{8}\right) =$（ ）。

(A) $-2$　(B) $-\sqrt{2}$　(C) $\sqrt{2}$　(D) $2$

**解析**

已知函数 $f(x) = A \sin(\omega x + \varphi)$ ($A > 0, \omega > 0, |\varphi| < \pi$) 是奇函数，
则 $f(0) = A \sin \varphi = 0$。
因为 $|\varphi| < \pi$，所以 $\varphi = 0$，即 $f(x) = A \sin(\omega x)$。
将 $y = f(x)$ 的图象上所有点的横坐标伸长到原来的 $2$ 倍（纵坐标不变），得到的函数为
$$g(x) = f\left(\frac{x}{2}\right) = A \sin\left(\frac{\omega}{2} x\right).$$
由题意，$g(x)$ 的最小正周期为 $2\pi$，即
$$\frac{2\pi}{\omega / 2} = 2\pi \implies \frac{\omega}{2} = 1 \implies \omega = 2.$$
所以 $g(x) = A \sin x$。
又已知 $g\left(\dfrac{\pi}{4}\right) = \sqrt{2}$，即
$$A \sin\frac{\pi}{4} = A \cdot \frac{\sqrt{2}}{2} = \sqrt{2} \implies A = 2.$$
从而原函数为 $f(x) = 2 \sin(2x)$。
计算 $f\left(\dfrac{3\pi}{8}\right)$ 的值：
$$f\left(\frac{3\pi}{8}\right) = 2 \sin\left(2 \cdot \frac{3\pi}{8}\right) = 2 \sin\frac{3\pi}{4} = 2 \cdot \frac{\sqrt{2}}{2} = \sqrt{2}.$$
故选 **C**。

**答案：C**

### 第 8 题

**题目**：

已知 $a \in \mathbb{R}$, 设函数 $f(x) = \begin{cases} x^2 - 2ax + 2a, & x \leqslant 1, \\ x - a \ln x, & x > 1, \end{cases}$ 若关于 $x$ 的不等式 $f(x) \geqslant 0$ 在 $\mathbb{R}$ 上恒成立, 则 $a$ 的取值范围为（ ）。

(A) $[0, 1]$　(B) $[0, 2]$　(C) $[0, \mathrm{e}]$　(D) $[1, \mathrm{e}]$

**解析**

分段讨论不等式 $f(x) \geqslant 0$ 在 $\mathbb{R}$ 上恒成立的条件：
(1) 当 $x \leqslant 1$ 时，$f(x) = x^2 - 2ax + 2a$。
二次函数对称轴为 $x = a$：
- 若对称轴 $a \leqslant 1$，则函数在 $(-\infty, 1]$ 上的最小值为顶点处的函数值。
  要求顶点纵坐标大于等于零，即判别式 $\Delta \leqslant 0$：
  $$\Delta = (-2a)^2 - 4 \cdot 1 \cdot 2a = 4a^2 - 8a \leqslant 0 \implies 0 \leqslant a \leqslant 2.$$
  结合 $a \leqslant 1$，得 $0 \leqslant a \leqslant 1$；
- 若对称轴 $a > 1$，则函数在 $(-\infty, 1]$ 上单调递减，其最小值为端点值
  $$f(1) = 1^2 - 2a \cdot 1 + 2a = 1 > 0.$$
  恒成立。因此所有 $a > 1$ 均满足 $x \leqslant 1$ 时 $f(x) \geqslant 0$。
综合以上两类情况，在 $x \leqslant 1$ 时 $f(x) \geqslant 0$ 恒成立的充要条件为 $a \geqslant 0$。

(2) 当 $x > 1$ 时，$f(x) = x - a \ln x \geqslant 0$ 恒成立。
因为 $x > 1$，所以 $\ln x > 0$，不等式等价于
$$a \leqslant \frac{x}{\ln x}.$$
令函数 $h(x) = \dfrac{x}{\ln x}$ ($x > 1$)，对其求导得：
$$h'(x) = \frac{1 \cdot \ln x - x \cdot \frac{1}{x}}{(\ln x)^2} = \frac{\ln x - 1}{(\ln x)^2}.$$
- 当 $1 < x < \mathrm{e}$ 时，$\ln x < 1$，$h'(x) < 0$，$h(x)$ 单调递减；
- 当 $x > \mathrm{e}$ 时，$\ln x > 1$，$h'(x) > 0$，$h(x)$ 单调递增。
因此 $h(x)$ 在 $x = \mathrm{e}$ 处取得极小值，也是最小值：
$$h_{\min} = h(\mathrm{e}) = \frac{\mathrm{e}}{\ln \mathrm{e}} = \mathrm{e}.$$
因此，$a \leqslant \dfrac{x}{\ln x}$ 恒成立的充要条件为 $a \leqslant \mathrm{e}$。

综合 (1) 与 (2)，取交集得 $a$ 的取值范围为 $[0, \mathrm{e}]$。
故选 **C**。

**答案：C**

## 二、填空题

### 第 9 题

**题目**：

$\mathrm{i}$ 是虚数单位, 则 $\dfrac{5 - \mathrm{i}}{1 + \mathrm{i}}$ 的值为 $\underline{\phantom{XXXX}}$.

**解析**

利用复数的除法法则，将分母实数化：
$$\frac{5 - \mathrm{i}}{1 + \mathrm{i}} = \frac{(5 - \mathrm{i})(1 - \mathrm{i})}{(1 + \mathrm{i})(1 - \mathrm{i})} = \frac{5 - 5\mathrm{i} - \mathrm{i} + \mathrm{i}^2}{1 - \mathrm{i}^2} = \frac{5 - 6\mathrm{i} - 1}{1 - (-1)} = \frac{4 - 6\mathrm{i}}{2} = 2 - 3\mathrm{i}.$$

**答案：$2 - 3\mathrm{i}$**

### 第 10 题

**题目**：

$\left(2x - \dfrac{1}{8x^3}\right)^8$ 的展开式中的常数项为 $\underline{\phantom{XXXX}}$.

**解析**

根据二项式定理，展开式的通项公式为：
$$T_{r+1} = \binom{8}{r} (2x)^{8-r} \left(-\frac{1}{8x^3}\right)^r = \binom{8}{r} 2^{8-r} (-1)^r \left(\frac{1}{2^3}\right)^r x^{8-r-3r} = \binom{8}{r} 2^{8-4r} (-1)^r x^{8-4r}.$$
令 $x$ 的指数为零，即 $8 - 4r = 0$，解得 $r = 2$。
将 $r = 2$ 代入通项公式，得到展开式中的常数项：
$$T_3 = \binom{8}{2} 2^{8 - 4 \times 2} (-1)^2 = \frac{8 \times 7}{2 \times 1} \times 2^0 \times 1 = 28.$$

**答案：$28$**

### 第 11 题

**题目**：

已知四棱锥的底面是边长为 $\sqrt{2}$ 的正方形, 侧棱长均为 $\sqrt{5}$. 若圆柱的一个底面的圆周经过四棱锥四条侧棱的中点, 另一个底面的圆心为四棱锥底面的中心, 则该圆柱的体积为 $\underline{\phantom{XXXX}}$.

**解析**

设四棱锥为 $P-ABCD$，底面正方形 $ABCD$ 的边长为 $\sqrt{2}$，侧棱长为 $\sqrt{5}$。
底面中心记为 $O$，连接 $AC$ 与 $BD$ 交于 $O$。
由正方形性质，对角线长 $AC = \sqrt{(\sqrt{2})^2 + (\sqrt{2})^2} = 2$，
因此底面中心到各顶点的距离为 $OA = \frac{1}{2} AC = 1$。
四棱锥为正四棱锥，高线 $PO \perp \text{平面 } ABCD$。
在直角三角形 $\triangle POA$ 中，由勾股定理得高线长：
$$PO = \sqrt{PA^2 - OA^2} = \sqrt{(\sqrt{5})^2 - 1^2} = \sqrt{4} = 2.$$
由题意，圆柱的一个底面的圆心为底面中心 $O$，另一个底面的圆周经过四棱锥四条侧棱的中点。
设四条侧棱的中点构成的截面与高线 $PO$ 交于 $O'$，则 $O'$ 为 $PO$ 的中点，且 $PO' \perp \text{平面 } ABCD$。
各侧棱中点到高线 $PO$ 的距离均为底面对角线半长的一半，即
$$r = \frac{1}{2} OA = \frac{1}{2} \times 1 = \frac{1}{2}.$$
因此圆柱的底面半径为 $r = \dfrac{1}{2}$。
圆柱的高等于线段 $OO'$ 的长度，即
$$h = OO' = \frac{1}{2} PO = \frac{1}{2} \times 2 = 1.$$
根据圆柱的体积公式：
$$V = \pi r^2 h = \pi \left(\frac{1}{2}\right)^2 \times 1 = \frac{\pi}{4}.$$

**答案：$\dfrac{\pi}{4}$**

### 第 12 题

**题目**：

设 $a \in \mathbb{R}$, 直线 $ax - y + 2 = 0$ 和圆 $\begin{cases} x = 2 + 2\cos\theta, \\ y = 1 + 2\sin\theta \end{cases}$ ($\theta$ 为参数) 相切, 则 $a$ 的值为 $\underline{\phantom{XXXX}}$.

**解析**

圆的参数方程为 $\begin{cases} x = 2 + 2\cos\theta, \\ y = 1 + 2\sin\theta \end{cases}$，
消去参数 $\theta$，得圆的标准方程为
$$(x - 2)^2 + (y - 1)^2 = 4.$$
因此圆心坐标为 $C(2, 1)$，半径 $r = 2$。
已知直线方程为 $ax - y + 2 = 0$。
直线与圆相切的充要条件是圆心到直线的距离等于半径，即
$$d = \frac{|2a - 1 + 2|}{\sqrt{a^2 + (-1)^2}} = \frac{|2a + 1|}{\sqrt{a^2 + 1}} = 2.$$
两边平方得：
$$(2a + 1)^2 = 4(a^2 + 1) \iff 4a^2 + 4a + 1 = 4a^2 + 4 \iff 4a = 3 \iff a = \frac{3}{4}.$$

**答案：$\dfrac{3}{4}$**

### 第 13 题

**题目**：

设 $x > 0, y > 0, x + 2y = 5$, 则 $\dfrac{(x + 1)(2y + 1)}{\sqrt{xy}}$ 的最小值为 $\underline{\phantom{XXXX}}$.

**解析**

展开分式的分子部分：
$$(x + 1)(2y + 1) = 2xy + x + 2y + 1.$$
已知 $x + 2y = 5$，代入分子可得：
$$(x + 1)(2y + 1) = 2xy + 5 + 1 = 2xy + 6.$$
因此待求最值的表达式可以写为：
$$\frac{(x + 1)(2y + 1)}{\sqrt{xy}} = \frac{2xy + 6}{\sqrt{xy}} = 2\sqrt{xy} + \frac{6}{\sqrt{xy}}.$$
因为 $x > 0, y > 0$，根据基本不等式：
$$5 = x + 2y \geqslant 2\sqrt{x \cdot 2y} = 2\sqrt{2xy},$$
两边除以 $2\sqrt{2}$ 并平方得：
$$\sqrt{2xy} \leqslant \frac{5}{2} \implies 2xy \leqslant \frac{25}{4} \implies xy \leqslant \frac{25}{8}.$$
设 $t = \sqrt{xy}$，则 $0 < t \leqslant \dfrac{5\sqrt{2}}{4}$。
构造对勾函数 $g(t) = 2t + \dfrac{6}{t}$ ($t > 0$)。
由均值不等式，$g(t) \geqslant 2\sqrt{2t \cdot \frac{6}{t}} = 2\sqrt{12} = 4\sqrt{3}$，
等号成立当且仅当 $2t = \dfrac{6}{t} \iff t^2 = 3 \iff t = \sqrt{3}$。
检验极值点是否在定义域内：
$$\sqrt{3} = \sqrt{\frac{24}{8}} < \sqrt{\frac{25}{8}} = \frac{5\sqrt{2}}{4},$$
因此 $t = \sqrt{3}$ 在取值范围之内。
此时由 $xy = 3$ 与 $x + 2y = 5$ 联立，解得 $x = 2, y = \dfrac{3}{2}$ 或 $x = 3, y = 1$，均存在正实数解。
因此，该表达式的最小值为 $4\sqrt{3}$。

**答案：$4\sqrt{3}$**

### 第 14 题

**题目**：

在四边形 $ABCD$ 中, $AD \parallel BC$, $AB = 2\sqrt{3}$, $AD = 5$, $\angle A = 30^\circ$, 点 $E$ 在线段 $CB$ 的延长线上, 且 $AE = BE$, 则 $\vec{BD} \cdot \vec{AE} =$ $\underline{\phantom{XXXX}}$.

**解析**

以点 $A$ 为原点，以射线 $AD$ 的方向为 $x$ 轴正方向，建立平面直角坐标系。
已知 $AD = 5$，则点 $D$ 的坐标为 $(5, 0)$。
已知 $AB = 2\sqrt{3}$ 且 $\angle DAB = 30^\circ$，
则点 $B$ 的坐标为：
$$B\left(2\sqrt{3}\cos 30^\circ, 2\sqrt{3}\sin 30^\circ\right) = \left(2\sqrt{3} \cdot \frac{\sqrt{3}}{2}, 2\sqrt{3} \cdot \frac{1}{2}\right) = (3, \sqrt{3}).$$
因为 $AD \parallel BC$，所以直线 $BC$ 平行于 $x$ 轴，其方程为 $y = \sqrt{3}$。
点 $E$ 在线段 $CB$ 的延长线上，因此点 $E$ 的纵坐标也为 $\sqrt{3}$，可设 $E(x_E, \sqrt{3})$。
已知 $AE = BE$，两边平方得：
$$x_E^2 + (\sqrt{3})^2 = (x_E - 3)^2 + (\sqrt{3} - \sqrt{3})^2 \iff x_E^2 + 3 = x_E^2 - 6x_E + 9.$$
化简得 $6x_E = 6 \implies x_E = 1$。
因此点 $E$ 的坐标为 $(1, \sqrt{3})$。
计算向量 $\vec{BD}$ 与 $\vec{AE}$ 的坐标：
$$\vec{BD} = D - B = (5 - 3, 0 - \sqrt{3}) = (2, -\sqrt{3}),$$
$$\vec{AE} = E - A = (1 - 0, \sqrt{3} - 0) = (1, \sqrt{3}).$$
计算两向量的数量积：
$$\vec{BD} \cdot \vec{AE} = 2 \times 1 + (-\sqrt{3}) \times \sqrt{3} = 2 - 3 = -1.$$

**答案：$-1$**

## 三、解答题

### 第 15 题

**题目**（本小题满分 13 分）：

在 $\triangle ABC$ 中, 内角 $A, B, C$ 所对的边分别为 $a, b, c$. 已知 $b + c = 2a$, $3c \sin B = 4a \sin C$.
(1) 求 $\cos B$ 的值;
(2) 求 $\sin\left(2B + \dfrac{\pi}{6}\right)$ 的值.

**解析**

**(1) 解**

在 $\triangle ABC$ 中，根据正弦定理：
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R,$$
则 $b = 2R\sin B$，$c = 2R\sin C$。
代入已知条件 $3c \sin B = 4a \sin C$：
$$3(2R\sin C)\sin B = 4a\sin C \implies 3(2R\sin B)\sin C = 4a\sin C.$$
因为 $\sin C \neq 0$，两边同除以 $\sin C$ 得：
$$3b = 4a \implies b = \frac{4}{3} a.$$
将 $b = \dfrac{4}{3} a$ 代入已知条件 $b + c = 2a$：
$$\frac{4}{3} a + c = 2a \implies c = \frac{2}{3} a.$$
根据余弦定理：
$$\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{a^2 + \left(\frac{2}{3}a\right)^2 - \left(\frac{4}{3}a\right)^2}{2a \cdot \frac{2}{3}a} = \frac{a^2 + \frac{4}{9}a^2 - \frac{16}{9}a^2}{\frac{4}{3}a^2} = \frac{-\frac{3}{9}}{\frac{4}{3}} = -\frac{1}{4}.$$

**(2) 解**

因为 $B \in (0, \pi)$ 且 $\cos B = -\dfrac{1}{4} < 0$，所以 $B$ 为钝角。
根据同角三角函数的基本关系：
$$\sin B = \sqrt{1 - \cos^2 B} = \sqrt{1 - \left(-\frac{1}{4}\right)^2} = \frac{\sqrt{15}}{4}.$$
由二倍角公式计算 $\sin 2B$ 和 $\cos 2B$：
$$\sin 2B = 2\sin B \cos B = 2 \times \frac{\sqrt{15}}{4} \times \left(-\frac{1}{4}\right) = -\frac{\sqrt{15}}{8},$$
$$\cos 2B = 2\cos^2 B - 1 = 2 \times \left(-\frac{1}{4}\right)^2 - 1 = \frac{2}{16} - 1 = -\frac{7}{8}.$$
应用两角和的正弦公式：
$$\sin\left(2B + \frac{\pi}{6}\right) = \sin 2B \cos\frac{\pi}{6} + \cos 2B \sin\frac{\pi}{6} = \left(-\frac{\sqrt{15}}{8}\right) \times \frac{\sqrt{3}}{2} + \left(-\frac{7}{8}\right) \times \frac{1}{2} = -\frac{3\sqrt{5} + 7}{16}.$$

**答案（1）：$-\dfrac{1}{4}$**

**答案（2）：$-\dfrac{3\sqrt{5} + 7}{16}$**

### 第 16 题

**题目**（本小题满分 13 分）：

设甲、乙两位同学上学期间, 每天 7:30 之前到校的概率均为 $\dfrac{2}{3}$. 假定甲、乙两位同学到校情况互不影响, 且任一同学每天到校情况相互独立.
(1) 用 $X$ 表示甲同学上学期间的三天中 7:30 之前到校的天数, 求随机变量 $X$ 的分布列和数学期望;
(2) 设 $M$ 为事件“上学期间的三天中, 甲同学在 7:30 之前到校的天数比乙同学在 7:30 之前到校的天数恰好多 2”, 求事件 $M$ 发生的概率.

**解析**

**(1) 解**

由题意，甲同学在三天中每天 7:30 之前到校相互独立，每次概率均为 $p = \dfrac{2}{3}$。
因此随机变量 $X$ 服从二项分布，即 $X \sim B\left(3, \dfrac{2}{3}\right)$。
$X$ 的所有可能取值为 $0, 1, 2, 3$。
计算各取值的概率：
$$P(X = 0) = \binom{3}{0} \left(1 - \frac{2}{3}\right)^3 = \left(\frac{1}{3}\right)^3 = \frac{1}{27},$$
$$P(X = 1) = \binom{3}{1} \left(\frac{2}{3}\right)^1 \left(\frac{1}{3}\right)^2 = 3 \times \frac{2}{27} = \frac{6}{27} = \frac{2}{9},$$
$$P(X = 2) = \binom{3}{2} \left(\frac{2}{3}\right)^2 \left(\frac{1}{3}\right)^1 = 3 \times \frac{4}{27} = \frac{12}{27} = \frac{4}{9},$$
$$P(X = 3) = \binom{3}{3} \left(\frac{2}{3}\right)^3 = \frac{8}{27}.$$
所以随机变量 $X$ 的分布列为：

| $X$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| $P$ | $\dfrac{1}{27}$ | $\dfrac{2}{9}$ | $\dfrac{4}{9}$ | $\dfrac{8}{27}$ |

由于 $X \sim B\left(3, \dfrac{2}{3}\right)$，数学期望为：
$$E(X) = 3 \times \frac{2}{3} = 2.$$

**(2) 解**

设 $Y$ 为乙同学在上学期间的三天中 7:30 之前到校的天数。
同样有 $Y \sim B\left(3, \dfrac{2}{3}\right)$，且 $X$ 与 $Y$ 相互独立。
事件 $M$ 发生当且仅当 $X - Y = 2$。
因为 $X, Y \in \{0, 1, 2, 3\}$，方程 $X - Y = 2$ 的非负整数解只有以下两种互斥情况：
- 情况 1：$X = 2$ 且 $Y = 0$；
- 情况 2：$X = 3$ 且 $Y = 1$。
分别计算各情况的发生概率：
$$P(X = 2, Y = 0) = P(X = 2) \cdot P(Y = 0) = \frac{12}{27} \times \frac{1}{27} = \frac{12}{729},$$
$$P(X = 3, Y = 1) = P(X = 3) \cdot P(Y = 1) = \frac{8}{27} \times \frac{6}{27} = \frac{48}{729}.$$
因此事件 $M$ 发生的概率为：
$$P(M) = P(X = 2, Y = 0) + P(X = 3, Y = 1) = \frac{12}{729} + \frac{48}{729} = \frac{60}{729} = \frac{20}{243}.$$

**答案（1）：分布列见解析版，$E(X) = 2$**

**答案（2）：$\dfrac{20}{243}$**

### 第 17 题

**题目**（本小题满分 13 分）：

如图, $AE \perp \text{平面 } ABCD$, $CF \parallel AE$, $AD \parallel BC$, $AD \perp AB$, $AB = AD = 1$, $AE = BC = 2$.

[TikZ 图稿：第 17 题](../math-gaokao-latex/2019_天津卷_理科/figures/q17.tikz.tex)

(1) 求证: $BF \parallel \text{平面 } ADE$;
(2) 求直线 $CE$ 与平面 $BDE$ 所成角的正弦值;
(3) 若二面角 $E - BD - F$ 的余弦值为 $\dfrac{1}{3}$, 求线段 $CF$ 的长.

**解析**

**(1) 证明**

依题意，$AE \perp \text{平面 } ABCD$，$AD \perp AB$。
以 $A$ 为坐标原点，分别以射线 $AB, AD, AE$ 的方向为 $x, y, z$ 轴的正方向建立空间直角坐标系。
根据题设各线段长度：$AB = AD = 1$，$AE = BC = 2$。
各点坐标分别为：
$$A(0, 0, 0),\quad B(1, 0, 0),\quad D(0, 1, 0),\quad E(0, 0, 2).$$
因为 $AD \parallel BC$ 且 $AD \perp AB$，所以 $BC \perp AB$。
又 $BC = 2$，故点 $C$ 的坐标为 $(1, 2, 0)$。
因为 $CF \parallel AE \parallel z$ 轴，可设 $F(1, 2, h)$，其中 $h = CF > 0$。
计算向量 $\vec{BF}$：
$$\vec{BF} = F - B = (1 - 1, 2 - 0, h - 0) = (0, 2, h).$$
平面 $ADE$ 经过点 $A(0, 0, 0), D(0, 1, 0), E(0, 0, 2)$，即为 $yOz$ 坐标平面。
其法向量可取为 $\vec{n}_1 = (1, 0, 0)$。
计算 $\vec{BF}$ 与法向量 $\vec{n}_1$ 的数量积：
$$\vec{BF} \cdot \vec{n}_1 = 0 \times 1 + 2 \times 0 + h \times 0 = 0.$$
因为 $BF \not\subset \text{平面 } ADE$（点 $B(1, 0, 0) \notin \text{平面 } ADE$），
所以 $BF \parallel \text{平面 } ADE$。

**(2) 解**

求平面 $BDE$ 的法向量：
由点坐标得 $\vec{BD} = (-1, 1, 0)$，$\vec{BE} = (-1, 0, 2)$。
设平面 $BDE$ 的法向量为 $\vec{n} = (x, y, z)$，则
$$
\begin{cases}
\vec{n} \cdot \vec{BD} = -x + y = 0, \\
\vec{n} \cdot \vec{BE} = -x + 2z = 0.
\end{cases}
$$
解得 $y = x$，$z = \dfrac{x}{2}$。取 $x = 2$，得法向量 $\vec{n} = (2, 2, 1)$。
其模长为 $|\vec{n}| = \sqrt{2^2 + 2^2 + 1^2} = 3$。
计算向量 $\vec{CE}$：
$$\vec{CE} = E - C = (0 - 1, 0 - 2, 2 - 0) = (-1, -2, 2),$$
其模长为 $|\vec{CE}| = \sqrt{(-1)^2 + (-2)^2 + 2^2} = 3$。
设直线 $CE$ 与平面 $BDE$ 所成角为 $\theta$，则
$$\sin\theta = |\cos\langle \vec{CE}, \vec{n} \rangle| = \frac{|\vec{CE} \cdot \vec{n}|}{|\vec{CE}| |\vec{n}|} = \frac{|(-1) \times 2 + (-2) \times 2 + 2 \times 1|}{3 \times 3} = \frac{|-2 - 4 + 2|}{9} = \frac{4}{9}.$$

**(3) 解**

求平面 $BDF$ 的法向量：
已知 $\vec{BD} = (-1, 1, 0)$，$\vec{BF} = (0, 2, h)$。
设平面 $BDF$ 的法向量为 $\vec{m} = (x_1, y_1, z_1)$，则
$$
\begin{cases}
\vec{m} \cdot \vec{BD} = -x_1 + y_1 = 0 \implies y_1 = x_1, \\
\vec{m} \cdot \vec{BF} = 2y_1 + hz_1 = 0 \implies 2x_1 + hz_1 = 0 \implies z_1 = -\dfrac{2x_1}{h}.
\end{cases}
$$
取 $x_1 = h$，得法向量 $\vec{m} = (h, h, -2)$。
其模长为 $|\vec{m}| = \sqrt{h^2 + h^2 + (-2)^2} = \sqrt{2h^2 + 4}$。
由题意，二面角 $E - BD - F$ 的余弦值为 $\dfrac{1}{3}$，即
$$|\cos\langle \vec{n}, \vec{m} \rangle| = \frac{|\vec{n} \cdot \vec{m}|}{|\vec{n}| |\vec{m}|} = \frac{|2h + 2h - 2|}{3\sqrt{2h^2 + 4}} = \frac{|4h - 2|}{3\sqrt{2h^2 + 4}} = \frac{1}{3}.$$
两边同乘以 $3$ 得：
$$\frac{|4h - 2|}{\sqrt{2h^2 + 4}} = 1 \implies (4h - 2)^2 = 2h^2 + 4.$$
展开化简：
$$16h^2 - 16h + 4 = 2h^2 + 4 \implies 14h^2 - 16h = 0 \implies 2h(7h - 8) = 0.$$
因为 $h > 0$ 为线段 $CF$ 的长度，所以 $7h - 8 = 0 \implies h = \dfrac{8}{7}$。
即线段 $CF$ 的长为 $\dfrac{8}{7}$。

**答案（1）：证明见解析版**

**答案（2）：$\dfrac{4}{9}$**

**答案（3）：$\dfrac{8}{7}$**

### 第 18 题

**题目**（本小题满分 13 分）：

设椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ ($a > b > 0$) 的左焦点为 $F$, 上顶点为 $B$. 已知椭圆的短轴长为 $4$, 离心率为 $\dfrac{\sqrt{5}}{5}$.
(1) 求椭圆的方程;
(2) 设点 $P$ 在椭圆上, 且异于椭圆的上、下顶点, 点 $M$ 为直线 $PB$ 与 $x$ 轴的交点, 点 $N$ 在 $y$ 轴的负半轴上. 若 $|ON| = |OF|$ ($O$ 为原点), 且 $OP \perp MN$, 求直线 $PB$ 的斜率.

**解析**

**(1) 解**

由题意，椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ ($a > b > 0$) 的短轴长为 $4$，
则 $2b = 4 \implies b = 2$。
椭圆离心率 $e = \dfrac{c}{a} = \dfrac{\sqrt{5}}{5}$，
两边平方得：
$$\frac{c^2}{a^2} = \frac{a^2 - b^2}{a^2} = 1 - \frac{4}{a^2} = \frac{1}{5} \implies \frac{4}{a^2} = \frac{4}{5} \implies a^2 = 5.$$
因此椭圆的标准方程为：
$$\frac{x^2}{5} + \frac{y^2}{4} = 1.$$

**(2) 解**

由 (1) 知 $c = \sqrt{a^2 - b^2} = 1$，左焦点为 $F(-1, 0)$，则 $|OF| = 1$。
上顶点为 $B(0, 2)$。
因为点 $N$ 在 $y$ 轴的负半轴上，且 $|ON| = |OF| = 1$，所以点 $N$ 的坐标为 $(0, -1)$。
设点 $P(x_0, y_0)$，因为点 $P$ 异于椭圆的上、下顶点，所以直线 $PB$ 的斜率存在且不为 $0$。
设直线 $PB$ 的斜率为 $k$ ($k \neq 0$)，其方程为 $y = kx + 2$。
令 $y = 0$，得 $kx + 2 = 0 \implies x = -\dfrac{2}{k}$，
所以点 $M$ 的坐标为 $\left(-\dfrac{2}{k}, 0\right)$。
计算向量 $\vec{MN}$：
$$\vec{MN} = N - M = \left(\frac{2}{k}, -1\right).$$
因为 $OP \perp MN$，所以 $\vec{OP} \cdot \vec{MN} = 0$。
代入点 $P(x_0, y_0)$ 的坐标：
$$\frac{2}{k} x_0 - y_0 = 0 \implies y_0 = \frac{2}{k} x_0.$$
又点 $P$ 在直线 $PB$ 上，满足 $y_0 = kx_0 + 2$，联立得：
$$\frac{2}{k} x_0 = kx_0 + 2 \implies \left(\frac{2}{k} - k\right) x_0 = 2 \implies \frac{2 - k^2}{k} x_0 = 2.$$
当 $k^2 \neq 2$ 时，解得
$$x_0 = \frac{2k}{2 - k^2},\quad y_0 = \frac{2}{k} x_0 = \frac{4}{2 - k^2}.$$
因为点 $P(x_0, y_0)$ 在椭圆上，满足 $4x_0^2 + 5y_0^2 = 20$，代入得：
$$4 \left(\frac{2k}{2 - k^2}\right)^2 + 5 \left(\frac{4}{2 - k^2}\right)^2 = 20 \implies \frac{16k^2 + 80}{(2 - k^2)^2} = 20.$$
两边除以 $4$：
$$\frac{4k^2 + 20}{(2 - k^2)^2} = 5 \implies 4k^2 + 20 = 5(2 - k^2)^2.$$
展开右边：
$$4k^2 + 20 = 5(4 - 4k^2 + k^4) = 20 - 20k^2 + 5k^4.$$
移项化简得：
$$5k^4 - 24k^2 = 0.$$
因为 $k \neq 0$，两边同除以 $k^2$ 得：
$$5k^2 - 24 = 0 \implies k^2 = \frac{24}{5}.$$
此时 $2 - k^2 = 2 - \dfrac{24}{5} = -\dfrac{14}{5} \neq 0$ 符合假设。
因此，
$$k = \pm\sqrt{\frac{24}{5}} = \pm\frac{2\sqrt{30}}{5}.$$
即直线 $PB$ 的斜率为 $\pm\dfrac{2\sqrt{30}}{5}$。

**答案（1）：$\dfrac{x^2}{5} + \dfrac{y^2}{4} = 1$**

**答案（2）：$\pm\dfrac{2\sqrt{30}}{5}$**

### 第 19 题

**题目**（本小题满分 14 分）：

设 $\{a_n\}$ 是等差数列, $\{b_n\}$ 是等比数列. 已知 $a_1 = 4, b_1 = 6, b_2 = 2a_2 - 2, b_3 = 2a_3 + 4$.
(1) 求 $\{a_n\}$ 和 $\{b_n\}$ 的通项公式;
(2) 设数列 $\{c_n\}$ 满足 $c_1 = 1$, $c_n = \begin{cases} 1, & 2^k < n < 2^{k+1}, \\ b_k, & n = 2^k, \end{cases}$ 其中 $k \in \mathbb{N}^*$.
① 求数列 $\{a_{2^n}(c_{2^n} - 1)\}$ 的通项公式;
② 求 $\sum_{i=1}^{2^n} a_i c_i$ ($n \in \mathbb{N}^*$).

**解析**

**(1) 解**

设等差数列 $\{a_n\}$ 的公差为 $d$，等比数列 $\{b_n\}$ 的公比为 $q$。
已知 $a_1 = 4, b_1 = 6$，则
$$a_2 = 4 + d,\quad a_3 = 4 + 2d,$$
$$b_2 = 6q,\quad b_3 = 6q^2.$$
由已知条件 $b_2 = 2a_2 - 2$ 和 $b_3 = 2a_3 + 4$ 可得：
$$
\begin{cases}
6q = 2(4 + d) - 2 = 6 + 2d, \\
6q^2 = 2(4 + 2d) + 4 = 12 + 4d.
\end{cases}
$$
由第一式得 $2d = 6q - 6 \implies d = 3q - 3$。
代入第二式：
$$6q^2 = 12 + 4(3q - 3) = 12 + 12q - 12 = 12q.$$
即 $6q^2 - 12q = 0 \implies 6q(q - 2) = 0$。
因为 $\{b_n\}$ 为等比数列，公比 $q \neq 0$，所以 $q = 2$。
代入得公差 $d = 3 \times 2 - 3 = 3$。
因此：
$$a_n = a_1 + (n - 1)d = 4 + 3(n - 1) = 3n + 1,$$
$$b_n = b_1 q^{n-1} = 6 \cdot 2^{n-1} = 3 \cdot 2^n.$$

**(2) 解**

依题意，当 $n = 2^k$ ($k \in \mathbb{N}^*$) 时，$c_n = b_k = 3 \cdot 2^k$；
当 $2^k < n < 2^{k+1}$ 时，$c_n = 1$；且 $c_1 = 1$。

① 当下标为 $2^n$ ($n \in \mathbb{N}^*$) 时，
$$a_{2^n} = 3 \cdot 2^n + 1,\quad c_{2^n} = b_n = 3 \cdot 2^n.$$
从而 $c_{2^n} - 1 = 3 \cdot 2^n - 1$。
因此：
$$a_{2^n}(c_{2^n} - 1) = (3 \cdot 2^n + 1)(3 \cdot 2^n - 1) = (3 \cdot 2^n)^2 - 1 = 9 \cdot 4^n - 1.$$

② 考虑和式 $\sum_{i=1}^{2^n} a_i c_i$：
在指标集合 $\{1, 2, \dots, 2^n\}$ 中，当 $i = 2^k$ ($k = 1, 2, \dots, n$) 时，$c_i = b_k$；其余项（包含 $i=1$）均有 $c_i = 1$。
因此可以将各项 $a_i c_i$ 改写为 $a_i + a_i(c_i - 1)$，从而总和可以拆为两部分：
$$\sum_{i=1}^{2^n} a_i c_i = \sum_{i=1}^{2^n} a_i + \sum_{k=1}^n a_{2^k}(c_{2^k} - 1).$$
计算第一部分（等差数列前 $2^n$ 项和）：
$$\begin{aligned}
\sum_{i=1}^{2^n} a_i &= \frac{2^n (a_1 + a_{2^n})}{2} = \frac{2^n [4 + (3 \cdot 2^n + 1)]}{2} \\
&= 2^{n-1}(3 \cdot 2^n + 5) = \frac{3}{2} \cdot 4^n + 5 \cdot 2^{n-1}.
\end{aligned}$$
计算第二部分（利用 ① 的结论）：
$$\begin{aligned}
\sum_{k=1}^n a_{2^k}(c_{2^k} - 1) &= \sum_{k=1}^n (9 \cdot 4^k - 1) = 9 \sum_{k=1}^n 4^k - \sum_{k=1}^n 1 \\
&= 9 \cdot \frac{4(4^n - 1)}{4 - 1} - n = 12 \cdot 4^n - n - 12.
\end{aligned}$$
将两部分相加，得到：
$$\sum_{i=1}^{2^n} a_i c_i = \left(\frac{3}{2} \cdot 4^n + 5 \cdot 2^{n-1}\right) + (12 \cdot 4^n - n - 12) = \frac{27}{2} \cdot 4^n + 5 \cdot 2^{n-1} - n - 12.$$

**答案（1）：$a_n = 3n + 1$，$b_n = 3 \cdot 2^n$**

**答案（2）：① $a_{2^n}(c_{2^n} - 1) = 9 \cdot 4^n - 1$；② $\sum_{i=1}^{2^n} a_i c_i = \dfrac{27}{2} \cdot 4^n + 5 \cdot 2^{n-1} - n - 12$**

### 第 20 题

**题目**（本小题满分 14 分）：

设函数 $f(x) = \mathrm{e}^x \cos x$, $g(x)$ 为 $f(x)$ 的导函数.
(1) 求 $f(x)$ 的单调区间;
(2) 当 $x \in \left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$ 时, 证明 $f(x) + g(x)\left(\dfrac{\pi}{2} - x\right) \geqslant 0$;
(3) 设 $x_n$ 为函数 $u(x) = f(x) - 1$ 在区间 $\left(2n\pi + \dfrac{\pi}{4}, 2n\pi + \dfrac{\pi}{2}\right)$ 内的零点, 其中 $n \in \mathbb{N}$, 证明 $2n\pi + \dfrac{\pi}{2} - x_n < \dfrac{\mathrm{e}^{-2n\pi}}{\sin x_0 - \cos x_0}$.

**解析**

**(1) 解**

对函数 $f(x) = \mathrm{e}^x \cos x$ 求导：
$$f'(x) = (\mathrm{e}^x)' \cos x + \mathrm{e}^x (\cos x)' = \mathrm{e}^x \cos x - \mathrm{e}^x \sin x = \mathrm{e}^x (\cos x - \sin x).$$
利用辅助角公式化简：
$$f'(x) = -\sqrt{2} \mathrm{e}^x \sin\left(x - \frac{\pi}{4}\right).$$
- 令 $f'(x) > 0 \iff \sin\left(x - \dfrac{\pi}{4}\right) < 0 \iff 2k\pi - \pi < x - \dfrac{\pi}{4} < 2k\pi \iff 2k\pi - \dfrac{3\pi}{4} < x < 2k\pi + \dfrac{\pi}{4}$ ($k \in \mathbb{Z}$)；
- 令 $f'(x) < 0 \iff \sin\left(x - \dfrac{\pi}{4}\right) > 0 \iff 2k\pi < x - \dfrac{\pi}{4} < 2k\pi + \pi \iff 2k\pi + \dfrac{\pi}{4} < x < 2k\pi + \dfrac{5\pi}{4}$ ($k \in \mathbb{Z}$)。
因此，$f(x)$ 的单调递增区间为
$$\left[2k\pi - \frac{3\pi}{4}, 2k\pi + \frac{\pi}{4}\right]\quad (k \in \mathbb{Z}),$$
单调递减区间为
$$\left[2k\pi + \frac{\pi}{4}, 2k\pi + \frac{5\pi}{4}\right]\quad (k \in \mathbb{Z}).$$

**(2) 证明**

已知 $g(x) = f'(x) = \mathrm{e}^x(\cos x - \sin x)$。
当 $x \in \left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$ 时，构造辅助函数：
$$F(x) = f(x) + g(x)\left(\frac{\pi}{2} - x\right).$$
代入端点值 $x = \dfrac{\pi}{2}$：
$$F\left(\frac{\pi}{2}\right) = f\left(\frac{\pi}{2}\right) + g\left(\frac{\pi}{2}\right) \times 0 = \mathrm{e}^{\pi/2} \cos\frac{\pi}{2} = 0.$$
对 $F(x)$ 求导：
$$F'(x) = f'(x) + g'(x)\left(\frac{\pi}{2} - x\right) + g(x) \cdot (-1) = g(x) + g'(x)\left(\frac{\pi}{2} - x\right) - g(x) = g'(x)\left(\frac{\pi}{2} - x\right).$$
计算 $g'(x) = f''(x)$：
$$g'(x) = [\mathrm{e}^x(\cos x - \sin x)]' = \mathrm{e}^x(\cos x - \sin x) + \mathrm{e}^x(-\sin x - \cos x) = -2\mathrm{e}^x \sin x.$$
当 $x \in \left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$ 时，$\sin x > 0$，因此 $g'(x) = -2\mathrm{e}^x \sin x < 0$。
又因为 $\dfrac{\pi}{2} - x > 0$，所以
$$F'(x) = g'(x)\left(\frac{\pi}{2} - x\right) < 0.$$
因此函数 $F(x)$ 在 $\left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$ 上单调递减。
所以对于任意 $x \in \left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$，恒有
$$F(x) \geqslant F\left(\frac{\pi}{2}\right) = 0,$$
即 $f(x) + g(x)\left(\dfrac{\pi}{2} - x\right) \geqslant 0$ 得证。

**(3) 证明**

函数 $u(x) = f(x) - 1$ 在区间 $\left(2n\pi + \dfrac{\pi}{4}, 2n\pi + \dfrac{\pi}{2}\right)$ 内的零点 $x_n$ 满足
$$f(x_n) = 1 \iff \mathrm{e}^{x_n}\cos x_n = 1.$$
设 $t_n = x_n - 2n\pi$，则 $t_n \in \left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$。
由三角函数周期性，$\cos x_n = \cos(2n\pi + t_n) = \cos t_n$。
代入得：
$$\mathrm{e}^{2n\pi + t_n} \cos t_n = 1 \implies \mathrm{e}^{t_n} \cos t_n = \mathrm{e}^{-2n\pi}.$$
由 (2) 的结论，当 $x \in \left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$ 时，$f(x) + g(x)\left(\dfrac{\pi}{2} - x\right) \geqslant 0$。
当 $x \in \left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$ 时，$\sin x > \cos x$，故 $g(x) = \mathrm{e}^x(\cos x - \sin x) < 0$。
移项得：
$$\left(\frac{\pi}{2} - x\right) \leqslant \frac{f(x)}{-g(x)} = \frac{\mathrm{e}^x\cos x}{\mathrm{e}^x(\sin x - \cos x)}.$$
将 $x = t_n$ 代入上述不等式：
$$\frac{\pi}{2} - t_n \leqslant \frac{\mathrm{e}^{t_n}\cos t_n}{\mathrm{e}^{t_n}(\sin t_n - \cos t_n)} = \frac{\mathrm{e}^{-2n\pi}}{\mathrm{e}^{t_n}(\sin t_n - \cos t_n)}.$$
考虑函数 $v(t) = \mathrm{e}^t(\sin t - \cos t)$ 在区间 $\left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$ 上的性质：
求导得
$$v'(t) = \mathrm{e}^t(\sin t - \cos t) + \mathrm{e}^t(\cos t + \sin t) = 2\mathrm{e}^t \sin t > 0,$$
因此 $v(t)$ 在 $\left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$ 上严格单调递增。
因为函数 $f(t) = \mathrm{e}^t \cos t$ 在 $\left[\dfrac{\pi}{4}, \dfrac{\pi}{2}\right]$ 上单调递减，且随着 $n$ 增大，$\mathrm{e}^{-2n\pi}$ 严格递减，
所以 $t_n$ 随着 $n$ 的增大而严格递增。
特别地，当 $n \geqslant 1$ 时，有 $t_n > t_0 = x_0$。
由 $v(t)$ 的单调性：
$$v(t_n) > v(x_0) = \mathrm{e}^{x_0}(\sin x_0 - \cos x_0).$$
又因为 $x_0 \in \left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$ 满足 $\mathrm{e}^{x_0} \cos x_0 = 1$，且 $\cos x_0 \in \left(0, \dfrac{\sqrt{2}}{2}\right)$，
所以 $\mathrm{e}^{x_0} = \dfrac{1}{\cos x_0} > \dfrac{2}{\sqrt{2}} = \sqrt{2} > 1$。
因为 $\sin x_0 - \cos x_0 > 0$，所以
$$v(x_0) = \mathrm{e}^{x_0}(\sin x_0 - \cos x_0) > \sin x_0 - \cos x_0.$$
综合上述放缩，当 $n \geqslant 1$ 时：
$$\frac{\pi}{2} - t_n \leqslant \frac{\mathrm{e}^{-2n\pi}}{v(t_n)} < \frac{\mathrm{e}^{-2n\pi}}{\sin x_0 - \cos x_0}.$$
当 $n = 0$ 时，$\dfrac{\pi}{2} - t_0 \leqslant \dfrac{1}{v(x_0)} = \dfrac{1}{\mathrm{e}^{x_0}(\sin x_0 - \cos x_0)} < \dfrac{1}{\sin x_0 - \cos x_0}$ 同样严格成立。
又由 $t_n = x_n - 2n\pi$，可得 $\dfrac{\pi}{2} - t_n = 2n\pi + \dfrac{\pi}{2} - x_n$。
因此对任意 $n \in \mathbb{N}$，均有
$$2n\pi + \frac{\pi}{2} - x_n < \frac{\mathrm{e}^{-2n\pi}}{\sin x_0 - \cos x_0}.$$
原命题得证。
