**(1) 答案**：焦点坐标为 $\left(0, \dfrac{1}{4a}\right)$，准线方程为 $y = -\dfrac{1}{4a}$。

**(2) 证明要点**：由割线斜率差商公式得 $x_2 + \lambda x_1 + (1+\lambda)x_0 = 0$，再由定比分点公式求得点 $M$ 的横坐标 $x_M = -x_0$，从而线段 $PM$ 中点的横坐标为 $\dfrac{x_0 + x_M}{2} = 0$，证得中点必在 $y$ 轴上。

**(3) 答案**：$y_1$ 的取值范围为 $(-\infty, -1) \cup \left(-1, -\dfrac{1}{4}\right)$。

**22．**

**(1) 证明要点**：由正弦函数的周期性 $\sin(x + 2k\pi) = \sin x$，展开 $f(x + 2k\pi) = (x + 2k\pi)\sin x = f(x) + 2k\pi \sin x$ 即可证得结论。

**(2) 证明要点**：由极值点导数 $f'(x_0) = \sin x_0 + x_0 \cos x_0 = 0$ 得 $\tan x_0 = -x_0$，再由同角三角函数公式 $\sin^2 x_0 = \dfrac{\tan^2 x_0}{1 + \tan^2 x_0} = \dfrac{x_0^2}{1 + x_0^2}$，代入 $[f(x_0)]^2 = x_0^2 \sin^2 x_0$ 即证。

**(3) 证明要点**：极值点满足方程 $\tan x = -x$。分析正切函数在各区间 $\left(n\pi - \dfrac{\pi}{2}, n\pi\right)$ 内的单调性与零点存在性知 $n\pi - \dfrac{\pi}{2} < a_n < n\pi$，两式相减得 $a_{n+1} - a_n > \dfrac{\pi}{2}$；再由 $\tan(a_n + \pi) = \tan a_n = -a_n > -a_{n+1} = \tan a_{n+1}$ 及正切函数的单调性推得 $a_{n+1} < a_n + \pi$，即 $a_{n+1} - a_n < \pi$。
