### 第 1 题

**解析**

分子为 $\dfrac{n(n + 1)}{2}$，故极限为 $\lim\limits_{n \to \infty}\left(\dfrac{1}{2} + \dfrac{1}{2n}\right) = \dfrac{1}{2}$。

### 第 2 题

**解析**

$d = \dfrac{|1 + 1 + 1|}{\sqrt{2}} = \dfrac{3\sqrt{2}}{2}$。

### 第 3 题

**解析**

$f\left(\dfrac{1}{2}\right) = \left|-\dfrac{1}{2}\right| - 2 = -\dfrac{3}{2}$，于是 $f\left(-\dfrac{3}{2}\right) = \dfrac{1}{1 + \frac{9}{4}} = \dfrac{4}{13}$。

### 第 4 题

**解析**

$\dfrac{\mathrm{i}}{1 + \mathrm{i}} = \dfrac{\mathrm{i}(1 - \mathrm{i})}{2} = \dfrac{1 + \mathrm{i}}{2}$，$(1 + \sqrt{3}\mathrm{i})^2 = -2 + 2\sqrt{3}\mathrm{i}$，故原式为 $-\dfrac{3}{2} + \left(\dfrac{1}{2} + 2\sqrt{3}\right)\mathrm{i}$，实部为负、虚部为正，位于第二象限。

### 第 5 题

**解析**

$x^3$ 的系数为 $-\left(\mathrm{C}_5^3 + \mathrm{C}_6^3 + \mathrm{C}_7^3 + \mathrm{C}_8^3\right) = -(10 + 20 + 35 + 56) = -121$。

### 第 6 题

**解析**

① 两平面平行时，两平面内的直线可能平行也可能异面，故假；② 两条互相垂直的直线可以同时与两平面的交线平行，此时两平面不垂直，故假。

### 第 7 题

**解析**

由三角形三边条件得 $x > 0$，$y > 0$，$x + y > \dfrac{1}{2}$，$x < \dfrac{1}{2}$，$y < \dfrac{1}{2}$，区域为以 $\left(0, \dfrac{1}{2}\right)$、$\left(\dfrac{1}{2}, 0\right)$、$\left(\dfrac{1}{2}, \dfrac{1}{2}\right)$ 为顶点、不含边界的三角形。

### 第 8 题

**解析**

$y = 2\cos^2x + k\cos x - (1 + k)$。令 $t = \cos x \in [-1, 1]$，抛物线对称轴 $t = -\dfrac{k}{4} > 1$，故在 $[-1, 1]$ 上单调递减，最小值在 $t = 1$ 处取得：$2 + k - 1 - k = 1$。

### 第 9 题

**解析**

$\hat{P} = \{0, 1, 2\}$，$\hat{Q} = \{1, 2, 3\}$，故 $\hat{P} \cap \complement_{\mathbf{N}}\hat{Q} = \{0\}$，$\hat{Q} \cap \complement_{\mathbf{N}}\hat{P} = \{3\}$，并集为 $\{0, 3\}$。

### 第 10 题

**解析**

两边平方得 $|\vec{a}|^2 - 2t\vec{a}\cdot\vec{e} + t^2 \geqslant |\vec{a}|^2 - 2\vec{a}\cdot\vec{e} + 1$，即
$$
t^2 - 2(\vec{a}\cdot\vec{e})t + 2\vec{a}\cdot\vec{e} - 1 \geqslant 0
$$
对一切 $t$ 成立，故判别式 $\leqslant 0$：$4(\vec{a}\cdot\vec{e})^2 - 4(2\vec{a}\cdot\vec{e} - 1) \leqslant 0$，即 $(\vec{a}\cdot\vec{e} - 1)^2 \leqslant 0$，得 $\vec{a}\cdot\vec{e} = 1$。于是 $\vec{e}\cdot(\vec{a} - \vec{e}) = 1 - 1 = 0$，即 $\vec{e} \perp (\vec{a} - \vec{e})$。

### 第 11 题

**解析**

由 $y(x + 2) = x$ 得 $x(y - 1) = -2y$，$x = \dfrac{2y}{1 - y}$，交换字母得 $y = \dfrac{2x}{1 - x}$（$x \neq 1$）。

### 第 12 题

**解析**

折起后 $A$ 在平面 $BCDE$ 内的射影恰为 $B$，故 $AB \perp$ 平面 $BCDE$；二面角 $A-DE-B$ 为 $45^\circ$ 即 $\angle AEB = 45^\circ$（$EA \perp DE$、$EB \perp DE$）。以 $E$ 为原点、$EB$ 为 $x$ 轴、$ED$ 为 $y$ 轴建系：$E(0,0,0)$、$B(b,0,0)$、$D(0,d,0)$、$C(b,d,0)$。由 $|AB| = |AE|\sin 45^\circ$、$|EB| = |AE|\cos 45^\circ$ 得 $|AB| = |EB| = b$，故 $A(b,0,b)$。

$M$、$N$ 为两腰 $AD$、$BC$ 的中点，故 $M\left(\dfrac b2, \dfrac d2, \dfrac b2\right)$、$N\left(b, \dfrac d2, 0\right)$，于是 $\overrightarrow{MN} = \left(\dfrac b2, 0, -\dfrac b2\right)$，而 $\overrightarrow{EA} = (b, 0, b)$，$\overrightarrow{MN} \cdot \overrightarrow{EA} = \dfrac{b^2}{2} - \dfrac{b^2}{2} = 0$。

故 $MN \perp AE$，所成角为 $90^\circ$。（注意 $MN$ 是折起后两腰中点的连线，不再是原平面图形的中位线，不能直接沿用 $MN \parallel AB$。）

### 第 13 题

**解析**

$|MN| = \dfrac{2b^2}{a}$，圆以 $(-c, 0)$ 为心、$\dfrac{b^2}{a}$ 为半径，右顶点在其上：$a + c = \dfrac{c^2 - a^2}{a}$，即 $e^2 - e - 2 = 0$，取 $e = 2$。

### 第 14 题

**解析**

总排法 $\mathrm{C}_5^2\mathrm{C}_{10}^2 \cdot 4! = 10 \times 45 \times 24 = 10800$。记 $A$ 为「$O$、$Q$ 同现」、$B$ 为「$O$、$0$ 同现」、$C$ 为「$Q$、$0$ 同现」，则 $|A| = 45 \times 24 = 1080$，$|B| = |C| = 4 \times 9 \times 24 = 864$，两两交与三重交均为 $1 \times 9 \times 24 = 216$。由容斥
$$
|A \cup B \cup C| = 1080 + 864 + 864 - 3 \times 216 + 216 = 2376,
$$
所求为 $10800 - 2376 = 8424$。

### 第 15 题

**解析**

#### (1)

$\dfrac{25\pi}{6} = 4\pi + \dfrac{\pi}{6}$，故 $\sin\dfrac{25\pi}{6} = \dfrac{1}{2}$，$\cos\dfrac{25\pi}{6} = \dfrac{\sqrt{3}}{2}$，$f = -\dfrac{\sqrt{3}}{4} + \dfrac{\sqrt{3}}{4} = 0$。

#### (2)

$f\left(\dfrac{\alpha}{2}\right) = -\dfrac{\sqrt{3}}{2}(1 - \cos\alpha) + \dfrac{1}{2}\sin\alpha = \dfrac{1}{4} - \dfrac{\sqrt{3}}{2}$，整理得 $\sin\alpha - \sqrt{3}\cos\alpha = \dfrac{1}{2}$，即 $\sin\left(\alpha - \dfrac{\pi}{3}\right) = \dfrac{1}{4}$。由 $\alpha \in (0, \pi)$ 知 $\alpha - \dfrac{\pi}{3} \in \left(-\dfrac{\pi}{3}, \dfrac{2\pi}{3}\right)$，故 $\cos\left(\alpha - \dfrac{\pi}{3}\right) = \dfrac{\sqrt{15}}{4}$，于是
$$
\sin\alpha = \frac{1}{4}\cdot\frac{1}{2} + \frac{\sqrt{15}}{4}\cdot\frac{\sqrt{3}}{2} = \frac{1 + 3\sqrt{5}}{8}.
$$

### 第 16 题

**解析**

#### (1)

图象关于原点对称即 $g(x) = -f(-x) = -x^2 + 2x$。

#### (2)

化为 $2x^2 \leqslant |x - 1|$：当 $x \geqslant 1$ 时 $2x^2 - x + 1 \leqslant 0$ 无解；当 $x < 1$ 时 $2x^2 + x - 1 \leqslant 0$，即 $(2x - 1)(x + 1) \leqslant 0$，得 $-1 \leqslant x \leqslant \dfrac{1}{2}$。

### 第 17 题

**解析**

#### (1)

$a = 2$，$M\left(-\dfrac{4}{c}, 0\right)$，由 $\dfrac{|MA_1|}{|A_1F_1|} = 2$ 得 $\dfrac{4}{c} - 2 = 2(2 - c)$，即 $c^2 - 3c + 2 = 0$，$c = 1$。故 $b^2 = 3$，椭圆为 $\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。

#### (2)

设 $P(m, t)$，两条视线斜率分别为 $\dfrac{t}{m + 1}$ 与 $\dfrac{t}{m - 1}$，则
$$
\tan\angle F_1PF_2 = \frac{\left|\frac{t}{m + 1} - \frac{t}{m - 1}\right|}{1 + \frac{t^2}{m^2 - 1}} = \frac{2|t|}{m^2 - 1 + t^2} \leqslant \frac{2|t|}{2\sqrt{m^2 - 1}\,|t|} = \frac{1}{\sqrt{m^2 - 1}},
$$
等号当 $|t| = \sqrt{m^2 - 1}$ 时成立，故 $Q\left(m, \pm\sqrt{m^2 - 1}\right)$。

### 第 18 题

**解析**

#### (1)

$O$、$D$ 分别为 $AC$、$PC$ 中点，故 $OD \parallel PA$，而 $PA \subset$ 平面 $PAB$，$OD \not\subset$ 平面 $PAB$，故 $OD \parallel$ 平面 $PAB$。

#### (2)

设 $AB = BC = a$，$k = \dfrac{1}{2}$ 时 $PA = 2a$。以 $B$ 为原点，$BA$、$BC$ 为 $x$、$y$ 轴，则 $A(a, 0, 0)$，$C(0, a, 0)$，$O\left(\dfrac{a}{2}, \dfrac{a}{2}, 0\right)$，$P\left(\dfrac{a}{2}, \dfrac{a}{2}, h\right)$，由 $|PA| = 2a$ 得 $h^2 = \dfrac{7}{2}a^2$。平面 $PBC$ 的法向量 $\vec{n} = (h, 0, -\dfrac{a}{2})$，$\overrightarrow{PA} = \left(\dfrac{a}{2}, -\dfrac{a}{2}, -h\right)$，故
$$
\sin\theta = \frac{ah}{2a\sqrt{h^2 + \frac{a^2}{4}}} = \sqrt{\frac{7}{30}}.
$$

#### (3)

同坐标系下 $\overrightarrow{OG} = \left(-\dfrac{a}{3}, 0, \dfrac{h}{3}\right)$，重心 $G = \left(\dfrac{a}{6}, \dfrac{a}{2}, \dfrac{h}{3}\right)$。要求 $OG \perp$ 平面 $PBC$，即 $\overrightarrow{OG} \parallel \vec{n} = (h, 0, -\dfrac{a}{2})$，比较分量得 $-\dfrac{a}{3} = \lambda h$、$\dfrac{h}{3} = -\dfrac{\lambda a}{2}$，消去 $\lambda$ 得 $a^2 = 2h^2$。又 $h^2 = \dfrac{a^2}{k^2} - \dfrac{a^2}{2}$，代入得 $\dfrac{a^2}{k^2} = a^2$，即 $k = 1$。

### 第 19 题

**解析**

#### (1)

① 前 $4$ 次恰有 $2$ 次红球、第 $5$ 次红球：$\mathrm{C}_4^2\left(\dfrac{1}{3}\right)^2\left(\dfrac{2}{3}\right)^2 \cdot \dfrac{1}{3} = 6 \times \dfrac{4}{81} \times \dfrac{1}{3} = \dfrac{8}{81}$。

② $\xi$ 取 $0, 1, 2, 3$：
$$
P(\xi = 0) = \left(\frac{2}{3}\right)^5 = \frac{32}{243},\quad P(\xi = 1) = \mathrm{C}_5^1\cdot\frac{1}{3}\cdot\left(\frac{2}{3}\right)^4 = \frac{80}{243},
$$
$$
P(\xi = 2) = \mathrm{C}_5^2\left(\frac{1}{3}\right)^2\left(\frac{2}{3}\right)^3 = \frac{80}{243},\quad P(\xi = 3) = 1 - \frac{192}{243} = \frac{51}{243}.
$$
故 $E\xi = \dfrac{80 + 160 + 153}{243} = \dfrac{131}{81}$。

#### (2)

设 $A$ 中球数为 $n$，则混合后摸到红球的概率为 $\dfrac{\frac{1}{3}n + 2np}{3n} = \dfrac{2}{5}$，解得 $p = \dfrac{13}{30}$。

### 第 20 题

**解析**

#### (1)

$a_1 = -2 - 4 - 1 = -7$，$C_1: y = x^2 - 7x + b_1$。由 $P_2(x_2, 2)$ 在 $C_1$ 上得 $b_1 = 2 - x_2^2 + 7x_2$。「$A_1$ 到 $C_1$ 上点的最短距离」在 $P_2$ 处取得，当且仅当 $\overrightarrow{A_1P_2}$ 与 $C_1$ 在 $P_2$ 处的切线垂直，切线斜率为 $2x_2 - 7$，故
$$
(x_2 - 1) + 2(2x_2 - 7) = 0 \Rightarrow 5x_2 = 15 \Rightarrow x_2 = 3,
$$
$b_1 = 2 - 9 + 21 = 14$，即 $C_1: y = x^2 - 7x + 14$。

#### (2)

同理对一般 $n$：$P_{n+1}(x_{n+1}, 2^n)$ 在 $C_n$ 上，最短距离条件给出
$$
(x_{n+1} - x_n) + 2^n\left(2x_{n+1} + a_n\right) = 0.
$$
代入 $a_n = -2 - 4n - \dfrac{1}{2^{n-1}}$：
$$
(1 + 2^{n+1})x_{n+1} = x_n + 2^n\left(4n + 2 + \frac{1}{2^{n-1}}\right) = x_n + 2^{n+1}(2n + 1) + 2.
$$
用归纳法验证 $x_n = 2n - 1$：$n = 1$ 时 $x_1 = 1$ 成立；若 $x_n = 2n - 1$，则
$$
(1 + 2^{n+1})x_{n+1} = (2n - 1) + 2^{n+1}(2n + 1) + 2,
$$
而 $(1 + 2^{n+1})(2n + 1) = (2n + 1) + 2^{n+1}(2n + 1)$，与右端比较得 $x_{n+1} = 2n + 1 = 2(n + 1) - 1$。故 $x_n = 2n - 1$，$\{x_n\}$ 是公差为 $2$ 的等差数列。
