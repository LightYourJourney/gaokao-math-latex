# 2005 年普通高等学校招生考试（天津卷文科）

## 一、选择题：本大题共 10 小题，每小题 5 分，共 50 分．在每小题给出的四个选项中，只有一项是符合题目要求的．

**1．** 设集合 $A = \{x \mid 0 \leqslant x < 3 \text{ 且 } x \in \mathbb{N}\}$ 的真子集的个数是（　　）

A．$16$

B．$8$

C．$7$

D．$4$

**2．** 已知 $\log_{\frac{1}{2}} b < \log_{\frac{1}{2}} a < \log_{\frac{1}{2}} c$，则（　　）

A．$2^b > 2^a > 2^c$

B．$2^a > 2^b > 2^c$

C．$2^c > 2^b > 2^a$

D．$2^c > 2^a > 2^b$

**3．** 某人射击一次击中的概率为 $0.6$，经过 $3$ 次射击，此人至少有两次击中目标的概率为（　　）

A．$\dfrac{81}{125}$

B．$\dfrac{54}{125}$

C．$\dfrac{36}{125}$

D．$\dfrac{27}{125}$

**4．** 将直线 $2x - y + \lambda = 0$ 沿 $x$ 轴向左平移 $1$ 个单位，所得直线与圆 $x^2 + y^2 + 2x - 4y = 0$ 相切，则实数 $\lambda$ 的值为（　　）

A．$-3$ 或 $7$

B．$-2$ 或 $8$

C．$0$ 或 $10$

D．$1$ 或 $11$

**5．** 设 $\alpha, \beta, \gamma$ 为平面，$m, n, l$ 为直线，则 $m \perp \beta$ 的一个充分条件是（　　）

A．$\alpha \perp \beta$，$\alpha \cap \beta = l$，$m \perp l$

B．$\alpha \cap \gamma = m$，$\alpha \perp \gamma$，$\beta \perp \gamma$

C．$\alpha \perp \gamma$，$\beta \perp \gamma$，$m \perp \alpha$

D．$n \perp \alpha$，$n \perp \beta$，$m \perp \alpha$

**6．** 设双曲线以椭圆 $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$ 长轴的两个端点为焦点，其准线过椭圆的焦点，则双曲线的渐近线的斜率为（　　）

A．$\pm 2$

B．$\pm \dfrac{4}{3}$

C．$\pm \dfrac{1}{2}$

D．$\pm \dfrac{3}{4}$

**7．** 给出下列三个命题：
① 若 $a \geqslant b > -1$，则 $\dfrac{a}{1+a} \geqslant \dfrac{b}{1+b}$；
② 若正整数 $m$ 和 $n$ 满足 $m \leqslant n$，则 $\sqrt{m(n-m)} \leqslant \dfrac{n}{2}$；
③ 设 $P(x_1, y_1)$ 为圆 $O_1 : x^2 + y^2 = 9$ 上任一点，圆 $O_2$ 以 $Q(a, b)$ 为圆心且半径为 $1$．当 $(a - x_1)^2 + (b - y_1)^2 = 1$ 时，圆 $O_1$ 与圆 $O_2$ 相切．
其中假命题的个数为（　　）

A．$0$

B．$1$

C．$2$

D．$3$

**8．** 函数 $y = A\sin(\omega x + \varphi)$ $\left(\omega > 0, |\varphi| < \dfrac{\pi}{2}, x \in \mathbb{R}\right)$ 的部分图象如图所示，则函数表达式为（　　）

[第 8 题图](../docs/exams/2005_天津卷_文科/figures/f2005_tianjin_arts_q08_trig.tex)

A．$y = -4\sin\left(\dfrac{\pi}{8}x + \dfrac{\pi}{4}\right)$

B．$y = 4\sin\left(\dfrac{\pi}{8}x - \dfrac{\pi}{4}\right)$

C．$y = -4\sin\left(\dfrac{\pi}{8}x - \dfrac{\pi}{4}\right)$

D．$y = 4\sin\left(\dfrac{\pi}{8}x + \dfrac{\pi}{4}\right)$

**9．** 若函数 $f(x) = \log_a(2x^2 + x)$ $(a > 0, a \neq 1)$ 在区间 $\left(0, \dfrac{1}{2}\right)$ 内恒有 $f(x) > 0$，则 $f(x)$ 的单调递增区间为（　　）

A．$\left(-\infty, -\dfrac{1}{4}\right)$

B．$\left(-\dfrac{1}{4}, +\infty\right)$

C．$(0, +\infty)$

D．$\left(-\infty, -\dfrac{1}{2}\right)$

**10．** 设 $f(x)$ 是定义在 $\mathbb{R}$ 上以 $6$ 为周期的函数，$f(x)$ 在 $(0, 3)$ 内单调递减，且 $y = f(x)$ 的图象关于直线 $x = 3$ 对称，则下面正确的结论是（　　）

A．$f(1.5) < f(3.5) < f(6.5)$
