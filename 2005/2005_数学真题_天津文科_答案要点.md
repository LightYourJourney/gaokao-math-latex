**(1) 答案**：$c = 1$ 或 $c = -\dfrac{1}{2}$。

**(2) 答案**：当 $c = 1$ 时，$S_n = \dfrac{n(n+1)}{2}$；当 $c = -\dfrac{1}{2}$ 时，$S_n = \dfrac{4}{9} - \dfrac{6n+4}{9}\left(-\dfrac{1}{2}\right)^n$。

**20．**

**(1) 答案**：$A_1A$ 与底面 $ABC$ 所成的角为 $60^\circ$（或 $\dfrac{\pi}{3}$）。

**(2) 证明要点**：在平行四边形 $BB_1C_1C$ 与底面中取相关中点构造平行四边形，或利用向量关系 $\vec{A_1E} = \dfrac{1}{2}(\vec{FB_1} + \vec{FC})$ 证得 $A_1E$ 平行于平面 $B_1FC$ 内的中线，从而 $A_1E \parallel \text{平面 } B_1FC$。

**(3) 答案**：$\dfrac{4\sqrt{3}}{27}\pi a^3$。

**21．**

**22．**

**答案**：$m$ 的取值范围为 $(-\infty, -1) \cup (4, 5] \cup [6, +\infty)$。

**23．**

**(1) 答案**：焦点坐标为 $\left(0, \dfrac{1}{4a}\right)$，准线方程为 $y = -\dfrac{1}{4a}$。

**(2) 证明要点**：由割线斜率差商公式得 $x_2 + \lambda x_1 + (1+\lambda)x_0 = 0$，再由定比分点公式求得点 $M$ 的横坐标 $x_M = -x_0$，从而线段 $PM$ 中点的横坐标为 $\dfrac{x_0 + x_M}{2} = 0$，证得中点必在 $y$ 轴上。

**(3) 答案**：$y_1$ 的取值范围为 $(-\infty, -1) \cup \left(-1, -\dfrac{1}{4}\right)$。
