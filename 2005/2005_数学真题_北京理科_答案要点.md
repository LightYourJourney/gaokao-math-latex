**(1) 答案**：$W_1$ 表示为 $\begin{cases} x < 0, \\ kx < y < -kx \end{cases}$；$W_2$ 表示为 $\begin{cases} x > 0, \\ -kx < y < kx \end{cases}$。

**19．**

**(1) 答案**：$a_2 = a + \dfrac{1}{4}$，$a_3 = \dfrac{1}{2}a + \dfrac{1}{8}$。

**(2) 证明要点**：由递推式奇偶组合得 $a_{2n+1} - \dfrac{1}{4} = \dfrac{1}{2}\left(a_{2n-1} - \dfrac{1}{4}\right)$，即 $b_{n+1} = \dfrac{1}{2}b_n$，首项 $b_1 = a - \dfrac{1}{4} \neq 0$，故 $\{b_n\}$ 是以 $a - \dfrac{1}{4}$ 为首项、$\dfrac{1}{2}$ 为公比的等比数列。

**(3) 答案**：$2a - \dfrac{1}{2}$。

**20．**

**(1) 证明要点**：利用单峰函数的单调性反证法分别证明峰点 $x^* \in (0, x_2)$ 与 $x^* \in (x_1, 1)$。

**(2) 证明要点**：取 $x_1 = 0.5 - r, x_2 = 0.5 + r$，间距 $x_2 - x_1 = 2r$，两区间的长度均为 $0.5 + r$。

**(3) 答案**：$x_1 = 0.34, x_2 = 0.66, x_3 = 0.32$（或 $x_1 = 0.32, x_2 = 0.66, x_3 = 0.34$）。
