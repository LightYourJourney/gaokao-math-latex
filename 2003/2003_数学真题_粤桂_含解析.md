# 2003 年粤桂卷数学解析正文

> 固定源 PDF 仅含两页题面，无官方答案与解析页。以下各题均依据题面独立复算并经双角色交叉核验；第 1、16、17、20、21 题的图形在 LaTeX 工程中统一采用 TikZ 矢量重绘。

### 第 1 题

**题目**：

在同一坐标系中，表示直线 $y = ax$ 与 $y = x + a$ 正确的是（　　）

[第 1 题四个坐标系中两直线选项图](../docs/exams/2003_粤桂卷/figures/f2003_yuegui_q1_lines.tex)

（A）A　　（B）B　　（C）C　　（D）D

**解析**

直线 $y = ax$ 过原点 $(0, 0)$，斜率为 $a$；直线 $y = x + a$ 的斜率为 1，在 $y$ 轴上的截距为 $a$。
- 若 $a > 0$，则 $y = ax$ 经过第一、三象限，而 $y = x + a$ 在 $y$ 轴上的截距为正（交点在 $y$ 轴正半轴上），且斜率为 1 为增函数；
- 若 $a < 0$，则 $y = ax$ 斜率为负，经过第二、四象限；而 $y = x + a$ 在 $y$ 轴上的截距 $a < 0$（交点在 $y$ 轴负半轴上），斜率为 1 为增函数。

观察四个选项图形：
- 在图 (A) 中，过原点的直线 $y = ax$ 斜率小于 0（单调递减），另一条直线 $y = x + a$ 斜率为正且在 $y$ 轴上的截距落在负半轴（即截距 $a < 0$），两线参数 $a$ 的正负完全一致，符合题意；
- 在图 (B) 中，过原点的直线斜率 $a > 0$，而另一条直线的截距在负半轴（$a < 0$），矛盾；
- 在图 (C) 中，过原点的直线斜率 $a < 0$，而另一条直线的截距在正半轴（$a > 0$），矛盾；
- 在图 (D) 中，另一条直线斜率小于 0，与斜率必须为 1 矛盾。

故选 A。

**答案：A**

### 第 2 题

**题目**：

已知 $x \in \left(-\dfrac{\pi}{2}, 0\right)$，$\cos x = \dfrac{4}{5}$，则 $\tan 2x =$（　　）

（A）$\dfrac{7}{24}$　　（B）$-\dfrac{7}{24}$　　（C）$\dfrac{24}{7}$　　（D）$-\dfrac{24}{7}$

**解析**

因为 $x \in \left(-\dfrac{\pi}{2}, 0\right)$，$\cos x = \dfrac{4}{5} > 0$，所以 $\sin x < 0$。由同角三角函数基本关系式：
$$\sin x = -\sqrt{1 - \cos^2 x} = -\sqrt{1 - \left(\frac{4}{5}\right)^2} = -\frac{3}{5}.$$
于是
$$\tan x = \frac{\sin x}{\cos x} = \frac{-\frac{3}{5}}{\frac{4}{5}} = -\frac{3}{4}.$$
由二倍角正切公式：
$$\tan 2x = \frac{2\tan x}{1 - \tan^2 x} = \frac{2 \left(-\frac{3}{4}\right)}{1 - \left(-\frac{3}{4}\right)^2} = \frac{-\frac{3}{2}}{1 - \frac{9}{16}} = \frac{-\frac{3}{2}}{\frac{7}{16}} = -\frac{3}{2} \times \frac{16}{7} = -\frac{24}{7}.$$

故选 D。

**答案：D**

### 第 3 题

**题目**：

圆锥曲线 $\rho = \dfrac{8\sin\theta}{\cos^2\theta}$ 的准线方程是（　　）

（A）$\rho\cos\theta = -2$　　（B）$\rho\cos\theta = 2$　　（C）$\rho\sin\theta = -2$　　（D）$\rho\sin\theta = 2$

**解析**

由极坐标与直角坐标互化公式 $x = \rho\cos\theta$，$y = \rho\sin\theta$，原方程为：
$$\rho = \frac{8\sin\theta}{\cos^2\theta} \implies \rho\cos^2\theta = 8\sin\theta.$$
两边同乘 $\rho$（$\rho \ne 0$）：
$$\rho^2\cos^2\theta = 8\rho\sin\theta \implies (\rho\cos\theta)^2 = 8(\rho\sin\theta),$$
即
$$x^2 = 8y.$$
这是顶点在原点、开口向上的抛物线标准方程，对应 $2p = 8 \implies p = 4$，其准线方程在直角坐标系下为 $y = -\dfrac{p}{2} = -2$。
化回极坐标方程，由于 $y = \rho\sin\theta$，准线方程即为：
$$\rho\sin\theta = -2.$$

故选 C。

**答案：C**

### 第 4 题

**题目**：

等差数列 $\{a_n\}$ 中，已知 $a_1 = \dfrac{1}{3}$，$a_2 + a_5 = 4$，$a_n = 33$，则 $n$ 为（　　）

（A）48　　（B）49　　（C）50　　（D）51

**解析**

设等差数列 $\{a_n\}$ 的公差为 $d$。由题意：
$$a_2 + a_5 = (a_1 + d) + (a_1 + 4d) = 2a_1 + 5d = 4.$$
代入 $a_1 = \dfrac{1}{3}$：
$$2 \left(\frac{1}{3}\right) + 5d = 4 \implies \frac{2}{3} + 5d = 4 \implies 5d = \frac{10}{3} \implies d = \frac{2}{3}.$$
数列通项公式为：
$$a_n = a_1 + (n - 1)d = \frac{1}{3} + (n - 1)\frac{2}{3} = \frac{2n - 1}{3}.$$
令 $a_n = 33$：
$$\frac{2n - 1}{3} = 33 \implies 2n - 1 = 99 \implies 2n = 100 \implies n = 50.$$

故选 C。

**答案：C**

### 第 5 题

**题目**：

双曲线虚轴的一个端点为 $M$，两个焦点为 $F_1, F_2$，$\angle F_1 M F_2 = 120^\circ$，则双曲线的离心率为（　　）

（A）$\sqrt{3}$　　（B）$\dfrac{\sqrt{6}}{2}$　　（C）$\dfrac{\sqrt{6}}{3}$　　（D）$\dfrac{\sqrt{3}}{3}$

**解析**

设双曲线的标准方程为 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ ($a > 0, b > 0$)，焦点为 $F_1(-c, 0), F_2(c, 0)$，虚轴端点不妨取 $M(0, b)$。
在等腰三角形 $\triangle F_1 M F_2$ 中，$OF_1 = OF_2 = c$，$OM = b$，$OM \perp F_1F_2$。
由对称性，高 $OM$ 平分顶角 $\angle F_1 M F_2$，因此：
$$\angle O M F_2 = \frac{1}{2} \angle F_1 M F_2 = 60^\circ.$$
在直角三角形 $\triangle O M F_2$ 中：
$$\tan 60^\circ = \frac{OF_2}{OM} = \frac{c}{b} = \sqrt{3} \implies c = \sqrt{3}b \implies c^2 = 3b^2.$$
由双曲线几何性质 $c^2 = a^2 + b^2$，得：
$$3b^2 = a^2 + b^2 \implies a^2 = 2b^2 \implies b^2 = \frac{1}{2}a^2.$$
从而：
$$c^2 = a^2 + \frac{1}{2}a^2 = \frac{3}{2}a^2.$$
离心率 $e$ 满足：
$$e = \frac{c}{a} = \sqrt{\frac{3}{2}} = \frac{\sqrt{6}}{2}.$$

故选 B。

**答案：B**

### 第 6 题

**题目**：

设函数
$$f(x) = \begin{cases} 2^{-x} - 1, & x \le 0, \\ x^{\frac{1}{2}}, & x > 0, \end{cases}$$
若 $f(x_0) > 1$，则 $x_0$ 的取值范围是（　　）

（A）$(-1, 1)$　　（B）$(-1, +\infty)$

（C）$(-\infty, -2) \cup (0, +\infty)$　　（D）$(-\infty, -1) \cup (1, +\infty)$

**解析**

分段讨论不等式 $f(x_0) > 1$：
1. 当 $x_0 \le 0$ 时，函数解析式为 $f(x_0) = 2^{-x_0} - 1$：
   $$2^{-x_0} - 1 > 1 \implies 2^{-x_0} > 2 \implies -x_0 > 1 \implies x_0 < -1.$$
   结合 $x_0 \le 0$，得 $x_0 \in (-\infty, -1)$。
2. 当 $x_0 > 0$ 时，函数解析式为 $f(x_0) = x_0^{\frac{1}{2}} = \sqrt{x_0}$：
   $$\sqrt{x_0} > 1 \implies x_0 > 1.$$
   结合 $x_0 > 0$，得 $x_0 \in (1, +\infty)$。

综上所述，$x_0$ 的取值范围是 $(-\infty, -1) \cup (1, +\infty)$。

故选 D。

**答案：D**

### 第 7 题

**题目**：

函数 $y = 2\sin x(\sin x + \cos x)$ 的最大值为（　　）

（A）$1 + \sqrt{2}$　　（B）$\sqrt{2} - 1$　　（C）$\sqrt{2}$　　（D）2

**解析**

对函数解析式进行三角恒等变形：
$$y = 2\sin x(\sin x + \cos x) = 2\sin^2 x + 2\sin x\cos x.$$
利用降幂公式 $2\sin^2 x = 1 - \cos 2x$ 及倍角公式 $2\sin x\cos x = \sin 2x$：
$$y = 1 - \cos 2x + \sin 2x = 1 + (\sin 2x - \cos 2x).$$
利用辅助角公式引入相位：
$$\sin 2x - \cos 2x = \sqrt{2}\sin\left(2x - \frac{\pi}{4}\right).$$
因此：
$$y = 1 + \sqrt{2}\sin\left(2x - \frac{\pi}{4}\right).$$
因为正弦函数的最大值为 1，所以当 $\sin\left(2x - \dfrac{\pi}{4}\right) = 1$ 时，$y$ 取得最大值：
$$y_{\max} = 1 + \sqrt{2}.$$

故选 A。

**答案：A**

### 第 8 题

**题目**：

已知圆 $C: (x - a)^2 + (y - 2)^2 = 4$ ($a > 0$) 及直线 $l: x - y + 3 = 0$，当直线 $l$ 被 $C$ 截得的弦长为 $2\sqrt{3}$ 时，$a$ 的值等于（　　）

（A）$\sqrt{2}$　　（B）$2 - \sqrt{2}$　　（C）$\sqrt{2} - 1$　　（D）$\sqrt{2} + 1$

**解析**

圆 $C: (x - a)^2 + (y - 2)^2 = 4$ 的圆心为 $(a, 2)$，半径 $R = 2$。
直线 $l: x - y + 3 = 0$ 截圆所得弦长为 $2\sqrt{3}$，设圆心到直线 $l$ 的距离为 $d$，由半弦长公式：
$$d = \sqrt{R^2 - \left(\frac{2\sqrt{3}}{2}\right)^2} = \sqrt{2^2 - (\sqrt{3})^2} = \sqrt{4 - 3} = 1.$$
由点到直线距离公式：
$$d = \frac{|a - 2 + 3|}{\sqrt{1^2 + (-1)^2}} = \frac{|a + 1|}{\sqrt{2}}.$$
故：
$$\frac{|a + 1|}{\sqrt{2}} = 1 \implies |a + 1| = \sqrt{2}.$$
由于已知条件中 $a > 0$，故 $a + 1 > 0$，从而：
$$a + 1 = \sqrt{2} \implies a = \sqrt{2} - 1.$$

故选 C。

**答案：C**

### 第 9 题

**题目**：

已知圆锥的底面半径为 $R$，高为 $3R$，在它的所有内接圆柱中，全面积的最大值是（　　）

（A）$2\pi R^2$　　（B）$\dfrac{9}{4}\pi R^2$　　（C）$\dfrac{8}{3}\pi R^2$　　（D）$\dfrac{3}{2}\pi R^2$

**解析**

圆锥的底面半径为 $R$，高为 $3R$。设内接圆柱的底面半径为 $r$ ($0 < r < R$)，高为 $h$。
在圆锥与圆柱的轴截面中，由相似三角形对应边成比例：
$$\frac{3R - h}{3R} = \frac{r}{R} \implies 3R - h = 3r \implies h = 3(R - r).$$
内接圆柱的全面积（即上下两底面积与侧面积之和）为：
$$S(r) = 2\pi r^2 + 2\pi rh = 2\pi r^2 + 2\pi r \cdot [3(R - r)] = 2\pi r^2 + 6\pi Rr - 6\pi r^2 = 6\pi Rr - 4\pi r^2.$$
提出公因式 $2\pi$：
$$S(r) = 2\pi (3Rr - 2r^2).$$
括号内是关于 $r$ 的二次函数 $f(r) = -2r^2 + 3Rr$，开口向下，其对称轴为：
$$r = -\frac{3R}{2(-2)} = \frac{3}{4}R.$$
因为 $0 < \dfrac{3}{4}R < R$，在定义域内，代入求极值：
$$f\left(\frac{3}{4}R\right) = 3R \left(\frac{3}{4}R\right) - 2 \left(\frac{3}{4}R\right)^2 = \frac{9}{4}R^2 - \frac{9}{8}R^2 = \frac{9}{8}R^2.$$
因此内接圆柱全面积的最大值为：
$$S_{\max} = 2\pi \cdot \frac{9}{8}R^2 = \frac{9}{4}\pi R^2.$$

故选 B。

**答案：B**

### 第 10 题

**题目**：

函数 $f(x) = \sin x, x \in \left[\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right]$ 的反函数 $f^{-1}(x) =$（　　）

（A）$-\arcsin x, x \in [-1, 1]$　　（B）$-\pi - \arcsin x, x \in [-1, 1]$

（C）$\pi + \arcsin x, x \in [-1, 1]$　　（D）$-\pi - \arcsin x, x \in [-1, 1]$

**解析**

由原函数 $y = \sin x$，$x \in \left[\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right]$，值域为 $[-1, 1]$。
在此区间上函数单调递减，存在反函数。
为求反函数，令 $t = x - \pi$，则当 $x \in \left[\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right]$ 时，$t \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$。
利用诱导公式：
$$y = \sin x = \sin(t + \pi) = -\sin t \implies \sin t = -y.$$
因为 $t \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ 处于反正弦函数的主值区间内，故：
$$t = \arcsin(-y) = -\arcsin y.$$
代回 $x$：
$$x - \pi = -\arcsin y \implies x = \pi - \arcsin y.$$
互换自变量与因变量符号，反函数表达式应为：
$$f^{-1}(x) = \pi - \arcsin x, \quad x \in [-1, 1].$$

**原卷排印笔误说明**：
对照 2003 年全国卷理科第 10 题，该选项正解为选项 (D) $\pi - \arcsin x, x \in [-1, 1]$。但在粤桂卷排版中，排字工将选项 (D) 前误添负号排为 $-\pi - \arcsin x$，导致选项 (D) 与选项 (B) 出现字面完全相同的重复项，而选项 (A)、(B)、(C)、(D) 中无一正确选项。按题库事实核查红线，标记为 U/PENDING。

**答案：U/PENDING**

### 第 11 题

**题目**：

已知长方形的四个顶点 $A(0, 0), B(2, 0), C(2, 1)$ 和 $D(0, 1)$，一质点从 $AB$ 的中点 $P_0$ 沿与 $AB$ 的夹角 $\theta$ 的方向射到 $BC$ 上的点 $P_1$ 后，依次反射到 $CD$、$DA$ 和 $AB$ 上的点 $P_2$、$P_3$ 和 $P_4$（入射角等于反射角），设 $P_4$ 的坐标为 $(x_4, 0)$，若 $1 < x_4 < 2$，则 $\tan\theta$ 的取值范围是（　　）

（A）$\left(\dfrac{1}{3}, 1\right)$　　（B）$\left(\dfrac{1}{3}, \dfrac{2}{3}\right)$　　（C）$\left(\dfrac{2}{5}, \dfrac{1}{2}\right)$　　（D）$\left(\dfrac{2}{5}, \dfrac{2}{3}\right)$

**解析**

建立直角坐标系，长方形顶点 $A(0, 0), B(2, 0), C(2, 1), D(0, 1)$。
$AB$ 的中点为 $P_0(1, 0)$。质点沿与 $AB$ 夹角 $\theta$ 的方向射出，设斜率 $k = \tan\theta > 0$。
1. **$P_0 \to P_1$**：
   射线方程为 $y = k(x - 1)$。与直线 $BC$ ($x = 2$) 相交于点 $P_1(2, k)$。
   因为 $P_1$ 在线段 $BC$ 上移动（不含端点），所以 $0 < k < 1$。
2. **$P_1 \to P_2$**：
   在 $BC$ 上发生镜面反射，入射角等于反射角，反射线斜率为 $-k$。
   反射直线方程为 $y - k = -k(x - 2) \implies y = -kx + 3k$。
   与直线 $CD$ ($y = 1$) 相交于点 $P_2$：
   $$1 = -kx_2 + 3k \implies x_2 = \frac{3k - 1}{k} = 3 - \frac{1}{k}.$$
   点 $P_2$ 位于线段 $CD$ 上，要求 $0 < 3 - \dfrac{1}{k} < 2 \implies 1 < \dfrac{1}{k} < 3 \implies \dfrac{1}{3} < k < 1$。
3. **$P_2 \to P_3$**：
   在 $CD$ 上反射，斜率变为 $k$。
   反射直线方程为 $y - 1 = k\left(x - \left(3 - \frac{1}{k}\right)\right) = kx - 3k + 1 \implies y = kx - 3k + 2$。
   与直线 $DA$ ($x = 0$) 相交于点 $P_3$：$y_3 = 2 - 3k$。
   点 $P_3$ 位于线段 $DA$ 上，要求 $0 < 2 - 3k < 1 \implies 1 < 3k < 2 \implies \dfrac{1}{3} < k < \dfrac{2}{3}$。
4. **$P_3 \to P_4$**：
   在 $DA$ 上反射，斜率变为 $-k$。
   反射直线方程为 $y - (2 - 3k) = -kx \implies y = -kx + 2 - 3k$。
   与直线 $AB$ ($y = 0$) 相交于点 $P_4(x_4, 0)$：
   $$0 = -kx_4 + 2 - 3k \implies x_4 = \frac{2 - 3k}{k} = \frac{2}{k} - 3.$$
   题设条件要求 $1 < x_4 < 2$：
   $$1 < \frac{2}{k} - 3 < 2 \implies 4 < \frac{2}{k} < 5 \implies \frac{2}{5} < k < \frac{1}{2}.$$

综合各反射段对 $k$ 的限制：
$$\frac{2}{5} < k < \frac{1}{2}$$
显然包含在 $\dfrac{1}{3} < k < \dfrac{2}{3}$ 之内，各点均能依序完成四次反射。
因此 $\tan\theta = k \in \left(\dfrac{2}{5}, \dfrac{1}{2}\right)$。

故选 C。

**答案：C**

### 第 12 题

**题目**：

一个四面体的所有棱长都为 $\sqrt{2}$，四个顶点在同一球面上，则此球的表面积为（　　）

（A）$3\pi$　　（B）$4\pi$　　（C）$3\sqrt{3}\pi$　　（D）$6\pi$

**解析**

正四面体的各棱长均为 $a = \sqrt{2}$。
将棱长为 $\sqrt{2}$ 的正四面体补全为一个正方体，使正四面体的 6 条棱恰好为正方体 6 个表面的对角线。
设正方体的棱长为 $s$，则正方形表面的对角线长为 $s\sqrt{2}$：
$$s\sqrt{2} = a = \sqrt{2} \implies s = 1.$$
正四面体的四个顶点即为正方体的四个互不相邻的顶点，两者具有完全相同的外接球。
正方体的体对角线长即为外接球的直径 $2R$：
$$(2R)^2 = s^2 + s^2 + s^2 = 3s^2 = 3 \times 1^2 = 3 \implies 4R^2 = 3.$$
外接球的表面积公式为：
$$S = 4\pi R^2 = 3\pi.$$

故选 A。

**答案：A**

### 第 13 题

**题目**：

不等式 $\sqrt{4x - x^2} < x$ 的解集是\_\_\_\_。

**解析**

解不等式 $\sqrt{4x - x^2} < x$：
1. 根号下有意义必须满足被开方数非负：
   $$4x - x^2 \ge 0 \iff x(x - 4) \le 0 \iff 0 \le x \le 4.$$
2. 由于根式 $\sqrt{4x - x^2} \ge 0$，不等式左侧非负，故右侧必须严格大于 0，即 $x > 0$。
3. 在 $x > 0$ 且 $0 \le x \le 4$ 条件下，两边同时平方：
   $$4x - x^2 < x^2 \iff 2x^2 - 4x > 0 \iff 2x(x - 2) > 0.$$
   由于 $x > 0$，两边同除以 $2x$ 得 $x - 2 > 0 \iff x > 2$。
4. 取交集：
   $$\begin{cases} 0 \le x \le 4, \\ x > 2 \end{cases} \implies 2 < x \le 4.$$

故不等式的解集为 $(2, 4]$（或 $\{x \mid 2 < x \le 4\}$）。

**答案：$(2, 4]$**

### 第 14 题

**题目**：

$\left(x^2 - \dfrac{1}{2x}\right)^9$ 的展开式中 $x^9$ 系数是\_\_\_\_。

**解析**

二项式 $\left(x^2 - \dfrac{1}{2x}\right)^9$ 展开式的通项公式为：
$$T_{r+1} = \mathrm{C}_9^r (x^2)^{9-r} \left(-\frac{1}{2x}\right)^r = \mathrm{C}_9^r (-1)^r \left(\frac{1}{2}\right)^r x^{18 - 2r - r} = (-1)^r \mathrm{C}_9^r \left(\frac{1}{2}\right)^r x^{18 - 3r},$$
其中 $r \in \{0, 1, 2, \dots, 9\}$。
令 $x$ 的指数等于 9：
$$18 - 3r = 9 \implies 3r = 9 \implies r = 3.$$
将 $r = 3$ 代入系数表达式：

**题目**：

已知正四棱柱 $ABCD - A_1B_1C_1D_1$，$AB = 1, AA_1 = 2$，$E$ 为 $CC_1$ 中点，$F$ 为 $BD_1$ 中点。

#### (1)

建立空间直角坐标系：
以点 $D$ 为原点，$DA$ 所在直线为 $x$ 轴，$DC$ 所在直线为 $y$ 轴，$DD_1$ 所在直线为 $z$ 轴。
由 $ABCD - A_1B_1C_1D_1$ 为正四棱柱，底面边长为 1，高为 2：
$$D(0, 0, 0), \quad A(1, 0, 0), \quad B(1, 1, 0), \quad C(0, 1, 0),$$
$$D_1(0, 0, 2), \quad A_1(1, 0, 2), \quad B_1(1, 1, 2), \quad C_1(0, 1, 2).$$
因为 $E$ 为 $CC_1$ 的中点，且 $C(0, 1, 0), C_1(0, 1, 2)$，所以：

$$F\left(\frac{1}{2}, \frac{1}{2}, 1\right).$$
由此计算向量：
$$\vec{EF} = \left(\frac{1}{2} - 0, \frac{1}{2} - 1, 1 - 1\right) = \left(\frac{1}{2}, -\frac{1}{2}, 0\right),$$
$$\vec{CC_1} = (0, 0, 2), \quad \vec{BD_1} = (-1, -1, 2).$$
检验正交性：
$$\vec{EF} \cdot \vec{CC_1} = \frac{1}{2} \times 0 + \left(-\frac{1}{2}\right) \times 0 + 0 \times 2 = 0 \implies EF \perp CC_1,$$
$$\vec{EF} \cdot \vec{BD_1} = \frac{1}{2} \times (-1) + \left(-\frac{1}{2}\right) \times (-1) + 0 \times 2 = -\frac{1}{2} + \frac{1}{2} + 0 = 0 \implies EF \perp BD_1.$$

$$d = \frac{|\vec{DD_1} \cdot \vec{n}|}{|\vec{n}|} = \frac{|0 \times 1 + 0 \times (-1) + 2 \times 1|}{\sqrt{3}} = \frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3}.$$

**答案（1）：证明见解析。**

### 第 18 题

**题目**：

已知复数 $z$ 的辐角为 $60^\circ$，且 $|z - 1|$ 是 $|z|$ 和 $|z - 2|$ 的等比中项，求 $|z|$。

**解析**

设复数 $z$ 的代数形式为 $z = x + yi$ ($x, y \in \mathbf{R}$)。
由于 $z$ 的辐角为 $60^\circ$，设 $|z| = r > 0$，则：
$$z = r(\cos 60^\circ + i\sin 60^\circ) = r\left(\frac{1}{2} + \frac{\sqrt{3}}{2}i\right) = \frac{r}{2} + \frac{\sqrt{3}r}{2}i.$$
计算模长平方：
$$|z - 1|^2 = \left(\frac{r}{2} - 1\right)^2 + \left(\frac{\sqrt{3}r}{2}\right)^2 = \frac{r^2}{4} - r + 1 + \frac{3r^2}{4} = r^2 - r + 1,$$
$$|z - 2|^2 = \left(\frac{r}{2} - 2\right)^2 + \left(\frac{\sqrt{3}r}{2}\right)^2 = \frac{r^2}{4} - 2r + 4 + \frac{3r^2}{4} = r^2 - 2r + 4.$$
因为 $|z - 1|$ 是 $|z|$ 和 $|z - 2|$ 的等比中项，所以：
$$|z - 1|^2 = |z| \cdot |z - 2| \implies r^2 - r + 1 = r\sqrt{r^2 - 2r + 4}.$$
两边平方得：
$$(r^2 - r + 1)^2 = r^2(r^2 - 2r + 4).$$
展开左边：
$$(r^2 - r + 1)^2 = (r^2 - r)^2 + 2(r^2 - r) + 1 = r^4 - 2r^3 + r^2 + 2r^2 - 2r + 1 = r^4 - 2r^3 + 3r^2 - 2r + 1.$$
展开右边：
$$r^2(r^2 - 2r + 4) = r^4 - 2r^3 + 4r^2.$$
两边相消消去 $r^4 - 2r^3$：
$$3r^2 - 2r + 1 = 4r^2 \implies r^2 + 2r - 1 = 0.$$
解此一元二次方程：
$$r = \frac{-2 \pm \sqrt{2^2 - 4(1)(-1)}}{2} = \frac{-2 \pm 2\sqrt{2}}{2} = -1 \pm \sqrt{2}.$$
由于模长 $r = |z| > 0$，舍去负根，得：
$$r = \sqrt{2} - 1.$$
验证：当 $r = \sqrt{2} - 1$ 时，$r^2 - r + 1 = (3 - 2\sqrt{2}) - (\sqrt{2} - 1) + 1 = 5 - 3\sqrt{2} \approx 5 - 4.242 > 0$，平方过程同解。
因此 $|z| = \sqrt{2} - 1$。

**答案：$|z| = \sqrt{2} - 1$**

### 第 19 题

**题目**：

已知 $c > 0$，设 $P$: 函数 $y = c^x$ 在 $\mathbf{R}$ 上单调递减；$Q$: 不等式 $x + |x - 2c| > 1$ 的解集为 $\mathbf{R}$。如果 $P$ 和 $Q$ 有且仅有一个正确，求 $c$ 的取值范围。

**解析**

已知 $c > 0$。分别讨论命题 $P$ 和命题 $Q$ 为真的充要条件：
1. **命题 $P$**：函数 $y = c^x$ 在 $\mathbf{R}$ 上单调递减。
   由指数函数的性质，$y = c^x$ 在 $\mathbf{R}$ 上单调递减的充要条件是：
   $$0 < c < 1.$$
2. **命题 $Q$**：不等式 $x + |x - 2c| > 1$ 的解集为 $\mathbf{R}$。
   记函数 $f(x) = x + |x - 2c|$。
   - 当 $x \ge 2c$ 时，$f(x) = x + x - 2c = 2x - 2c \ge 2(2c) - 2c = 2c$；
   - 当 $x < 2c$ 时，$f(x) = x - (x - 2c) = 2c$。
   因此，函数 $f(x)$ 在 $\mathbf{R}$ 上的最小值为 $2c$。
   不等式 $x + |x - 2c| > 1$ 对任意 $x \in \mathbf{R}$ 恒成立 $\iff \min f(x) > 1 \iff 2c > 1 \iff c > \dfrac{1}{2}$。

题目要求“$P$ 和 $Q$ 有且仅有一个正确”，即 $P$ 真 $Q$ 假 或 $P$ 假 $Q$ 真：
- **情形一：$P$ 真且 $Q$ 假**：
  $$\begin{cases} 0 < c < 1, \\ c \le \dfrac{1}{2} \end{cases} \implies 0 < c \le \frac{1}{2}.$$
- **情形二：$P$ 假且 $Q$ 真**：
  $$\begin{cases} c \ge 1, \\ c > \dfrac{1}{2} \end{cases} \implies c \ge 1.$$

综上所述，$c$ 的取值范围为 $\left(0, \dfrac{1}{2}\right] \cup [1, +\infty)$。

**答案：$\left(0, \dfrac{1}{2}\right] \cup [1, +\infty)$**

**题目**：

在某海滨城市附近海面有一台风，据监测，当前台风中心位于城市 $O$（如图）的东偏南 $\theta$ $\left(\theta = \arccos\dfrac{\sqrt{2}}{10}\right)$ 方向 $300\text{ km}$ 的海面 $P$ 处，并以 $20\text{ km/h}$ 的速度向西偏北 $45^\circ$ 方向移动，台风侵袭的范围为圆形区域，当前半径为 $60\text{ km}$，并以 $10\text{ km/h}$ 的速度不断增大，问几小时后该城市开始受到台风的侵袭？

$$\vec{v} = 20 \left(-\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2}\right) = (-10\sqrt{2}, 10\sqrt{2}).$$
设经过 $t$ 小时后，台风中心的坐标为 $P(t) = (x(t), y(t))$：
$$x(t) = 30\sqrt{2} - 10\sqrt{2}t = 10\sqrt{2}(3 - t),$$
$$y(t) = -210\sqrt{2} + 10\sqrt{2}t = 10\sqrt{2}(t - 21).$$

$$(t - 3)^2 + (t - 21)^2 = (t^2 - 6t + 9) + (t^2 - 42t + 441) = 2t^2 - 48t + 450 = 2(t^2 - 24t + 225).$$

$$d^2(t) = 400(t^2 - 24t + 225) \implies d(t) = 20\sqrt{t^2 - 24t + 225}.$$

### 第 21 题

**题目**：

已知常数 $a > 0$，在矩形 $ABCD$ 中，$AB = 4, BC = 4a$，$O$ 为 $AB$ 的中点，点 $E、F、G$ 分别在 $BC、CD、DA$ 上移动，且 $\dfrac{BE}{BC} = \dfrac{CF}{CD} = \dfrac{DG}{DA}$，$P$ 为 $GE$ 与 $OF$ 的交点（如图），问是否存在两个定点，使 $P$ 到这两点的距离的和为定值？若存在，求出这两点的坐标及此定值；若不存在，请说明理由。

[第 21 题矩形动点与交点轨迹示意图](../docs/exams/2003_粤桂卷/figures/f2003_yuegui_q21_rectangle_locus.tex)

**解析**

以 $AB$ 所在的直线为 $x$ 轴，$AB$ 的中垂线为 $y$ 轴建立直角坐标系。
由于 $AB = 4$，$O$ 为 $AB$ 中点，则 $O(0, 0), A(-2, 0), B(2, 0)$。
因为 $BC = 4a$ 垂直于 $AB$，长方形四个顶点坐标为：
$$A(-2, 0), \quad B(2, 0), \quad C(2, 4a), \quad D(-2, 4a).$$
设比值 $\dfrac{BE}{BC} = \dfrac{CF}{CD} = \dfrac{DG}{DA} = k \in [0, 1]$：
- 点 $E$ 在边 $BC$ 上，横坐标为 2，纵坐标为 $4ak$，即 $E(2, 4ak)$；
- 点 $F$ 在边 $CD$ 上，纵坐标为 $4a$，横坐标由 $C(2, 4a)$ 向左移动 $4k$，即 $F(2 - 4k, 4a)$；
- 点 $G$ 在边 $DA$ 上，横坐标为 $-2$，纵坐标由 $D(-2, 4a)$ 向下移动 $4ak$，即 $G(-2, 4a(1 - k))$。

接下来求直线 $GE$ 与直线 $OF$ 的方程：
1. **直线 $GE$**：
   过点 $G(-2, 4a - 4ak)$ 与 $E(2, 4ak)$，其中点坐标为：
   $$\left(\frac{-2 + 2}{2}, \frac{4a - 4ak + 4ak}{2}\right) = (0, 2a).$$
   直线 $GE$ 的斜率 $m_{GE} = \dfrac{4ak - (4a - 4ak)}{2 - (-2)} = \dfrac{4a(2k - 1)}{4} = a(2k - 1)$。
   由点斜式，直线 $GE$ 的方程为：
   $$y - 2a = a(2k - 1)x.$$
2. **直线 $OF$**：
   过原点 $O(0, 0)$ 与点 $F(2(1 - 2k), 4a)$。
   - 当 $k = \dfrac{1}{2}$ 时，$F(0, 4a)$ 在 $y$ 轴上，$OF$ 的方程为 $x = 0$。代入 $GE$ 方程得 $y = 2a$，交点 $P(0, 2a)$；
   - 当 $k \ne \dfrac{1}{2}$ 时，直线 $OF$ 的斜率为 $\dfrac{4a}{2(1 - 2k)} = -\dfrac{2a}{2k - 1}$。
   其方程为 $y = -\dfrac{2a}{2k - 1}x$，变形得：
   $$a(2k - 1) = -\frac{2a^2 x}{y}.$$
3. **联立消去参数 $k$**：
   将 $a(2k - 1) = -\dfrac{2a^2 x}{y}$ 代入直线 $GE$ 的方程 $y - 2a = [a(2k - 1)]x$：
   $$y - 2a = -\frac{2a^2 x^2}{y} \implies y(y - 2a) = -2a^2 x^2 \implies 2a^2 x^2 + y^2 - 2ay = 0.$$
   配方得：
   $$2a^2 x^2 + (y - a)^2 = a^2.$$
   两边同除以 $a^2$：
   $$2x^2 + \frac{(y - a)^2}{a^2} = 1 \iff \frac{x^2}{\frac{1}{2}} + \frac{(y - a)^2}{a^2} = 1.$$
   当 $k = \dfrac{1}{2}$ 时交点 $(0, 2a)$ 亦满足此方程。

因此，点 $P$ 的轨迹是中心为 $(0, a)$ 的二次曲线，根据椭圆第一定义讨论定点和定值：
- **当 $0 < a < \dfrac{\sqrt{2}}{2}$ 时**：
  $\dfrac{1}{2} > a^2$，长轴在水平方向平行于 $x$ 轴。半长轴 $A = \dfrac{\sqrt{2}}{2}$，半短轴 $B = a$。
  半焦距 $c = \sqrt{\frac{1}{2} - a^2}$。
  焦点坐标为 $\left(\pm\sqrt{\dfrac{1}{2} - a^2}, a\right)$。
  此时点 $P$ 到两焦点的距离之和为定值 $2A = \sqrt{2}$。
- **当 $a = \dfrac{\sqrt{2}}{2}$ 时**：
  方程化为 $x^2 + \left(y - \dfrac{\sqrt{2}}{2}\right)^2 = \dfrac{1}{2}$，轨迹是以 $\left(0, \dfrac{\sqrt{2}}{2}\right)$ 为圆心、半径为 $\dfrac{\sqrt{2}}{2}$ 的圆。
  此时两定点可视为重合于圆心 $\left(0, \dfrac{\sqrt{2}}{2}\right)$，距离之和为定值 $\sqrt{2}$。
- **当 $a > \dfrac{\sqrt{2}}{2}$ 时**：
  $a^2 > \dfrac{1}{2}$，长轴在铅直方向落在 $y$ 轴上。半长轴 $A = a$，半短轴 $B = \dfrac{\sqrt{2}}{2}$。
  半焦距 $c = \sqrt{a^2 - \frac{1}{2}}$。
  焦点坐标为 $\left(0, a \pm\sqrt{a^2 - \dfrac{1}{2}}\right)$。
  此时点 $P$ 到两焦点的距离之和为定值 $2A = 2a$。

**答案：当 $0 < a < \dfrac{\sqrt{2}}{2}$ 时，存在两定点 $\left(\pm\sqrt{\dfrac{1}{2} - a^2}, a\right)$，距离之和为定值 $\sqrt{2}$；当 $a = \dfrac{\sqrt{2}}{2}$ 时，点 $P$ 轨迹为圆，两定点重合于圆心 $\left(0, \dfrac{\sqrt{2}}{2}\right)$，距离之和为 $\sqrt{2}$；当 $a > \dfrac{\sqrt{2}}{2}$ 时，存在两定点 $\left(0, a \pm\sqrt{a^2 - \dfrac{1}{2}}\right)$，距离之和为定值 $2a$。**

### 第 22 题

**题目**：

设 $a_0$ 为常数，且 $a_n = 3^{n-1} - 2a_{n-1}$ ($n \in \mathbf{N}^*$)。

（1） 证明对任意 $n \ge 1$，
$$a_n = \dfrac{1}{5}[3^n + (-1)^{n-1} \cdot 2^n] + (-1)^n \cdot 2^n a_0;$$

（2） 假设对任意 $n \ge 1$ 有 $a_n > a_{n-1}$，求 $a_0$ 的取值范围。

**解析**

#### (1)

用数学归纳法证明对任意 $n \ge 1$，
$$a_n = \frac{1}{5}[3^n + (-1)^{n-1} \cdot 2^n] + (-1)^n \cdot 2^n a_0.$$

1. **当 $n = 1$ 时**：
   由递推公式：
   $$a_1 = 3^{1-1} - 2a_0 = 1 - 2a_0.$$
   代入通项公式右边：
   $$\frac{1}{5}[3^1 + (-1)^0 \cdot 2^1] + (-1)^1 \cdot 2^1 a_0 = \frac{1}{5}(3 + 2) - 2a_0 = 1 - 2a_0.$$
   左边等于右边，命题在 $n = 1$ 时成立。
2. **假设当 $n = k$ ($k \ge 1$) 时命题成立**，即：
   $$a_k = \frac{1}{5}[3^k + (-1)^{k-1} \cdot 2^k] + (-1)^k \cdot 2^k a_0.$$
   那么当 $n = k + 1$ 时，由递推关系 $a_{k+1} = 3^k - 2a_k$：
   $$\begin{aligned}
   a_{k+1} &= 3^k - 2\left[\frac{1}{5}(3^k + (-1)^{k-1} \cdot 2^k) + (-1)^k \cdot 2^k a_0\right] \\
   &= 3^k - \frac{2}{5} \cdot 3^k - \frac{2}{5} (-1)^{k-1} \cdot 2^k - 2(-1)^k \cdot 2^k a_0 \\
   &= \left(1 - \frac{2}{5}\right) 3^k + \frac{1}{5} (-1)^k \cdot 2^{k+1} + (-1)^{k+1} \cdot 2^{k+1} a_0 \\
   &= \frac{3}{5} \cdot 3^k + \frac{1}{5} (-1)^k \cdot 2^{k+1} + (-1)^{k+1} \cdot 2^{k+1} a_0 \\
   &= \frac{1}{5}[3^{k+1} + (-1)^k \cdot 2^{k+1}] + (-1)^{k+1} \cdot 2^{k+1} a_0.
   \end{aligned}$$
   这表明当 $n = k + 1$ 时命题也成立。

由数学归纳法，公式对所有 $n \ge 1$ 恒成立。

#### (2)

由题设，对任意 $n \ge 1$ 均有 $a_n > a_{n-1}$。
利用递推关系式 $a_n = 3^{n-1} - 2a_{n-1}$，得：
$$a_n - a_{n-1} = 3^{n-1} - 3a_{n-1} > 0 \iff 3a_{n-1} < 3^{n-1} \iff a_{n-1} < 3^{n-2}.$$
即对任意 $n \ge 1$，$a_{n-1} < 3^{n-2}$ 恒成立：
1. 当 $n = 1$ 时：
   $$a_0 < 3^{-1} = \frac{1}{3}.$$
2. 当 $n \ge 2$ 时，令 $m = n - 1 \ge 1$，则要求对任意正整数 $m$，均有：
   $$a_m < 3^{m-1} = \frac{1}{3} \cdot 3^m.$$
   将 (1) 中已证的通项表达式代入：
   $$\frac{1}{5}[3^m + (-1)^{m-1} \cdot 2^m] + (-1)^m \cdot 2^m a_0 < \frac{1}{3} \cdot 3^m.$$
   整理分离含 $a_0$ 的项：
   $$(-1)^m \cdot 2^m a_0 + \frac{1}{5}(-1)^{m-1} \cdot 2^m < \left(\frac{1}{3} - \frac{1}{5}\right) 3^m = \frac{2}{15} \cdot 3^m.$$
   由于 $(-1)^{m-1} = -(-1)^m$，提公因式 $(-1)^m \cdot 2^m$：
   $$(-1)^m \cdot 2^m \left(a_0 - \frac{1}{5}\right) < \frac{2}{15} \cdot 3^m.$$
   两边同除以 $2^m > 0$：
   $$(-1)^m \left(a_0 - \frac{1}{5}\right) < \frac{2}{15} \left(\frac{3}{2}\right)^m.$$

该不等式必须对一切正整数 $m \ge 1$ 恒成立，按 $m$ 的奇偶性分类讨论：
- **当 $m$ 为正偶数时**，设 $m = 2k$ ($k \in \mathbf{N}^*$)，$(-1)^m = 1$：
  $$a_0 - \frac{1}{5} < \frac{2}{15} \left(\frac{3}{2}\right)^{2k}.$$
  由于数列 $\left\{\left(\dfrac{3}{2}\right)^{2k}\right\}$ 随 $k$ 单调递增，右端的最小值为 $k = 1$ 时的值：
  $$\frac{2}{15} \left(\frac{3}{2}\right)^2 = \frac{2}{15} \times \frac{9}{4} = \frac{3}{10}.$$
  因此必须满足：
  $$a_0 - \frac{1}{5} \le \frac{3}{10} \implies a_0 \le \frac{1}{5} + \frac{3}{10} = \frac{1}{2}.$$
  （当 $a_0 < \dfrac{1}{2}$ 时不等式对所有偶数 $m$ 严格成立）。
- **当 $m$ 为正奇数时**，设 $m = 2k - 1$ ($k \in \mathbf{N}^*$)，$(-1)^m = -1$：
  $$-\left(a_0 - \frac{1}{5}\right) < \frac{2}{15} \left(\frac{3}{2}\right)^{2k-1} \iff a_0 - \frac{1}{5} > -\frac{2}{15} \left(\frac{3}{2}\right)^{2k-1}.$$
  为了使此式对一切正奇数成立，$a_0 - \dfrac{1}{5}$ 必须大于数列 $\left\{-\dfrac{2}{15}\left(\dfrac{3}{2}\right)^{2k-1}\right\}$ 的上确界。
  因为数列 $\left\{-\dfrac{2}{15}\left(\dfrac{3}{2}\right)^{2k-1}\right\}$ 随 $k$ 单调递减，其最大值在 $k = 1$（即 $m = 1$）处取得：
  $$-\frac{2}{15} \left(\frac{3}{2}\right)^1 = -\frac{1}{5}.$$
  因此必须满足：
  $$a_0 - \frac{1}{5} > -\frac{1}{5} \implies a_0 > 0.$$

结合 $n = 1$ 时的条件 $a_0 < \dfrac{1}{3}$：
因为 $\dfrac{1}{3} < \dfrac{1}{2}$，偶数约束 $a_0 \le \dfrac{1}{2}$ 被 $a_0 < \dfrac{1}{3}$ 完全覆盖。
综上所述，$a_0$ 的取值范围是：
$$0 < a_0 < \frac{1}{3}.$$

**答案（1）：证明见解析。**

**答案（2）：$0 < a_0 < \dfrac{1}{3}$**
