# 1982 年普通高等学校招生考试（全国卷）文科数学

> **来源说明**：本卷为 1982 年全国统一命题的**文科数学**卷（同年另有独立的理科卷，两份试卷题目不同），单页（原卷页码第 20 页），全卷共 9 题。题面不含答案（答案由本库独立推导）。原卷按左、中、右三栏分栏排版，本文按题号 1—9 顺序转录，题面文字未作改动。
>
> **题面说明**：第 1、3 题为填表题，原卷表中“使函数有意义的 $x$ 的实数范围”“曲线名称”“图形”三列留空待填，本文照原卷保留空列。第 5、9 题依原卷配图重绘为 TikZ 矢量图。
>
> **源注**：第 9 题原卷不等号印作“$\geqslant$”，本文统一转写为 $\ge$（与同期各卷一致）；该题“$B_1A_1\parallel BA$”“$B_2A_2\parallel BA$”中的平行号在纯文本提取时会丢失，本文按页面图像转录。

**1．** 填表：

| | 函数 | 使函数有意义的 $x$ 的实数范围 |
|:---:|---|---|
| 1 | $y=\sqrt{-x^2}$ | |
| 2 | $y=\sqrt{(-x)^2}$ | |
| 3 | $y=10^{\lg x}$ | |
| 4 | $y=\lg 10^x$ | |

**2．** 求 $(-1+\mathrm i)^{20}$ 展开式中第 15 项的数值。

**3．** 在平面直角坐标系内，表中的方程表示什么曲线？并画出它们的图形：

| | 方程 | 曲线名称 | 图形 |
|:---:|---|---|---|
| 1 | $4x^2+y^2=4$ | | |
| 2 | $x-3=0$ | | |

**4．** 已知 $x-y=\dfrac12$，$x^2+y^2=1$，求 $x^2-y^2$ 的值。

**5．** 以墙为一边，用篱笆围成长方形的场地，并用平行于一边的篱笆隔开（如图）。已知篱笆的总长为定值 $L$，这块场地的长和宽各为多少时场地的面积最大？最大面积是多少？

![以墙为一边的矩形场地与分隔篱笆示意图](images/1982-1982-arts-t5-fence.png)

**6．** 已知正方体 $ABCD\text{-}A_1B_1C_1D_1$ 的棱长为 $a$。

（1） 用平面 $A_1BC_1$ 截去一角后，求剩余部分的体积；

（2） 求 $A_1B$ 和 $B_1C$ 所成的角。

**7．** 已知定点 $A$、$B$ 且 $AB=2a$，如果动点 $P$ 到点 $A$ 的距离和到点 $B$ 的距离之比为 $2:1$，求点 $P$ 的轨迹方程，并说明它表示什么曲线。

**8．** 求 $\tan 9^\circ+\cot 117^\circ-\tan 243^\circ-\cot 351^\circ$ 的值。

**9．** 如图，已知 $\triangle AOB$ 中，$OA=b$，$OB=a$，$\angle AOB=\theta$（$a\ge b$，$\theta$ 是锐角）。作 $AB_1\perp OB$，$B_1A_1\parallel BA$；再作 $A_1B_2\perp OB$，$B_2A_2\parallel BA$；如此无限连续作下去。设 $\triangle ABB_1$，$\triangle A_1B_1B_2$，$\cdots$ 的面积分别为 $S_1$，$S_2$，$\cdots$，求无穷数列 $S_1$，$S_2$，$\cdots$ 的和。
