(1) 证明：设 $A(x_1, y_1), B(x_2, y_2)$。由点在椭圆上 $\dfrac{x_1^2}{4} + \dfrac{y_1^2}{3} = 1$，$\dfrac{x_2^2}{4} + \dfrac{y_2^2}{3} = 1$，两式相减得 $\dfrac{(x_1-x_2)(x_1+x_2)}{4} + \dfrac{(y_1-y_2)(y_1+y_2)}{3} = 0$。由中点 $M(1, m)$ 知 $x_1+x_2 = 2$，$y_1+y_2 = 2m$。又 $k = \dfrac{y_1-y_2}{x_1-x_2}$，代入得 $\dfrac{2}{4} + \dfrac{2km}{3} = 0 \implies k = -\dfrac{3}{4m}$。因为中点 $M(1, m)$ 在椭圆内部，所以 $\dfrac{1}{4} + \dfrac{m^2}{3} < 1 \implies m^2 < \dfrac94$。又 $m > 0$，所以 $0 < m < \dfrac32$。因此 $k = -\dfrac{3}{4m} < -\dfrac{3}{4 \times \frac32} = -\dfrac12$。
(2) 证明：右焦点 $F(1, 0)$。由 $\vec{FP} + \vec{FA} + \vec{FB} = \vec{0}$ 得 $\vec{FA} + \vec{FB} = -\vec{FP}$。设 $P(x_0, y_0)$，则 $\vec{FA} + \vec{FB} = (x_1+x_2-2, y_1+y_2) = (0, 2m)$，故 $\vec{FP} = (x_0-1, y_0) = (0, -2m) \implies x_0 = 1, y_0 = -2m$。代入椭圆方程 $\dfrac{1}{4} + \dfrac{4m^2}{3} = 1 \implies m = \dfrac34$。由焦半径公式，对于右焦点 $F(1, 0)$，椭圆上任意点 $(x, y)$ 到 $F$ 的距离为 $a - ex = 2 - \dfrac12 x$。因此 $|\vec{FP}| = 2 - \dfrac12 \times 1 = \dfrac32 \implies 2|\vec{FP}| = 3$；$|\vec{FA}| + |\vec{FB}| = (2 - \dfrac12 x_1) + (2 - \dfrac12 x_2) = 4 - \dfrac12(x_1+x_2) = 4 - \dfrac12 \times 2 = 3$。所以 $2|\vec{FP}| = |\vec{FA}| + |\vec{FB}|$。

21.
(1) $f'(x) = \dfrac{-ax^2 + (2a-1)x + 2}{\mathrm e^x}$。在 $x=0$ 处，$f'(0) = 2$。切线方程为 $y - (-1) = 2(x - 0)$，即 $y = 2x - 1$（或 $2x - y - 1 = 0$）。
(2) 证明：当 $a \geqslant 1$ 时，$ax^2 + x - 1 \geqslant x^2 + x - 1$，故 $f(x) \geqslant \dfrac{x^2+x-1}{\mathrm e^x}$。设 $g(x) = \dfrac{x^2+x-1}{\mathrm e^x}$，则 $g'(x) = -\dfrac{(x-2)(x+1)}{\mathrm e^x}$。当 $x \in (-\infty, -1)$ 时 $g'(x) < 0$；当 $x \in (-1, 2)$ 时 $g'(x) > 0$；当 $x \in (2, +\infty)$ 时 $g'(x) < 0$。且当 $x \to +\infty$ 时 $g(x) \to 0$；当 $x \to -\infty$ 时 $g(x) \to +\infty$。因此 $g(x)$ 在 $x = -1$ 处取得极小值也是最小值，最小值为 $g(-1) = \dfrac{1-1-1}{\mathrm e^{-1}} = -\mathrm e$。从而对任意 $x \in \mathbb R$ 均有 $f(x) \geqslant g(x) \geqslant -\mathrm e$，即 $f(x) + \mathrm e \geqslant 0$ 得证。

23.
(1) 分段解析式为 $f(x) = \begin{cases} -3x, & x < -\dfrac12, \\ x + 2, & -\dfrac12 \leqslant x \leqslant 1, \\ 3x, & x > 1。 \end{cases}$ 图象为连接点 $\left(-\dfrac12, \dfrac32\right)$、$(1, 3)$ 的折线。
(2) 当 $x \in [0, 1]$ 时 $f(x) = x + 2$；当 $x > 1$ 时 $f(x) = 3x$。当 $x = 0$ 时，$b \geqslant f(0) = 2$；当 $x \to +\infty$ 时，$ax + b \geqslant 3x \implies a \geqslant 3$。所以 $a + b \geqslant 3 + 2 = 5$。当 $a = 3, b = 2$ 时，直线为 $y = 3x + 2$，当 $x \in [0, 1]$ 时 $3x+2 \geqslant x+2 \iff 2x \geqslant 0$ 恒成立；当 $x > 1$ 时 $3x+2 > 3x$ 恒成立，符合题意。因此 $a + b$ 的最小值为 $5$。
