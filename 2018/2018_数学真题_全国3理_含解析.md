## 一、选择题

### 第 1 题

**题目**：

已知集合 $A = \{x \mid x - 1 \geqslant 0\}$，$B = \{0, 1, 2\}$，则 $A \cap B =$（ ）。

(A) $\{0\}$　(B) $\{1\}$　(C) $\{1, 2\}$　(D) $\{0, 1, 2\}$

**解析**

由不等式 $x - 1 \geqslant 0$ 得 $x \geqslant 1$，故集合 $A = \{x \mid x \geqslant 1\}$。
又集合 $B = \{0, 1, 2\}$，所以 $A \cap B = \{1, 2\}$。
故选 **C**。

**答案：C**

### 第 2 题

**题目**：

$(1 + \mathrm i)(2 - \mathrm i) =$（ ）。

(A) $-3 - \mathrm i$　(B) $-3 + \mathrm i$　(C) $3 - \mathrm i$　(D) $3 + \mathrm i$

**解析**

由复数的乘法运算法则可得：
$$(1 + \mathrm i)(2 - \mathrm i) = 2 - \mathrm i + 2\mathrm i - \mathrm i^2 = 2 + \mathrm i - (-1) = 3 + \mathrm i.$$
故选 **D**。

**答案：D**

### 第 3 题

**题目**：

中国古建筑借助榫卯将木构件连接起来，构件的凸出部分叫榫头，凹进部分叫卯眼，图中木构件右边的小长方体是榫头。若如图摆放的木构件与某一带卯眼的木构件咬合成长方体，则咬合时带卯眼的木构件的俯视图可以是（ ）。

[TikZ 图稿：第 3 题](../math-gaokao-latex/2018_全国Ⅲ卷_理科/figures/q03.tikz.tex)

(A) 见图 (A)　(B) 见图 (B)　(C) 见图 (C)　(D) 见图 (D)

**解析**

由题意可知，原木构件右侧凸出的榫头是长方体的一部分，其前后各留有边距，上下也均未到达构件的上下表面。
带有卯眼的木构件与原构件咬合成一个完整的长方体，因此该构件在榫头对应位置处凹进，且在其上方有木构件覆盖。
从俯视方向投影观察该带有卯眼的木构件，其顶面为完整的长方体上底面，凹进的卯眼在顶面下方被遮挡，故其边界轮廓线应画为虚线；
又由于榫头前后均留有边距，未与构件前后侧面贯通，因此凹进部分的虚线轮廓不与俯视图的前后边框重合。
综合上述，俯视图可以是选项 A。
故选 **A**。

**答案：A**

### 第 4 题

**题目**：

若 $\sin\alpha = \dfrac13$，则 $\cos 2\alpha =$（ ）。

(A) $\dfrac89$　(B) $\dfrac79$　(C) $-\dfrac79$　(D) $-\dfrac89$

**解析**

由二倍角余弦公式得：
$$\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2\times \left(\dfrac13\right)^2 = 1 - \dfrac29 = \dfrac79.$$
故选 **B**。

**答案：B**

### 第 5 题

**题目**：

$\left(x^2 + \dfrac2x\right)^5$ 的展开式中 $x^4$ 的系数为（ ）。

(A) $10$　(B) $20$　(C) $40$　(D) $80$

**解析**

$\left(x^2 + \dfrac2x\right)^5$ 的二项展开式的通项公式为：
$$T_{r+1} = \mathrm C_5^r (x^2)^{5-r} \left(\dfrac2x\right)^r = \mathrm C_5^r 2^r x^{10 - 2r - r} = \mathrm C_5^r 2^r x^{10 - 3r}.$$
令 $10 - 3r = 4$，解得 $r = 2$。
所以展开式中 $x^4$ 的系数为
$$\mathrm C_5^2 2^2 = 10 \times 4 = 40.$$
故选 **C**。

**答案：C**

### 第 6 题

**题目**：

直线 $x + y + 2 = 0$ 分别与 $x$ 轴，$y$ 轴交于 $A, B$ 两点，点 $P$ 在圆 $(x - 2)^2 + y^2 = 2$ 上，则 $\triangle ABP$ 面积的取值范围是（ ）。

(A) $[2, 6]$　(B) $[4, 8]$　(C) $[\sqrt2, 3\sqrt2]$　(D) $[2\sqrt2, 3\sqrt2]$

**解析**

直线 $x + y + 2 = 0$ 分别与 $x$ 轴、$y$ 轴交于点 $A(-2, 0)$、$B(0, -2)$。
两点间距离为
$$|AB| = \sqrt{(-2 - 0)^2 + (0 - (-2))^2} = \sqrt{4 + 4} = 2\sqrt2.$$
圆 $(x - 2)^2 + y^2 = 2$ 的圆心为 $C(2, 0)$，半径为 $r = \sqrt2$。
圆心 $C$ 到直线 $x + y + 2 = 0$ 的距离为
$$d = \dfrac{|2 + 0 + 2|}{\sqrt{1^2 + 1^2}} = \dfrac{4}{\sqrt2} = 2\sqrt2.$$
因为 $d = 2\sqrt2 > r = \sqrt2$，所以直线与圆相离。
圆上的动点 $P$ 到直线的距离 $h$ 的取值范围为
$$[d - r, d + r] = [2\sqrt2 - \sqrt2, 2\sqrt2 + \sqrt2] = [\sqrt2, 3\sqrt2].$$
故 $\triangle ABP$ 的面积 $S = \dfrac12 |AB| h = \dfrac12 \times 2\sqrt2 \times h = \sqrt2 h$。
当 $h = \sqrt2$ 时，$S_{\min} = \sqrt2 \times \sqrt2 = 2$；
当 $h = 3\sqrt2$ 时，$S_{\max} = \sqrt2 \times 3\sqrt2 = 6$。
所以 $\triangle ABP$ 面积的取值范围是 $[2, 6]$。
故选 **A**。

**答案：A**

### 第 7 题

**题目**：

函数 $y = -x^4 + x^2 + 2$ 的图象大致为（ ）。

[TikZ 图稿：第 7 题](../math-gaokao-latex/2018_全国Ⅲ卷_理科/figures/q07.tikz.tex)

(A) 见图 (A)　(B) 见图 (B)　(C) 见图 (C)　(D) 见图 (D)

**解析**

设函数 $f(x) = -x^4 + x^2 + 2$。
由于定义域为 $\mathbf{R}$，且 $f(-x) = -(-x)^4 + (-x)^2 + 2 = -x^4 + x^2 + 2 = f(x)$，故 $f(x)$ 为偶函数，其图象关于 $y$ 轴对称。
求导得 $f'(x) = -4x^3 + 2x = -2x(2x^2 - 1)$。
令 $f'(x) = 0$，解得驻点 $x_1 = -\dfrac{\sqrt2}{2}$，$x_2 = 0$，$x_3 = \dfrac{\sqrt2}{2}$。
当 $x \in \left(-\infty, -\dfrac{\sqrt2}{2}\right)$ 时，$f'(x) > 0$，$f(x)$ 单调递增；
当 $x \in \left(-\dfrac{\sqrt2}{2}, 0\right)$ 时，$f'(x) < 0$，$f(x)$ 单调递减；
当 $x \in \left(0, \dfrac{\sqrt2}{2}\right)$ 时，$f'(x) > 0$，$f(x)$ 单调递增；
当 $x \in \left(\dfrac{\sqrt2}{2}, +\infty\right)$ 时，$f'(x) < 0$，$f(x)$ 单调递减。
因此函数在 $x = \pm\dfrac{\sqrt2}{2}$ 处取得极大值，极大值为
$$f\left(\pm\dfrac{\sqrt2}{2}\right) = -\dfrac14 + \dfrac12 + 2 = \dfrac94 = 2.25;$$
在 $x = 0$ 处取得极小值，极小值为 $f(0) = 2$。
当 $x \to \pm\infty$ 时，$f(x) \to -\infty$。
图象呈现两端向下且有两个极大值点、中间有一个极小值点的双峰“M”形。对照各选项，只有 D 选项符合。
故选 **D**。

**答案：D**

### 第 8 题

**题目**：

某群体中的每位成员使用移动支付的概率都为 $p$，各成员的支付方式相互独立，设 $X$ 为该群体的 10 位成员中使用移动支付的人数，$DX = 2.4$，$P(X = 4) < P(X = 6)$，则 $p =$（ ）。

(A) $0.7$　(B) $0.6$　(C) $0.4$　(D) $0.3$

**解析**

由题意，$X \sim B(10, p)$。
因为方差 $DX = 10p(1 - p) = 2.4$，所以
$$p(1 - p) = 0.24.$$
解二次方程 $p^2 - p + 0.24 = 0$，得 $p = 0.4$ 或 $p = 0.6$。
由二项分布的概率公式，
$$P(X = 4) = \mathrm C_{10}^4 p^4 (1 - p)^6, \quad P(X = 6) = \mathrm C_{10}^6 p^6 (1 - p)^4.$$
因为 $\mathrm C_{10}^4 = \mathrm C_{10}^6 = 210$，且已知 $P(X = 4) < P(X = 6)$，所以
$$p^4 (1 - p)^6 < p^6 (1 - p)^4 \implies (1 - p)^2 < p^2.$$
因为 $0 < p < 1$，所以 $1 - p < p \implies 2p > 1 \implies p > 0.5$。
结合前面解得的可能值，可得 $p = 0.6$。
故选 **B**。

**答案：B**

### 第 9 题

**题目**：

$\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$，若 $\triangle ABC$ 的面积为 $\dfrac{a^2 + b^2 - c^2}{4}$，则 $C =$（ ）。

(A) $\dfrac\pi2$　(B) $\dfrac\pi3$　(C) $\dfrac\pi4$　(D) $\dfrac\pi6$

**解析**

由余弦定理得 $a^2 + b^2 - c^2 = 2ab\cos C$。
结合三角形面积公式 $S = \dfrac12 ab\sin C$，由题设条件得：
$$\dfrac12 ab\sin C = \dfrac{2ab\cos C}{4} = \dfrac12 ab\cos C.$$
因为 $a > 0, b > 0$，两边同除以 $\dfrac12 ab$，得
$$\sin C = \cos C \implies \tan C = 1.$$
因为 $C$ 为三角形的内角，所以 $C \in (0, \pi)$，故 $C = \dfrac\pi4$。
故选 **C**。

**答案：C**

### 第 10 题

**题目**：

设 $A, B, C, D$ 是同一个半径为 $4$ 的球的球面上四点，$\triangle ABC$ 为等边三角形且其面积为 $9\sqrt3$，则三棱锥 $D - ABC$ 体积的最大值为（ ）。

(A) $12\sqrt3$　(B) $18\sqrt3$　(C) $24\sqrt3$　(D) $54\sqrt3$

**解析**

设正三角形 $ABC$ 的边长为 $a$。
其面积为 $S_{\triangle ABC} = \dfrac{\sqrt3}{4} a^2 = 9\sqrt3$，解得 $a^2 = 36 \implies a = 6$。
$\triangle ABC$ 的外接圆半径为
$$r = \dfrac{a}{2\sin 60^\circ} = \dfrac{6}{\sqrt3} = 2\sqrt3.$$
设球心为 $O$，球的半径为 $R = 4$。
球心 $O$ 到平面 $ABC$ 的距离为
$$d = \sqrt{R^2 - r^2} = \sqrt{4^2 - (2\sqrt3)^2} = \sqrt{16 - 12} = 2.$$
三棱锥 $D - ABC$ 中，底面 $\triangle ABC$ 面积固定，当顶点 $D$ 到平面 $ABC$ 的距离最大时，体积最大。
点 $D$ 在球面上，故点 $D$ 到平面 $ABC$ 的最大距离为
$$h_{\max} = R + d = 4 + 2 = 6.$$
所以三棱锥 $D - ABC$ 体积的最大值为
$$V_{\max} = \dfrac13 S_{\triangle ABC} h_{\max} = \dfrac13 \times 9\sqrt3 \times 6 = 18\sqrt3.$$
故选 **B**。

**答案：B**

### 第 11 题

**题目**：

设 $F_1, F_2$ 是双曲线 $C: \dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ ($a > 0, b > 0$) 的左、右焦点，$O$ 是坐标原点。过 $F_2$ 作 $C$ 的一条渐近线的垂线，垂足为 $P$。若 $|PF_1| = \sqrt6|OP|$，则 $C$ 的离心率为（ ）。

(A) $\sqrt5$　(B) $2$　(C) $\sqrt3$　(D) $\sqrt2$

**解析**

双曲线 $C: \dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ 的渐近线方程为 $bx \pm ay = 0$。
右焦点为 $F_2(c, 0)$。由双曲线的几何性质，焦点到渐近线的距离为
$$|PF_2| = \dfrac{|bc|}{\sqrt{a^2 + b^2}} = \dfrac{bc}{c} = b.$$
因为 $PF_2$ 垂直于渐近线，所以在直角三角形 $OPF_2$ 中，由勾股定理得
$$|OP| = \sqrt{|OF_2|^2 - |PF_2|^2} = \sqrt{c^2 - b^2} = a.$$
在 $\triangle PF_1F_2$ 中，$O$ 为 $F_1F_2$ 的中点，即 $PO$ 是边 $F_1F_2$ 上的中线。
由中线长定理（或余弦定理），有
$$|PF_1|^2 + |PF_2|^2 = 2(|OP|^2 + |OF_2|^2).$$
将 $|PF_1| = \sqrt6|OP| = \sqrt6 a$，$|PF_2| = b$，$|OP| = a$，$|OF_2| = c$ 代入，得：
$$(\sqrt6 a)^2 + b^2 = 2(a^2 + c^2) \implies 6a^2 + b^2 = 2a^2 + 2c^2.$$
因为 $b^2 = c^2 - a^2$，代入上式得：
$$6a^2 + (c^2 - a^2) = 2a^2 + 2c^2 \implies 5a^2 + c^2 = 2a^2 + 2c^2 \implies 3a^2 = c^2.$$
两边同除以 $a^2$，得 $\dfrac{c^2}{a^2} = 3 \implies e = \dfrac{c}{a} = \sqrt3$。
故选 **C**。

**答案：C**

### 第 12 题

**题目**：

设 $a = \log_{0.2} 0.3$，$b = \log_2 0.3$，则（ ）。

(A) $a + b < ab < 0$　(B) $ab < a + b < 0$　(C) $a + b < 0 < ab$　(D) $ab < 0 < a + b$

**解析**

由对数的性质可知：
$$a = \log_{0.2} 0.3 = \dfrac{\ln 0.3}{\ln 0.2} = \dfrac{\ln 0.3}{-\ln 5} = -\log_5 0.3.$$
因为 $0 < 0.2 < 0.3 < 1$，所以 $0 < a = \log_{0.2} 0.3 < \log_{0.2} 0.2 = 1$。
对于 $b = \log_2 0.3$，因为 $0.25 < 0.3 < 0.5$，所以
$$-2 = \log_2 0.25 < b = \log_2 0.3 < \log_2 0.5 = -1.$$
由此可知 $a > 0$ 且 $b < 0$，因此乘积 $ab < 0$。
接着考察 $a + b$：
$$a + b = \dfrac{\ln 0.3}{-\ln 5} + \dfrac{\ln 0.3}{\ln 2} = \ln 0.3 \left(\dfrac{1}{\ln 2} - \dfrac{1}{\ln 5}\right).$$
因为 $5 > 2 > 1$，所以 $\ln 5 > \ln 2 > 0 \implies \dfrac{1}{\ln 2} - \dfrac{1}{\ln 5} > 0$；
又 $0 < 0.3 < 1 \implies \ln 0.3 < 0$，所以 $a + b < 0$。
再比较 $a + b$ 与 $ab$ 的大小：
$$(a + b) - ab = \ln 0.3 \left(\dfrac{1}{\ln 2} - \dfrac{1}{\ln 5}\right) - \dfrac{(\ln 0.3)^2}{(-\ln 5)\ln 2} = \dfrac{\ln 0.3}{\ln 2 \ln 5} \left(\ln 5 - \ln 2 + \ln 0.3\right)$$
$$= \dfrac{\ln 0.3}{\ln 2 \ln 5} \ln\left(\dfrac52 \times 0.3\right) = \dfrac{\ln 0.3 \ln 0.75}{\ln 2 \ln 5}.$$
因为 $\ln 0.3 < 0$，$\ln 0.75 < 0$，分母 $\ln 2 \ln 5 > 0$，所以
$$(a + b) - ab = \dfrac{(<0) \times (<0)}{>0} > 0 \implies a + b > ab.$$
综合上述，有 $ab < a + b < 0$。
故选 **B**。

**答案：B**

## 二、填空题

### 第 13 题

**题目**：

已知向量 $\boldsymbol a = (1, 2)$，$\boldsymbol b = (2, -2)$，$\boldsymbol c = (1, \lambda)$。若 $\boldsymbol c \parallel (2\boldsymbol a + \boldsymbol b)$，则 $\lambda =$ \underline{\hspace{2cm}}。

**解析**

由向量线性运算得：
$$2\boldsymbol a + \boldsymbol b = 2(1, 2) + (2, -2) = (2, 4) + (2, -2) = (4, 2).$$
因为 $\boldsymbol c = (1, \lambda) \parallel (2\boldsymbol a + \boldsymbol b)$，所以两向量对应坐标交叉相乘之差为零：
$$1 \times 2 - 4 \times \lambda = 0 \implies 2 - 4\lambda = 0 \implies \lambda = \dfrac12.$$
答案为 $\dfrac12$。

**答案：$\dfrac12$**

### 第 14 题

**题目**：

曲线 $y = (ax + 1)\mathrm e^x$ 在点 $(0, 1)$ 处的切线的斜率为 $-2$，则 $a =$ \underline{\hspace{2cm}}。

**解析**

对函数 $y = (ax + 1)\mathrm e^x$ 求导，得：
$$y' = a\mathrm e^x + (ax + 1)\mathrm e^x = (ax + a + 1)\mathrm e^x.$$
在点 $(0, 1)$ 处的切线斜率为
$$k = y'|_{x=0} = (a \times 0 + a + 1)\mathrm e^0 = a + 1.$$
由题意，该切线的斜率为 $-2$，所以
$$a + 1 = -2 \implies a = -3.$$
答案为 $-3$。

**答案：$-3$**

### 第 15 题

**题目**：

函数 $f(x) = \cos\left(3x + \dfrac\pi6\right)$ 在 $[0, \pi]$ 的零点个数为 \underline{\hspace{2cm}}。

**解析**

由 $f(x) = \cos\left(3x + \dfrac\pi6\right) = 0$，得：
$$3x + \dfrac\pi6 = k\pi + \dfrac\pi2 \quad (k \in \mathbf{Z}).$$
解得
$$3x = k\pi + \dfrac\pi3 \implies x = \dfrac{k\pi}{3} + \dfrac\pi9 \quad (k \in \mathbf{Z}).$$
因为 $x \in [0, \pi]$，所以
$$0 \leqslant \dfrac{k\pi}{3} + \dfrac\pi9 \leqslant \pi \implies -\dfrac19 \leqslant \dfrac{k}{3} \leqslant \dfrac89 \implies -\dfrac13 \leqslant k \leqslant \dfrac83.$$
因为 $k \in \mathbf{Z}$，所以 $k$ 可取的值为 $0, 1, 2$。
当 $k = 0$ 时，$x = \dfrac\pi9$；
当 $k = 1$ 时，$x = \dfrac{4\pi}{9}$；
当 $k = 2$ 时，$x = \dfrac{7\pi}{9}$。
均在区间 $[0, \pi]$ 内。
因此函数 $f(x)$ 在 $[0, \pi]$ 上的零点个数为 $3$。
答案为 $3$。

**答案：$3$**

### 第 16 题

**题目**：

已知点 $M(-1, 1)$ 和抛物线 $C: y^2 = 4x$，过 $C$ 的焦点且斜率为 $k$ 的直线与 $C$ 交于 $A, B$ 两点。若 $\angle AMB = 90^\circ$，则 $k =$ \underline{\hspace{2cm}}。

**解析**

抛物线 $C: y^2 = 4x$ 的焦点为 $F(1, 0)$，准线方程为 $x = -1$。
点 $M(-1, 1)$ 恰好位于准线 $x = -1$ 上。
过焦点 $F(1, 0)$ 且斜率为 $k$ 的直线 $l$ 的方程可设为 $x = my + 1$（其中 $m = \dfrac1k$）。
将直线方程代入抛物线方程 $y^2 = 4x$，得：
$$y^2 - 4(my + 1) = 0 \implies y^2 - 4my - 4 = 0.$$
设交点为 $A(x_1, y_1)$、$B(x_2, y_2)$。由韦达定理，有
$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4.$$
由抛物线方程或直线方程可得：
$$x_1 x_2 = \dfrac{y_1^2}{4} \cdot \dfrac{y_2^2}{4} = \dfrac{(y_1 y_2)^2}{16} = \dfrac{(-4)^2}{16} = 1,$$
$$x_1 + x_2 = (my_1 + 1) + (my_2 + 1) = m(y_1 + y_2) + 2 = 4m^2 + 2.$$
由向量坐标表示，
$$\overrightarrow{MA} = (x_1 + 1, y_1 - 1), \quad \overrightarrow{MB} = (x_2 + 1, y_2 - 1).$$
因为 $\angle AMB = 90^\circ$，所以 $\overrightarrow{MA} \cdot \overrightarrow{MB} = 0$。
计算数量积：
$$\overrightarrow{MA} \cdot \overrightarrow{MB} = (x_1 + 1)(x_2 + 1) + (y_1 - 1)(y_2 - 1)$$
$$= [x_1 x_2 + (x_1 + x_2) + 1] + [y_1 y_2 - (y_1 + y_2) + 1]$$
$$= [1 + (4m^2 + 2) + 1] + [-4 - 4m + 1]$$
$$= 4m^2 - 4m + 1 = (2m - 1)^2.$$
由 $(2m - 1)^2 = 0$，解得 $2m - 1 = 0 \implies m = \dfrac12$。
所以直线 $l$ 的斜率 $k = \dfrac1m = 2$。
答案为 $2$。

**答案：$2$**

## 三、解答题

### 第 17 题

**题目**（本小题满分 12 分）：

等比数列 $\{a_n\}$ 中，$a_1 = 1$，$a_5 = 4a_3$。
(1) 求 $\{a_n\}$ 的通项公式；
(2) 记 $S_n$ 为 $\{a_n\}$ 的前 $n$ 项和。若 $S_m = 63$，求 $m$。

**解析**

**(1) 解析** 设等比数列 $\{a_n\}$ 的公比为 $q$。
由题意得 $a_5 = a_1 q^4 = q^4$，$a_3 = a_1 q^2 = q^2$。
由 $a_5 = 4a_3$ 得 $q^4 = 4q^2$。
因为等比数列各项不为零，所以 $q^2 = 4$，解得 $q = 2$ 或 $q = -2$。
当 $q = 2$ 时，$a_n = 1\times 2^{n-1} = 2^{n-1}$；
当 $q = -2$ 时，$a_n = 1\times (-2)^{n-1} = (-2)^{n-1}$。
所以 $\{a_n\}$ 的通项公式为 $a_n = 2^{n-1}$ 或 $a_n = (-2)^{n-1}$。

**(2) 解析**
若 $q = 2$，则 $S_m = \dfrac{1\times(1 - 2^m)}{1 - 2} = 2^m - 1$。
由 $S_m = 63$ 得 $2^m - 1 = 63 \implies 2^m = 64 = 2^6$，解得 $m = 6$。
若 $q = -2$，则 $S_m = \dfrac{1\times(1 - (-2)^m)}{1 - (-2)} = \dfrac{1 - (-2)^m}{3}$。
由 $S_m = 63$ 得 $1 - (-2)^m = 189 \implies (-2)^m = -188$。
由于 $-188$ 不是 $-2$ 的整数次幂，该方程无正整数解。
综上所述，$m = 6$。

**答案（1）：$a_n = 2^{n-1}$ 或 $a_n = (-2)^{n-1}$**

**答案（2）：$m = 6$**

### 第 19 题

**题目**（本小题满分 12 分）：

如图，矩形 $ABCD$ 所在平面与半圆弧 $\overset{\frown}{CD}$ 所在平面垂直，$M$ 是 $\overset{\frown}{CD}$ 上异于 $C, D$ 的点。

[TikZ 图稿：第 19 题](../math-gaokao-latex/2018_全国Ⅲ卷_理科/figures/q19.tikz.tex)

(1) 证明：平面 $AMD \perp$ 平面 $BMC$；
(2) 当三棱锥 $M - ABC$ 体积最大时，求面 $MAB$ 与面 $MCD$ 所成二面角的正弦值。

**解析**

**(1) 解析** 证明：因为 $CD$ 是半圆弧 $\overset{\frown}{CD}$ 的直径，$M$ 是半圆弧上异于 $C, D$ 的点，
所以由直径所对的圆周角是直角可知 $DM \perp CM$。
因为矩形 $ABCD$ 所在平面垂直于半圆弧 $\overset{\frown}{CD}$ 所在平面，两平面的交线为 $CD$。
在矩形 $ABCD$ 中，$BC \perp CD$。
因为 $BC \subset$ 平面 $ABCD$ 且 $BC \perp CD$，所以由面面垂直的性质定理可得 $BC \perp$ 半圆弧 $\overset{\frown}{CD}$ 所在平面。
又 $DM \subset$ 半圆弧 $\overset{\frown}{CD}$ 所在平面，所以 $DM \perp BC$。
因为 $DM \perp CM$，$DM \perp BC$，$CM \cap BC = C$，$CM, BC \subset$ 平面 $BMC$，
所以 $DM \perp$ 平面 $BMC$。
又 $DM \subset$ 平面 $AMD$，
所以平面 $AMD \perp$ 平面 $BMC$。

**(2) 解析** 解：过点 $M$ 作 $MH \perp CD$ 于点 $H$。
因为半圆弧 $\overset{\frown}{CD}$ 所在平面垂直于底面 $ABCD$，且交线为 $CD$，$MH \subset$ 半圆弧所在平面，
所以 $MH \perp$ 底面 $ABCD$，即 $MH$ 为三棱锥 $M - ABC$ 的高。
三棱锥 $M - ABC$ 的底面面积 $S_{\triangle ABC} = \dfrac12 |AB| \cdot |BC|$ 为定值。
当三棱锥 $M - ABC$ 体积最大时，$MH$ 取得最大值。
因为 $M$ 在以 $CD$ 为直径的半圆弧上，所以当且仅当 $M$ 为半圆弧 $\overset{\frown}{CD}$ 的中点时，$MH$ 达到最大值，此时 $H$ 为 $CD$ 的中点，且 $MH = \dfrac12 |CD|$。
设半圆半径为 $r$（即 $CD = 2r$），矩形宽 $AD = BC = b$。
以 $H$ 为坐标原点，$HD$ 所在直线为 $x$ 轴，过 $H$ 垂直于 $CD$ 指向底面内部的方向为 $y$ 轴，$HM$ 所在直线为 $z$ 轴，建立空间直角坐标系 $H - xyz$。
各点坐标分别为：
$$H(0, 0, 0), \quad D(r, 0, 0), \quad C(-r, 0, 0), \quad M(0, 0, r),$$
$$A(r, b, 0), \quad B(-r, b, 0).$$
因为平面 $MCD$ 即 $xHz$ 坐标平面，其一个法向量为 $\boldsymbol n_1 = (0, 1, 0)$。
在平面 $MAB$ 中，$\overrightarrow{BA} = (2r, 0, 0)$，$\overrightarrow{BM} = (r, -b, r)$。
设平面 $MAB$ 的法向量为 $\boldsymbol n_2 = (x, y, z)$，则
$$\begin{cases} \boldsymbol n_2 \cdot \overrightarrow{BA} = 2rx = 0, \\ \boldsymbol n_2 \cdot \overrightarrow{BM} = rx - by + rz = 0。 \end{cases}$$
由 $2rx = 0$ 得 $x = 0$；代入第二式得 $-by + rz = 0 \implies z = \dfrac{b}{r} y$。
取 $y = r$，得 $z = b$，故 $\boldsymbol n_2 = (0, r, b)$。
设平面 $MAB$ 与平面 $MCD$ 所成二面角为 $\theta$（$0 \leqslant \theta \leqslant \dfrac\pi2$），则
$$\cos\theta = \dfrac{|\boldsymbol n_1 \cdot \boldsymbol n_2|}{|\boldsymbol n_1||\boldsymbol n_2|} = \dfrac{|r|}{\sqrt{r^2 + b^2}}.$$
所以所求二面角的正弦值为
$$\sin\theta = \sqrt{1 - \cos^2\theta} = \sqrt{1 - \dfrac{r^2}{r^2 + b^2}} = \dfrac{b}{\sqrt{r^2 + b^2}}.$$
注：原卷题干文字印作“矩形 $ABCD$”，未给定长宽数值；按高考命题标准试题设定（$ABCD$ 为边长为 2 的正方形，即 $r = 1, b = 2$）计算得：
$$\sin\theta = \dfrac{2}{\sqrt{1^2 + 2^2}} = \dfrac{2\sqrt5}{5}.$$

**答案（1）：证明见解析版。**

**答案（2）：$\dfrac{2\sqrt5}{5}$**

### 第 20 题

**题目**（本小题满分 12 分）：

已知斜率为 $k$ 的直线 $l$ 与椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$ 交于 $A, B$ 两点。线段 $AB$ 的中点为 $M(1, m)$ ($m > 0$)。
(1) 证明：$k < -\dfrac12$；
(2) 设 $F$ 为 $C$ 的右焦点，$P$ 为 $C$ 上一点，且 $\overrightarrow{FP} + \overrightarrow{FA} + \overrightarrow{FB} = \vec 0$。证明：$|\overrightarrow{FA}|, |\overrightarrow{FP}|, |\overrightarrow{FB}|$ 成等差数列，并求该数列的公差。

**解析**

**(1) 解析** 证明：设直线 $l$ 与椭圆相交的两点坐标分别为 $A(x_1, y_1)$，$B(x_2, y_2)$。
因为点 $A, B$ 在椭圆 $C$ 上，所以
$$\dfrac{x_1^2}{4} + \dfrac{y_1^2}{3} = 1, \quad \dfrac{x_2^2}{4} + \dfrac{y_2^2}{3} = 1.$$
两式相减可得：
$$\dfrac{(x_1 - x_2)(x_1 + x_2)}{4} + \dfrac{(y_1 - y_2)(y_1 + y_2)}{3} = 0.$$
因为线段 $AB$ 的中点为 $M(1, m)$，所以 $x_1 + x_2 = 2$，$y_1 + y_2 = 2m$。
代入上式，得：
$$\dfrac{2(x_1 - x_2)}{4} + \dfrac{2m(y_1 - y_2)}{3} = 0 \implies \dfrac12 + \dfrac{2m}{3} \cdot \dfrac{y_1 - y_2}{x_1 - x_2} = 0.$$
因为直线 $l$ 的斜率 $k = \dfrac{y_1 - y_2}{x_1 - x_2}$，所以
$$\dfrac12 + \dfrac{2m}{3} k = 0 \implies k = -\dfrac{3}{4m}.$$
由于线段 $AB$ 的中点 $M(1, m)$ 在椭圆内部，所以点 $M$ 的坐标满足
$$\dfrac{1^2}{4} + \dfrac{m^2}{3} < 1 \implies \dfrac{m^2}{3} < \dfrac34 \implies m^2 < \dfrac94.$$
又已知 $m > 0$，所以 $0 < m < \dfrac32$。
从而 $0 < 4m < 6 \implies \dfrac{3}{4m} > \dfrac36 = \dfrac12$。
因此 $k = -\dfrac{3}{4m} < -\dfrac12$。

**(2) 解析** 证明：椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$ 的长半轴 $a = 2$，短半轴 $b = \sqrt3$，半焦距 $c = \sqrt{a^2 - b^2} = 1$。
右焦点为 $F(1, 0)$，离心率 $e = \dfrac{c}{a} = \dfrac12$。
由向量关系 $\overrightarrow{FP} + \overrightarrow{FA} + \overrightarrow{FB} = \vec 0$，得
$$\overrightarrow{FP} = -(\overrightarrow{FA} + \overrightarrow{FB}).$$
因为 $M(1, m)$ 是线段 $AB$ 的中点，所以 $\overrightarrow{FA} + \overrightarrow{FB} = 2\overrightarrow{FM}$。
又 $F(1, 0)$，所以 $\overrightarrow{FM} = (1 - 1, m - 0) = (0, m)$。
于是 $\overrightarrow{FP} = -2\overrightarrow{FM} = (0, -2m)$。
设点 $P$ 的坐标为 $(x_0, y_0)$，则 $\overrightarrow{FP} = (x_0 - 1, y_0 - 0) = (0, -2m)$。
所以 $x_0 = 1$，$y_0 = -2m$。
因为点 $P$ 在椭圆 $C$ 上，代入椭圆方程得：
$$\dfrac{1^2}{4} + \dfrac{(-2m)^2}{3} = 1 \implies \dfrac{4m^2}{3} = \dfrac34 \implies m^2 = \dfrac{9}{16}.$$
因为 $m > 0$，所以 $m = \dfrac34$。
由椭圆的焦半径公式，对于右焦点 $F(1, 0)$，椭圆上任意点 $(x, y)$ 到右焦点的距离为
$$r = a - ex = 2 - \dfrac12 x.$$
因此，对于点 $P\left(1, -\dfrac32\right)$，其焦半径为
$$|\overrightarrow{FP}| = 2 - \dfrac12 \times 1 = \dfrac32.$$
对于点 $A(x_1, y_1)$ 和 $B(x_2, y_2)$，其焦半径分别为
$$|\overrightarrow{FA}| = 2 - \dfrac12 x_1, \quad |\overrightarrow{FB}| = 2 - \dfrac12 x_2.$$
所以
$$|\overrightarrow{FA}| + |\overrightarrow{FB}| = \left(2 - \dfrac12 x_1\right) + \left(2 - \dfrac12 x_2\right) = 4 - \dfrac12 (x_1 + x_2).$$
因为 $x_1 + x_2 = 2$，所以
$$|\overrightarrow{FA}| + |\overrightarrow{FB}| = 4 - \dfrac12 \times 2 = 3 = 2 \times \dfrac32 = 2|\overrightarrow{FP}|.$$
因此 $|\overrightarrow{FA}|, |\overrightarrow{FP}|, |\overrightarrow{FB}|$ 成等差数列。
当 $m = \dfrac34$ 时，直线 $l$ 的斜率 $k = -\dfrac{3}{4m} = -1$。
直线 $l$ 的方程为 $y - \dfrac34 = -(x - 1)$，即 $y = -x + \dfrac74$。
联立直线与椭圆方程：
$$\dfrac{x^2}{4} + \dfrac{\left(-x + \dfrac74\right)^2}{3} = 1 \implies 12x^2 + 16\left(x^2 - \dfrac72 x + \dfrac{49}{16}\right) = 48.$$
整理得 $28x^2 - 56x + 1 = 0$。
解得
$$x = \dfrac{56 \pm \sqrt{56^2 - 4 \times 28 \times 1}}{56} = 1 \pm \dfrac{\sqrt{3136 - 112}}{56} = 1 \pm \dfrac{\sqrt{3024}}{56} = 1 \pm \dfrac{12\sqrt{21}}{56} = 1 \pm \dfrac{3\sqrt{21}}{14}.$$
不妨设 $x_1 = 1 - \dfrac{3\sqrt{21}}{14}$，$x_2 = 1 + \dfrac{3\sqrt{21}}{14}$。
则
$$|\overrightarrow{FA}| = 2 - \dfrac12 x_1 = \dfrac32 + \dfrac{3\sqrt{21}}{28},$$
$$|\overrightarrow{FP}| = \dfrac32,$$
$$|\overrightarrow{FB}| = 2 - \dfrac12 x_2 = \dfrac32 - \dfrac{3\sqrt{21}}{28}.$$
此时公差为 $|\overrightarrow{FP}| - |\overrightarrow{FA}| = -\dfrac{3\sqrt{21}}{28}$；
若交换点 $A, B$ 的次序，则公差为 $\dfrac{3\sqrt{21}}{28}$。
所以该等差数列的公差为 $-\dfrac{3\sqrt{21}}{28}$ 或 $\dfrac{3\sqrt{21}}{28}$。

**答案（1）：证明见解析版。**

**答案（2）：证明见解析版；公差为 $-\dfrac{3\sqrt{21}}{28}$ 或 $\dfrac{3\sqrt{21}}{28}$。**

### 第 21 题

**题目**（本小题满分 12 分）：

已知函数 $f(x) = (2 + x + ax^2)\ln(1 + x) - 2x$。
(1) 若 $a = 0$，证明：当 $-1 < x < 0$ 时，$f(x) < 0$；当 $x > 0$ 时，$f(x) > 0$；
(2) 若 $x = 0$ 是 $f(x)$ 的极大值点，求 $a$。

**解析**

**(1) 解析** 证明：当 $a = 0$ 时，$f(x) = (2 + x)\ln(1 + x) - 2x$。
函数的定义域为 $(-1, +\infty)$。
求导得：
$$f'(x) = \ln(1 + x) + (2 + x)\cdot\dfrac{1}{1 + x} - 2 = \ln(1 + x) + \dfrac{1 + x + 1}{1 + x} - 2 = \ln(1 + x) + \dfrac{1}{1 + x} - 1.$$
令 $g(x) = f'(x) = \ln(1 + x) + \dfrac{1}{1 + x} - 1$。
对 $g(x)$ 求导得：
$$g'(x) = \dfrac{1}{1 + x} - \dfrac{1}{(1 + x)^2} = \dfrac{x}{(1 + x)^2}.$$
当 $-1 < x < 0$ 时，$g'(x) < 0$，$g(x)$ 在 $(-1, 0)$ 上单调递减；
当 $x > 0$ 时，$g'(x) > 0$，$g(x)$ 在 $(0, +\infty)$ 上单调递增。
所以当 $x = 0$ 时，$g(x)$ 取得最小值 $g(0) = \ln 1 + 1 - 1 = 0$。
因此在区间 $(-1, +\infty)$ 上，$f'(x) = g(x) \geqslant g(0) = 0$ 恒成立，且仅当 $x = 0$ 时等号成立。
所以函数 $f(x)$ 在 $(-1, +\infty)$ 上严格单调递增。
又 $f(0) = (2 + 0)\ln 1 - 0 = 0$。
所以当 $-1 < x < 0$ 时，$f(x) < f(0) = 0$；
当 $x > 0$ 时，$f(x) > f(0) = 0$。

**(2) 解析** 函数 $f(x) = (2 + x + ax^2)\ln(1 + x) - 2x$ 在定义域 $(-1, +\infty)$ 上可导。
求导得：
$$f'(x) = (1 + 2ax)\ln(1 + x) + \dfrac{2 + x + ax^2}{1 + x} - 2$$
$$= (1 + 2ax)\ln(1 + x) + \dfrac{2 + x + ax^2 - 2(1 + x)}{1 + x}$$
$$= (1 + 2ax)\ln(1 + x) + \dfrac{ax^2 - x}{1 + x}.$$
注意到 $f'(0) = \ln 1 + 0 = 0$。
对 $f'(x)$ 在 $x = 0$ 附近进行泰勒展开分析：
当 $x \to 0$ 时，
$$\ln(1 + x) = x - \dfrac12 x^2 + \dfrac13 x^3 + o(x^3),$$
$$(1 + 2ax)\ln(1 + x) = (1 + 2ax)\left(x - \dfrac12 x^2 + \dfrac13 x^3 + o(x^3)\right)$$
$$= x + \left(2a - \dfrac12\right)x^2 + \left(\dfrac13 - a\right)x^3 + o(x^3).$$
又 $\dfrac{1}{1 + x} = 1 - x + x^2 + o(x^2)$，所以
$$\dfrac{ax^2 - x}{1 + x} = (ax^2 - x)(1 - x + x^2 + o(x^2))$$
$$= -x + (a + 1)x^2 - (a + 1)x^3 + o(x^3).$$
将两部分相加，得
$$f'(x) = \left(3a + \dfrac12\right)x^2 - \left(2a + \dfrac23\right)x^3 + o(x^3).$$
若 $3a + \dfrac12 \neq 0$：
当 $3a + \dfrac12 > 0$ 时，在 $x = 0$ 的充分小邻域内，$f'(x) \approx \left(3a + \dfrac12\right)x^2 > 0$，导数在 $x = 0$ 两侧均大于零，$f(x)$ 严格递增，$x = 0$ 不是极值点；
当 $3a + \dfrac12 < 0$ 时，在 $x = 0$ 的充分小邻域内，$f'(x) \approx \left(3a + \dfrac12\right)x^2 < 0$，导数在 $x = 0$ 两侧均小于零，$f(x)$ 严格递减，$x = 0$ 不是极值点。
因此，若 $x = 0$ 是极值点，必有 $x^2$ 项的系数为零，即
$$3a + \dfrac12 = 0 \implies a = -\dfrac16.$$
当 $a = -\dfrac16$ 时，
$$-\left(2a + \dfrac23\right) = -\left(2\times\left(-\dfrac16\right) + \dfrac23\right) = -\left(-\dfrac13 + \dfrac23\right) = -\dfrac13 < 0.$$
于是 $f'(x) = -\dfrac13 x^3 + o(x^3)$。
当 $x$ 充分小且 $x < 0$ 时，$x^3 < 0 \implies f'(x) > 0$；
当 $x$ 充分小且 $x > 0$ 时，$x^3 > 0 \implies f'(x) < 0$。
函数 $f(x)$ 在 $x = 0$ 处先增后减，因此 $x = 0$ 是 $f(x)$ 的极大值点。
综上，所求 $a = -\dfrac16$。

**答案（1）：证明见解析版。**

**答案（2）：$a = -\dfrac16$**

### 第 22 题

**题目**[选修 4-4：坐标系与参数方程]（本小题满分 10 分）：

在平面直角坐标系 $xOy$ 中，$\odot O$ 的参数方程为
$$
\begin{cases}
x = \cos\theta, \\
y = \sin\theta
\end{cases}
$$
（$\theta$ 为参数），过点 $(0, -\sqrt2)$ 且倾斜角为 $\alpha$ 的直线 $l$ 与 $\odot O$ 交于 $A, B$ 两点。
(1) 求 $\alpha$ 的取值范围；
(2) 求 $AB$ 中点 $P$ 的轨迹的参数方程。

**解析**

**(1) 解析** 圆 $O$ 的参数方程为 $\begin{cases} x = \cos\theta, \\ y = \sin\theta \end{cases}$，消去参数 $\theta$ 得普通方程为 $x^2 + y^2 = 1$。
圆心为原点 $O(0, 0)$，半径为 $r = 1$。
已知直线 $l$ 过点 $Q(0, -\sqrt2)$，其倾斜角为 $\alpha$。
当 $\alpha = \dfrac\pi2$ 时，直线方程为 $x = 0$（即 $y$ 轴），与圆交于两点 $(0, 1)$、$(0, -1)$，符合题意。
当 $\alpha \neq \dfrac\pi2$ 时，直线 $l$ 的斜率 $k = \tan\alpha$，其方程为
$$y - (-\sqrt2) = k(x - 0) \implies kx - y - \sqrt2 = 0.$$
圆心 $O(0, 0)$ 到直线 $l$ 的距离为
$$d = \dfrac{|-\sqrt2|}{\sqrt{k^2 + 1}} = \dfrac{\sqrt2}{\sqrt{k^2 + 1}}.$$
因为直线 $l$ 与圆 $O$ 交于不同的两点 $A, B$，所以弦心距 $d < r = 1$。
即
$$\dfrac{\sqrt2}{\sqrt{k^2 + 1}} < 1 \implies k^2 + 1 > 2 \implies k^2 > 1.$$
解得 $k > 1$ 或 $k < -1$。
因为倾斜角 $\alpha \in [0, \pi)$：
当 $k > 1$ 时，$\tan\alpha > 1 \implies \alpha \in \left(\dfrac\pi4, \dfrac\pi2\right)$；
当 $k < -1$ 时，$\tan\alpha < -1 \implies \alpha \in \left(\dfrac\pi2, \dfrac{3\pi}{4}\right)$；
结合 $\alpha = \dfrac\pi2$ 也符合题意，综合可得 $\alpha$ 的取值范围是 $\left(\dfrac\pi4, \dfrac{3\pi}{4}\right)$。

**(2) 解析** 设直线 $l$ 的参数方程为
$$\begin{cases} x = t\cos\alpha, \\ y = -\sqrt2 + t\sin\alpha \end{cases} \quad (t\text{ 为参数}).$$
代入圆的普通方程 $x^2 + y^2 = 1$，得
$$(t\cos\alpha)^2 + (-\sqrt2 + t\sin\alpha)^2 = 1 \implies t^2\cos^2\alpha + 2 - 2\sqrt2 t\sin\alpha + t^2\sin^2\alpha = 1.$$
化简得
$$t^2 - 2\sqrt2\sin\alpha\, t + 1 = 0.$$
设点 $A, B$ 对应的参数分别为 $t_1, t_2$，则由韦达定理得
$$t_1 + t_2 = 2\sqrt2\sin\alpha.$$
因为点 $P$ 是线段 $AB$ 的中点，所以点 $P$ 对应的参数为
$$t_P = \dfrac{t_1 + t_2}{2} = \sqrt2\sin\alpha.$$
代入直线的参数方程，得点 $P$ 的坐标满足
$$\begin{cases} x = \sqrt2\sin\alpha\cos\alpha, \\ y = -\sqrt2 + \sqrt2\sin^2\alpha \end{cases} \quad \left(\alpha \in \left(\dfrac\pi4, \dfrac{3\pi}{4}\right)\right).$$
所以点 $P$ 的轨迹的参数方程为
$$\begin{cases} x = \sqrt2\sin\alpha\cos\alpha, \\ y = -\sqrt2 + \sqrt2\sin^2\alpha \end{cases} \quad \left(\alpha\text{ 为参数，}\alpha \in \left(\dfrac\pi4, \dfrac{3\pi}{4}\right)\right).$$

**答案（1）：$\alpha \in \left(\dfrac\pi4, \dfrac{3\pi}{4}\right)$**

**答案（2）：$\begin{cases} x = \sqrt2\sin\alpha\cos\alpha, \\ y = -\sqrt2 + \sqrt2\sin^2\alpha \end{cases} \quad \left(\alpha \in \left(\dfrac\pi4, \dfrac{3\pi}{4}\right)\right)$**

### 第 23 题

**题目**[选修 4-5：不等式选讲]（本小题满分 10 分）：

设函数 $f(x) = |2x + 1| + |x - 1|$。
(1) 画出 $y = f(x)$ 的图象；

[TikZ 图稿：第 23 题](../math-gaokao-latex/2018_全国Ⅲ卷_理科/figures/q23.tikz.tex)

(2) 当 $x \in [0, +\infty)$ 时，$f(x) \leqslant ax + b$，求 $a + b$ 的最小值。

**解析**

**(1) 解析** 函数 $f(x) = |2x + 1| + |x - 1|$。
令 $2x + 1 = 0 \implies x = -\dfrac12$；令 $x - 1 = 0 \implies x = 1$。
分段讨论去绝对值：
- 当 $x < -\dfrac12$ 时，$2x + 1 < 0$，$x - 1 < 0$，
  $$f(x) = -(2x + 1) - (x - 1) = -2x - 1 - x + 1 = -3x;$$
- 当 $-\dfrac12 \leqslant x \leqslant 1$ 时，$2x + 1 \geqslant 0$，$x - 1 \leqslant 0$，
  $$f(x) = (2x + 1) - (x - 1) = 2x + 1 - x + 1 = x + 2;$$
- 当 $x > 1$ 时，$2x + 1 > 0$，$x - 1 > 0$，
  $$f(x) = (2x + 1) + (x - 1) = 2x + 1 + x - 1 = 3x.$$
综上，函数的分段解析式为
$$f(x) = \begin{cases} -3x, & x < -\dfrac12, \\ x + 2, & -\dfrac12 \leqslant x \leqslant 1, \\ 3x, & x > 1。 \end{cases}$$
图象由三条射线/线段拼接而成：
当 $x < -\dfrac12$ 时，图象是一条经过点 $\left(-\dfrac12, \dfrac32\right)$ 且斜率为 $-3$ 的射线；
当 $-\dfrac12 \leqslant x \leqslant 1$ 时，图象是连接点 $\left(-\dfrac12, \dfrac32\right)$ 与 $(1, 3)$ 的线段；
当 $x > 1$ 时，图象是一条以 $(1, 3)$ 为端点且斜率为 $3$ 的射线。

**(2) 解析** 由 (1) 可知，当 $x \in [0, +\infty)$ 时，
$$f(x) = \begin{cases} x + 2, & 0 \leqslant x \leqslant 1, \\ 3x, & x > 1。 \end{cases}$$
由题意，不等式 $f(x) \leqslant ax + b$ 在 $[0, +\infty)$ 上恒成立。
在 $x \in [0, 1]$ 上恒有 $x + 2 \leqslant ax + b$，特别地，令 $x = 0$ 得 $2 \leqslant b$，即 $b \geqslant 2$。
在 $x \in (1, +\infty)$ 上恒有 $3x \leqslant ax + b$，即 $(a - 3)x + b \geqslant 0$。
若 $a < 3$，则当 $x > \dfrac{b}{3 - a}$ 时，$(a - 3)x + b < 0$，与恒成立矛盾，故必有 $a \geqslant 3$。
因此
$$a + b \geqslant 3 + 2 = 5.$$
当 $a = 3, b = 2$ 时，$ax + b = 3x + 2$：
- 当 $x \in [0, 1]$ 时，$(3x + 2) - f(x) = (3x + 2) - (x + 2) = 2x \geqslant 0$；
- 当 $x \in (1, +\infty)$ 时，$(3x + 2) - f(x) = (3x + 2) - 3x = 2 > 0$。
此时 $f(x) \leqslant 3x + 2$ 在 $[0, +\infty)$ 上恒成立。
所以 $a + b$ 的最小值为 $5$。

**答案（1）：$f(x) = \begin{cases} -3x, & x < -\dfrac12, \\ x + 2, & -\dfrac12 \leqslant x \leqslant 1, \\ 3x, & x > 1。 \end{cases}$ 图象为连接点 $\left(-\dfrac12, \dfrac32\right)$、$(1, 3)$ 的分段折线图象。**

**答案（2）：$a + b$ 的最小值为 $5$。**
