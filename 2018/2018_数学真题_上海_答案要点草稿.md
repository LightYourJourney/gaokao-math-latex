## 一、填空题（共 12 题）

### 1. 行列式求值
- **答案**：$18$
- **推导**：
  $$
  \begin{vmatrix} 4 & 1 \\ 2 & 5 \end{vmatrix} = 4 \times 5 - 1 \times 2 = 20 - 2 = 18
  $$

### 2. 双曲线渐近线方程
- **答案**：$y = \pm \dfrac{1}{2}x$（或 $x \pm 2y = 0$）
- **推导**：
  双曲线方程为 $\dfrac{x^2}{4} - y^2 = 1$，渐近线方程满足 $\dfrac{x^2}{4} - y^2 = 0 \iff y^2 = \dfrac{1}{4}x^2 \iff y = \pm \dfrac{1}{2}x$。

### 3. 二项式展开式系数
- **答案**：$21$
- **推导**：
  $(1 + x)^7$ 展开式的通项为 $T_{r+1} = \binom{7}{r} x^r$。令 $r = 2$，得 $x^2$ 项系数为 $\binom{7}{2} = \dfrac{7 \times 6}{2} = 21$。

### 4. 反函数图象与对数函数参数
- **答案**：$7$
- **推导**：
  反函数的图象经过点 $(3, 1) \iff$ 原函数 $f(x) = \log_2 (x + a)$ 经过点 $(1, 3)$。
  代入得 $\log_2 (1 + a) = 3 \implies 1 + a = 2^3 = 8 \implies a = 7$。

### 5. 复数的模
- **答案**：$5$
- **推导**：
  对 $(1 + \mathrm{i}) z = 1 - 7\mathrm{i}$ 两边取模：
  $$
  |1 + \mathrm{i}| \cdot |z| = |1 - 7\mathrm{i}| \implies \sqrt{1^2 + 1^2} \cdot |z| = \sqrt{1^2 + (-7)^2} \implies \sqrt{2} |z| = \sqrt{50} = 5\sqrt{2} \implies |z| = 5
  $$
  （或直接化简 $z = \dfrac{1 - 7\mathrm{i}}{1 + \mathrm{i}} = \dfrac{(1 - 7\mathrm{i})(1 - \mathrm{i})}{2} = \dfrac{-6 - 8\mathrm{i}}{2} = -3 - 4\mathrm{i}$，则 $|z| = \sqrt{(-3)^2 + (-4)^2} = 5$）。

### 6. 等差数列前 n 项和
- **答案**：$14$
- **推导**：
  设公差为 $d$。由 $a_3 = a_1 + 2d = 0 \implies a_1 = -2d$。
  $a_6 + a_7 = (a_1 + 5d) + (a_1 + 6d) = 2a_1 + 11d = -4d + 11d = 7d = 14 \implies d = 2$。
  从而 $a_1 = -4$，$a_4 = a_3 + d = 2$。
  等差数列前 7 项和 $S_7 = 7 a_4 = 7 \times 2 = 14$。

### 7. 幂函数的性质与参数确定
- **答案**：$-1$
- **推导**：
  若幂函数 $f(x) = x^\alpha$ 在 $(0, +\infty)$ 上单调递减，则 $\alpha < 0$。候选集中负数为 $-2, -1, -\dfrac{1}{2}$。
  - 若 $\alpha = -2$，$f(x) = x^{-2}$ 为偶函数；
  - 若 $\alpha = -\dfrac{1}{2}$，$f(x) = x^{-1/2} = \dfrac{1}{\sqrt{x}}$，定义域为 $(0, +\infty)$，非奇非偶；
  - 若 $\alpha = -1$，$f(x) = \dfrac{1}{x}$，定义域为 $\{x \mid x \ne 0\}$，满足 $f(-x) = -f(x)$ 为奇函数，且在 $(0, +\infty)$ 上单调递减。
  故 $\alpha = -1$。

### 8. 平面向量数量积的最值
- **答案**：$-3$
- **推导**：
  点 $A(-1, 0)$，$B(2, 0)$。设动点 $E(0, y_1)$，$F(0, y_2)$。
  已知 $|\vec{EF}| = |y_2 - y_1| = 2$。
  向量 $\vec{AE} = (1, y_1)$，$\vec{BF} = (-2, y_2)$。
  数量积 $\vec{AE} \cdot \vec{BF} = 1 \times (-2) + y_1 y_2 = -2 + y_1 y_2$。
  因为 $|y_2 - y_1| = 2 \implies (y_2 - y_1)^2 = 4 \implies y_1 y_2 = y_1(y_1 \pm 2) = (y_1 \pm 1)^2 - 1 \ge -1$。
  当 $y_1 = \mp 1$、$y_2 = \pm 1$ 时取等号，此时 $y_1 y_2 = -1$。
  因此 $\vec{AE} \cdot \vec{BF} = -2 + y_1 y_2 \ge -2 + (-1) = -3$。

### 9. 随机选取砝码的概率计算
- **答案**：$\dfrac{1}{5}$
- **推导**：
  记 5 个砝码为 $5, 3, 2_A, 2_B, 1$。
  从中随机选取 3 个，基本事件总数为 $\binom{5}{3} = 10$。
  总质量为 9 克的组合情况：
  - 组合一：$5 + 3 + 1 = 9$（1 种可能）；
  - 组合二：$5 + 2_A + 2_B = 9$（1 种可能）；
  其他组合（如 $3 + 2 + 1 = 6$、$5 + 3 + 2 = 10$、$3 + 2_A + 2_B = 7$）均不等于 9 克。
  满足条件的组合共 2 种。
  故所求概率为 $P = \dfrac{2}{10} = \dfrac{1}{5}$。

### 10. 等比数列前 n 项和与通项的极限
- **答案**：$3$
- **推导**：
  $a_n = q^{n-1}$，则 $a_{n+1} = q^n$。
  若 $|q| \le 1$，$\lim\limits_{n \to \infty} \dfrac{S_n}{a_{n+1}}$ 不存在或非有限非零常数。
  若 $|q| > 1$，$S_n = \dfrac{1 - q^n}{1 - q}$，则：
  $$
  \dfrac{S_n}{a_{n+1}} = \dfrac{1 - q^n}{(1 - q) q^n} = \dfrac{q^{-n} - 1}{1 - q}
  $$
  当 $n \to \infty$ 时，$q^{-n} \to 0$，故极限为 $\dfrac{-1}{1 - q} = \dfrac{1}{q - 1}$。
  由题意 $\dfrac{1}{q - 1} = \dfrac{1}{2} \implies q - 1 = 2 \implies q = 3$（满足 $|q| > 1$）。

### 11. 指数分式函数图象与参数
- **答案**：$6$
- **推导**：
  函数 $f(x) = \dfrac{2^x}{2^x + ax}$。
  点 $P\left(p, \dfrac{6}{5}\right)$ 在图象上 $\implies \dfrac{2^p}{2^p + ap} = \dfrac{6}{5} \implies 5 \cdot 2^p = 6 \cdot 2^p + 6ap \implies 2^p = -6ap$。
  点 $Q\left(q, -\dfrac{1}{5}\right)$ 在图象上 $\implies \dfrac{2^q}{2^q + aq} = -\dfrac{1}{5} \implies 5 \cdot 2^q = -2^q - aq \implies 6 \cdot 2^q = -aq \implies 2^q = -\dfrac{1}{6}aq$。
  两式相乘：
  $$
  2^{p+q} = 2^p \cdot 2^q = (-6ap) \left(-\dfrac{1}{6}aq\right) = a^2 pq
  $$
  已知 $2^{p+q} = 36pq$。由 $2^p > 0, 2^q > 0$ 知 $pq \ne 0$。
  因此 $a^2 = 36$。因常数 $a > 0$，得 $a = 6$。

### 12. 单位圆上动点到直线距离和的最大值
- **答案**：$\sqrt{2} + \sqrt{3}$（或 $\dfrac{2 + \sqrt{6}}{\sqrt{2}}$）
- **推导**：
  设点 $A(x_1, y_1)$ 与 $B(x_2, y_2)$ 位于单位圆 $x^2 + y^2 = 1$ 上。
  $\vec{OA} \cdot \vec{OB} = x_1 x_2 + y_1 y_2 = \dfrac{1}{2} \implies \cos\angle AOB = \dfrac{1}{2} \implies \angle AOB = \dfrac{\pi}{3}$。
  表达式 $\dfrac{|x + y - 1|}{\sqrt{2}}$ 表示点 $(x, y)$ 到直线 $l: x + y - 1 = 0$ 的点线距离。
  所求即为单位圆上圆心角为 $\dfrac{\pi}{3}$ 的两动点 $A, B$ 到直线 $l$ 的距离之和 $d_A + d_B$ 的最大值。
  直线 $l$ 经过点 $(1, 0)$ 与 $(0, 1)$，圆心 $O(0, 0)$ 到 $l$ 的距离为 $\dfrac{\sqrt{2}}{2}$。
  当 $A, B$ 位于直线 $l$ 的同一侧（第三象限方向，即远离 $l$ 的一侧）时，有 $x_i + y_i - 1 < 0$：
  $$
  d_A + d_B = \dfrac{1 - (x_1 + y_1)}{\sqrt{2}} + \dfrac{1 - (x_2 + y_2)}{\sqrt{2}} = \sqrt{2} - \dfrac{(x_1 + x_2) + (y_1 + y_2)}{\sqrt{2}}
  $$
  设 $A\left(\cos\alpha, \sin\alpha\right)$，$B\left(\cos\left(\alpha + \dfrac{\pi}{3}\right), \sin\left(\alpha + \dfrac{\pi}{3}\right)\right)$。
  则 $(x_1 + x_2) + (y_1 + y_2) = \sqrt{6} \sin\left(\alpha + \dfrac{5\pi}{12}\right)$。
  当 $\sin\left(\alpha + \dfrac{5\pi}{12}\right) = -1$ 时，上式取得最小值 $-\sqrt{6}$。
  代入得最大距离和为：
  $$
  \dfrac{2 - (-\sqrt{6})}{\sqrt{2}} = \dfrac{2 + \sqrt{6}}{\sqrt{2}} = \sqrt{2} + \sqrt{3}
  $$
  此时两点坐标均位于直线 $l$ 下方，绝对值拆解严格成立。

### 14. 充分必要条件判断
- **答案**：A
- **推导**：
  - 充分性：若 $a > 1$，则 $\dfrac{1}{a} \in (0, 1)$，必有 $\dfrac{1}{a} < 1$，充分性成立；
  - 必要性：若 $\dfrac{1}{a} < 1 \iff \dfrac{1 - a}{a} < 0 \iff a(a - 1) > 0 \iff a > 1$ 或 $a < 0$。例如 $a = -1$ 时，$\dfrac{1}{-1} = -1 < 1$，但推不出 $a > 1$，必要性不成立。
  因此“$a > 1$”是“$\dfrac{1}{a} < 1$”的充分非必要条件。
  故选 A。

### 15. 正六棱柱中的阳马计数
- **答案**：D
- **推导**：
  底面正六边形设为 $ABCDEF$，上底面为 $A_1 B_1 C_1 D_1 E_1 F_1$。
  阳马定义：底面为矩形且有一侧棱垂直于底面的四棱锥。
  要求以 $AA_1$ 为底面矩形的一条边，则底面矩形包含棱 $AA_1$。
  正六棱柱中包含 $AA_1$ 的矩形截面或侧面有：
  1. 侧面矩形 $AA_1 B_1 B$：在底面正六边形中，$AE \perp AB$，又 $AA_1 \perp AE$，故 $AE \perp$ 平面 $AA_1 B_1 B$；同理 $A_1 E_1 \perp$ 平面 $AA_1 B_1 B$。又由对称性，$BD \perp AB \implies BD \perp$ 平面 $AA_1 B_1 B$，$B_1 D_1 \perp$ 平面 $AA_1 B_1 B$。因此顶点取 $E, E_1, D, D_1$ 这 4 个点时，侧棱分别垂直于底面矩形 $AA_1 B_1 B$，均构成阳马，共 4 个；
  2. 侧面矩形 $AA_1 F_1 F$：同理对称可知，以其为底面的阳马顶点可取 $C, C_1, D, D_1$ 共 4 个；
  3. 次对角面矩形 $AA_1 E_1 E$：因为 $AB \perp AE$ 且 $AB \perp AA_1$，所以 $AB \perp$ 平面 $AA_1 E_1 E$，$A_1 B_1 \perp$ 平面 $AA_1 E_1 E$；在 $E$ 端有 $ED \perp AE$，故 $ED \perp$ 平面 $AA_1 E_1 E$，$E_1 D_1 \perp$ 平面 $AA_1 E_1 E$。因此顶点可取 $B, B_1, D, D_1$，均构成阳马，共 4 个；
  4. 次对角面矩形 $AA_1 C_1 C$：同理顶点可取 $F, F_1, D, D_1$，共 4 个；
  5. 主对角面矩形 $AA_1 D_1 D$：正六边形中无任何顶点连到 $A$ 或 $D$ 与对角线 $AD$ 垂直，故不能构成阳马。
  综上，这样的阳马个数共有 $4 + 4 + 4 + 4 = 16$ 个。
  故选 D。

### 16. 有限点集函数图象的旋转对称性
- **答案**：B
- **推导**：
  设 $G = \{(x, f(x)) \mid x \in D\}$ 为函数图象。由函数定义，$G$ 中任意两点横坐标互不相同。
  已知 $1 \in D$，点 $P_0(1, f(1)) \in G$。设其极坐标为 $(r, \theta)$，其中 $r = \sqrt{1 + [f(1)]^2} > 0$，$\theta \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$，$\tan\theta = f(1)$。
  由于 $G$ 绕原点逆时针旋转 $\dfrac{\pi}{6}$ 后与原图象重合，故 12 个旋转点 $P_k\left(r, \theta + \dfrac{k\pi}{6}\right)$（$k = 0, 1, \dots, 11$）均在 $G$ 中。
  由函数垂直线检验，对任意 $k_1 \ne k_2 \pmod{12}$，两点横坐标不能相等，即：
  $$
  \cos\left(\theta + \dfrac{k_1\pi}{6}\right) \ne \cos\left(\theta + \dfrac{k_2\pi}{6}\right)
  $$
  两角余弦相等当且仅当其和为 $2\pi$ 的整数倍，即存在 $k_1 \ne k_2$ 使得 $2\theta + (k_1 + k_2)\dfrac{\pi}{6} = 2m\pi \iff \theta = \dfrac{N\pi}{12}$（即 $\theta$ 是 $15^\circ$ 的整数倍）。
  检验各选项：
  - (A) $f(1) = \sqrt{3} \implies \theta = 60^\circ = 4 \times 15^\circ$，$k=0$ 与 $k=8$ 横坐标相同；
  - (C) $f(1) = \dfrac{\sqrt{3}}{3} \implies \theta = 30^\circ = 2 \times 15^\circ$，$k=0$ 与 $k=10$ 横坐标相同；
  - (D) $f(1) = 0 \implies \theta = 0^\circ = 0 \times 15^\circ$，$k=1$ 与 $k=11$ 横坐标相同；
  - (B) $f(1) = \dfrac{\sqrt{3}}{2} \implies \theta \ne 15^\circ$ 的整数倍，12 个旋转点的横坐标互不相同，满足函数定义。
  故选 B。

### 17. 圆锥体积与异面直线所成角
- **答案**：
  (1) $V = \dfrac{8\sqrt{3}\pi}{3}$；
  (2) 异面直线 $PM$ 与 $OB$ 所成的角为 $\arccos\dfrac{\sqrt{2}}{6}$。
- **推导**：
  (1) 底面半径 $r = 2$，母线 $l = 4$。
  圆锥高 $h = \sqrt{l^2 - r^2} = \sqrt{4^2 - 2^2} = \sqrt{12} = 2\sqrt{3}$。
  底面面积 $S = \pi r^2 = 4\pi$。
  体积 $V = \dfrac{1}{3} S h = \dfrac{1}{3} \times 4\pi \times 2\sqrt{3} = \dfrac{8\sqrt{3}\pi}{3}$。
  (2) 建立空间直角坐标系：以底面圆心 $O$ 为原点，$\vec{OA}$ 方向为 $x$ 轴正方向，$\vec{OB}$ 方向为 $y$ 轴正方向，$\vec{OP}$ 方向为 $z$ 轴正方向。
  由已知 $OA = 2, OB = 2, PO = 4$：
  $O(0, 0, 0)$，$A(2, 0, 0)$，$B(0, 2, 0)$，$P(0, 0, 4)$。
  $M$ 是 $AB$ 中点，故 $M(1, 1, 0)$。
  $\vec{PM} = (1, 1, -4)$，$\vec{OB} = (0, 2, 0)$。
  $|\vec{PM}| = \sqrt{1^2 + 1^2 + (-4)^2} = \sqrt{18} = 3\sqrt{2}$，$|\vec{OB}| = 2$。
  $\vec{PM} \cdot \vec{OB} = 1 \times 0 + 1 \times 2 + (-4) \times 0 = 2$。
  设所成角为 $\theta \in \left[0, \dfrac{\pi}{2}\right]$，则：
  $$
  \cos\theta = \dfrac{|\vec{PM} \cdot \vec{OB}|}{|\vec{PM}| \cdot |\vec{OB}|} = \dfrac{2}{3\sqrt{2} \times 2} = \dfrac{1}{3\sqrt{2}} = \dfrac{\sqrt{2}}{6}
  $$
  故所成角大小为 $\arccos\dfrac{\sqrt{2}}{6}$。

### 18. 三角函数的奇偶性与方程求解
- **答案**：
  (1) $a = 0$；
  (2) $x = -\dfrac{11\pi}{24}, -\dfrac{5\pi}{24}, \dfrac{13\pi}{24}, \dfrac{19\pi}{24}$。
- **推导**：
  (1) $f(x) = a\sin 2x + 2\cos^2 x = a\sin 2x + \cos 2x + 1$。
  因为 $f(x)$ 为偶函数，所以 $f(-x) = f(x)$，即 $-a\sin 2x + \cos 2x + 1 = a\sin 2x + \cos 2x + 1 \implies 2a\sin 2x = 0$ 对任意 $x \in \mathbf{R}$ 恒成立，故 $a = 0$。
  (2) $f\left(\dfrac{\pi}{4}\right) = a\sin\dfrac{\pi}{2} + 2\cos^2\dfrac{\pi}{4} = a + 1$。
  由已知 $a + 1 = \sqrt{3} + 1 \implies a = \sqrt{3}$。
  此时 $f(x) = \sqrt{3}\sin 2x + \cos 2x + 1 = 2\sin\left(2x + \dfrac{\pi}{6}\right) + 1$。
  方程 $f(x) = 1 - \sqrt{2} \iff 2\sin\left(2x + \dfrac{\pi}{6}\right) + 1 = 1 - \sqrt{2} \iff \sin\left(2x + \dfrac{\pi}{6}\right) = -\dfrac{\sqrt{2}}{2}$。
  因为 $x \in [-\pi, \pi]$，令 $u = 2x + \dfrac{\pi}{6}$，则 $u \in \left[-\dfrac{11\pi}{6}, \dfrac{13\pi}{6}\right]$。
  在此区间内满足 $\sin u = -\dfrac{\sqrt{2}}{2}$ 的解为：
  $u = -\dfrac{3\pi}{4}, -\dfrac{\pi}{4}, \dfrac{5\pi}{4}, \dfrac{7\pi}{4}$。
  解得：
  - $2x = -\dfrac{3\pi}{4} - \dfrac{\pi}{6} = -\dfrac{11\pi}{12} \implies x = -\dfrac{11\pi}{24}$；
  - $2x = -\dfrac{\pi}{4} - \dfrac{\pi}{6} = -\dfrac{5\pi}{12} \implies x = -\dfrac{5\pi}{24}$；
  - $2x = \dfrac{5\pi}{4} - \dfrac{\pi}{6} = \dfrac{13\pi}{12} \implies x = \dfrac{13\pi}{24}$；
  - $2x = \dfrac{7\pi}{4} - \dfrac{\pi}{6} = \dfrac{19\pi}{12} \implies x = \dfrac{19\pi}{24}$。

### 19. 通勤时间模型与函数单调性
- **答案**：
  (1) $x \in (45, 100)$；
  (2) $g(x) = \begin{cases} 40 - \dfrac{x}{10}, & 0 < x \le 30, \\ \dfrac{x^2 - 65x + 2900}{50}, & 30 < x < 100 \end{cases}$。单调性与实际意义见推导。
- **推导**：
  (1) 公交群体人均通勤时间恒为 40 分钟。公交少于自驾即 $f(x) > 40$。
  - 当 $0 < x \le 30$ 时，$f(x) = 30 \le 40$，无解；
  - 当 $30 < x < 100$ 时，$2x + \dfrac{1800}{x} - 90 > 40 \iff 2x^2 - 130x + 1800 > 0 \iff x^2 - 65x + 900 > 0 \iff (x - 20)(x - 45) > 0$。
  结合 $30 < x < 100$，得 $45 < x < 100$。
  (2) 自驾占比 $\dfrac{x}{100}$，公交占比 $1 - \dfrac{x}{100}$。
  $g(x) = \dfrac{x}{100} f(x) + \left(1 - \dfrac{x}{100}\right) \times 40 = 40 + \dfrac{x}{100}[f(x) - 40]$。
  - 当 $0 < x \le 30$ 时，$g(x) = 40 + \dfrac{x}{100}(30 - 40) = 40 - \dfrac{x}{10}$；
  - 当 $30 < x < 100$ 时，$g(x) = 40 + \dfrac{x}{100}\left(2x + \dfrac{1800}{x} - 130\right) = \dfrac{x^2 - 65x + 2900}{50}$。
  单调性分析：
  - 在 $(0, 30]$ 上，$g(x)$ 为一次减函数，单调递减；
  - 在 $(30, 100)$ 上，二次函数对称轴为 $x = 32.5$。因此在 $(30, 32.5]$ 上单调递减，在 $[32.5, 100)$ 上单调递增。
  综上，$g(x)$ 在 $(0, 32.5]$ 上单调递减，在 $[32.5, 100)$ 上单调递增。
  实际意义：当自驾比例在 $32.5\%$ 以内时，自驾比例增加能使全体上班族人均通勤时间减少；当自驾比例达到 $32.5\%$ 时人均用时最少；若自驾比例超过 $32.5\%$，因道路拥堵加剧，人均通勤时间将不降反增。

- **推导**：
  (1) 曲线 $\Gamma: y^2 = 8x$（$y \ge 0$），焦点 $F(2, 0)$，准线方程为 $x = -2$。
  $B(t, \sqrt{8t})$ 在抛物线上，根据抛物线几何性质，点 $B$ 到焦点 $F$ 的距离等于点 $B$ 到准线的距离：
  $|BF| = t - (-2) = t + 2$。
  (2) 当 $t = 3$ 时，直线 $l: x = 3$，$A(3, 0)$，$B(3, 2\sqrt{6})$。
  $Q$ 在线段 $AB$ 上，设 $Q(3, y_Q)$，其中 $0 \le y_Q \le 2\sqrt{6}$。
  $|FQ|^2 = (3 - 2)^2 + y_Q^2 = 1 + y_Q^2 = 2^2 = 4 \implies y_Q = \sqrt{3}$，即 $Q(3, \sqrt{3})$。
  线段 $OQ$ 中点为 $M\left(\dfrac{3}{2}, \dfrac{\sqrt{3}}{2}\right)$。
  直线 $FM$ 斜率 $k = \dfrac{\sqrt{3}/2 - 0}{3/2 - 2} = -\sqrt{3}$，直线方程为 $y = -\sqrt{3}(x - 2)$。
  联立曲线方程 $y^2 = 8x$ 得 $3(x - 2)^2 = 8x \iff 3x^2 - 20x + 12 = 0 \iff (3x - 2)(x - 6) = 0$。
  由于 $0 \le x \le 3$，故 $x_P = \dfrac{2}{3}$，代入得 $y_P = \dfrac{4\sqrt{3}}{3}$，即 $P\left(\dfrac{2}{3}, \dfrac{4\sqrt{3}}{3}\right)$。
  底边 $|AQ| = y_Q = \sqrt{3}$，高为 $3 - x_P = 3 - \dfrac{2}{3} = \dfrac{7}{3}$。
  面积 $S_{\triangle AQP} = \dfrac{1}{2} \times \sqrt{3} \times \dfrac{7}{3} = \dfrac{7\sqrt{3}}{6}$。
  (3) 当 $t = 8$ 时，$A(8, 0)$，$B(8, 8)$。设 $Q(8, y_0)$，其中 $0 \le y_0 \le 8$。
  $\vec{FQ} = (6, y_0)$。
  设 $P(x_1, y_1)$ 在 $\Gamma$ 上，满足 $y_1^2 = 8x_1$，$0 \le x_1 \le 8, y_1 \ge 0$。
  $\vec{FP} = (x_1 - 2, y_1)$。
  以 $FP, FQ$ 为邻边构成矩形：
  - $\vec{FP} \perp \vec{FQ} \implies 6(x_1 - 2) + y_0 y_1 = 0 \implies y_0 y_1 = 12 - 6x_1$；
  - 矩形第四个顶点 $E$: $\vec{FE} = \vec{FP} + \vec{FQ} \implies x_E = x_1 + 6$，$y_E = y_1 + y_0$。
  $E$ 在 $\Gamma$ 上 $\implies (y_1 + y_0)^2 = 8(x_1 + 6) \iff y_1^2 + 2y_1 y_0 + y_0^2 = 8x_1 + 48$。
  将 $y_1^2 = 8x_1$ 和 $y_1 y_0 = 12 - 6x_1$ 代入消元：
  $8x_1 + 2(12 - 6x_1) + y_0^2 = 8x_1 + 48 \implies y_0^2 = 12x_1 + 24$。
  两边平方关系：$(y_1 y_0)^2 = y_1^2 y_0^2 \implies (12 - 6x_1)^2 = 8x_1(12x_1 + 24)$。
  化简：$36(2 - x_1)^2 = 96x_1(x_1 + 2) \implies 3(x_1^2 - 4x_1 + 4) = 8(x_1^2 + 2x_1) \implies 5x_1^2 + 28x_1 - 12 = 0$。
  因式分解 $(5x_1 - 2)(x_1 + 6) = 0$。由 $x_1 \ge 0$ 得 $x_1 = \dfrac{2}{5}$。
  此时 $y_1 = \dfrac{4\sqrt{5}}{5}$，$y_0 = \dfrac{12\sqrt{5}}{5} \le 8$，$x_E = \dfrac{32}{5} \le 8$，均在定义域内且两邻边非零非退化。
  故存在这样的矩形，点 $P$ 坐标为 $\left(\dfrac{2}{5}, \dfrac{4\sqrt{5}}{5}\right)$。

### 21. 接近数列的性质与公差范围
- **答案**：
  (1) 数列 $\{b_n\}$ 与 $\{a_n\}$ 接近；
  (2) $m = 3$ 或 $4$；
  (3) $d \in (-2, +\infty)$（即 $d > -2$）。
- **推导**：
  (1) $a_n = \left(\dfrac{1}{2}\right)^{n-1}$，$b_n = a_{n+1} + 1 = \left(\dfrac{1}{2}\right)^n + 1$。
  $|b_n - a_n| = \left|\left(\dfrac{1}{2}\right)^n + 1 - \left(\dfrac{1}{2}\right)^{n-1}\right| = \left|1 - \left(\dfrac{1}{2}\right)^n\right|$。
  对任意 $n \in \mathbf{N}^*$，$0 < \left(\dfrac{1}{2}\right)^n \le \dfrac{1}{2} \implies 0 < 1 - \left(\dfrac{1}{2}\right)^n < 1 \le 1$。
  故对任意 $n \in \mathbf{N}^*$ 均有 $|b_n - a_n| \le 1$，数列 $\{b_n\}$ 与 $\{a_n\}$ 接近。
  (2) 由 $|b_i - a_i| \le 1$ 知：
  $b_1 \in [0, 2]$，$b_2 \in [1, 3]$，$b_3 \in [3, 5]$，$b_4 \in [7, 9]$。
  显然 $b_4 \in [7, 9]$ 与前三者区间均无交集，必互不相同；$b_3 \in [3, 5]$ 与 $b_1 \in [0, 2]$ 无交集，必不相同。
  可能相同的项仅有：
  - $b_1 = b_2 \in [1, 2]$（此时 $b_3 \ne b_2$，不同元素有 3 个）；
  - $b_2 = b_3 = 3$（此时 $b_1 \ne b_2$，不同元素有 3 个）；
  - $b_1, b_2, b_3$ 三者两两不同（如分别取 $1, 2, 4$，不同元素有 4 个）。
  由于 $[0, 2] \cap [1, 3] \cap [3, 5] = \varnothing$，三者不可能同时相等。
  故集合 $M$ 中元素个数 $m$ 的可能值为 $3$ 或 $4$。
  (3) $a_n = a_1 + (n - 1)d$。$\{b_n\}$ 与 $\{a_n\}$ 接近等价于对任意 $n$ 满足 $a_n - 1 \le b_n \le a_n + 1$。
  考虑差分 $b_{k+1} - b_k$（$k = 1, 2, \dots, 200$）。
  若 $d \le -2$，对任意 $k$：
  $$
  b_{k+1} - b_k \le (a_{k+1} + 1) - (a_k - 1) = a_{k+1} - a_k + 2 = d + 2 \le 0
  $$
  即所有差分均非正，不可能有任何一项为正数。故必有 $d > -2$。
  反之，当 $d > -2$ 时：
  对任意 $j \in \{1, 2, \dots, 100\}$，取 $b_{2j-1} = a_{2j-1} - 1$，$b_{2j} = a_{2j} + 1$，且取 $b_{201} = a_{201} - 1$。
  显然所有 $b_n$ 均满足 $|b_n - a_n| = 1 \le 1$。
  对于奇数指标 $k = 2j - 1$（共 100 个）：
  $$
  b_{2j} - b_{2j-1} = (a_{2j} + 1) - (a_{2j-1} - 1) = d + 2 > 0
  $$
  即这 100 个差分均为正数。
  故当且仅当 $d > -2$ 时，至少有 100 个为正数。
  因此 $d$ 的取值范围为 $(-2, +\infty)$。
