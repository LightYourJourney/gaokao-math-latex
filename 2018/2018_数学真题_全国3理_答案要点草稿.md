## 一、选择题（共 12 题，每题 5 分，共 60 分）

1. **C**：$A = \{x \mid x - 1 \geqslant 0\} = [1, +\infty)$，$B = \{0, 1, 2\}$，则 $A \cap B = \{1, 2\}$。
2. **D**：$(1+\mathrm i)(2-\mathrm i) = 2 - \mathrm i + 2\mathrm i - \mathrm i^2 = 3 + \mathrm i$。
3. **A**：榫头在右侧，与带卯眼的构件咬合成长方体时，带卯眼的木构件对应位置为凹槽；从俯视方向看，凹槽轮廓在左侧且不可见，应为左侧虚线矩形，故选 A。
4. **B**：$\sin\alpha = \frac13 \implies \cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2\left(\frac13\right)^2 = \frac79$。
5. **C**：通项 $T_{r+1} = \mathrm C_5^r (x^2)^{5-r}\left(\frac2x\right)^r = \mathrm C_5^r 2^r x^{10-3r}$。令 $10 - 3r = 4 \implies r = 2$。系数为 $\mathrm C_5^2 \times 2^2 = 10 \times 4 = 40$。
6. **A**：直线 $x+y+2=0$ 与两轴交于 $A(-2, 0), B(0, -2)$，$|AB| = 2\sqrt2$。圆心 $(2, 0)$ 到直线距离 $d = \frac{|2+0+2|}{\sqrt{1^2+1^2}} = 2\sqrt2$，圆半径 $r = \sqrt2$。圆上点 $P$ 到直线距离 $h \in [d - r, d + r] = [\sqrt2, 3\sqrt2]$。面积 $S = \frac12 |AB| h = \sqrt2 h \in [2, 6]$。
7. **D**：$f(x) = -x^4 + x^2 + 2$ 为偶函数，图象关于 $y$ 轴对称。$f'(x) = -4x^3 + 2x = -2x(2x^2 - 1)$，极值点为 $x = 0$ 和 $x = \pm\frac{\sqrt2}{2}$。极大值为 $f\left(\pm\frac{\sqrt2}{2}\right) = \frac94 = 2.25$，极小值为 $f(0) = 2$。当 $x \to \pm\infty$ 时 $f(x) \to -\infty$，双峰向下，故选 D。
8. **B**：$X \sim B(10, p)$，$DX = 10p(1-p) = 2.4 \implies p(1-p) = 0.24 \implies p = 0.4$ 或 $p = 0.6$。由 $P(X=4) < P(X=6) \implies \mathrm C_{10}^4 p^4(1-p)^6 < \mathrm C_{10}^6 p^6(1-p)^4 \implies (1-p)^2 < p^2 \implies p > 1-p \implies p > 0.5$，故 $p = 0.6$。
9. **C**：$S = \frac12 ab\sin C = \frac{a^2+b^2-c^2}{4} = \frac{2ab\cos C}{4} = \frac12 ab\cos C \implies \sin C = \cos C \implies \tan C = 1$。因为 $C \in (0, \pi)$，所以 $C = \frac\pi4$。
10. **B**：正 $\triangle ABC$ 面积 $\frac{\sqrt3}{4}a^2 = 9\sqrt3 \implies a = 6$，外接圆半径 $r = \frac{a}{\sqrt3} = 2\sqrt3$。球心到平面 $ABC$ 距离 $d = \sqrt{R^2 - r^2} = \sqrt{4^2 - (2\sqrt3)^2} = 2$。三棱锥 $D-ABC$ 的高最大值为 $R + d = 4 + 2 = 6$。体积最大值为 $\frac13 \times 9\sqrt3 \times 6 = 18\sqrt3$。
11. **C**：双曲线渐近线 $bx \pm ay = 0$。焦点 $F_2(c, 0)$ 到渐近线距离 $|PF_2| = \frac{|bc|}{\sqrt{a^2+b^2}} = b$，在 Rt$\triangle OPF_2$ 中，$|OP| = \sqrt{c^2 - b^2} = a$。在 $\triangle PF_1F_2$ 中，$O$ 为 $F_1F_2$ 中点，由中线长公式 $|PF_1|^2 + |PF_2|^2 = 2(|OP|^2 + |OF_2|^2) \implies (\sqrt6 a)^2 + b^2 = 2(a^2 + c^2) \implies 6a^2 + c^2 - a^2 = 2a^2 + 2c^2 \implies 3a^2 = c^2 \implies e = \frac{c}{a} = \sqrt3$。
12. **B**：$a = \log_{0.2} 0.3 \in (0, 1)$，$b = \log_2 0.3 \in (-2, -1)$，故 $ab < 0$。又 $a + b = -\log_5 0.3 + \log_2 0.3 = \ln 0.3\left(\frac{1}{\ln 2} - \frac{1}{\ln 5}\right) < 0$。比较得 $(a+b) - ab = \frac{\ln 0.3}{\ln 2\ln 5}\ln\left(\frac52 \times 0.3\right) = \frac{\ln 0.3\ln 0.75}{\ln 2\ln 5} > 0 \implies a+b > ab$。故 $ab < a+b < 0$。

## 二、填空题（共 4 题，每题 5 分，共 20 分）

13. $\dfrac12$：$2\boldsymbol a + \boldsymbol b = (4, 2)$，$\boldsymbol c = (1, \lambda) \parallel (4, 2) \implies 1 \times 2 - 4\lambda = 0 \implies \lambda = \frac12$。
14. $-3$：$y' = (ax+a+1)\mathrm e^x$，在 $(0, 1)$ 处切线斜率 $y'|_{x=0} = a + 1 = -2 \implies a = -3$。
15. $3$：$f(x) = \cos(3x+\frac\pi6) = 0 \implies 3x+\frac\pi6 = k\pi+\frac\pi2 \implies x = \frac{k\pi}{3} + \frac\pi9$。在 $[0, \pi]$ 内对应 $k = 0, 1, 2$，共 3 个零点（分别为 $\frac\pi9, \frac{4\pi}{9}, \frac{7\pi}{9}$）。
16. $2$：抛物线 $C: y^2=4x$ 焦点 $F(1, 0)$，准线 $x = -1$，点 $M(-1, 1)$ 在准线上。设直线 $l: x = my + 1$ 代入得 $y^2 - 4my - 4 = 0$。$y_1+y_2 = 4m, y_1y_2 = -4, x_1x_2 = 1, x_1+x_2 = 4m^2+2$。$\overrightarrow{MA} \cdot \overrightarrow{MB} = (x_1+1)(x_2+1) + (y_1-1)(y_2-1) = x_1x_2 + (x_1+x_2) + 1 + y_1y_2 - (y_1+y_2) + 1 = 1 + (4m^2+2) + 1 - 4 - 4m + 1 = 4m^2 - 4m + 1 = (2m-1)^2 = 0 \implies m = \frac12 \implies k = \frac1m = 2$。

(1) 证明：当 $a = 0$ 时，$f(x) = (2+x)\ln(1+x) - 2x$。求导得 $f'(x) = \ln(1+x) + \frac{1}{1+x} - 1$。令 $g(x) = f'(x)$，则 $g'(x) = \frac{x}{(1+x)^2}$。当 $-1 < x < 0$ 时 $g'(x) < 0$；当 $x > 0$ 时 $g'(x) > 0$。因此 $f'(x) \geqslant f'(0) = 0$ 恒成立，且仅在 $x = 0$ 处取零。故 $f(x)$ 在 $(-1, +\infty)$ 单调递增。由 $f(0) = 0$ 可得：当 $-1 < x < 0$ 时 $f(x) < 0$；当 $x > 0$ 时 $f(x) > 0$。
