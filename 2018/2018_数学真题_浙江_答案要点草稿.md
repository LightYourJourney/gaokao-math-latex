## 一、选择题（共 10 题，每题 4 分，共 40 分）

1. **C**：$U = \{1, 2, 3, 4, 5\}$，$A = \{1, 3\}$，则 $\complement_U A = \{2, 4, 5\}$。
2. **B**：双曲线 $\frac{x^2}{3} - y^2 = 1 \implies c = \sqrt{3 + 1} = 2$，焦点在 $x$ 轴上，坐标为 $(-2, 0), (2, 0)$。
3. **C**：底面直角梯形面积 $S = \frac{2 + 1}{2} \times 2 = 3$，直四棱柱高 $h = 2$，体积 $V = 3 \times 2 = 6$。
4. **B**：$\frac{2}{1 - \mathrm i} = \frac{2(1 + \mathrm i)}{2} = 1 + \mathrm i$，其共轭复数为 $1 - \mathrm i$。
5. **D**：$f(-x) = -f(x)$ 为奇函数，图象关于原点对称；当 $x \in (0, \frac{\pi}{2})$ 时 $f(x) > 0$，且振幅随 $|x|$ 增大而增大，选 D。
6. **A**：若 $m \parallel n$ 且 $m \not\subset \alpha, n \subset \alpha \implies m \parallel \alpha$；反之 $m \parallel \alpha, n \subset \alpha$ 时 $m$ 与 $n$ 可异面，故为充分不必要条件。
7. **D**：$E(\xi) = p + \frac12$，$E(\xi^2) = 2p + \frac12$，$D(\xi) = -(p - \frac12)^2 + \frac12$。当 $p \in (0, 1)$ 时，对称轴 $p = \frac12$，故先增大后减小。
8. **D**：设正方形边长为 $2a$，高为 $h$。$\tan\theta_3 = \frac{h}{a}$，$\tan\theta_2 = \frac{h}{OE} \leqslant \frac{h}{a} \implies \theta_2 \leqslant \theta_3$；$\cos\theta_1 = \frac{a}{\sqrt{x_0^2 + a^2 + h^2}} \leqslant \frac{a}{\sqrt{a^2 + h^2}} = \cos\theta_3 \implies \theta_3 \leqslant \theta_1$。故 $\theta_2 \leqslant \theta_3 \leqslant \theta_1$。
9. **A**：由 $|\boldsymbol b - 2\boldsymbol e|^2 = 1$，点 $B$ 在以 $2\boldsymbol e$ 为圆心、半径为 1 的圆上；点 $A$ 在与 $\boldsymbol e$ 夹角为 $60^\circ$ 的射线上。圆心到射线的距离为 $2\sin 60^\circ = \sqrt3$，最小距离为 $\sqrt3 - 1$。
10. **B**：由 $S_4 = \ln S_3 < S_3$ 得 $a_4 < 0 \implies q < 0$；由 $\ln S_3 > 0 \implies 1 + q > 0 \implies -1 < q < 0$。由 $0 < q^2 < 1$ 得 $a_3 = a_1 q^2 < a_1$ 且 $a_4 = a_2 q^2 > a_2$（因 $a_2 < 0$），故 $a_1 > a_3, a_2 < a_4$。

## 二、填空题（共 7 题，第 11–14 题各 6 分，第 15–17 题各 4 分，多空题每空 3 分，共 36 分）

11. $8$；$11$：代入 $z = 81$ 得 $x + y = 19$ 且 $5x + 3y = 73$，解得 $x = 8, y = 11$。
12. $-2$；$8$：可行域顶点为 $(1, 1), (2, 2), (4, -2)$，代入 $z = x + 3y$ 得最小值为 $-2$（在 $(4, -2)$），最大值为 $8$（在 $(2, 2)$）。
13. $\dfrac{\sqrt{21}}{7}$；$3$：正弦定理 $\sin B = \frac{b\sin A}{a} = \frac{\sqrt{21}}{7}$；余弦定理 $c^2 - 2c - 3 = 0 \implies c = 3$。
14. $7$：通项 $T_{r+1} = \mathrm C_8^r 2^{-r} x^{\frac{8-4r}{3}}$，令 $8 - 4r = 0 \implies r = 2$，常数项为 $\mathrm C_8^2 \times 2^{-2} = 7$。
15. $(1, 4)$；$(1, 3] \cup (4, +\infty)$：当 $\lambda = 2$ 时解集为 $(1, 2) \cup [2, 4) = (1, 4)$；候选零点 $x = 4$（需 $\lambda \leqslant 4$）、$x = 1$（需 $\lambda > 1$）、$x = 3$（需 $\lambda > 3$），恰有两个零点当且仅当 $\lambda \in (1, 3] \cup (4, +\infty)$。
16. $1260$：不含 0 有 $\mathrm C_5^2 \mathrm C_3^2 \mathrm A_4^4 = 720$ 个；含 0 有 $\mathrm C_5^2 \mathrm C_3^1 (3 \times \mathrm A_3^3) = 540$ 个；合计 $720 + 540 = 1260$ 个。
17. $5$：由 $A = 3P - 2B$ 代入椭圆方程得二次项抵消，$y_0 = \frac{m+3}{4}$，则 $x_0^2 = \frac{-m^2+10m-9}{4} = \frac{-(m-5)^2+16}{4}$，当 $m = 5$ 时 $|x_0|$ 取得最大值 2。

## 三、解答题（共 5 题，共 74 分）

18.
(1) $\sin(\alpha + \pi) = -\sin\alpha = \dfrac45$。
(2) $\cos\beta = -\dfrac{56}{65}$ 或 $\dfrac{16}{65}$：由 $\cos(\alpha+\beta) = \pm\frac{12}{13}$，展开 $\cos\beta = \cos[(\alpha+\beta)-\alpha]$ 得两解。

19.
(1) 证明：由勾股定理逆定理在 $\triangle AA_1B_1$ 中 $AB_1^2 + A_1B_1^2 = 8 + 8 = 16 = AA_1^2 \implies AB_1 \perp A_1B_1$；在 $\triangle AB_1C_1$ 中 $AB_1^2 + B_1C_1^2 = 8 + 5 = 13 = AC_1^2 \implies AB_1 \perp B_1C_1$。故 $AB_1 \perp$ 平面 $A_1B_1C_1$。
(2) $\dfrac{\sqrt{39}}{13}$：建系得 $\overrightarrow{AC_1} = (\sqrt3, -3, 1)$，平面 $ABB_1$ 法向量为 $(1, 0, 0)$，线面角正弦值为 $\frac{\sqrt3}{\sqrt{13}} = \frac{\sqrt{39}}{13}$。

20.
(1) $q = 2$：由等差中项与三项和得 $a_4 = 8$ 且 $a_3 + a_5 = 20$，解得 $2q^2 - 5q + 2 = 0$，由 $q > 1$ 得 $q = 2$。
(2) $b_n = 15 - \dfrac{4n + 3}{2^{n-2}}$（或 $15 - \dfrac{8n + 6}{2^{n-1}}$）：$a_n = 2^{n-1}$，$(b_{n+1} - b_n)a_n = 4n - 1$，错位相减求和得通项。

21.
(1) 证明：设 $P(x_0, y_0)$，中点在抛物线上结合 $A, B$ 在抛物线上得 $y_1, y_2$ 为方程 $y^2 - 2y_0 y + (8x_0 - y_0^2) = 0$ 的两根，由韦达定理 $y_1 + y_2 = 2y_0 \implies y_M = y_0$，故 $PM$ 垂直于 $y$ 轴。
(2) $\left[6\sqrt2, \dfrac{15\sqrt{10}}{4}\right]$：$|PM| = 3(\frac{y_0^2}{4} - x_0)$，$|y_1 - y_2| = 4\sqrt2\sqrt{\frac{y_0^2}{4}-x_0}$，$S_{\triangle PAB} = 6\sqrt2(\frac{y_0^2}{4}-x_0)^{3/2}$。代入半椭圆方程得 $t(x_0) = -(x_0+\frac12)^2 + \frac54 \in [1, \frac54]$，故面积范围为 $[6\sqrt2, \frac{15\sqrt{10}}{4}]$。

22.
(1) 证明：令 $\sqrt{x_1} = u, \sqrt{x_2} = v$（$0 < u < v$），导数相等得 $uv = 2(u + v) > 16$ 且 $u + v = \frac{uv}{2}$。$f(x_1) + f(x_2) = \frac{t^2}{2} - 4\ln t$（$t = \sqrt{uv} > 4$），导数大于 0 单调递增，故大于 $g(4) = 8 - 8\ln 2$。
(2) 证明：令 $h(x) = \sqrt x - \ln x - kx - a$。若 $k \geqslant \frac{1}{16}$，导数恒非正，$h(x)$ 单调递减且两端趋于 $\pm\infty$，有唯一零点；若 $0 < k < \frac{1}{16}$，极小值点 $x_1$ 处 $u_1 \in (2, 4)$，极小值 $h(x_1) = \frac{u_1+2}{2} - 2\ln u_1 - a > (3 - 4\ln 2) - a \geqslant 0$，故在 $(0, x_2]$ 上无零点，在 $[x_2, +\infty)$ 上单调减至 $-\infty$，有唯一零点。综上，公共点唯一。
