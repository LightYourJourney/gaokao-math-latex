## 一、填空题

### 第 1 题

**题目**：

行列式 $\begin{vmatrix} 4 & 1 \\ 2 & 5 \end{vmatrix}$ 的值为______。

**解析**

根据二阶行列式的定义直接展开计算：
$$\begin{vmatrix} 4 & 1 \\ 2 & 5 \end{vmatrix} = 4 \times 5 - 1 \times 2 = 20 - 2 = 18.$$
故所求行列式的值为 $18$。

**答案：$18$**

### 第 2 题

**题目**：

双曲线 $\dfrac{x^2}{4} - y^2 = 1$ 的渐近线方程为______。

**解析**

双曲线的标准方程为 $\dfrac{x^2}{4} - y^2 = 1$。
令双曲线方程右端常数项为 0，得渐近线方程：
$$\frac{x^2}{4} - y^2 = 0 \iff y^2 = \frac{1}{4}x^2 \iff y = \pm \frac{1}{2}x.$$
故渐近线方程为 $y = \pm \dfrac{1}{2}x$（或 $x \pm 2y = 0$）。

**答案：$y = \pm \dfrac{1}{2}x$**

### 第 3 题

**题目**：

在 $(1 + x)^7$ 的二项展开式中，$x^2$ 项的系数为______。（结果用数值表示）

**解析**

由二项式定理，$(1 + x)^7$ 的展开式通项为：
$$T_{r+1} = \binom{7}{r} 1^{7-r} x^r = \binom{7}{r} x^r.$$
令 $r = 2$，得 $x^2$ 项的系数为：
$$\binom{7}{2} = \frac{7 \times 6}{2 \times 1} = 21.$$

**答案：$21$**

### 第 4 题

**题目**：

设常数 $a \in \mathbf{R}$，函数 $f(x) = \log_2 (x + a)$。若 $f(x)$ 的反函数的图象经过点 $(3, 1)$，则 $a =$______。

**解析**

因为函数 $f(x) = \log_2 (x + a)$ 的反函数的图象经过点 $(3, 1)$，
所以原函数 $f(x)$ 的图象经过点 $(1, 3)$，即 $f(1) = 3$。
代入得：
$$\log_2 (1 + a) = 3 \implies 1 + a = 2^3 = 8 \implies a = 7.$$

**答案：$7$**

### 第 5 题

**题目**：

已知复数 $z$ 满足 $(1 + \mathrm{i}) z = 1 - 7\mathrm{i}$（$\mathrm{i}$ 是虚数单位），则 $|z| =$______。

**解析**

已知等式 $(1 + \mathrm{i}) z = 1 - 7\mathrm{i}$。
两边同时取复数的模：
$$|1 + \mathrm{i}| \cdot |z| = |1 - 7\mathrm{i}|.$$
计算各复数的模：
$$|1 + \mathrm{i}| = \sqrt{1^2 + 1^2} = \sqrt{2},$$
$$|1 - 7\mathrm{i}| = \sqrt{1^2 + (-7)^2} = \sqrt{50} = 5\sqrt{2}.$$
代入得 $\sqrt{2} |z| = 5\sqrt{2}$，解得 $|z| = 5$。

**答案：$5$**

### 第 6 题

**题目**：

记等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$。若 $a_3 = 0$，$a_6 + a_7 = 14$ 则 $S_7 =$______。

**解析**

设等差数列 $\{a_n\}$ 的首项为 $a_1$，公差为 $d$。
由题设条件列方程组：
$$\begin{cases} a_3 = a_1 + 2d = 0, \\ a_6 + a_7 = (a_1 + 5d) + (a_1 + 6d) = 2a_1 + 11d = 14. \end{cases}$$
由第 1 式得 $a_1 = -2d$，代入第 2 式得：
$$2(-2d) + 11d = 7d = 14 \implies d = 2.$$
从而 $a_1 = -4$。
由等差数列前 $n$ 项和公式及性质：
$$S_7 = 7a_4 = 7(a_3 + d) = 7(0 + 2) = 14.$$

**答案：$14$**

### 第 7 题

**题目**：

已知 $\alpha \in \left\{-2, -1, -\dfrac{1}{2}, \dfrac{1}{2}, 1, 2, 3\right\}$，若幂函数 $f(x) = x^\alpha$ 为奇函数，且在 $(0, +\infty)$ 上递减，则 $\alpha =$______。

**解析**

由幂函数 $f(x) = x^\alpha$ 在 $(0, +\infty)$ 上单调递减，得 $\alpha < 0$。
在集合 $\left\{-2, -1, -\dfrac{1}{2}, \dfrac{1}{2}, 1, 2, 3\right\}$ 中，负数有 $-2, -1, -\dfrac{1}{2}$。
逐一检验：
- 当 $\alpha = -2$ 时，$f(x) = x^{-2} = \dfrac{1}{x^2}$，满足 $f(-x) = f(x)$，为偶函数，不合题意；
- 当 $\alpha = -\dfrac{1}{2}$ 时，$f(x) = x^{-1/2} = \dfrac{1}{\sqrt{x}}$，定义域为 $(0, +\infty)$，非奇非偶，不合题意；
- 当 $\alpha = -1$ 时，$f(x) = x^{-1} = \dfrac{1}{x}$，定义域为 $\{x \mid x \ne 0\}$ 关于原点对称，且 $f(-x) = -\dfrac{1}{x} = -f(x)$，为奇函数，在 $(0, +\infty)$ 上单调递减，符合题意。
综上所述，$\alpha = -1$。

**答案：$-1$**

### 第 8 题

**题目**：

在平面直角坐标系中，已知点 $A(-1, 0)$，$B(2, 0)$，$E, F$ 是 $y$ 轴上的两个动点，且 $|\vec{EF}| = 2$，则 $\vec{AE} \cdot \vec{BF}$ 的最小值为______。

**解析**

在平面直角坐标系中，设动点 $E(0, y_1)$，$F(0, y_2)$。
由 $|\vec{EF}| = 2$，得 $|y_2 - y_1| = 2$。
已知点 $A(-1, 0)$，$B(2, 0)$，则向量坐标为：
$$\vec{AE} = (0 - (-1), y_1 - 0) = (1, y_1),$$
$$\vec{BF} = (0 - 2, y_2 - 0) = (-2, y_2).$$
因此向量数量积为：
$$\vec{AE} \cdot \vec{BF} = 1 \times (-2) + y_1 y_2 = -2 + y_1 y_2.$$
由 $|y_2 - y_1| = 2$，两边平方得：
$$(y_2 - y_1)^2 = y_1^2 + y_2^2 - 2y_1 y_2 = 4.$$
由基本不等式 $y_1^2 + y_2^2 \ge 2|y_1 y_2| \ge -2y_1 y_2$，或直接表示 $y_2 = y_1 \pm 2$：
$$y_1 y_2 = y_1(y_1 \pm 2) = y_1^2 \pm 2y_1 = (y_1 \pm 1)^2 - 1 \ge -1.$$
当且仅当 $y_1 = \mp 1$ 且 $y_2 = \pm 1$ 时取等号，此时 $y_1 y_2 = -1$。
从而数量积的最小值为：
$$\vec{AE} \cdot \vec{BF} \ge -2 + (-1) = -3.$$

**答案：$-3$**

### 第 9 题

**题目**：

有编号互不相同的五个砝码，其中 5 克、3 克、1 克砝码各一个，2 克砝码两个。从中随机选取三个，则这三个砝码的总质量为 9 克的概率是______。（结果用最简分数表示）

**解析**

将 5 个砝码记为 $5$、$3$、$2_A$、$2_B$、$1$。
从这 5 个砝码中随机选取 3 个，所有可能的基本事件总数为：
$$\binom{5}{3} = 10.$$
设事件 $A$ 为“选取的 3 个砝码总质量为 9 克”。
分析满足条件的质量组合：
- 组合一：$5 + 3 + 1 = 9$，对应选取 $\{5, 3, 1\}$，共 1 种情况；
- 组合二：$5 + 2_A + 2_B = 9$，对应选取 $\{5, 2_A, 2_B\}$，共 1 种情况；
若不含 5 克砝码，其余 4 个砝码总和仅为 $3 + 2 + 2 + 1 = 8 < 9$ 克，不可能构成 9 克。
若含 5 克砝码，剩余两砝码质量之和必须等于 4 克，而 $4 = 3 + 1 = 2 + 2$，仅有上述两种选取方案。
故事件 $A$ 包含的基本事件数为 $2$。
所求概率为 $P(A) = \dfrac{2}{10} = \dfrac{1}{5}$。

**答案：$\dfrac{1}{5}$**

### 第 10 题

**题目**：

设等比数列 $\{a_n\}$ 的通项公式为 $a_n = q^{n-1}$（$n \in \mathbf{N}^*$），前 $n$ 项和为 $S_n$，若 $\lim\limits_{n \to \infty} \dfrac{S_n}{a_{n+1}} = \dfrac{1}{2}$，则 $q =$______。

**解析**

等比数列 $\{a_n\}$ 通项为 $a_n = q^{n-1}$，则 $a_{n+1} = q^n$。
分情况讨论公比 $q$：
- 若 $|q| < 1$，当 $n \to \infty$ 时，$S_n \to \dfrac{1}{1 - q}$，$a_{n+1} = q^n \to 0$，分式极限趋于无穷大，不合题意；
- 若 $q = 1$，$S_n = n$，$a_{n+1} = 1$，极限为无穷大，不合题意；
- 若 $q = -1$，$a_{n+1}$ 及 $S_n$ 振荡，极限不存在；
- 若 $|q| > 1$，前 $n$ 项和为 $S_n = \dfrac{1 - q^n}{1 - q}$，则：
$$\frac{S_n}{a_{n+1}} = \frac{1 - q^n}{(1 - q)q^n} = \frac{q^{-n} - 1}{1 - q}.$$
当 $n \to \infty$ 时，因为 $|q| > 1$，所以 $q^{-n} \to 0$。
故：
$$\lim_{n \to \infty} \frac{S_n}{a_{n+1}} = \frac{0 - 1}{1 - q} = \frac{1}{q - 1}.$$
由已知 $\dfrac{1}{q - 1} = \dfrac{1}{2}$，解得 $q - 1 = 2 \implies q = 3$。
$q = 3$ 满足 $|q| > 1$。

**答案：$3$**

### 第 11 题

**题目**：

已知常数 $a > 0$，函数 $f(x) = \dfrac{2^x}{2^x + ax}$ 的图象经过点 $P\left(p, \dfrac{6}{5}\right)$，$Q\left(q, -\dfrac{1}{5}\right)$。若 $2^{p+q} = 36pq$，则 $a =$______。

**解析**

函数为 $f(x) = \dfrac{2^x}{2^x + ax}$，常数 $a > 0$。
将点 $P\left(p, \dfrac{6}{5}\right)$ 代入函数解析式：
$$\frac{2^p}{2^p + ap} = \frac{6}{5} \implies 5 \cdot 2^p = 6 \cdot 2^p + 6ap \implies 2^p = -6ap.$$
将点 $Q\left(q, -\dfrac{1}{5}\right)$ 代入函数解析式：
$$\frac{2^q}{2^q + aq} = -\frac{1}{5} \implies 5 \cdot 2^q = -2^q - aq \implies 6 \cdot 2^q = -aq \implies 2^q = -\frac{1}{6}aq.$$
两式相乘得：
$$2^{p+q} = 2^p \cdot 2^q = (-6ap) \left(-\frac{1}{6}aq\right) = a^2 pq.$$
已知 $2^{p+q} = 36pq$。
因为对任意实数 $x$ 恒有 $2^x > 0$，所以 $2^p > 0$，$2^q > 0$。
由上两式知 $-6ap > 0$ 且 $-\dfrac{1}{6}aq > 0$，从而 $p < 0, q < 0$，必有 $pq > 0 \ne 0$。
因此两边除以 $pq$，得：
$$a^2 = 36.$$
又已知 $a > 0$，解得 $a = 6$。

**答案：$6$**

### 第 12 题

**题目**：

已知实数 $x_1, x_2, y_1, y_2$ 满足：$x_1^2 + y_1^2 = 1$，$x_2^2 + y_2^2 = 1$，$x_1 x_2 + y_1 y_2 = \dfrac{1}{2}$，则 $\dfrac{|x_1 + y_1 - 1|}{\sqrt{2}} + \dfrac{|x_2 + y_2 - 1|}{\sqrt{2}}$ 的最大值为______。

**解析**

设平面上点 $A(x_1, y_1)$ 与 $B(x_2, y_2)$。
由 $x_1^2 + y_1^2 = 1$ 与 $x_2^2 + y_2^2 = 1$ 知，点 $A, B$ 均在单位圆 $x^2 + y^2 = 1$ 上。
向量内积为：
$$\vec{OA} \cdot \vec{OB} = x_1 x_2 + y_1 y_2 = \frac{1}{2}.$$
因为 $|\vec{OA}| = |\vec{OB}| = 1$，所以 $\cos\angle AOB = \dfrac{1}{2}$，故 $\angle AOB = \dfrac{\pi}{3}$ 为定角。
考虑直线 $l: x + y - 1 = 0$。平面上任意点 $(x, y)$ 到直线 $l$ 的距离为：
$$d = \frac{|x + y - 1|}{\sqrt{1^2 + 1^2}} = \frac{|x + y - 1|}{\sqrt{2}}.$$
因此所求式子等价于单位圆上两动点 $A, B$ 到直线 $l$ 的距离之和 $d_A + d_B$ 的最大值。
圆心 $O(0, 0)$ 到直线 $l$ 的距离为 $d_O = \dfrac{|0 + 0 - 1|}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$。
直线 $l$ 与单位圆交于 $(1, 0)$ 和 $(0, 1)$。
当 $A, B$ 位于直线 $l$ 下方且远离直线（向第三象限方向）时，$x_i + y_i - 1 < 0$：
$$d_A + d_B = \frac{1 - (x_1 + y_1)}{\sqrt{2}} + \frac{1 - (x_2 + y_2)}{\sqrt{2}} = \sqrt{2} - \frac{(x_1 + x_2) + (y_1 + y_2)}{\sqrt{2}}.$$
设 $A\left(\cos\alpha, \sin\alpha\right)$，则 $B\left(\cos\left(\alpha + \dfrac{\pi}{3}\right), \sin\left(\alpha + \dfrac{\pi}{3}\right)\right)$。
利用三角恒等变换：
$$x_1 + x_2 = \cos\alpha + \cos\left(\alpha + \frac{\pi}{3}\right) = 2\cos\left(\alpha + \frac{\pi}{6}\right)\cos\frac{\pi}{6} = \sqrt{3}\cos\left(\alpha + \frac{\pi}{6}\right),$$
$$y_1 + y_2 = \sin\alpha + \sin\left(\alpha + \frac{\pi}{3}\right) = 2\sin\left(\alpha + \frac{\pi}{6}\right)\cos\frac{\pi}{6} = \sqrt{3}\sin\left(\alpha + \frac{\pi}{6}\right).$$
两式相加：
$$(x_1 + x_2) + (y_1 + y_2) = \sqrt{3}\left[\cos\left(\alpha + \frac{\pi}{6}\right) + \sin\left(\alpha + \frac{\pi}{6}\right)\right] = \sqrt{6}\sin\left(\alpha + \frac{\pi}{6} + \frac{\pi}{4}\right) = \sqrt{6}\sin\left(\alpha + \frac{5\pi}{12}\right).$$
当 $\sin\left(\alpha + \dfrac{5\pi}{12}\right) = -1$ 时，取得最小值 $-\sqrt{6}$。
代入得两点到直线距离之和的最大值为：
$$\frac{2 - (-\sqrt{6})}{\sqrt{2}} = \frac{2 + \sqrt{6}}{\sqrt{2}} = \sqrt{2} + \sqrt{3}.$$
此时两点横纵坐标之和均为负值，均严格位于直线 $l$ 下方，绝对值拆解无误。
故最大值为 $\sqrt{2} + \sqrt{3}$。

**答案：$\sqrt{2} + \sqrt{3}$**

## 二、选择题

### 第 13 题

**题目**：

设 $P$ 是椭圆 $\dfrac{x^2}{5} + \dfrac{y^2}{3} = 1$ 上的动点，则 $P$ 到该椭圆的两个焦点的距离之和为（ ）
(A) $2\sqrt{2}$
(B) $2\sqrt{3}$
(C) $2\sqrt{5}$
(D) $4\sqrt{2}$

**解析**

椭圆方程为 $\dfrac{x^2}{5} + \dfrac{y^2}{3} = 1$。
这里 $a^2 = 5$，$b^2 = 3$，长半轴长 $a = \sqrt{5}$。
根据椭圆的几何定义，椭圆上的动点 $P$ 到两焦点的距离之和等于长轴长 $2a$：
$$|PF_1| + |PF_2| = 2a = 2\sqrt{5}.$$
故选 C。

**答案：C**

### 第 14 题

**题目**：

已知 $a \in \mathbf{R}$，则“$a > 1$”是“$\dfrac{1}{a} < 1$”的（ ）
(A) 充分非必要条件
(B) 必要非充分条件
(C) 充要条件
(D) 既非充分又非必要条件

**解析**

- 充分性：若 $a > 1$，则显然 $a > 0$，在不等式两边同除以 $a$，得 $\dfrac{1}{a} < 1$，故充分性成立；
- 必要性：若 $\dfrac{1}{a} < 1$，移项通分得 $\dfrac{1 - a}{a} < 0 \iff a(a - 1) > 0$，解得 $a > 1$ 或 $a < 0$。例如取 $a = -1$，满足 $\dfrac{1}{-1} = -1 < 1$，但推不出 $a > 1$，故必要性不成立。
综上，“$a > 1$”是“$\dfrac{1}{a} < 1$”的充分非必要条件。
故选 A。

**答案：A**

### 第 15 题

**题目**：

《九章算术》中，称底面为矩形而有一侧棱垂直于底面的四棱锥为阳马。设 $AA_1$ 是正六棱柱的一条侧棱，如图。若阳马以该正六棱柱的顶点为顶点、以 $AA_1$ 为底面矩形的一边，则这样的阳马的个数是（ ）
(A) 4
(B) 8
(C) 12
(D) 16

[题图：正六棱柱与阳马](../math-gaokao-latex/2018_上海卷/figures/q15.tikz.tex)

**解析**

设底面正六边形为 $ABCDEF$，上底面对应顶点为 $A_1B_1C_1D_1E_1F_1$。
阳马的定义为：底面为矩形且有一条侧棱垂直于底面的四棱锥。
题目要求以 $AA_1$ 为底面矩形的一边，故底面矩形必含棱 $AA_1$。
正六棱柱中包含侧棱 $AA_1$ 的矩形截面或侧面共有 5 个，分别讨论：
1. 侧面矩形 $AA_1B_1B$：
   在底面正六边形中，连接 $AE$，由对称性 $\angle BAE = 90^\circ$，即 $AE \perp AB$。又正六棱柱中 $AA_1 \perp$ 底面，故 $AA_1 \perp AE$。因 $AB \cap AA_1 = A$，故 $AE \perp$ 平面 $AA_1B_1B$。
   同理，连接 $A_1E_1$，有 $A_1E_1 \perp$ 平面 $AA_1B_1B$。
   在 $B$ 端，同理有 $BD \perp AB$ 且 $BD \perp BB_1$，故 $BD \perp$ 平面 $AA_1B_1B$，$B_1D_1 \perp$ 平面 $AA_1B_1B$。
   因此，以矩形 $AA_1B_1B$ 为底面，顶点分别取 $E, E_1, D, D_1$ 时，连接顶点的侧棱垂直于底面，均构成阳马，共 4 个；
2. 侧面矩形 $AA_1F_1F$：
   同理，由 $AC \perp AF$ 及 $FD \perp AF$，垂直于平面 $AA_1F_1F$ 的棱为从 $C, C_1, D, D_1$ 引向底面的棱，顶点取这 4 点时均构成阳马，共 4 个；
3. 次对角面矩形 $AA_1E_1E$：
   由上知 $AB \perp AE$ 且 $AB \perp AA_1$，故棱 $AB \perp$ 平面 $AA_1E_1E$，$A_1B_1 \perp$ 平面 $AA_1E_1E$。
   在 $E$ 端，正六边形中 $ED \perp AE$，故 $ED \perp$ 平面 $AA_1E_1E$，$E_1D_1 \perp$ 平面 $AA_1E_1E$。
   因此顶点分别取 $B, B_1, D, D_1$ 时，侧棱垂直于底面，均构成阳马，共 4 个；
4. 次对角面矩形 $AA_1C_1C$：
   同理，由 $AF \perp AC$ 及 $CD \perp AC$，顶点取 $F, F_1, D, D_1$ 时均构成阳马，共 4 个；
5. 主对角面矩形 $AA_1D_1D$：
   在正六边形中，过 $A$ 点的边 $AB, AF$ 与主对角线 $AD$ 所成角均为 $60^\circ \ne 90^\circ$；同理过 $D$ 点的边与 $AD$ 成角亦为 $60^\circ$。六棱柱中不存在任何棱垂直于主对角面，故不能构成阳马。
综合以上情况，这样的阳马个数总计为：
$$4 + 4 + 4 + 4 = 16.$$
故选 D。

**答案：D**

### 第 16 题

**题目**：

设 $D$ 是含数 1 的有限实数集，$f(x)$ 是定义在 $D$ 上的函数。若 $f(x)$ 的图象绕原点逆时针旋转 $\dfrac{\pi}{6}$ 后与原图象重合，则在以下各项中，$f(1)$ 的可能取值只能是（ ）
(A) $\sqrt{3}$
(B) $\dfrac{\sqrt{3}}{2}$
(C) $\dfrac{\sqrt{3}}{3}$
(D) 0

**解析**

设图象为点集 $G = \{(x, f(x)) \mid x \in D\}$。由函数定义，图象上任意两点横坐标互不相同。
因为 $1 \in D$，所以点 $P_0(1, f(1)) \in G$。
点 $P_0$ 的横坐标为 $1 > 0$。设点 $P_0$ 的极坐标为 $(r, \theta)$，其中 $r = \sqrt{1 + [f(1)]^2} > 0$，极角 $\theta \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$，且满足 $\tan\theta = f(1)$。
若图象 $G$ 绕原点逆时针旋转 $\dfrac{\pi}{6}$ 后与原图象重合，则点 $P_0$ 绕原点旋转 $\dfrac{k\pi}{6}$（$k = 0, 1, 2, \dots, 11$）所得的 12 个点：
$$P_k\left(r, \theta + \frac{k\pi}{6}\right) \quad (k = 0, 1, \dots, 11)$$
全部位于图象 $G$ 中。
根据函数定义，$G$ 中任意两点不能具有相同的横坐标。即对任意 $k_1 \ne k_2 \pmod{12}$，必须满足：
$$r \cos\left(\theta + \frac{k_1\pi}{6}\right) \ne r \cos\left(\theta + \frac{k_2\pi}{6}\right) \iff \cos\left(\theta + \frac{k_1\pi}{6}\right) \ne \cos\left(\theta + \frac{k_2\pi}{6}\right).$$
两角余弦相等当且仅当其和或差为 $2\pi$ 的整数倍。
由于两极角之差为 $(k_1 - k_2)\dfrac{\pi}{6}$，非 $2\pi$ 的整数倍，故横坐标相同只能发生在两角之和为 $2\pi$ 的整数倍时：
$$\left(\theta + \frac{k_1\pi}{6}\right) + \left(\theta + \frac{k_2\pi}{6}\right) = 2m\pi \iff 2\theta + (k_1 + k_2)\frac{\pi}{6} = 2m\pi.$$
即 $2\theta = 2m\pi - (k_1 + k_2)\dfrac{\pi}{6}$，也就是 $\theta$ 为 $\dfrac{\pi}{12} = 15^\circ$ 的整数倍。
检验各选项：
- 若取 (A) $f(1) = \sqrt{3}$，则 $\tan\theta = \sqrt{3} \implies \theta = \dfrac{\pi}{3} = 60^\circ$（为 $15^\circ$ 的整数倍），此时 $k=0$ 与 $k=8$ 旋转点的横坐标均为 $r\cos 60^\circ = \dfrac{1}{2}r$，违背函数定义；
- 若取 (C) $f(1) = \dfrac{\sqrt{3}}{3}$，则 $\tan\theta = \dfrac{\sqrt{3}}{3} \implies \theta = \dfrac{\pi}{6} = 30^\circ$，此时 $k=0$ 与 $k=10$ 横坐标相同，矛盾；
- 若取 (D) $f(1) = 0$，则 $\tan\theta = 0 \implies \theta = 0^\circ$，此时 $k=1$ 与 $k=11$ 横坐标相同，矛盾；
- 若取 (B) $f(1) = \dfrac{\sqrt{3}}{2}$，此时 $\tan\theta = \dfrac{\sqrt{3}}{2}$，$\theta$ 不是 $15^\circ$ 的整数倍，所有 12 个点的横坐标两两不同，符合函数图象定义。
故选 B。

**答案：B**

### 第 17 题

**题目**：

已知圆锥的顶点为 $P$，底面圆心为 $O$，半径为 2。
(1) 设圆锥的母线长为 4，求圆锥的体积；
(2) 设 $PO = 4$，$OA, OB$ 是底面半径，且 $\angle AOB = 90^\circ$，$M$ 为线段 $AB$ 的中点，如图，求异面直线 $PM$ 与 $OB$ 所成的角的大小。

[题图：圆锥与截面三角形](../math-gaokao-latex/2018_上海卷/figures/q17.tikz.tex)

**解析**

**(1) 解析**

设底面半径为 $r = 2$，母线长为 $l = 4$。
由圆锥的高、底面半径与母线满足勾股定理：
$$h = \sqrt{l^2 - r^2} = \sqrt{4^2 - 2^2} = \sqrt{12} = 2\sqrt{3}.$$
圆锥的底面积为：
$$S = \pi r^2 = \pi \times 2^2 = 4\pi.$$
故圆锥的体积为：
$$V = \frac{1}{3} S h = \frac{1}{3} \times 4\pi \times 2\sqrt{3} = \frac{8\sqrt{3}\pi}{3}.$$

**(2) 解析**

以底面圆心 $O$ 为坐标原点，分别以 $\vec{OA}$ 方向为 $x$ 轴正方向，$\vec{OB}$ 方向为 $y$ 轴正方向，$\vec{OP}$ 方向为 $z$ 轴正方向建立空间直角坐标系。
根据题设条件 $OA = 2, OB = 2, PO = 4$，各点坐标为：
$$O(0, 0, 0), \quad A(2, 0, 0), \quad B(0, 2, 0), \quad P(0, 0, 4).$$
因为 $M$ 是线段 $AB$ 的中点，由中点坐标公式得：
$$M(1, 1, 0).$$
计算向量坐标：
$$\vec{PM} = (1 - 0, 1 - 0, 0 - 4) = (1, 1, -4),$$
$$\vec{OB} = (0, 2, 0).$$
求两向量模长与数量积：
$$|\vec{PM}| = \sqrt{1^2 + 1^2 + (-4)^2} = \sqrt{18} = 3\sqrt{2},$$
$$|\vec{OB}| = 2,$$
$$\vec{PM} \cdot \vec{OB} = 1 \times 0 + 1 \times 2 + (-4) \times 0 = 2.$$
设异面直线 $PM$ 与 $OB$ 所成的角为 $\theta$（$\theta \in \left[0, \dfrac{\pi}{2}\right]$），则：
$$\cos\theta = \frac{|\vec{PM} \cdot \vec{OB}|}{|\vec{PM}| \cdot |\vec{OB}|} = \frac{2}{3\sqrt{2} \times 2} = \frac{1}{3\sqrt{2}} = \frac{\sqrt{2}}{6}.$$
故异面直线 $PM$ 与 $OB$ 所成角的大小为 $\arccos\dfrac{\sqrt{2}}{6}$。

**答案（1）：$\dfrac{8\sqrt{3}\pi}{3}$**

**答案（2）：$\arccos\dfrac{\sqrt{2}}{6}$**

### 第 18 题

**题目**：

设常数 $a \in \mathbf{R}$，函数 $f(x) = a\sin 2x + 2\cos^2 x$。
(1) 若 $f(x)$ 为偶函数，求 $a$ 的值；
(2) 若 $f\left(\dfrac{\pi}{4}\right) = \sqrt{3} + 1$，求方程 $f(x) = 1 - \sqrt{2}$ 在区间 $[-\pi, \pi]$ 上的解。

**解析**

**(1) 解析**

利用二倍角公式降次：$2\cos^2 x = \cos 2x + 1$。
函数解析式可整理为：
$$f(x) = a\sin 2x + \cos 2x + 1.$$
因为函数 $f(x)$ 为偶函数，所以定义域为 $\mathbf{R}$ 且恒有 $f(-x) = f(x)$。
代入得：
$$-a\sin 2x + \cos 2x + 1 = a\sin 2x + \cos 2x + 1,$$
整理得 $2a\sin 2x = 0$ 对任意 $x \in \mathbf{R}$ 恒成立，故 $a = 0$。
反之，当 $a = 0$ 时，$f(x) = \cos 2x + 1 = 2\cos^2 x$，显然为偶函数。
因此 $a = 0$。

**(2) 解析**

由题意 $f\left(\dfrac{\pi}{4}\right) = \sqrt{3} + 1$，代入原函数：
$$f\left(\frac{\pi}{4}\right) = a\sin\frac{\pi}{2} + 2\cos^2\frac{\pi}{4} = a \times 1 + 2 \times \frac{1}{2} = a + 1.$$
故 $a + 1 = \sqrt{3} + 1 \implies a = \sqrt{3}$。
从而：
$$f(x) = \sqrt{3}\sin 2x + \cos 2x + 1 = 2\sin\left(2x + \frac{\pi}{6}\right) + 1.$$
方程 $f(x) = 1 - \sqrt{2}$ 等价于：
$$2\sin\left(2x + \frac{\pi}{6}\right) + 1 = 1 - \sqrt{2} \iff \sin\left(2x + \frac{\pi}{6}\right) = -\frac{\sqrt{2}}{2}.$$
因为 $x \in [-\pi, \pi]$，所以 $2x \in [-2\pi, 2\pi]$，
令 $u = 2x + \dfrac{\pi}{6}$，则：
$$u \in \left[-2\pi + \frac{\pi}{6}, 2\pi + \frac{\pi}{6}\right] = \left[-\frac{11\pi}{6}, \frac{13\pi}{6}\right].$$
在区间 $\left[-\dfrac{11\pi}{6}, \dfrac{13\pi}{6}\right]$ 上，满足 $\sin u = -\dfrac{\sqrt{2}}{2}$ 的解为：
$$u_1 = -\frac{3\pi}{4}, \quad u_2 = -\frac{\pi}{4}, \quad u_3 = \frac{5\pi}{4}, \quad u_4 = \frac{7\pi}{4}.$$
分别代入 $2x + \dfrac{\pi}{6} = u$ 解得：
1. $2x = -\dfrac{3\pi}{4} - \dfrac{\pi}{6} = -\dfrac{11\pi}{12} \implies x = -\dfrac{11\pi}{24}$；
2. $2x = -\dfrac{\pi}{4} - \dfrac{\pi}{6} = -\dfrac{5\pi}{12} \implies x = -\dfrac{5\pi}{24}$；
3. $2x = \dfrac{5\pi}{4} - \dfrac{\pi}{6} = \dfrac{13\pi}{12} \implies x = \dfrac{13\pi}{24}$；
4. $2x = \dfrac{7\pi}{4} - \dfrac{\pi}{6} = \dfrac{19\pi}{12} \implies x = \dfrac{19\pi}{24}$。
故原方程在 $[-\pi, \pi]$ 上的解为 $x = -\dfrac{11\pi}{24}, -\dfrac{5\pi}{24}, \dfrac{13\pi}{24}, \dfrac{19\pi}{24}$。

**答案（1）：$a = 0$**

**答案（2）：$x = -\dfrac{11\pi}{24}, -\dfrac{5\pi}{24}, \dfrac{13\pi}{24}, \dfrac{19\pi}{24}$**

### 第 19 题

**题目**：

某群体的人均通勤时间，是指单日内该群体中成员从居住地到工作地的平均用时。某地上班族 $S$ 中的成员仅以自驾或公交方式通勤。分析显示：当 $S$ 中 $x\%$（$0 < x < 100$）的成员自驾时，自驾群体的人均通勤时间为
$$f(x) = \begin{cases} 30, & 0 < x \le 30, \\ 2x + \dfrac{1800}{x} - 90, & 30 < x < 100 \end{cases}$$
（单位：分钟）而公交群体的人均通勤时间不受 $x$ 影响，恒为 40 分钟。试根据上述分析结果回答下列问题：
(1) 当 $x$ 在什么范围内时，公交群体的人均通勤时间少于自驾群体的人均通勤时间？
(2) 求该地上班族 $S$ 的人均通勤时间 $g(x)$ 的表达式；讨论 $g(x)$ 的单调性，并说明其实际意义。

**解析**

**(1) 解析**

由题意，公交群体的人均通勤时间恒为 40 分钟。
公交群体的人均通勤时间少于自驾群体，即满足不等式 $f(x) > 40$。
分段求解：
- 当 $0 < x \le 30$ 时，$f(x) = 30 \le 40$，不等式无解；
- 当 $30 < x < 100$ 时：
$$2x + \frac{1800}{x} - 90 > 40 \iff 2x + \frac{1800}{x} - 130 > 0.$$
因为 $x > 0$，两边同乘 $x$ 并整理：
$$2x^2 - 130x + 1800 > 0 \iff x^2 - 65x + 900 > 0.$$
因式分解得：
$$(x - 20)(x - 45) > 0.$$
解得 $x < 20$ 或 $x > 45$。
结合定义域 $30 < x < 100$，得 $45 < x < 100$。
综上所述，当 $x \in (45, 100)$ 时，公交群体的人均通勤时间少于自驾群体的人均通勤时间。

**(2) 解析**

在上班族群体 $S$ 中，自驾人数所占比例为 $\dfrac{x}{100}$，乘公交人数所占比例为 $1 - \dfrac{x}{100}$。
因此上班族 $S$ 的人均通勤时间为其加权平均：
$$g(x) = \frac{x}{100} f(x) + \left(1 - \frac{x}{100}\right) \times 40 = 40 + \frac{x}{100}[f(x) - 40].$$
分段代入化简：
- 当 $0 < x \le 30$ 时：
$$g(x) = 40 + \frac{x}{100}(30 - 40) = 40 - \frac{x}{10};$$
- 当 $30 < x < 100$ 时：
$$g(x) = 40 + \frac{x}{100}\left(2x + \frac{1800}{x} - 130\right) = 40 + \frac{2x^2 - 130x + 1800}{100} = \frac{x^2 - 65x + 2900}{50}.$$
在分界点 $x = 30$ 处：
$g(30) = 40 - 3 = 37$，而 $\dfrac{30^2 - 65 \times 30 + 2900}{50} = \dfrac{1850}{50} = 37$，函数在 $x = 30$ 处连续。
故 $g(x)$ 的解析式为：
$$g(x) = \begin{cases} 40 - \dfrac{x}{10}, & 0 < x \le 30, \\ \dfrac{x^2 - 65x + 2900}{50}, & 30 < x < 100. \end{cases}$$
讨论函数 $g(x)$ 的单调性：
- 当 $x \in (0, 30]$ 时，$g(x) = -\dfrac{x}{10} + 40$ 是减函数；
- 当 $x \in (30, 100)$ 时，$g(x) = \dfrac{1}{50}\left(x - \dfrac{65}{2}\right)^2 + \dfrac{7375}{200}$ 为二次函数，对称轴为 $x = 32.5$。
  所以在 $(30, 32.5]$ 上，$g(x)$ 单调递减；在 $[32.5, 100)$ 上，$g(x)$ 单调递增。
综上所述，$g(x)$ 在 $(0, 32.5]$ 上单调递减，在 $[32.5, 100)$ 上单调递增。
实际意义：
当自驾人数比例不超过 $32.5\%$ 时，随着自驾比例增加，上班族人均通勤时间逐步缩短；当自驾人数占比达到 $32.5\%$ 时，人均通勤时间达到最小值；当自驾人数比例超过 $32.5\%$ 时，随着自驾人数比例继续增加，道路拥堵加剧，上班族人均通勤时间反而随之增长。

**答案（1）：$(45, 100)$**

**答案（2）：$g(x) = \begin{cases} 40 - \dfrac{x}{10}, & 0 < x \le 30, \\ \dfrac{x^2 - 65x + 2900}{50}, & 30 < x < 100 \end{cases}$。单调性与实际意义见解析。**

### 第 20 题

**题目**：

设常数 $t > 2$。在平面直角坐标系 $xOy$ 中，已知点 $F(2, 0)$，直线 $l: x = t$，曲线 $\Gamma: y^2 = 8x$（$0 \le x \le t, y \ge 0$）。$l$ 与 $x$ 轴交于点 $A$、与 $\Gamma$ 交于点 $B$。$P, Q$ 分别是曲线 $\Gamma$ 与线段 $AB$ 上的动点。
(1) 用 $t$ 表示点 $B$ 到点 $F$ 的距离；
(2) 设 $t = 3$，$|FQ| = 2$，线段 $OQ$ 的中点在直线 $FP$ 上，求 $\triangle AQP$ 的面积；
(3) 设 $t = 8$，是否存在以 $FP, FQ$ 为邻边的矩形 $FPEQ$，使得点 $E$ 在 $\Gamma$ 上？若存在，求点 $P$ 的坐标；若不存在，说明理由。

**解析**

**(1) 解析**

直线 $l: x = t$，$A(t, 0)$。
因为点 $B$ 为直线 $l$ 与曲线 $\Gamma: y^2 = 8x$（$y \ge 0$）的交点，所以 $B(t, \sqrt{8t})$。
曲线 $\Gamma$ 为抛物线，标准方程为 $y^2 = 8x$，其焦点为 $F(2, 0)$，准线方程为 $x = -2$。
由抛物线的几何定义，抛物线上的点到焦点的距离等于其到准线的距离：
$$|BF| = t - (-2) = t + 2.$$

**(2) 解析**

当 $t = 3$ 时，直线 $l: x = 3$，$A(3, 0)$，$B(3, 2\sqrt{6})$。
动点 $Q$ 在线段 $AB$ 上，设 $Q(3, y_Q)$，其中 $0 \le y_Q \le 2\sqrt{6}$。
由 $|FQ| = 2$ 及两点间距离公式：
$$|FQ|^2 = (3 - 2)^2 + y_Q^2 = 1 + y_Q^2 = 2^2 = 4 \implies y_Q^2 = 3.$$
因 $y_Q \ge 0$，故 $y_Q = \sqrt{3}$，即 $Q(3, \sqrt{3})$。
线段 $OQ$ 的中点设为 $M$，由中点坐标公式得：
$$M\left(\frac{3}{2}, \frac{\sqrt{3}}{2}\right).$$
点 $F(2, 0)$，直线 $FM$ 的斜率为：
$$k_{FM} = \frac{\dfrac{\sqrt{3}}{2} - 0}{\dfrac{3}{2} - 2} = -\sqrt{3}.$$
从而直线 $FP$（即直线 $FM$）的方程为：
$$y - 0 = -\sqrt{3}(x - 2) \iff y = -\sqrt{3}x + 2\sqrt{3}.$$
将直线方程与曲线 $\Gamma: y^2 = 8x$ 联立：
$$3(x - 2)^2 = 8x \iff 3x^2 - 20x + 12 = 0.$$
因式分解得 $(3x - 2)(x - 6) = 0$。
由于点 $P$ 位于曲线 $\Gamma$（$0 \le x \le t = 3$）上，故 $x = 6$ 舍去，得 $x_P = \dfrac{2}{3}$。
代入得 $y_P = -\sqrt{3}\left(\dfrac{2}{3} - 2\right) = \dfrac{4\sqrt{3}}{3}$。
即点 $P\left(\dfrac{2}{3}, \dfrac{4\sqrt{3}}{3}\right)$。
在 $\triangle AQP$ 中，底边 $AQ$ 在垂直线 $x = 3$ 上，底边长为 $|AQ| = y_Q = \sqrt{3}$。
点 $P$ 到直线 $AQ$ 的距离即高为 $h = 3 - x_P = 3 - \dfrac{2}{3} = \dfrac{7}{3}$。
故 $\triangle AQP$ 的面积为：
$$S_{\triangle AQP} = \frac{1}{2} |AQ| \cdot h = \frac{1}{2} \times \sqrt{3} \times \frac{7}{3} = \frac{7\sqrt{3}}{6}.$$

**(3) 解析**

当 $t = 8$ 时，$A(8, 0)$，$B(8, 8)$。动点 $Q$ 在线段 $AB$ 上，设 $Q(8, y_0)$，其中 $0 \le y_0 \le 8$。
焦点 $F(2, 0)$，则向量 $\vec{FQ} = (8 - 2, y_0 - 0) = (6, y_0)$。
设动点 $P(x_1, y_1)$ 在 $\Gamma$ 上，满足 $y_1^2 = 8x_1$，$0 \le x_1 \le 8, y_1 \ge 0$。
则向量 $\vec{FP} = (x_1 - 2, y_1)$。
以 $FP, FQ$ 为邻边构成矩形 $FPEQ$：
第一，两邻边相互垂直，即 $\vec{FP} \cdot \vec{FQ} = 0$：
$$6(x_1 - 2) + y_0 y_1 = 0 \implies y_0 y_1 = 12 - 6x_1.$$
第二，在矩形中，对角线向量满足平行四边形法则：
$$\vec{FE} = \vec{FP} + \vec{FQ} = (x_1 + 4, y_1 + y_0).$$
设 $E(x_E, y_E)$，则 $E$ 点坐标为：
$$x_E = 2 + (x_1 + 4) = x_1 + 6, \quad y_E = y_1 + y_0.$$
已知点 $E$ 在曲线 $\Gamma$ 上，故满足 $y_E^2 = 8x_E$（$0 \le x_E \le 8, y_E \ge 0$），代入得：
$$(y_1 + y_0)^2 = 8(x_1 + 6) = 8x_1 + 48.$$
展开左端得 $y_1^2 + 2y_0 y_1 + y_0^2 = 8x_1 + 48$。
将 $y_1^2 = 8x_1$ 与 $y_0 y_1 = 12 - 6x_1$ 代入消元：
$$8x_1 + 2(12 - 6x_1) + y_0^2 = 8x_1 + 48 \implies y_0^2 = 12x_1 + 24.$$
对垂直条件所得的 $y_0 y_1 = 12 - 6x_1$ 两边平方：
$$(y_0 y_1)^2 = y_0^2 y_1^2 = (12 - 6x_1)^2.$$
将 $y_1^2 = 8x_1$ 及 $y_0^2 = 12x_1 + 24$ 代入上式：
$$(12x_1 + 24) \cdot 8x_1 = 36(2 - x_1)^2.$$
两边同除以 12：
$$2(x_1 + 2) \cdot 8x_1 = 3(x_1^2 - 4x_1 + 4) \iff 16x_1^2 + 32x_1 = 3x_1^2 - 12x_1 + 12.$$
整理得一元二次方程：
$$13x_1^2 + 44x_1 - 12 = 0 \iff (13x_1 - ?)$$
稍作核算系数：
$(12x_1 + 24) \cdot 8x_1 = 96x_1(x_1 + 2) = 96x_1^2 + 192x_1$。
右边为 $36(x_1 - 2)^2 = 36x_1^2 - 144x_1 + 144$。
两边同除以 12：
$8x_1(x_1 + 2) = 3(x_1 - 2)^2 \iff 8x_1^2 + 16x_1 = 3x_1^2 - 12x_1 + 12$。
整理得：
$$5x_1^2 + 28x_1 - 12 = 0.$$
因式分解得：
$$(5x_1 - 2)(x_1 + 6) = 0.$$
因为 $x_1 \ge 0$，故解得唯一正根 $x_1 = \dfrac{2}{5}$。
此时各点及参数的有效性核验：
1. $x_E = x_1 + 6 = \dfrac{32}{5} \le 8$；
2. $y_1 = \sqrt{8x_1} = \sqrt{\dfrac{16}{5}} = \dfrac{4\sqrt{5}}{5}$；
3. $y_0 = \sqrt{12x_1 + 24} = \sqrt{\dfrac{24}{5} + 24} = \sqrt{\dfrac{144}{5}} = \dfrac{12\sqrt{5}}{5} \le 8$（因 $\dfrac{144}{5} = 28.8 < 64$）；
4. $y_0 y_1 = \dfrac{12\sqrt{5}}{5} \times \dfrac{4\sqrt{5}}{5} = \dfrac{48}{5} = 12 - 6 \times \dfrac{2}{5}$，垂直条件满足且两邻边非零非退化。
因此存在满足条件的矩形，点 $P$ 的坐标为 $\left(\dfrac{2}{5}, \dfrac{4\sqrt{5}}{5}\right)$。

**答案（1）：$t + 2$**

**答案（2）：$\dfrac{7\sqrt{3}}{6}$**

**答案（3）：存在，$P\left(\dfrac{2}{5}, \dfrac{4\sqrt{5}}{5}\right)$**

### 第 21 题

**题目**：

给定无穷数列 $\{a_n\}$，若无穷数列 $\{b_n\}$ 满足：对任意 $n \in \mathbf{N}^*$，都有 $|b_n - a_n| \le 1$，则称 $\{b_n\}$ 与 $\{a_n\}$“接近”。
(1) 设 $\{a_n\}$ 是首项为 1，公比为 $\dfrac{1}{2}$ 的等比数列，$b_n = a_{n+1} + 1$，$n \in \mathbf{N}^*$，判断数列 $\{b_n\}$ 是否与 $\{a_n\}$ 接近，并说明理由；
(2) 设数列 $\{a_n\}$ 的前四项为：$a_1 = 1, a_2 = 2, a_3 = 4, a_4 = 8$，$\{b_n\}$ 是一个与 $\{a_n\}$ 接近的数列，记集合 $M = \{x \mid x = b_i, i = 1, 2, 3, 4\}$，求 $M$ 中元素个数 $m$；
(3) 已知 $\{a_n\}$ 是公差为 $d$ 的等差数列。若存在数列 $\{b_n\}$ 满足：$\{b_n\}$ 与 $\{a_n\}$ 接近，且在 $b_2 - b_1, b_3 - b_2, \dots, b_{201} - b_{200}$ 中至少有 100 个为正数，求 $d$ 的取值范围。

**解析**

**(1) 证明**

因为 $\{a_n\}$ 是首项为 1，公比为 $\dfrac{1}{2}$ 的等比数列，所以其通项公式为：
$$a_n = \left(\frac{1}{2}\right)^{n-1} \quad (n \in \mathbf{N}^*).$$
已知 $b_n = a_{n+1} + 1 = \left(\dfrac{1}{2}\right)^n + 1$。
则对任意 $n \in \mathbf{N}^*$：
$$|b_n - a_n| = \left|\left(\frac{1}{2}\right)^n + 1 - \left(\frac{1}{2}\right)^{n-1}\right| = \left|1 - \left(\frac{1}{2}\right)^n\right|.$$
因为对任意 $n \in \mathbf{N}^*$，均有 $0 < \left(\dfrac{1}{2}\right)^n \le \dfrac{1}{2}$，
所以 $0 < 1 - \left(\dfrac{1}{2}\right)^n < 1$。
从而 $|b_n - a_n| < 1 \le 1$ 对一切 $n \in \mathbf{N}^*$ 恒成立。
根据定义，数列 $\{b_n\}$ 与 $\{a_n\}$ 接近。

**(2) 解析**

由题意，数列 $\{b_n\}$ 与 $\{a_n\}$ 接近，即对任意 $i \in \{1, 2, 3, 4\}$，均有 $|b_i - a_i| \le 1$，即 $a_i - 1 \le b_i \le a_i + 1$。
代入前四项数值：
- $a_1 = 1 \implies b_1 \in [0, 2]$；
- $a_2 = 2 \implies b_2 \in [1, 3]$；
- $a_3 = 4 \implies b_3 \in [3, 5]$；
- $a_4 = 8 \implies b_4 \in [7, 9]$。
由区间互斥性：
因为 $[7, 9]$ 与 $[0, 2]$、$[1, 3]$、$[3, 5]$ 均无交集，所以 $b_4$ 与 $b_1, b_2, b_3$ 必不相等；
因为 $[3, 5]$ 与 $[0, 2]$ 无交集，所以 $b_3$ 与 $b_1$ 必不相等。
可能相等的项仅有：
- $b_1$ 与 $b_2$：$[0, 2] \cap [1, 3] = [1, 2]$，两项可以相等；
- $b_2$ 与 $b_3$：$[1, 3] \cap [3, 5] = \{3\}$，两项仅当 $b_2 = b_3 = 3$ 时可以相等。
由于 $[0, 2] \cap [1, 3] \cap [3, 5] = [1, 2] \cap \{3\} = \varnothing$，所以 $b_1, b_2, b_3$ 不可能三者同时相等。
因此集合 $M = \{b_1, b_2, b_3, b_4\}$ 中：
- 若取 $b_1 = 1, b_2 = 2, b_3 = 4, b_4 = 8$，四个元素互不相等，此时集合中元素个数 $m = 4$；
- 若取 $b_1 = 2, b_2 = 2, b_3 = 4, b_4 = 8$，此时 $b_1 = b_2 = 2$，集合 $M = \{2, 4, 8\}$ 中元素个数 $m = 3$；
- 若取 $b_1 = 1, b_2 = 3, b_3 = 3, b_4 = 8$，此时 $b_2 = b_3 = 3$，集合 $M = \{1, 3, 8\}$ 中元素个数 $m = 3$。
综上所述，$M$ 中元素的个数 $m$ 的可能值为 $3$ 或 $4$。

**(3) 解析**

等差数列 $\{a_n\}$ 通项为 $a_n = a_1 + (n - 1)d$。
数列 $\{b_n\}$ 与 $\{a_n\}$ 接近，等价于对任意 $n \in \mathbf{N}^*$，满足：
$$a_n - 1 \le b_n \le a_n + 1.$$
对任意 $k \in \{1, 2, \dots, 200\}$，相邻项差分满足：
$$b_{k+1} - b_k \le (a_{k+1} + 1) - (a_k - 1) = a_{k+1} - a_k + 2 = d + 2.$$
若 $d \le -2$，则对一切 $k \in \{1, 2, \dots, 200\}$，均有：
$$b_{k+1} - b_k \le d + 2 \le 0,$$
即全部 200 个差分 $b_2 - b_1, b_3 - b_2, \dots, b_{201} - b_{200}$ 均非正，不可能存在正数，矛盾。
因此必有 $d > -2$。
反之，当 $d > -2$ 时，构造数列 $\{b_n\}$ 如下：
对于 $j = 1, 2, \dots, 100$：
令 $b_{2j-1} = a_{2j-1} - 1$，$b_{2j} = a_{2j} + 1$，且令 $b_{201} = a_{201} - 1$。
对任意 $n \in \{1, 2, \dots, 201\}$，均有 $|b_n - a_n| = 1 \le 1$；对 $n > 201$ 可令 $b_n = a_n$。
考察其奇数位差分（共 100 个）：
对每个 $j \in \{1, 2, \dots, 100\}$，有：
$$b_{2j} - b_{2j-1} = (a_{2j} + 1) - (a_{2j-1} - 1) = a_{2j} - a_{2j-1} + 2 = d + 2.$$
因为 $d > -2$，所以 $d + 2 > 0$。
因此在 $b_2 - b_1, b_3 - b_2, \dots, b_{201} - b_{200}$ 中，所有形如 $b_{2j} - b_{2j-1}$（$j = 1, 2, \dots, 100$）的 100 个差分全为正数。
即差分序列中至少有 100 个为正数。
综上所述，$d$ 的取值范围为 $(-2, +\infty)$。

**答案（1）：接近**

**答案（2）：$m = 3$ 或 $4$**

**答案（3）：$(-2, +\infty)$**
