## 文件形态（对转录管线的关键结论）

1. **纯 PDF 档案，无任何结构化文本**（无 Markdown / LaTeX / docx 存留；README 注明小部分由 docx 转来）。
2. **以试题卷为主，普遍无解析**：README 反馈规则「补充答案只接收教育部或省级考试单位出版印发的试题分析或答案」，侧面说明答案是稀缺件而非标配；3 份抽样实测均为纯试题（见下节）。
3. 命名规则：`(春季)+年份+卷种(+文理)(+初试).pdf`，括号内为适用省份，如
   `2021全国乙理(河南,山西,…,新疆).pdf`、`2021新高考1(山东,广东,…,福建).pdf`。
4. 已移除元数据与水印；2003 起收录副题之外的延考卷等特殊卷（详见源 README 第 6 节）。
5. 源 README 自报已知缺失：1958 剩余地区、1977 浙江预选、1977 部分独立命题地区；春季 2003 安徽文、春季 2002 内蒙古。

- 渲染目检（2021 新高考2 第 1 页）：三栏紧凑版式、标准数学字体、矢量立体几何线图，
  页脚有连续页码「1155」——证实主体 PDF 是从一部 LaTeX 排版的**合集**（README 致谢的
  刘威《1977—2025 高考数学真题全编》为主要参考对象）按卷拆分而来，**但 .tex 源未公开**。
- 对转录的含义：文本型 PDF 可半自动抽取文字，但公式在文本层已碎片化（分数/上下标散落、
  行序错乱），**逆向回 LaTeX 仍需逐题人工重建公式与图形**；扫描件只能 OCR/照录，成本数倍。

## 与本库  的对照

- 本库已有 **2017–2026 全国Ⅰ卷系 14 套**的人工转写校对 Markdown（含逐题解析与答案要点），
  并已完成 XeLaTeX 重排版（合并书 + 14 独立项目 × 4 版本，见 `math-gaokao-latex/`）。
- 源仓库同期（2017–2026）约有 100 份 PDF（含全国Ⅱ/Ⅲ/甲/乙、新高考Ⅱ、京津沪浙苏鲁等），
  这些卷种本库**无转写源**，欲成 LaTeX 项目须从 PDF 逐题转录并自写解析。
