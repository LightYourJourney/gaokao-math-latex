\]

\Needspace{5\baselineskip}
中所有的数从小到大排列成的数列，即 $a_1=3\text{、}a_2=5\text{、}a_3=6\text{、}a_4=9\text{、}a_5=10\text{、}a_6=12\text{、}\ldots$。将数列 $\{a_n\}$ 各项按照“上小下大，左小右大”的原则写成三角形数表：

\nopagebreak[4]
\[
\begin{array}{c}
3\\
5\quad6\\
9\quad10\quad12\\
\cdots
\end{array}
\]

（1） 写出这个三角形数表的第四行、第五行各数；

（2） 求 $a_{100}$。

\Needspace{5\baselineskip}
（3） 【乙】设 $\{b_n\}$ 是集合

\nopagebreak[4]
\[
\{2^r+2^s+2^t\mid 0\leqslant r<s<t,\ r,s,t\in\mathbb Z\}
\]

中所有的数从小到大排列成的数列，已知 $b_k=1160$，求 $k$。

\Needspace{4\baselineskip}
\textbf{解析}

\gksubpart{(1)}

\Needspace{5\baselineskip}
由递推式计算 $a_2=4\text{、}a_3=13$。令

\nopagebreak[4]
\[
b_n=a_n-\frac15\left[3^n+(-1)^{n-1}2^n\right],
\]

则 $b_n=-2b_{n-1}$。由 $b_0=a_0+1/5$ 得题设通项。

\gksubpart{(2)}

\Needspace{5\baselineskip}
条件 $a_n>a_{n-1}$ 等价于

\nopagebreak[4]
\[
a_{n-1}<3^{n-2}.
\]

\Needspace{5\baselineskip}
将通项分别代入偶数、奇数指标，得到 $a_0>0$ 与 $a_0<1/2$；再由 $n=1$ 的条件 $1-2a_0>a_0$ 得 $a_0<1/3$。故

\nopagebreak[4]
\[
0<a_0<\frac13.
\]

\gksubpart{(3)}

\nopagebreak[4]
\[
1160=2^3+2^7+2^{10}.
\]

最大指数小于 $10$ 的三元组有 $\binom{10}{3}=120$ 个；最大指数为 $10$ 且前两指数对应的二元和小于 $2^3+2^7$ 的有 $21+3=24$ 个。因此 $1160$ 是第 $145$ 项，即 $k=145$。

\gkanswer{答案（1）：$a_2=4,\ a_3=13$；$a_n=\dfrac{3^n-1}{2}$。}

\gkanswer{答案（2）：$0<a_0<\dfrac13$。}

\gkanswer{答案（3）：$k=145$。}

\end{answer}
