# 1999 广东卷答案与解析数学复核

## 范围与方法

独立复核分别包含：一轮只读取 `1999_数学真题_广东_试题.md` 的盲解；一轮对照答案要点与解析正文，检查数学推导和结论一致性。复核者均只读、未修改文件。复核以题面文本为准；涉及图形的 Q1/Q10 需结合固定扫描件与重绘图判断。独立审查者在本 worktree 未找到固定 PDF，因此其意见不构成第 6–13 页源件目视复核。

## 发现与修订

- **Q9**：盲解首轮错误地把圆心距与半径之比当作半弦长与半径之比，误报选项不匹配。按固定题面，圆心距为 $\sqrt3$、半径为 2，半弦长为 $\sqrt{2^2-(\sqrt3)^2}=1$，故小弧圆心角为 $2\arcsin(1/2)=\pi/3$，选 C。复核者按该几何关系重算后更正首轮结果；正式答案与解析保持 C。
- **Q19**：初稿把棱柱高误写为 $a/\sqrt2$，并把截面高误写为 $a/2$，还与答案要点中的异面直线距离 $\sqrt2a$ 矛盾。现改为 $DE=a/\sqrt2$、$DD_1=\sqrt2a$，$E$ 到 $AC$ 的距离为 $a$；截面面积 $a^2/\sqrt2$、异面直线距离 $\sqrt2a$、三棱锥体积 $a^3/(2\sqrt2)$。
- **Q21**：初稿的条件解析给出数列、极限和分段函数，但遗漏题目要求的函数定义域。现补充：若 $b>1$，定义域为 $[0,b/(b-1))$；若 $0<b<1$，定义域为 $[0,+\infty)$。这些仍以把扫描字面 $x(x_n)=n$ 条件性理解为 $f(x_n)=n$ 为前提，不消除原题未决。
