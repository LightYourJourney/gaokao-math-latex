# 2006 江苏卷视觉失败：分页根因诊断

- 核查日期：2026-11-02；批次：`phase1-b69`。
- 范围：解释现有复核中试题版、解析版和简答版第 3 页及第 5 页的留白失败；本阶段只记录根因，不更改版式或卷内分页。

## 第 3 页：解答题分节整体移页

- 规范题面第 16 题结束后紧接“三、解答题”和第 17 题。生成的 `2006_江苏卷/questions.tex` 同样在第 16 题后输出 `\gkpart{三、解答题}`，然后开始第 17 题。
- 共享 `common/macros.tex` 的 `\gkpart` 在每个分节标题前执行 `\Needspace{0.6\textheight}`。第 3 页填空题结束时剩余空间达不到该阈值，分节标题与第 17 题一起移至下一页，于是第 3 页留下大块空白。该机制用于全部卷，不是江苏卷专属。
- 共享注释说明，较小阈值曾导致分节标题落在页尾、下一题被推页；仅把江苏卷的阈值调小会改变公共版式规则或引入卷内例外，不能作为无影响的局部修复。

## 第 5 页：末题独占新页

- 第 21 题是短证明题。公共 `question` 环境默认在每题前保留 `0.15\textheight`；若前页剩余空间不足，整题会移到末页，导致末页上方之外空白较多。
- 生成器支持源内 `question-needspace` 元数据调整单题起始预留量。但对第 21 题采用它只会影响末题分页，不能解决第 3 页的分节留白；两个失败位置需要分别评估。

## 阶段处理

- 未改 `macros.tex`、`questions_env.tex`、题面源或共享生成器；未添加江苏专属分页指令，也未重建旧 PDF。
