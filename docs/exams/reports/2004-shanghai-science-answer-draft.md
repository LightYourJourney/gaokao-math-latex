- Q17 经 300 DPI 图像高分辨率核验，原卷字面明确印有共轭横杠作 $|z_1 - \overline{z_2}| < |z_1|$。代数推导得 $(1 + \mathrm{i})z_1 = -1 + 5\mathrm{i} \implies z_1 = 2 + 3\mathrm{i}$，$z_2 = a - 2 - \mathrm{i} \implies \overline{z_2} = a - 2 + \mathrm{i}$，则 $|z_1 - \overline{z_2}|^2 = (a - 4)^2 + 4$，$|z_1|^2 = 13$。不等式化简为 $(a - 4)^2 < 9$，解得 $1 < a < 7$。
- Q18 框架总面积 $S = xy + \frac{1}{4}x^2 = 8$，用料总长 $l = (2 + \sqrt{2})x + 2y = \left(\frac{3}{2} + \sqrt{2}\right)x + \frac{16}{x}$。由均值不等式解得 $x = 8 - 4\sqrt{2} \approx 2.343\text{ m}$，$y = 2\sqrt{2} \approx 2.828\text{ m}$。原卷面积量纲印作 $\text{cm}^2$ 与边长单位 $\text{m}$ 不一致，按数值 8 推导并在解析中保留说明。
- Q19(1) 解得 $A = (-\infty, -1) \cup [1, +\infty)$；小问 (2) 原题面字面条件为“若 $B \subseteq A$”，但题干未定义集合 $B$（题干函数定义域记作 $D$）。若按题意将 $B$ 视为定义域 $D = (2a, a+1)$，则解得实数范围为 $(-\infty, -2] \cup \left[\frac{1}{2}, 1\right)$。因原卷字面符号脱节，小问 (2) 标记 U/PENDING 并保留说明。
- Q20(1) 由原点为顶点且过 $(1, 1)$ 得 $f_1(x) = x^2$；由 $y = \frac{k}{x}$ 与 $y = x$ 交点间距 $\sqrt{8k} = 8$ 得 $k = 8$，故 $f(x) = x^2 + \frac{8}{x}$；(2) 方程 $f(x) = f(a) \iff (x - a)(x^2 + ax - \frac{8}{a}) = 0$。当 $a > 3$ 时，二次判别式 $\Delta = a^2 + \frac{32}{a} > 0$，两根均不为 $0$ 且均不等于 $a$，证得方程必有三个不同的实数解。
- Q21(1) 棱台棱长和 $3 + 3k + 3(1-k)l = 3 + 3l \implies l = 1$，证明为正四面体；(2) $PA$ 中点 $D$ 与 $BC$ 中点 $M$，在等腰 $\triangle PAM$ 中 $DM \perp PA$，二面角平面角 $\angle DMA$ 满足 $\cos\angle DMA = \frac{\sqrt{6}}{3}$；(3) 棱台棱长和恒为 $6$，构造各棱长均为 $\frac{1}{2}$、底面菱形相邻边夹角 $\alpha = \arcsin(8V)$ 的直平行六面体，由于 $0 < 8V < \frac{2\sqrt{2}}{3} < 1$，存在性严格成立。
- Q22(1) 原卷字面印载点 $P_1(3, 0)$ 不在椭圆 $\frac{x^2}{100} + \frac{y^2}{25} = 1$ 上且由 $S_3 = 255$ 推出 $a_3 = 161 > 100$ 在实数范围内无解，保留 U/PENDING；若按第（2）问 $P_1(a, 0)$ 结构原题疑将椭圆右顶点 $P_1(10, 0)$ 误印作 $(3, 0)$，按 $P_1(10, 0)$ 则可解得 $a_1 = 100, a_2 = 85, a_3 = 70$ 及 $P_3$ 坐标为 $(2\sqrt{15}, \sqrt{10})$ 等；(2) 椭圆上 $b^2 \leqslant |OP|^2 \leqslant a^2$，$a_1 = a^2$ 为最大项，$d < 0$，$a_n \geqslant b^2 \implies d \geqslant -\frac{a^2 - b^2}{n - 1}$，$S_n$ 随 $d$ 单调递增，最小值为 $\frac{n(a^2 + b^2)}{2}$；(3) 选定开口向右抛物线 $y^2 = 2px\ (p > 0)$ 及顶点 $P_1(0, 0)$，由 $|OP|^2 = x^2 + 2px$ 在 $[0, +\infty)$ 严格单调递增，充要条件为 $d > 0$。
