    - Q19：取 $AC$ 中点 $O$，则 $SO \perp$ 底面 $ABC$；(1) $\vec{AC} = (-4, 0, 0)$，$\vec{SB} = (0, 2\sqrt{3}, -2)$，点积为 0 得 $AC \perp SB$；(2) 平面 $SCM$ 法向量 $(1, -\sqrt{3}, -1)$，底面法向 $(0, 0, 1)$，二面角余弦 $\frac{\sqrt{5}}{5}$，大小为 $\arccos\frac{\sqrt{5}}{5}$；(3) 向量投影或等体积法得点 $B$ 到平面 $SCM$ 距离为 $\frac{4\sqrt{5}}{5}$；
    - Q20：(1) $A_n = \sum_{k=1}^n (500 - 20k) = 490n - 10n^2$，$B_n = 500n + 500(1 - 2^{-n}) - 600 = 500n - 100 - \frac{500}{2^n}$；(2) $B_n - A_n > 0 \iff n^2 + n - 10 - \frac{50}{2^n} > 0$，经检验 $n=3$ 时为 $-4.25$，$n=4$ 时为 $6.875 > 0$，至少经过 4 年；
    - Q21：(1) $P(2, 2)$ 处切线斜率 2，法线斜率 $-\frac{1}{2}$，方程为 $y - 2 = -\frac{1}{2}(x - 2) \iff x + 2y - 6 = 0$；(2) 设 $P(x_0, \frac{1}{2}x_0^2)$（$x_0 \neq 0$），法线斜率 $-\frac{1}{x_0}$，与抛物线联立得 $x_Q = -x_0 - \frac{2}{x_0}$，中点横坐标 $x = -\frac{1}{x_0}$，纵坐标 $y = x^2 + \frac{1}{2x^2} + 1$（$x \neq 0$）；由均值不等式，$y \geqslant 2\sqrt{\frac{1}{2}} + 1 = \sqrt{2} + 1$，点 $M$ 到 $x$ 轴最短距离为 $\sqrt{2} + 1$；
    - Q22：(1) $f'(x) = -2(x^2 - ax - 2) \geqslant 0$ 在 $[-1, 1]$ 恒成立 $\iff g(\pm 1) \leqslant 0 \implies A = \{a \mid -1 \leqslant a \leqslant 1\}$；(2) $x^2 - ax - 2 = 0$ 两非零实根之差 $|x_1 - x_2| = \sqrt{a^2+8} \in [2\sqrt{2}, 3]$，恒成立等价于 $m^2 + tm + 1 \geqslant 3 \iff m^2 + tm - 2 \geqslant 0$ 在 $t \in [-1, 1]$ 恒成立，解得 $m \leqslant -2$ 或 $m \geqslant 2$。
