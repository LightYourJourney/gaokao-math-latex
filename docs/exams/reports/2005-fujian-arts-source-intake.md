## 2. 原卷排印与考订说明

1. **第 1 题（集合不等式与交集）**：
   - 不等式 $|x - 1| \leqslant 1 \iff 0 \leqslant x \leqslant 2$；自然数集合 $Q = \{0, 1, 2, \dots\}$，交集 $P \cap Q = \{0, 1, 2\}$，选 D。
2. **第 2 题（分式不等式解集）**：
   - 转化为 $(2x - 1)(3x + 1) > 0$，解得 $x < -\dfrac{1}{3}$ 或 $x > \dfrac{1}{2}$，选 A。
3. **第 3 题（等差数列通项与中项）**：
   - $a_7 + a_9 = 2a_8 = 16 \implies a_8 = 8$；$4d = a_8 - a_4 = 7 \implies a_{12} = a_8 + 4d = 15$，选 A。
4. **第 4 题（余弦型函数单调减区间）**：
   - $2k\pi \leqslant 2x \leqslant 2k\pi + \pi \iff k\pi \leqslant x \leqslant k\pi + \dfrac{\pi}{2}$；当 $k = 0$ 时为 $\left[0, \dfrac{\pi}{2}\right]$，选 C。
5. **第 5 题（基本不等式命题辨析）**：
   - 考查基本不等式条件与最值；A项对数可负、C项最小值在端点2.5、D项递增有最大值1.5，B项 $\sqrt{x} + \dfrac{1}{\sqrt{x}} \geqslant 2$ 恒成立，选 B。
6. **第 6 题（指数型函数图象参数判断）**：
   - 递减知底数 $0 < a < 1$；$x = 0$ 处 $f(0) = a^{-b} > 1 \implies -b < 0 \implies b > 0$，选 C。
7. **第 7 题（立体几何线面命题辨析）**：
   - ① 两线可异面（假）；② 线面平行性质得线线平行结合线面垂直得线线垂直（真）；③ 平行面内平行线垂直另一面得面面垂直（真）；真命题共 2 个，选 C。
8. **第 8 题（充分必要条件判定）**：
   - $ab \neq 0 \iff a \neq 0$ 且 $b \neq 0$；$q \implies p$ 但 $p \centernot\implies q$，故为必要而不充分条件，选 B。
9. **第 9 题（双曲线定义与最值）**：
   - $|PA| - |PB| = 3 < |AB| = 4$，动点 $P$ 轨迹为靠近 $B$ 的双曲线右支；$2c = 4, 2a = 3 \implies c = 2, a = 3/2$；最小距离在右顶点取得，$|PA|_{\min} = a + c = \dfrac{7}{2}$，选 C。
10. **第 10 题（受限位置排列组合）**：
    - 特殊位置巴黎从其余 4 人中选 1 人，余下 3 个城市从 5 人中选 3 人排列，总方案数 $4 \times 60 = 240$ 种，选 B。
11. **第 11 题（长方体中异面直线所成角）**：
    - 建系计算向量 $\overrightarrow{A_1E} = (-1, 0, -1)$，$\overrightarrow{GF} = (1, -1, -1)$；数量积 $\overrightarrow{A_1E} \cdot \overrightarrow{GF} = 0$，异面直线垂直，所成角为 $\dfrac{\pi}{2}$，选 D。
12. **第 12 题（偶函数周期性与区间零点个数）**：
    - $f(2) = 0 \implies f(-2) = 0$；由周期 3 得 $f(1) = f(4) = f(5) = 0$；在 $(0, 6)$ 内零点个数至少为 4 个（$x = 1, 2, 4, 5$），选 B。
13. **第 13 题（二项式定理常数项）**：
    - 通项指数 $3 - \dfrac{3r}{2} = 0 \implies r = 2$；常数项 $\mathrm{C}_6^2 \cdot 2^4 \cdot (-1)^2 = 240$。
14. **第 14 题（直角三角形向量垂直求参数）**：
    - $\angle C = 90^\circ \implies \overrightarrow{CA} \cdot \overrightarrow{CB} = 0$；$(-2)(k - 2) + (-3)(-2) = 10 - 2k = 0 \implies k = 5$。
15. **第 15 题（退化可行域线性规划）**：
    - 非负实数 $x \geqslant 0, y \geqslant 0$ 与 $2x + y \leqslant 0$ 联立得唯一解 $x = y = 0$；可行域退化为单点 $(0, 0)$，最大值为 $0$。
16. **第 16 题（对称变换与真命题开放填空）**：
    - 关于直线 $y = x$ 对称得反函数 $g(x) = 2^{x-3}$（或关于 $x$ 轴对称得 $g(x) = -3 - \log_2 x$）。
17. **第 17 题（同角三角函数平方关系与化简求值）**：
    - (1) 平方得 $2\sin x\cos x = -\dfrac{24}{25}$；第四象限 $\sin x < 0, \cos x > 0 \implies \sin x - \cos x = -\dfrac{7}{5}$；
    - (2) 化简得原式等于 $\dfrac{2\sin x\cos x(\sin x + \cos x)}{\cos x - \sin x} = -\dfrac{24}{175}$。
18. **第 18 题（离散型随机变量期望与对立事件概率）**：
    - (1) 各投一次，$\xi$ 取 $0, 1, 2$，分布列为 $\dfrac{3}{10}, \dfrac{5}{10}, \dfrac{2}{10}$，数学期望 $\mathbf{E}\xi = \dfrac{9}{10}$；
    - (2) 各投二次，四次均不命中的概率为 $\dfrac{1}{4} \times \dfrac{9}{25} = \dfrac{9}{100}$；至少一次命中的概率为 $1 - \dfrac{9}{100} = \dfrac{91}{100}$。
19. **第 19 题（等比等差混合数列公比与前项和比较）**：
    - (1) $2a_1 q^2 = a_1 + a_1 q \implies 2q^2 - q - 1 = 0 \implies q = 1$ 或 $q = -\dfrac{1}{2}$；
    - (2) $q = 1$ 时，$S_n - b_n = \dfrac{(n+2)(n-1)}{2} > 0 \implies S_n > b_n$；$q = -\dfrac{1}{2}$ 时，$S_n - b_n = -\dfrac{(n-1)(n-10)}{4}$，当 $2 \leqslant n \leqslant 9$ 时 $S_n > b_n$，当 $n = 10$ 时 $S_{10} = b_{10}$，当 $n \geqslant 11$ 时 $S_n < b_n$。
20. **第 20 题（三次多项式切线待定系数与单调区间）**：
    - (1) 过点 $(0, 2) \implies d = 2$；在 $x = -1$ 处切线 $y = 6x + 7$，解得 $a = -3, b = -3$；$f(x) = x^3 - 3x^2 - 3x + 2$；
    - (2) 导数零点 $1 \pm \sqrt{2}$，单调增区间为 $(-\infty, 1 - \sqrt{2})$ 和 $(1 + \sqrt{2}, +\infty)$，减区间为 $(1 - \sqrt{2}, 1 + \sqrt{2})$。
21. **第 21 题（直二面角中线面垂直、二面角与点面距离）**：
    - (1) 面面垂直性质定理得 $CB \perp AE$，结合已知 $BF \perp AE$ 证明 $AE \perp \text{平面 } BCE$；
    - (2) 得 $\triangle ABE$ 为等腰直角三角形；作高线得二面角平面角余弦为 $\dfrac{\sqrt{3}}{3}$，二面角为 $\arccos\dfrac{\sqrt{3}}{3}$；
    - (3) 等体积法 $V_{D-ACE} = V_{E-ACD} = \dfrac{2}{3}$，结合 $S_{\triangle ACE} = \sqrt{3}$ 求得距离 $d = \dfrac{2\sqrt{3}}{3}$。
22. **第 22 题（椭圆标准方程与直线割线三角形面积）**：
    - (1) 直线 $l$ 过焦点 $(2, 0) \implies c = 2$；原点关于 $l$ 的对称点为 $(3, -\sqrt{3})$，在右准线上得 $\dfrac{a^2}{c} = 3 \implies a^2 = 6, b^2 = 2$；椭圆方程为 $\dfrac{x^2}{6} + \dfrac{y^2}{2} = 1$；
    - (2) 条件等价于 $S_{\triangle MON} = \dfrac{2\sqrt{6}}{3}$ 且 $\overrightarrow{OM} \cdot \overrightarrow{ON} \neq 0$；斜率不存在时 $x = -2$ 满足；斜率存在时 $y = k(x+2)$，求得 $k = \pm\dfrac{\sqrt{3}}{3}$ 且数量积非零；满足条件的直线共有 3 条。
