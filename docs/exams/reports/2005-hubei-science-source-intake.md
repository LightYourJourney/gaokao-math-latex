## 2. 原卷排印与考订说明

1. **第 1 题（集合和定义与元素去重计数）**：
   - 设 $P = \{0, 2, 5\}, Q = \{1, 2, 6\}$；
   - 遍历和得：$0+1=1, 0+2=2, 0+6=6, 2+1=3, 2+2=4, 2+6=8, 5+1=6, 5+2=7, 5+6=11$；
   - 去重后集合为 $\{1, 2, 3, 4, 6, 7, 8, 11\}$，共 8 个元素，选 B。
2. **第 2 题（充要条件与命题真假辨析）**：
   - ① “$a = b$”推得出 $ac = bc$，但 $c = 0$ 时反推不成立，是充分不必要条件，① 假；
   - ② “$a + 5$ 是无理数”与“$a$ 是无理数”互为逆否等价证明（有理数加减 5 仍为有理数），互为充要条件，② 真；
   - ③ $a = 1 > b = -2$，但 $a^2 = 1 < b^2 = 4$，充分性不成立，③ 假；
   - ④ $a < 3 \implies a < 5$，故“$a < 5$”是“$a < 3$”的必要条件，④ 真；
   - 真命题共 2 个，选 B。
3. **第 3 题（含绝对值函数分段图象辨析）**：
   - $x \in (0, 1)$ 时，$y = \dfrac{1}{x} - (1 - x) = x + \dfrac{1}{x} - 1$，单调递减下凸；
   - $x \geqslant 1$ 时，$y = x - (x - 1) = 1$，为水平射线；
   - 函数在 $x = 1$ 处连续，选项 (D) 正确，选 D。
4. **第 4 题（球体相似体积比与表面积比）**：
   - 体积比 $k^3 = 240\sqrt{30} = \sqrt{1728000} = \sqrt{120^3} = 120^{3/2} \implies k = \sqrt{120}$；
   - 表面积比为 $k^2 = (\sqrt{120})^2 = 120$，选 C。
5. **第 5 题（双曲线离心率与抛物线公共焦点）**：
   - 抛物线焦点为 $(1, 0)$，双曲线半焦距 $c = 1$；
   - $e = \dfrac{c}{a} = 2 \implies a = \dfrac{1}{2} \implies m = a^2 = \dfrac{1}{4}$；
   - $n = c^2 - a^2 = 1 - \dfrac{1}{4} = \dfrac{3}{4} \implies mn = \dfrac{3}{16}$，选 A。
6. **第 6 题（Jensen 不等式与二阶导数凹凸性）**：
   - 不等式 $f\left(\dfrac{x_1 + x_2}{2}\right) > \dfrac{f(x_1) + f(x_2)}{2}$ 恒成立等价于函数在 $(0, 1)$ 上严格上凸（$f''(x) < 0$）；
   - $2^x$ 与 $x^2$ 二阶导恒正；$\cos 2x$ 在 $x \in (\pi/4, 1)$ 上二阶导为正；
   - 仅有 $\log_2 x$ 的二阶导数 $-\dfrac{1}{x^2 \ln 2} < 0$ 恒成立，共 1 个函数，选 B。
7. **第 7 题（三角方程根的区间估计）**：
   - 设 $g(\alpha) = \sin\alpha + \cos\alpha - \tan\alpha$；
   - $g(\pi/4) = \sqrt{2} - 1 > 0$；$g(\pi/3) = \dfrac{\sqrt{3}+1}{2} - \sqrt{3} = \dfrac{1-\sqrt{3}}{2} < 0$；
   - 零点落在 $\left(\dfrac{\pi}{4}, \dfrac{\pi}{3}\right)$，选 C。
8. **第 8 题（极限待定系数计算）**：
   - 通分得 $\dfrac{ax+a-b}{1-x^2}$，分母趋于 0 要求分子趋于 0，即 $2a - b = 0 \implies b = 2a$；
   - 极限值为 $-\dfrac{a}{2} = 1 \implies a = -2, b = -4$，选 C。
9. **第 9 题（指数函数与三角函数区间大小比较）**：
   - $x \to 0^+$ 时 $2^x > 3\sin x$；$x = \pi/3$ 时 $2^x \approx 2.07 < 3\sin x \approx 2.60$；
   - 大小关系与 $x$ 取值有关，选 D。
10. **第 10 题（三棱柱中点重心立体几何与平行棱数判定）**：
    - $\vec{EF} = \dfrac{1}{2}\vec{AB}$，故棱柱已有 $AB$ 与 $A'B'$ 2 条棱平行于面 $PEF$；
    - 要使“恰有 2 条棱平行”，面 $PEF$ 不能再平行于侧棱或底面其余棱；
    - 取 $P = K$ 时面平行于侧棱（至少 5 条）；取 $P = H$ 时面平行于 $AC$（至少 4 条）；取 $P = B'$ 时相交；
    - 仅当 $P = G$（$\triangle ABC$ 重心）时恰有 2 条棱平行，选 C。
11. **第 11 题（三次曲线切线倾斜角与整点判定）**：
    - 倾斜角小于 $\pi/4$ 等价于斜率 $0 \leqslant 3x^2 - 8 < 1 \iff \dfrac{8}{3} \leqslant x^2 < 3$；
    - 在该区间内不存在任何整数的平方，故整点个数为 0，选 D。
12. **第 12 题（平行六面体顶点三角形共面概率）**：
    - 8 顶点作三角形共有 $\mathrm{C}_8^3 = 56$ 个，任取两个共有 $\mathrm{C}_{56}^2 = 1540$ 对；
    - 含 4 顶点的平面共有 12 个（6 表面 + 6 对角面），每个平面产生 $\mathrm{C}_4^2 = 6$ 对共面三角形，共 $12 \times 6 = 72$ 对；
    - 共面概率为 $\dfrac{72}{1540} = \dfrac{18}{385}$，不共面概率为 $1 - \dfrac{18}{385} = \dfrac{367}{385}$，选 A。
13. **第 13 题（向量线性运算模长不等式）**：
    - $\vec{a} + \vec{b} = (3, k + 2)$，模长不超过 5 得 $(k+2)^2 \leqslant 16 \implies [-6, 2]$。
14. **第 14 题（三项多项式展开常数项计算）**：
    - 多项式定理展开通项系数分析，常数项对应 $a = b$ 且 $2a + c = 5$；
    - $(a, b, c) = (0, 0, 5) \implies 4\sqrt{2}$；$(1, 1, 3) \implies 20\sqrt{2}$；$(2, 2, 1) \implies \dfrac{15\sqrt{2}}{2}$；
    - 累加得 $\dfrac{63\sqrt{2}}{2}$。
15. **第 15 题（等比数列前 $n$ 项和等差性质求公比）**：
    - $2S_n = S_{n+1} + S_{n+2} \implies 2a_{n+1} + a_{n+2} = 0 \implies 2 + q = 0 \implies q = -2$。
16. **第 16 题（整数线性规划购料最省）**：
    - $35x + 24y \geqslant 106$，单价 35 千克为 4 元/千克，24 千克为 5 元/千克；
    - 遍历非负整数解可知 $x = 1, y = 3$（总重 107 千克）花费最少，最少花费为 500 元。
17. **第 17 题（向量数量积与导数单调性求参）**：
    - $f'(x) = -3x^2 + 2x + t \geqslant 0 \iff t \geqslant 3x^2 - 2x$ 对 $x \in (-1, 1)$ 恒成立；
    - 上确界在端点 $x = -1$ 处为 5，解得 $t \in [5, +\infty)$。
18. **第 18 题（解三角形中线定理与正弦定理）**：
    - $\cos B = \dfrac{\sqrt{6}}{6} \implies \sin B = \dfrac{\sqrt{30}}{6}$；
    - 中线向量模长公式求得边长 $a = BC = 2$；余弦定理得 $b = AC = \dfrac{2\sqrt{21}}{3}$；
    - 正弦定理得 $\sin A = \dfrac{a\sin B}{b} = \dfrac{\sqrt{70}}{14}$。
19. **第 19 题（独立重复试验机动车考试离散分布列与期望）**：
    - (1) $P(\xi=1) = 0.6$，$P(\xi=2) = 0.28$，$P(\xi=3) = 0.096$，$P(\xi=4) = 0.024$；期望 $\mathbf{E}\xi = 1.544$；
    - (2) 领到驾照概率为 $1 - 0.4 \times 0.3 \times 0.2 \times 0.1 = 0.9976$。
20. **第 20 题（四棱锥线面角与法向量垂直求点）**：
    - (1) 建立空间直角坐标系，$A(0, 0, 0), B(\sqrt{3}, 0, 0), C(\sqrt{3}, 1, 0), P(0, 0, 2)$，求得 $\cos\theta = \dfrac{3\sqrt{7}}{14}$；
    - (2) 由 $\vec{NE} \perp \vec{AP}$ 且 $\vec{NE} \perp \vec{AC}$ 解得 $N\left(\dfrac{\sqrt{3}}{6}, 0, 1\right)$；到 $AB$ 距离为 1，到 $AP$ 距离为 $\dfrac{\sqrt{3}}{6}$。
21. **第 21 题（椭圆中点弦方程与四点共圆恒等性证明）**：
    - (1) 点差法求得中点弦斜率 $k = -1$，方程为 $x + y - 4 = 0$；$\Delta > 0 \iff \lambda \in (12, +\infty)$；
    - (2) 垂直平分线 $CD$ 斜率为 1，利用直角参数方程代入椭圆方程，由韦达定理证明 $|NA|\cdot|NB| = |NC|\cdot|ND| = \dfrac{\lambda - 12}{2}$ 恒成立，四点恒共圆。
22. **第 22 题（数列不等式累加倒数与极限压轴）**：
    - (1) 倒数累加法得 $\dfrac{1}{a_n} \geqslant \dfrac{1}{b} + \sum_{k=2}^n \dfrac{1}{k} > \dfrac{1}{b} + \dfrac{1}{2}[\log_2 n] \implies a_n < \dfrac{2b}{2 + b[\log_2 n]}$；
    - (2) 极限存在，极限值为 0；
    - (3) 由 $a_n < \dfrac{2}{[\log_2 n]} \leqslant \dfrac{1}{5} \iff [\log_2 n] \geqslant 10 \iff n \geqslant 1024$，取正整数 $N = 1023$（或 $1024$）。
