## 2. 原卷排印与考订说明

1. **第 1 题（集合交补运算）**：
   - 全集 $U = \{-2, -1, 0, 1, 2\}$，子集 $A = \{-2, -1, 0\}$，补集 $\complement_U A = \{1, 2\}$；
   - 与集合 $B = \{0, 1, 2\}$ 求交得 $\{1, 2\}$，选 C。
2. **第 2 题（诱导公式与正切求值）**：
   - $\tan 600^\circ = \tan(360^\circ + 240^\circ) = \tan 240^\circ = \tan(180^\circ + 60^\circ) = \tan 60^\circ = \sqrt{3}$，选 D。
3. **第 3 题（指数型偶次根式定义域）**：
   - 被开方数非负：$1 - 2^x \geqslant 0 \iff 2^x \leqslant 1 \iff x \leqslant 0$，定义域为 $(-\infty, 0]$，选 A。
4. **第 4 题（正方体中点到对角截面距离）**：
   - 正方体棱长为 1，对角面 $ABC_1D_1$ 与侧棱面交线为 $AB$ 和 $C_1D_1$；
   - $E$ 为 $A_1B_1$ 中点，因 $A_1B_1 \parallel AB \subset ABC_1D_1$，点 $E$ 到平面 $ABC_1D_1$ 的距离等于点 $A_1$ 到平面 $ABC_1D_1$ 的距离；
   - 在侧面 $AA_1D_1D$ 中，$A_1$ 到对角线 $AD_1$ 的高为 $\dfrac{\sqrt{2}}{2}$，选 B。
5. **第 5 题（正切型递推数列与周期性）**：
   - 递推关系对应正切差角公式，由 $a_1 = 0$ 逐项计算：$a_2 = -\sqrt{3}, a_3 = \sqrt{3}, a_4 = 0$；
   - 数列周期为 3，$a_{20} = a_{3 \times 6 + 2} = a_2 = -\sqrt{3}$，选 B。
6. **第 6 题（集合非空充要条件判定）**：
   - $A = (-\infty, a)$，$B = (0, 1)$；
   - 若 $a = 1$，则 $A \cap B = (0, 1) \neq \varnothing$，充分性成立；
   - 若 $A \cap B \neq \varnothing$，只需 $a > 0$，不能推出 $a = 1$，必要性不成立；
   - 故为充分不必要条件，选 A。
7. **第 7 题（平面网格两点斜率去重计数）**：
   - 集合 $M = \{(x, y) \mid x, y \in \{1, 2, 3, 4, 5\}\}$；
   - 考察不同斜率直线条数，去除重复斜率后共有 18 条，选 C。
8. **第 8 题（双曲线渐近线与准线围成三角形面积）**：
   - 双曲线渐近线为 $y = \pm \dfrac{b}{a}x$，右准线为 $x = \dfrac{a^2}{c}$；
   - 渐近线与右准线交点纵坐标为 $\pm \dfrac{ab}{c}$，三角形面积为 $\dfrac{a^3b}{c^2}$；
   - 题设面积为 $\dfrac{a^2}{2}$，解得 $a = b$，双曲线为等轴双曲线，渐近线互相垂直，夹角为 $90^\circ$，选 D。
9. **第 9 题（向量数量积与三角形垂心判定）**：
   - $\vec{PA}\cdot\vec{PB} = \vec{PB}\cdot\vec{PC} \iff \vec{PB}\cdot(\vec{PA} - \vec{PC}) = 0 \iff \vec{PB}\cdot\vec{CA} = 0 \iff PB \perp AC$；
   - 同理可得 $PC \perp AB$，故 $P$ 点为高线交点即垂心，选 D。
10. **第 10 题（分段利润函数求最值）**：
    - 设甲地销售 $x$ 辆，乙地销售 $15 - x$ 辆，总利润 $L(x) = (5.06x - 0.15x^2) + 2(15 - x) = -0.15x^2 + 3.06x + 30$；
    - 对称轴为 $x = 10.2$，取最接近的整数 $x = 10$ 时利润最大，$L(10) = 45.6$ 万元，选 B。
11. **第 11 题（圆的弦垂直平分线方程）**：
    - 圆方程化为标准方程 $(x-1)^2 + y^2 = 4$，圆心为 $(1, 0)$；
    - 垂直平分线过圆心且斜率与已知直线垂直，$k = \dfrac{3}{2}$，方程为 $3x - 2y - 3 = 0$。
12. **第 12 题（分层抽样与等差数列）**：
    - 总体共 16800 件，三条生产线抽取的个体数成等差数列，依分层抽样比例，三条生产线实际产量亦成等差数列；
    - 设产量为 $a-d, a, a+d$，则 $3a = 16800 \implies a = 5600$ 件。
13. **第 13 题（二项式定理系数累加）**：
    - 展开式中 $x^2$ 项系数为 $\sum_{k=2}^6 \mathrm{C}_k^2 = \mathrm{C}_7^3 = 35$。
14. **第 14 题（中心对称与反函数值）**：
    - 图象关于 $(1, 2)$ 对称，已知 $f(4) = 0$ 即图象过 $(4, 0)$；
    - 对称点为 $(2 \times 1 - 4, 2 \times 2 - 0) = (-2, 4)$，故 $f(-2) = 4 \implies f^{-1}(4) = -2$。
15. **第 15 题（空间线面关系符号辨析）**：
    - (1) $m \subset \alpha$ 且 $\alpha \parallel \beta \implies m \parallel \beta$，选 ③⑤；
    - (2) $m \perp \alpha$ 且 $\alpha \parallel \beta \implies m \perp \beta$，选 ②⑤。
16. **第 16 题（等差数列通项与裂项求和不等式）**：
    - (1) 等差数列通项 $b_n = \log_2(a_n - 1) = n \implies a_n = 2^n + 1$；
    - (2) 分母差分 $a_{k+1} - a_k = 2^k$，裂项累加得 $1 - (1/2)^n < 1$。
17. **第 17 题（解三角形三角恒等变换）**：
    - 由 $\sin A(\sin B+\cos B) - \sin(A+B) = 0$ 展开化简得 $\sin B(\sin A - \cos A) = 0 \implies \tan A = 1 \implies A = \dfrac{\pi}{4}$；
    - 结合 $\sin B + \cos 2C = 0$ 解得 $B = \dfrac{\pi}{3}, C = \dfrac{5\pi}{12}$。
18. **第 18 题（等腰梯形折成直二面角空间向量与二面角）**：
    - (1) 建立空间直角坐标系，$A(3,0,0), B(0,3,0), O_1(0,0,\sqrt{3}), C(0,1,\sqrt{3})$，$\vec{AC}\cdot\vec{BO_1} = 0 \implies AC \perp BO_1$；
    - (2) 面 $OAC$ 与面 $O_1AC$ 法向量计算得二面角余弦值为 $\dfrac{\sqrt{3}}{4}$，二面角大小为 $\arccos\dfrac{\sqrt{3}}{4}$。
19. **第 19 题（三次曲线切线与函数单调性参数范围）**：
    - (1) 联立切点与公共切线斜率解得 $a = -t^2, b = t, c = -t^3$；
    - (2) 导函数二次因式分解 $h'(x) = (3x+t)(x-t) \leqslant 0$ 在 $(-1, 3)$ 恒成立，得 $t \in (-\infty, -9] \cup [3, +\infty)$。
20. **第 20 题（古典概型与部门旅游景区选择）**：
    - 4 个部门各选 3 个景区，基本事件总数为 $3^4 = 81$；
    - (1) 3 景区都有部门选：分拆组合 $\mathrm{C}_4^2 \times \mathrm{A}_3^3 = 36$，概率 $P_1 = \dfrac{36}{81} = \dfrac{4}{9}$；
    - (2) 恰选 2 个景区：$\mathrm{C}_3^2 \times (2^4 - 2) = 42$，概率 $P_2 = \dfrac{42}{81} = \dfrac{14}{27}$。
21. **第 21 题（椭圆综合题：切线、对称点与等腰三角形）**：
    - (1) 联立消元配方，由公共点唯一性求得切点处 $\lambda = 1 - e^2$；
    - (2) 由对称性质与通径性质，代入周长求得椭圆方程为 $\dfrac{x^2}{3} + \dfrac{y^2}{\frac{9}{4}} = 1$；
    - (3) 讨论等腰三角形三种顶点情况，解得唯一可能为 $\lambda = \dfrac{2}{3}$。
