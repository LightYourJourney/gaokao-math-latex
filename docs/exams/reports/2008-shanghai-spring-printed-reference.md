## 解答题印载结论

- **17**：原式化为 \(\frac{\sin\theta}{\cos\theta}\)，印载结果为 \(-\frac{\sqrt{14}}2\)。
- **18**：印载 \(A(2,0),B(0,2),C(1,1)\)，抛物线为 \(y^2=x\)，焦点 \(F(\frac14,0)\)，到 \(AB\) 的距离为 \(\frac{7\sqrt2}{8}\)。
- **19**：印载证明 \(f(x)=\log_2(2^x+1)\) 在实数范围单调递增；\(f^{-1}(x)=\log_2(2^x-1)\ (x>0)\)。方程在 \([1,2]\) 上有解时，\(m\in[\log_2(\frac13),\log_2(\frac35)]\)。
- **20(1)**：设细钢管上下两段之比为 \(\lambda\)，由印载解得 \(\lambda=\frac{2\sqrt3}{9-2\sqrt3}\approx0.63\)。参考答案页可辨文字为“已知凳子高度为 30”，与题面页一致。
- **20(2)**：印载 \(BH=8, AH=8\sqrt7, OH=12\)。三根细钢管长度依次为 \(10\sqrt{37}\approx60.8\text{ cm}\)、\(10\sqrt{13}\approx36.1\text{ cm}\)、\(10\sqrt{37}\approx60.8\text{ cm}\)。
- **21(1)**：印载取 \(a_n=1/n\)，得 \(b_n=1/(n+1)-1/n=-1/[n(n+1)]\)，并判为 \(T\) 点列。
- **21(2)**：在“\(A_2\) 在 \(A_1\) 右上方”条件下，印载用 \(b_1>0\) 及严格递增推出各 \(b_n>0\)，结论为连续三点构成钝角三角形。
- **21(3)**：印载利用 \(q-p=n-m\) 及 \(b_n\) 严格递增，得到 \(a_q-a_p>a_n-a_m\)，进而证明题设向量纵向分量的不等式。
- **22(1)**：按版面写法照录：\(z=-b\pm\sqrt{-2b-b^2}\,i\)，相应点为 \(P_z(-b,\sqrt{-2b-b^2})\) 或 \(P_z(-b,-\sqrt{-2b-b^2})\)。这里只保留印载表达，不改写根号或虚数单位的位置。
- **22(2)**：印载线段为
  \[
  s:\quad c=-2mb+r^2-m^2,\qquad b\in[-m-r,-m+r]。
  \]
- **22(3)**：印载表格内容如下。

| 线段 \(s\) 与线段 \(s_1\) 的关系 | \(m、r\) 的取值或表达式 |
|---|---|
| \(s\) 所在直线平行于 \(s_1\) 所在直线 | \(m=1,\ r\ne1\) |
| \(s\) 所在直线平分线段 \(s_1\) | \(r^2-(m-1)^2=1,\ m\ne1\) |
| 线段 \(s\) 与线段 \(s_1\) 长度相等 | \((1+4m^2)r^2=5\) |
