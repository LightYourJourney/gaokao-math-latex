## 2. 原卷排印与考订说明

1. **第 8 题（含绝对值三角函数单调区间考订）**：
   - 函数 $f(x) = \dfrac{\sqrt{1 - \cos 2x}}{\cos x} = \sqrt{2}\dfrac{|\sin x|}{\cos x}$ 在 $[0, 2\pi]$ 内除去了 $\dfrac{\pi}{2}$ 与 $\dfrac{3\pi}{2}$。
   - 在第一象限 $\left[0, \dfrac{\pi}{2}\right)$ 与第二象限 $\left(\dfrac{\pi}{2}, \pi\right]$ 上，$|\sin x| = \sin x$，函数化为 $f(x) = \sqrt{2}\tan x$，在两区间内分别严格单调递增；
   - 在第三象限 $\left[\pi, \dfrac{3\pi}{2}\right)$ 与第四象限 $\left(\dfrac{3\pi}{2}, 2\pi\right]$ 上，$|\sin x| = -\sin x$，函数化为 $f(x) = -\sqrt{2}\tan x$，在两区间内分别严格单调递减。
   - 对比题干选项，唯一完全符合该单调区间划分的选项为 A。
2. **第 11 题（二项式展开常数项）**：
   - 展开式 $\left(x - \dfrac{1}{x}\right)^6$ 通项为 $T_{r+1} = (-1)^r \mathrm{C}_6^r x^{6-2r}$。
   - 常数项对应 $6 - 2r = 0 \implies r = 3$，结果为 $(-1)^3 \mathrm{C}_6^3 = -20$。
3. **第 16 题（直四棱柱立体几何计算）**：
   - 底面 $ABCD$ 为垂直对角线筝形，$AB = AD = 2$，$DC = BC = 2\sqrt{3}$，$AC = 4$，$AE = 1$，$EC = 3$，$BE = DE = \sqrt{3}$。
   - (1) $AA_1 \perp \text{底面} \implies AA_1 \perp BD$，结合 $AC \perp BD$ 得 $BD \perp \text{平面 } A_1AC \implies BD \perp A_1C$；
   - (2) 二面角 $A_1 - BD - C_1$ 的平面角为 $\angle A_1EC_1$。在平面 $A_1AC$ 中，$\tan\angle A_1EA = \sqrt{3} \implies \angle A_1EA = 60^\circ$；$\tan\angle C_1EC = \dfrac{1}{\sqrt{3}} \implies \angle C_1EC = 30^\circ$。两角互余，故平面角 $\angle A_1EC_1 = 180^\circ - 60^\circ - 30^\circ = 90^\circ$（向量坐标点积同样精确得 0）；
   - (3) 建立空间直角坐标系计算向量夹角，$\vec{AD} = (1, \sqrt{3}, 0)$，$\vec{BC_1} = (3, \sqrt{3}, \sqrt{3})$，数量积为 6，模长乘积为 $2\sqrt{15}$，余弦值为 $\dfrac{\sqrt{15}}{5}$。
4. **第 17 题（独立射击概率模型复算）**：
   - 甲每次命中概率 $\dfrac{1}{2}$，乙每次命中概率 $\dfrac{2}{3}$；
   - (1) $\xi \sim B(3, 1/2)$，分布列各项为 $1/8, 3/8, 3/8, 1/8$，$E\xi = 3/2$；
   - (2) 乙至多中 2 次概率为 $1 - (2/3)^3 = \dfrac{19}{27}$；
   - (3) 甲比乙多中 2 次由 $(\xi=2, \eta=0)$ 与 $(\xi=3, \eta=1)$ 构成，概率为 $\dfrac{3}{8}\times\dfrac{1}{27} + \dfrac{1}{8}\times\dfrac{6}{27} = \dfrac{9}{216} = \dfrac{1}{24}$。
5. **第 18 题（双曲线轨迹与重心重合）**：
   - 点到两渐近线距离积为定值的轨迹为双曲线 $k^2 x^2 - y^2 = (k^2+1)d^2$；
   - 割线被双曲线与渐近线截得的线段中点重合，与原点构成的两个三角形重心恒重合。
6. **第 19 题（分段递推数列求和）**：
   - 由递推关系奇偶两步复合得 $a_{2n+1} - \dfrac{1}{4} = \dfrac{1}{2}\left(a_{2n-1} - \dfrac{1}{4}\right)$，即 $b_{n+1} = \dfrac{1}{2}b_n$；
   - $\{b_n\}$ 是以 $a - \dfrac{1}{4}$ 为首项、$\dfrac{1}{2}$ 为公比的无穷等比数列，级数和为 $2a - \dfrac{1}{2}$。
7. **第 20 题（单峰函数含峰区间缩短）**：
   - 证明单调区间判定准则与对称试验点构造（$x_1 = 0.5 - r, x_2 = 0.5 + r$）；
   - 二次缩短测试点取 $x_1 = 0.34, x_2 = 0.66, x_3 = 0.32$，满足两两间距不小于 $0.02$，缩短后新含峰区间长度精确为 $0.34$。
8. **图形矢量重绘说明**：

   - Q18：双曲线渐近线夹角阴影区域 $W_1, W_2$ 图（`f2005_beijing_science_q18_regions.tex`）。
