## 分歧与纠正

1. 第一份盲解把第2题复数模误写为2，正确值为 \(|2+2i|=2\sqrt2\)。第9题的代数推导实际得出 \(x>w\)，但其选项字母错标为C；正确为B。
2. 第10题第一份盲解错误地把A、D、C说成始终共线。正确的机构关系是D为两杆铰点；由 \(AD=1,DC=3\) 得 \(2\le AC\le4\)，等号仅在三点共线的极限位置，继而得到选项B。
3. 第11题的一份盲解误报 \(-1/2\)；圆心到直线距离方程给出唯一值0。
4. 第12题两份盲解的中间公式曾错；正确恒等式是 \(S_n-S_5=(n-5)(a_1-n-4)\)，因而 \(a_1\) 全部可行范围为 \([8,10]\)。
5. 第17（2）曾出现超几何值。题面按频率估计概率的解法在本稿使用多项分布模型 \(6(0.2)^4=6/625\)，并明示抽样设计未详；不把模型选择伪装成来源答案。
6. 第18题第二份盲解误称条件②得 \(t=1\)、且两平面重合；点积和法向量复算均给 \(t=1/2\)、余弦 \(2/3\)。条件③对所有非退化P成立，不唯一。
7. 第19题第一份盲解先给出四个近似根，原因是面积差把两个面积绝对值相减时未处理A位于弦BC内部的符号关系。按 \(\bigl||u-1|-|v-1|\bigr|=|u+v-2|\) 化简后仅有 \(k=\pm\sqrt2/4\)。
8. 第21（3）早期推导曾将“四项和为0”等同于“四项乘积为1”，该等价命题为假；本报告不采用该论证。下述线性方程组直接来自原题的四项和约束。

## 第21（3）精确消元证书

将52个合法矩形四项和式视为对36个实数变量 \(x_{ij}\) 的齐次线性方程。对每一约束按 \(i<p,j<q\) 只生成一次。精确有理数 Gauss–Jordan 消元的秩为34，按行优先零起始编号的自由列为34、35。零空间的一组基如下：

\[
U=\begin{pmatrix}
0&1&1&-1&-1&0\\
1&0&0&0&0&-1\\
1&0&2&-2&0&-1\\
-1&0&-2&2&0&1\\
-1&0&0&0&0&1\\
0&-1&-1&1&1&0
\end{pmatrix},\qquad
V=\begin{pmatrix}
1&0&0&0&0&-1\\
0&1&1&-1&-1&0\\
0&1&-1&1&-1&0\\
0&-1&1&-1&1&0\\
0&-1&-1&1&1&0\\
-1&0&0&0&0&1
\end{pmatrix}.
\]

所以任何满足四项和条件的实数阵都形如 \(X=\alpha U+\beta V\)。附加 \(a_{11}=1\) 给出 \(\beta=1\)；又 \(a_{12}=\alpha\in\{-1,1\}\)。若 \(\alpha=-1\)，则 \(a_{33}=2\alpha-1=-3\)，违反所有阵元为 \(\pm1\)；故 \(\alpha=1\)。于是 \(X=U+V\)，前三行为 \((1,1,1,-1,-1,-1)\)，后三行为其相反数，逐项满足 \(a_{ij}=a_{i1}a_{1j}\)。

以下代码完整生成52条约束并进行精确有理数消元，可在 Python 标准库下重跑：

```python
from fractions import Fraction

N = 6
matrix = []
for i in range(N):
    for p in range(i + 1, N):
        for j in range(N):
            for q in range(j + 1, N):
                if abs((p - i) - (q - j)) == 2:
                    row = [Fraction(0) for _ in range(N * N)]
                    for r, c in ((i, j), (i, q), (p, j), (p, q)):
                        row[r * N + c] = Fraction(1)
                    matrix.append(row)

rank = 0
pivots = []
for col in range(N * N):
    pivot = next((r for r in range(rank, len(matrix))
                  if matrix[r][col]), None)
    if pivot is None:
        continue
    matrix[rank], matrix[pivot] = matrix[pivot], matrix[rank]
    scale = matrix[rank][col]
    matrix[rank] = [x / scale for x in matrix[rank]]
    for r in range(len(matrix)):
        if r != rank and matrix[r][col]:
            scale = matrix[r][col]
            matrix[r] = [x - scale * y
                         for x, y in zip(matrix[r], matrix[rank])]
    pivots.append(col)
    rank += 1

free = [col for col in range(N * N) if col not in pivots]
basis = []
for free_col in free:
    vector = [Fraction(0) for _ in range(N * N)]
    vector[free_col] = Fraction(1)
    for row_index, pivot_col in enumerate(pivots):
        vector[pivot_col] = -matrix[row_index][free_col]
    basis.append([vector[r * N:(r + 1) * N] for r in range(N)])

assert len(matrix) == 52
assert rank == 34
assert free == [34, 35]
assert basis[0] == [
    [0, 1, 1, -1, -1, 0], [1, 0, 0, 0, 0, -1],
    [1, 0, 2, -2, 0, -1], [-1, 0, -2, 2, 0, 1],
    [-1, 0, 0, 0, 0, 1], [0, -1, -1, 1, 1, 0]]
assert basis[1] == [
    [1, 0, 0, 0, 0, -1], [0, 1, 1, -1, -1, 0],
    [0, 1, -1, 1, -1, 0], [0, -1, 1, -1, 1, 0],
    [0, -1, -1, 1, 1, 0], [-1, 0, 0, 0, 0, 1]]
print("constraints:", len(matrix))
print("rank:", rank)
print("free columns:", free)
print("nullity:", len(basis))
```

实际输出：

```text
constraints: 52
rank: 34
free columns: [34, 35]
nullity: 2
```

这是对本题线性约束的精确有理数消元证据；阵元为 \(\pm1\) 的条件再将二维实数零空间缩为唯一可行阵。它是可复现的计算辅助证明，并非声称复原了原卷解析。
