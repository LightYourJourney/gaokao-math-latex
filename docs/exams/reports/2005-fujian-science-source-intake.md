## 2. 原卷排印与考订说明

1. **第 1 题（复数除法与共轭复数）**：
   - $z = \dfrac{1}{1-\mathrm{i}} = \dfrac{1}{2} + \dfrac{1}{2}\mathrm{i}$，共轭复数 $\bar{z} = \dfrac{1}{2} - \dfrac{1}{2}\mathrm{i}$，选 B。
2. **第 2 题（等差数列中项与通项）**：
   - $a_7 + a_9 = 2a_8 = 16 \implies a_8 = 8$；$4d = a_8 - a_4 = 7 \implies a_{12} = a_8 + 4d = 15$，选 A。
3. **第 3 题（直角三角形向量垂直求参数）**：
   - $\angle C = 90^\circ \implies \overrightarrow{CA} \cdot \overrightarrow{CB} = 0$；$(-2)(k - 2) + (-3)(-2) = 10 - 2k = 0 \implies k = 5$，选 A。
4. **第 4 题（立体几何线面命题辨析）**：
   - ① 两线可异面（假）；② 线面平行性质得线线平行结合线面垂直得线线垂直（真）；③ 平行面内平行线垂直另一面得面面垂直（真）；真命题共 2 个，选 C。
5. **第 5 题（指数型函数图象参数判断）**：
   - 单调递减知底数 $0 < a < 1$；$x = 0$ 处 $f(0) = a^{-b} \in (0, 1) \implies -b > 0 \implies b < 0$，选 D。
6. **第 6 题（正弦型函数图象参数确定）**：
   - 波峰 $(1, 1)$，相邻零点 $(3, 0)$，$\dfrac{T}{4} = 2 \implies T = 8 \implies \omega = \dfrac{\pi}{4}$；由 $x = 1$ 取最大值结合 $0 \leqslant \varphi < 2\pi$ 得 $\varphi = \dfrac{\pi}{4}$，选 C。
7. **第 7 题（绝对值不等式与二次不等式充分必要条件）**：
   - $p: 1 < x < 2$，$q: 0 < x < 3$；$(1, 2) \subsetneqq (0, 3)$，为充分不必要条件，选 A。
8. **第 8 题（长方体中异面直线所成角）**：
   - 建系计算向量 $\overrightarrow{A_1E} = (-1, 0, -1)$，$\overrightarrow{GF} = (1, -1, -1)$；数量积 $\overrightarrow{A_1E} \cdot \overrightarrow{GF} = 0$，异面直线垂直，所成角为 $\dfrac{\pi}{2}$，选 D。
9. **第 9 题（受限位置排列组合）**：
   - 特殊位置巴黎从其余 4 人中选 1 人，余下 3 个城市从 5 人中选 3 人排列，总方案数 $4 \times 60 = 240$ 种，选 B。
10. **第 10 题（双曲线定义与正三角形中点离心率）**：
    - 正三角形中线即高，$F_2P \perp MF_1$；$|PF_1| = c, |PF_2| = \sqrt{3}c \implies 2a = (\sqrt{3}-1)c \implies e = \sqrt{3}+1$，选 D。
11. **第 11 题（二元二次条件最值与柯西不等式）**：
    - 由柯西不等式 $(a+b)^2 \leqslant \left(1 + \dfrac{1}{2}\right)(a^2 + 2b^2) = 9 \implies a+b \geqslant -3$，最小值在 $a=-2, b=-1$ 处取得，选 C。
12. **第 12 题（奇函数周期性与区间零点个数）**：
    - $f(0) = 0$；由周期 3 得 $f(3) = f(6) = 0$；$f(2) = 0 \implies f(-1) = 0 \implies f(1) = 0 \implies f(4) = f(5) = 0$；在 $(0, 6)$ 内至少有 $1, 2, 3, 4, 5$ 共 5 个零点，选 C。
13. **第 13 题（二项式定理常数项）**：
    - 通项指数 $3 - \dfrac{3r}{2} = 0 \implies r = 2$；常数项 $\mathrm{C}_6^2 \cdot 2^4 \cdot (-1)^2 = 240$。
14. **第 14 题（退化可行域线性规划）**：
    - 非负实数 $x \geqslant 0, y \geqslant 0$ 与 $2x + y \leqslant 0$ 联立得唯一解 $x = y = 0$；可行域退化为单点 $(0, 0)$，最大值为 $0$。
15. **第 15 题（等比数列和式极限）**：
    - 分子等比数列求和 $\dfrac{b^n-1}{b-1}$；除以 $b^n$ 得 $\dfrac{1 - b^{-n}}{b-1}$；因 $|b|>1$，$b^{-n}\to 0$，极限为 $\dfrac{1}{b-1}$。
16. **第 16 题（对称变换与真命题开放填空）**：
    - 关于直线 $y = x$ 对称得反函数 $g(x) = 2^{x-3}$（或关于 $x$ 轴对称得 $g(x) = -3 - \log_2 x$ 等）。
17. **第 17 题（同角三角函数平方关系与半角倍角化简）**：
    - (1) 平方得 $2\sin x\cos x = -\dfrac{24}{25}$；第四象限 $\sin x < 0, \cos x > 0 \implies \sin x - \cos x = -\dfrac{7}{5}$；
    - (2) 分子利用降幂化简为 $2 - (\sin x + \cos x) = \dfrac{9}{5}$；分母切化弦得 $\dfrac{1}{\sin x\cos x} = -\dfrac{25}{12}$；代入得 $-\dfrac{108}{125}$。
18. **第 18 题（离散型随机变量期望与对立事件概率）**：
    - (1) 各投一次，$\xi$ 取 $0, 1, 2$，分布列为 $\dfrac{3}{10}, \dfrac{5}{10}, \dfrac{2}{10}$，数学期望 $\mathbf{E}\xi = \dfrac{9}{10}$；
    - (2) 各投二次，四次均不命中的概率为 $\dfrac{1}{4} \times \dfrac{9}{25} = \dfrac{9}{100}$；至少一次命中的概率为 $1 - \dfrac{9}{100} = \dfrac{91}{100}$。
19. **第 19 题（分式函数切线待定系数与导数单调区间）**：
    - (1) 切点 $M(-1, -2)$ 且切线斜率 $-\dfrac{1}{2}$，联立解得 $a = 2, b = 3$；解析式 $f(x) = \dfrac{2x - 6}{x^2 + 3}$；
    - (2) 导数零点 $3 \pm 2\sqrt{3}$，单调增区间为 $(3 - 2\sqrt{3}, 3 + 2\sqrt{3})$，单调减区间为 $(-\infty, 3 - 2\sqrt{3})$ 和 $(3 + 2\sqrt{3}, +\infty)$。
20. **第 20 题（直二面角中线面垂直、二面角与点面距离）**：
    - (1) 面面垂直性质定理得 $CB \perp AE$，结合已知 $BF \perp AE$ 证明 $AE \perp \text{平面 } BCE$；
    - (2) 得 $\triangle ABE$ 为等腰直角三角形；作高线得二面角平面角余弦为 $\dfrac{\sqrt{3}}{3}$，二面角为 $\arccos\dfrac{\sqrt{3}}{3}$；
    - (3) 对角线中点对称法（或等体积法），点 $D$ 与点 $B$ 到平面 $ACE$ 距离相等，求得距离 $d = \dfrac{2\sqrt{3}}{3}$。
21. **第 21 题（椭圆标准方程与直线割线三角形面积）**：
    - (1) 直线 $l$ 过焦点 $(2, 0) \implies c = 2$；原点关于 $l$ 的对称点为 $(3, -\sqrt{3})$，在右准线上得 $\dfrac{a^2}{c} = 3 \implies a^2 = 6, b^2 = 2$；椭圆方程为 $\dfrac{x^2}{6} + \dfrac{y^2}{2} = 1$；
    - (2) 条件等价于 $S_{\triangle MON} = \dfrac{2\sqrt{6}}{3}$ 且 $\overrightarrow{OM} \cdot \overrightarrow{ON} \neq 0$；斜率不存在时 $x = -2$ 满足；斜率存在时设方程联立得二次方程判别式负定无实数解；故满足条件的直线仅有 1 条：$x = -2$。
22. **第 22 题（分式递推数列、有穷数列判定与正向不变区间）**：
    - (1) 逆推得 $a_4 = 0 \implies a_3 = -1 \implies a_2 = -\dfrac{1}{2} \implies a_1 = -\dfrac{2}{3}$；
    - (2) 数学归纳法证明当 $a = b_k$ 时，$a_m = b_{k-m+1}$，特别地 $a_k = b_1 = -1 \implies a_{k+1} = 0$，第 $k+2$ 项无意义，故必为项数 $k+1$ 的有穷数列；
    - (3) $n = 4$ 时 $\dfrac{3}{2} < a_4 < 2 \iff a > 0$；由 $g(x) = 1 + \dfrac{1}{x}$ 的严格单调减性与正向不变集 $g\left(\left(\dfrac{3}{2}, 2\right)\right) \subset \left(\dfrac{3}{2}, 2\right)$，数学归纳法证明对所有 $n \geqslant 4$ 均满足要求；故 $a > 0$（即取值范围 $(0, +\infty)$）。
