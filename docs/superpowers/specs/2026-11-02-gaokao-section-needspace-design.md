# 高考数学题库：局部分节分页阈值设计

- 日期：2026-11-02
- 状态：设计提案，待用户确认；未进入实施
- 对象：`phase1-b69` 中 `gk-2006-regular-jiangsu` 的第 3 页留白

## 意图

让固定题源能为单个结构标题声明分页所需的最小剩余空间，缓解江苏卷填空题页末到解答题之间的大块留白，同时保留共享排版默认值，避免为一个版面问题调整所有试卷。

## 目标

- 支持紧邻 Markdown 二级分节标题的 `<!-- section-needspace: 0.30 -->` 元数据；缺省时继续使用公共 `\gkpart` 的现行阈值。
- 生成器只对该条元数据对应的一个标题局部降低 `Needspace`，题目正文、答案和解析内容不变。
- 验证格式和阈值范围，拒绝无效、重复、悬空或指向不存在分节的指令。
- 用江苏卷试跑并重建四版；全页复核重排页，只有视觉结果通过后才关闭相应留白 issue。

## 非目标与失败条件

- 不修改公共 `\gkpart` 默认值，不改变其他试卷的分页。
- 不把新增空白、手动 `\vspace` 或 `\newpage` 写进题源。
- 不改写源题、答案、官方身份或 `U` 状态。
- 若降低阈值导致孤立分节标题、标题与首题分离、其他页出现新的大块留白，或任何版本的四版构建失败，则不接受此方案；保留 blocker 并撤销试跑改动。

## 现状与边界

公共 `\gkpart` 当前用 `\Needspace{0.6\textheight}`，以防止结构标题落在页底。现有 `question-needspace` 只局部控制单个题块，无法影响标题处的换页。江苏卷试题、解析和简答版第 3 页同为 Q11–Q16 后留白，印刷版不在该 issue 中。

## 考虑过的做法

1. **降低公共 `\gkpart` 阈值**：改动简单，但会影响整个题库并可能使其他卷出现孤立标题；不选。
2. **新增局部分节元数据**：在题源相应标题前声明阈值，生成器仅包装该标题；范围与问题相符，推荐此方案。
3. **手改生成后的 TeX 或插入强制分页/间距命令**：不能从规范题源确定性再生，且绕开现有来源规则；不选。

推荐项是实现提案，不代表用户已批准。

## 提案实现边界

- 在规范 `_试题.md` 的 `## 三、解答题` 前声明 `<!-- section-needspace: 0.30 -->`。
- 扩展源解析/生成路径，在文档结构中把指令绑定到紧随其后的分节标题；指令不进入最终题面。
- 生成的 `questions.tex` 只在该标题周围局部设置阈值，继续使用当前 `\subsection*` 标题层级与 `\nopagebreak` 行为；默认标题仍走 `\gkpart`。
- 增加 parser/generator 单元测试：默认行为字节级保持；合法指令只作用于下一标题；边界值、重复、悬空、非法格式均有明确失败。
- 更新确定性派生物与 provenance 中受题源哈希影响的记录；检查 manifest、题源投影和构建回执的 currentness。
- 正式构建江苏四版。对四版所有发生变化的页重新渲染和复核，并执行该批所需的生成器/来源/收据校验；通过后再更新 issue、报告、进度并提交这一阶段。
