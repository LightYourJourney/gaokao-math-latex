# 高考数学 LaTeX 工程阶段 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通「从上游 PDF 新建一套试卷」的完整链路，并用批次 7（`2021_全国甲卷_文科`、`2023_全国甲卷_文科`）端到端验证。阶段 0 只迁移了既有 21 套，本阶段补上缺失的注册能力与转录工作流，使后续 2–6 阶段可以批量复用。

**Architecture:** 沿用阶段 0 契约不变：`source-manifest.json` 是唯一事实源，`provenance.json` 逐题存证，四版本 LaTeX 由 manifest 确定性生成，构建/视觉回执 + 批次报告构成关闭门禁。本阶段新增的唯一写入口是 `source_manifest.py register-papers`，把「未绑定来源 → paper 记录 + batch 记录」这一步纳入既有 `state` 事务，不新建第二条状态通路。

**Tech Stack:** 与阶段 0 相同（Python 3.9 标准库、Bash 3.2、Git、XeLaTeX/TeX Live 2026、Poppler、TikZ/PGF）。

**Approved Spec:** `docs/superpowers/specs/2026-08-04-高考数学真题全量LaTeX工程-design.md` 第 12 节「阶段 1：补齐 2017–2026」。

## 阶段 0 实测语料事实（本计划的设计前提）

以下数字由 2026-08-14 对固定 commit `34c13a6` 的 775 份 PDF 全量机械扫描得出（`pdftotext -layout`，每页字符密度判定），是阶段 1–6 排期的依据：

| 事实 | 数值 | 对计划的约束 |
|---|---|---|
| 上游来源总数 | 775（普通 734 + 春季 41） | 已绑定 20，**待转录 755** |
| 无文本层（每页 < 50 字符） | **88（11%）** | 必须 OCR 或人工转录；集中在 1977（47）、1990s（18）、1980s（12） || 文本充分（每页 ≥ 200 字符） | 687（89%） | 可走 `pdftotext` 抽取 + 人工校对 |
| 含显式答案章节（参考答案/评分标准） | **19（2%）** | — |
| 含弱答案迹象（≥3 处行首「解:/证明:/答:」） | 4 | — |
| **无任何答案迹象** | **664 / 687 可抽文本者（96%）** | 绝大多数试卷的答案与解析**没有上游来源** |

**由此确定的核心口径（不可协商）**：目标要求「缺源或存疑内容明确标记待补，严禁编造」，规格第 12 节亦写明「来源不可读或答案不可核实时保留阻塞状态，不为覆盖率猜写」。因此阶段 1 起，绝大多数新卷的正常终态是 `blocked`（题面已核、答案证据等级 `U`），**不是** `complete`。批次报告必须如实呈现该比例，不得为提高 complete 计数而降低证据标准。解析版仍然生成，但无源处渲染为显式「待补」标记。

## Global Constraints

- 继承阶段 0 全部 Global Constraints（工程根目录、上游固定 commit、775 守恒、Python 3.9、Bash 3.2、`shell=True` 禁用、`-no-shell-escape`、中文注释、不 push、精确暂存）。
- 上游 clone 路径由 `GAOKAOMATH_SRC` 提供（当前主工作区为 `gaokaomath-src`，HEAD 必须为 `34c13a6cf632c0b69c95f89b9b923bbc4a08924d`）。
- 新增 paper/batch 记录只能经由 `state` 事务写入，CAS `expected_revision`，manifest 最后提交并递增 revision；禁止手工编辑 `source-manifest.json`。
- 新卷初始 `production_state` 为 `planned`；只有真实 provenance、当前构建回执与视觉回执俱全才可派生更高状态。
- 题面必须逐题对照 PDF 核验；答案/解析无源时证据等级记 `U` 并在 `missing-issues.md` 立问题，不得以「常识可推」补写。
- 批次规模遵循规格：阶段 1 每批 2–4 套，首批固定 2 套。

## Stage 1 Exit Criteria

- `register-papers` 有测试冻结的契约，且是新增 paper/batch 的唯一写入口。
- 批次 7 两套完成转录、构建、视觉审查并生成批次报告，`git_state=committed`。
- 2017–2026 区间内所有未绑定来源要么已注册，要么在总账中有明确的未处理理由。
- 无答案来源的卷诚实停在 `blocked`，问题总账逐条可追溯。
- 工作区干净，分任务提交，未 push。
