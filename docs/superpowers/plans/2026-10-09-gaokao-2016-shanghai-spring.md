# 2016 春季上海卷 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. 卷面转录与独立求解由不同角色分头完成，主会话独占规范整合、manifest、回执与提交。Steps use checkbox (`- [ ]`) syntax.

**Goal:** 将固定上游中的 2016 上海春季卷（暨学业水平考）整理为可追溯、可编译、可逐页复核的四版本 LaTeX 项目。

**Architecture:** 同 b15–b23 批次：固定来源 ID 是身份根；转录与盲解角色分离；规范三件套 + TikZ 图源由主会话整合；不提交扫描件与构建中间件。**本批两个全库首例**：① **固定源自带官方参考答案（简略版，p8–9）**——答案证据等级 **A**（spec §6.2：可标明官方来源、仍须防转录错误）；② **第Ⅱ卷（附加题）源内独立编号 1–7**——内部按全卷连续编号 **30–36**（映射记入来源说明与证据文本）。

建模先例：`2016_江苏卷`（phase3-b00，附加题结构与流程图先例）。

## 已知口径与坑（b11–b23 沉淀）

- 四版本口径：试题版=纯题面；解析版=题目+完整解析；简答版=题目+答案速查；印刷版=题目+完整解析紧凑排版；「见解析版」为生成器既有口径。
- 规范源写裸 `%`；解答题小问「（N） 内容」；长定义式 `\frac`；TikZ 图源全坐标统一缩放（照源 pt 换算）。
- **图标签 `inner sep=0`**；**分数型标签禁按字框并集中心定位**；探针必须 400/600 dpi 连通域量测；**选项内嵌图（本卷首例）注意 `\begin{center}` 与 \@doendpe 的首行缩进抑制为模板级 pass**。
- **分页守卫注入规范源**（b17）：`\Needspace{N\textheight}` 独立行于题前。
- **公共宏/转换器（`common/*`、`md2tex.py`）是全项目回执依赖闭包**：齐左、留白、「解析」标签孤悬、印刷版页眉横线短/页脚左偏、选项断行类均留档不修（b16 原则）。
- **数值抽验行须主会话复算**（b18）。
- **CJK 入数学模式＝静默缺字**（b20）→ `\text{}` 或纯文本；build 后必查四日志 `Missing character`。
- **答案行裸 `*` 丢绿框**（b21）→ `\ast`；**答案行含 `&` 用 `$...$` 保护段**（b23）。
- **源↔成品图保真由主会话对照**（b19/b20/b22）：非直线要素逐 path 清点；新图元类型首现必查连通域。
- **差分基线须与重建同引擎**（b23）：统一 pdftoppm；先交叉测试锁定（待测渲染↔v1 mean=0）。
