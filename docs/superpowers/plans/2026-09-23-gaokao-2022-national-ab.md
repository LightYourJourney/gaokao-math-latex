## 固定边界

- 批次 ID：`phase2-b04`（现有清单在 `phase2-b03` 后按两位序号继续）。执行期间不 push。
- 上游固定为 `gaokaomath-src` 的 commit `34c13a6cf632c0b69c95f89b9b923bbc4a08924d`；source ID、路径及 SHA-256 以当前 manifest 为准。
- 四份 PDF 均为 2 页，题号 1–23。各题实际页码、纸面页码和图形元素须逐页复核，不以文件名或文本抽取代替视觉核对。
- 本地上游 2022 目录未发现答案文件；没有官方答案证据的题目按等级 D（项目独立推导并由第二代理盲核），不得称为官方答案。冲突无法收敛时标 U 并登记问题。

- 四份规范 Markdown（三个字段源及真实生成的含解析稿）齐备、题量与图形引用通过检查后，主代理才创建注册规格；先 dry-run，再且仅一次 `register-papers --write`。主代理独占共享清单与问题总账写入。
- 所有构建 PDF 留在各卷被忽略的 `build/`；最终清除 `.aux`、`.log`、渲染页和其他编译中间件。提交只含文本、LaTeX/TikZ 源与机器可复核的 JSON/报告，不含 PDF 或图片。

## 工作项

### 一、来源与题面

- [ ] 注册前逐份复验上游 commit、SHA-256、PDF 页数、纸面页码和题面身份；确认四份来源未绑定其他 paper，且与已有 2022 新高考Ⅰ/Ⅱ卷不是同一试卷。
- [ ] 每卷独立转录 23 题及所有选项、小问、公式、文字、表格和图示，写题号—PDF 页—纸面页映射和不确定点；保持原文，不按语义猜补。
- [ ] 第二代理逐页对照 PDF，列出差异；主代理逐项裁决。问题无法核实则保留原貌并登记阻塞，不静默订正。
- [ ] 答案由独立求解代理给出逐题结论和推导证据；另一代理在不看首份结论的情况下盲核。题面与答案哈希、证据等级和 reviewer role 按 provenance schema 留痕。
- [ ] 图形只用 TikZ/PGFPlots 源重绘；列明坐标、点名、虚实线、遮挡、刻度及不可确认元素。逐题检查源卷有图则有引用、源卷无图则不添图。

### 二、主代理整合、登记与生成

- [ ] 以每卷三份规范 Markdown（`_试题.md`、`_答案要点.md`、`_解析正文.md`）为唯一人工维护内容；通过 `solution_sources.render_combined()` 生成真实 `_含解析.md`，不写占位稿。
- [ ] 按实数题量登记 `question_count`、题型结构、source IDs、source_files、figure_files 与 index metadata；每个图形标记的出现次数须由校验器实测。
- [ ] 注册前运行 `register-papers` dry-run；确认四卷 source/paper/batch 映射、路径和状态无冲突后，只执行一次 `--write`。再运行 `extract-batch`、`check-batch`、简答答案及四版壳生成校验。
- [ ] 生成 `questions.tex`、`answers.tex`、`answers_short.tex`、`provenance.json` 和四个独立入口；按现有生成器产物管理，不手改确定性文件。

### 三、构建、视觉复核与结项

- [ ] 16 个目标（4 卷 × 4 版）逐卷编译，验证输入依赖闭包、工具链、未解析引用、Missing character、日志告警与 PDF 页数；构建回执由主代理统一生成。
- [ ] 逐卷检查四版首页、题面密集页、全部图形页、解析起始页、简答页、印刷拥挤页与末页；视觉回执写页码与输入哈希，不提交截图。
- [ ] 核对 `answers.tex` 与 `answers_short.tex` 结论一致；计算题复算并检查量纲。证据不足项继续 blocked。
- [ ] 更新 manifest CSV 投影、问题总账、批次报告和全局报告；运行本批全部来源、schema、题量、解析、生成、provenance、构建、审查与报告门禁。
- [ ] 清理本批 build 中 PDF 以外的编译文件及临时渲染；检查精确暂存区与 `git diff --check`；分阶段提交，不 push。

## 验收标准

- `phase2-b04` 只含上述四个 source/paper 映射，revision 与 CSV 投影一致；source PDF SHA 均与固定上游匹配。
- 每套 23 题完整，题面可逐页回溯，题量、页码、选项、公式及图形均通过独立复核。
- 解析和简答答案逐题一致；无官方材料时答案等级为 D，答案证据不足或存在未解冲突则标 U/blocked。
- 每套四版均有有效的当前构建及视觉回执；图形仅为可编译 TikZ/PGFPlots 源，仓库无源 PDF、PNG/JPEG、页面截图或编译中间件。
- 报告与机器清单一致；精确提交本批文件，目标分支不 push。
