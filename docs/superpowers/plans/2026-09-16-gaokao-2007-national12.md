# 2007 年全国卷Ⅰ/Ⅱ数学资产 Implementation Plan

> **For agentic workers:** Use the executing-plans or subagent-driven-development workflow task by task. Steps use checkbox syntax.

**Goal:** 将固定源对应的 2007 年全国大纲卷Ⅰ、全国大纲卷Ⅱ文理四套数学试卷整理为可追溯 Markdown、四种可编译 LaTeX 版本、六个矢量图源和通过全页复核的 PDF。

**Architecture:** 四卷各自拥有唯一题面 Markdown、答案要点 Markdown 和解析正文 Markdown；solution_sources.py 确定性生成含解析稿，generate_projects.py 生成共享 questions.tex/answers.tex，make_short_answers.py 与 make_editions.py 生成其余入口。固定源 PDF 只用于核对，不进入仓库；原卷图形全部用项目内 TikZ/PGFPlots .tex 重绘。

## Global Constraints

- 固定上游为 gaokaomath-src 的 commit 34c13a6cf632c0b69c95f89b9b923bbc4a08924d；四份 PDF 的 SHA-256、字节数、A3 页数和印刷页码必须进入 provenance/报告链路。
- 四卷均为 22 题，结构为选择题 1–12、填空题 13–16、解答题 17–22；题面必须忠实保留原卷符号、选项、图形和所有分问。
- 全国Ⅱ文/理的固定源 upstream 文件名含 2002大纲2，这是上游文件名事实，不得擅自改写。
- 固定源、页面渲染 PNG、编译日志和 .work 不进入 Git；图形只能提交 TikZ/PGFPlots .tex，本批次不得新增栅格媒体。
- 固定源均未附答案页；答案与解析必须独立推导并进行第二次盲审，存疑内容必须登记 issue。
- 四卷各生成试题版.pdf、解析版.pdf、简答版.pdf、印刷版.pdf；最终每个 build/ 只保留四个 PDF。
- 生成/构建命令严格串行，不主动 push。
