# 2021 年全国甲、乙卷数学批次实施计划

> 执行方式：控制者负责跨卷集成；三卷的规范 Markdown 与项目图源分工互不重叠。卷别执行者不得改 manifest、问题总账、共享模板、跨项目报告或其他试卷文件。

**目标：** 将 2021 年全国乙文、全国甲理、全国乙理三卷转录、独立解答、以矢量图重绘并纳入 LaTeX 题库；保留来源歧义与答案置信度边界。

**来源与生成：** `source-manifest.json` 是唯一来源／试卷／批次登记表。每卷规范源为 `_试题.md`、`_答案要点.md`、`_解析正文.md`；`_含解析.md` 由 `solution_sources.py` 确定性生成。图源仅用项目内 `figures/*.tex`。`generate_projects.py`、`make_short_answers.py` 和 `make_editions.py` 生成 LaTeX、简答答案和四种版式。

项目文档使用简体中文。

## 约束

- 批次固定为 `phase2-b03`；上游工作树固定为 `gaokaomath-src`。以 manifest 锁定的来源路径、修订、ID 和 SHA-256 为准。
- 三份 PDF 内页标题与上游文件名卷别冲突。保留原题头；身份只依据固定路径与独立题目指纹确认，并用考试中心评论作辅助佐证。不得猜测冲突原因；三项冲突及证据记入 `missing-issues.md` 和 provenance。
- 每卷 23 题：选择题 1–12、填空题 13–16、必答题 17–21、选做题 22–23（二选一）。两道选做题都转录并求解；逐题核对源页映射。
- 不猜补有歧义的题干、图示或答案。无权威答案时独立推导并盲审，等级为 D；只有确认官方答案来源后方可标 A。
- 图示仅用 TikZ／PGFPlots 矢量源。源 PDF、页面渲染图、PNG／JPEG 等栅格素材不得入库；源 PDF 与临时渲染放在工作树之外。
- 只有控制者修改 manifest、问题总账、登记规格、provenance 导入、共享脚本／模板、批次／全局报告和跨卷文件。各卷执行者只改分配到自己的三份规范 Markdown 与项目 `figures/*.tex`。
- 完成全量页审后，`build/` 目录只留 PDF，删除 LaTeX 辅助文件和临时渲染。不得 push。
