# 2017 全国Ⅱ/Ⅲ卷文理科 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Each paper gets an independent transcription/solution role and a different blind reviewer; main agent owns canonical integration, manifests, receipts, and commit. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将固定上游中的 2017 全国Ⅱ、Ⅲ卷文理科四套数学试卷整理为可追溯、可编译、可复核的四版本 LaTeX 项目。

**Architecture:** 以 `source-manifest.json` 中固定 `source_id` 为身份根，四套题面的规范 Markdown 放在 `2017/`，生成器产出共享 LaTeX、简答版和四个独立入口。转录与答案独立推导按卷隔离在忽略目录，之后由不同角色盲核；图稿仅保留 TikZ/PGFPlots `.tex`，来源 PDF、渲染图和编译中间件均不入库。

**Tech Stack:** Markdown、Python 3 标准库工具、XeLaTeX、TikZ/PGFPlots、Git、Poppler（`pdfinfo` / `pdftotext` / `pdftoppm`）。


## Global Constraints

- 固定批次：`phase2-b07`；只处理本计划列出的四套 2017 全国Ⅱ/Ⅲ卷文理科，不改公共生成器、模板、宏或其他批次。
- 上游固定 commit：`34c13a6cf632c0b69c95f89b9b923bbc4a08924d`；`source_id`、SHA-256、blob OID 和路径以本表及当前 `source-manifest.json` 为准。
- 每份源 PDF 为 2 页 A3、预期 23 题；题量、题型和题号分段须在逐页核对后确认，不能为匹配预期补题。
- 题面必须逐页对照 PDF。四份源件只有题面，没有随附答案；无可追溯的可靠答案来源时用独立求解与异人盲核支持等级 D，未能收敛的题标 U 并阻断完成。
- 转录与解题草稿仅写忽略目录 `.work/phase2-b07/<paper_id>/`；规范题面、答案、解析及生成展示文件仅写 `2017/`。
- 选择题顺序、文理差异、限定词、旧题型、计分说明和原卷编号忠实保留；OCR/文本层只用于初稿，不得代替人工视觉核对。
- 图稿只用各项目 `figures/*.tex` TikZ/PGFPlots 源；不得将 PDF、页面裁图、PNG/JPEG、截图或 OCR 中间图加入 Git。
- 四卷各构建试题、解析、简答、印刷四版；忽略的 `build/` 每卷只留四份最终 PDF，所有编译中间件与渲染图清除。
- 不暂存或提交无关更改，不改动上游目录中的既有未跟踪文件；本批不 push。

## Review Focus

- 文理卷与全国Ⅱ/Ⅲ卷之间题号相似但题干、数据、选项和小问不同：逐卷按固定 PDF 核对，禁止复制近似版本。
- 两页 A3 的多栏顺序可能与文本抽取顺序不同：页码映射须覆盖每题，核对跨栏、跨页处无漏题、重复或错序。
- 程序框图、三视图、统计图、函数图象和空间几何图中的点名、方向、刻度、虚实线必须从 PDF 确认；看不清则登记问题，不按数学常识补画。
- 上下标、根式、分式、集合、向量和参数限定容易被扫描/OCR 丢失：含复杂公式的每题必须回看原页渲染。
- 原卷答案缺席时，求解者与盲核者必须分离；无法独立收敛的结论保留 U/blocked，不以多数意见或记忆填补。
