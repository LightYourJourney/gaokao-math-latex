# 2016 全国Ⅰ/Ⅱ卷文理科 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将固定上游中的 2016 全国Ⅰ、Ⅱ卷文理科四套数学试卷整理为可追溯、可编译、可直接打印的四版本 LaTeX 项目。

**Architecture:** 以 `source-manifest.json` 中固定 `source_id` 为身份根，四套题面的唯一人工来源放在 `2016/`，生成器产出共享 LaTeX、简答版和四个独立入口。项目图形只存 TikZ/PGFPlots `.tex`；来源 PDF、渲染图和构建中间件留在本地或忽略目录。

**Tech Stack:** Markdown、Python 3 标准库工具、XeLaTeX、TikZ/PGFPlots、Poppler (`pdfinfo` / `pdftotext` / `pdftoppm`)、Git。

**Spec:** `docs/superpowers/specs/2026-08-04-高考数学真题全量LaTeX工程-design.md` 与仓库根目录 `CLAUDE.md`。

## Global Constraints

- 固定批次：`phase2-b05`；只处理本计划列出的四套 2016 全国Ⅰ/Ⅱ卷文理科，不修改公共生成器或其他批次内容。
- 上游固定 commit：`34c13a6cf632c0b69c95f89b9b923bbc4a08924d`；每套来源的 `source_id`、SHA-256 和路径以本计划及 `source-manifest.json` 为准。
- 四份源 PDF 均为 2 页、题号 1–24；题面必须逐页视觉对照 PDF，文本提取与 OCR 只作初稿辅助。
- 上游目录未提供答案文件；没有可追溯外部答案材料时，答案标 D 且须独立盲核。若本会话无独立 reviewer 能力，相关答案标 U 并阻断，不把自我复算冒充盲核。
- 转录草稿先写入忽略目录 `.work/phase2-b05/<paper_id>/`；题面、答案和解析规范 Markdown 才可进入 `2016/`。
- 题面、答案或图形不确定处保持源文并登记 `missing-issues.md`，不得凭记忆补题、答案或图形特征。
- 规范图源仅为卷目录内 TikZ/PGFPlots `.tex`；PNG/JPEG/PDF 页面图、截图和 OCR 临时图不得入库。
- 所有 4×4 个版本独立编译；中间文件、页面渲染和临时文件不得提交，卷目录 `build/` 只保留 PDF。
- 本批收尾前不 push；不暂存或提交当前工作树中与本批无关的既有改动。

## Review Focus

- 两个 PDF 页面为 A3 排版且跨栏阅读次序不等于纯文本顺序：逐题记录 PDF 页和纸面页，检查题号无漏、重、乱序。
- 上下标、根号、绝对值、参数方程和选做题式样容易在文本层丢失：每道含复杂公式的题必须回看渲染页。
- 文理卷共享题号或题干时不能因相似而复制错版：逐卷核对独有数据、选项和小问。
- 题面带图而源图细节不清时不得按比例猜绘：只画源 PDF 可确认的元素，其余登记阻塞。
- 无官方答案源时不能将同一代理的复算描述为独立盲核：证据不够就保留 U/blocked。
