# 2015 全国Ⅰ/Ⅱ卷文理科 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** 将固定上游中的 2015 全国Ⅰ、Ⅱ卷文理科四套数学试卷制作为有逐题来源证据、可编译并通过视觉复核的 LaTeX 项目。

**Architecture:** 以 `source-manifest.json` 中四个固定 `source_id` 为来源身份根，规范题面、答案与解析落在 `2015/`，项目内图形只保留 TikZ/PGFPlots `.tex`。转录、独立求解和盲核先分角色写入忽略目录，主会话裁决后调用现有生成器、provenance、构建和回执工具。

**Tech Stack:** Markdown、仓库 Python 工具、XeLaTeX/latexmk、TikZ/PGFPlots、Poppler、Git。

**Spec:** `docs/superpowers/specs/2026-08-04-高考数学真题全量LaTeX工程-design.md`，以及仓库根 `CLAUDE.md`。

## Global Constraints

- 批次固定为 `phase2-b10`；只处理本计划列出的 2015 全国Ⅰ/Ⅱ卷文理科四套，不改公共生成器、模板、宏或其他批次；不 push。
- 上游固定为 `gaokaomath-src` 的 commit `34c13a6cf632c0b69c95f89b9b923bbc4a08924d`；注册前重新验证每个来源的 SHA-256、Git blob OID、PDF 页数、印刷页码与试卷身份。
- 四份来源 PDF 均为两页 A3、题号 1–24；逐页视觉核对为准，文本抽取/OCR 只作初稿辅助。页码映射初验：全国Ⅰ文 963–964、全国Ⅰ理 961–962、全国Ⅱ文 967–968、全国Ⅱ理 965–966。
- 来源包未确认含官方答案前，不得声称答案为官方答案；项目独立推导须由不同代理盲核后标 D，证据不足或无法收敛标 U 并阻断相应完成态。
- 内容代理只写当前隔离工作树中的 `.work/phase2-b10/<paper_id>/`；主会话独占规范源整合、manifest、index、CSV、问题总账、正式 provenance、构建/视觉回执及报告。
- 转录者、题面复核者、求解者、答案盲核者按卷分离；盲核者在独立答案定稿前不得看首解结论。代理不得创建子代理。
- 规范图源仅为卷目录内 TikZ/PGFPlots `.tex`；禁止将 PDF、页面图、截图、PNG/JPEG 或编译中间件加入 Git。
- 四卷各独立构建试题、解析、简答、印刷四版；构建目录最终只保留正式 PDF 与所需 `.tex` 源。

## Review Focus

- 同年文理卷存在共享题型/题面，不可按相似记忆复用题干、选项、数据或答案；逐卷按 PDF 证据确认。
- 两页 A3 多栏版式易造成错序、漏题与页码错配；页码表必须覆盖 1–24 全题及图示。
- 函数图、算法框图、统计图和空间几何图需按原图核点名、刻度、线型、遮挡及表格；不能确认的部分登记阻塞，不猜绘。
- 参数、向量、极坐标、数列、根式和选做题公式需视觉复核文本抽取结果，不能以数学上“更合理”的写法修正来源。
- 解析答案必须与简答版逐题一致；答案盲核不可读取首解结论后再宣称独立。
