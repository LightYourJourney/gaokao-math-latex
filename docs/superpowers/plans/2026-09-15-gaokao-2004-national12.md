# 2004 年全国卷Ⅰ/Ⅱ数学资产 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将固定源对应的 2004 年全国卷Ⅰ、全国卷Ⅱ文理四套数学试卷整理为可追溯 Markdown、四种可编译 LaTeX 版本、矢量图源和通过全页复核的 PDF。

**Architecture:** 四卷各自拥有唯一题面 Markdown、答案要点 Markdown 和解析正文 Markdown；`solution_sources.py` 确定性生成含解析稿，`generate_projects.py` 生成共享 `questions.tex/answers.tex`，`make_short_answers.py` 与 `make_editions.py` 生成其余入口。固定源 PDF 只用于核对，不进入仓库；原卷图形全部用 TikZ/PGFPlots 重绘为项目内 `.tex` 图源。

**Tech Stack:** Markdown、Python 3 工具链、XeLaTeX/PGFPlots/TikZ、Poppler (`pdfinfo`/`pdftoppm`/`pdftotext`)、仓库 manifest/provenance/review receipts。

**Spec:** `math-gaokao-latex/README.md`、`docs/superpowers/plans/2026-08-14-高考数学LaTeX阶段1实施计划.md` 与既有 manifest/transaction 契约。

## Global Constraints

- 固定上游为 `gaokaomath-src` 的 commit `34c13a6cf632c0b69c95f89b9b923bbc4a08924d`；四份 PDF 的 SHA-256、字节数、A3 页数和印刷页码必须记录在 provenance/报告可追溯链中。
- 四卷均为 22 题，结构为选择题 1–12、填空题 13–16、解答题 17–22；题面必须忠实保留原卷符号、选项、表格、图形和所有分问。
- 固定源 PDF、源仓库、页面渲染 PNG、编译日志和 `.work/` 不进入 Git；图形只能提交 TikZ/PGFPlots `.tex`，本批次不得新增 PNG/JPEG 或其他栅格媒体。
- 新卷没有 `legacy_ids`；答案与解析无官方随卷来源时，必须由独立解题和盲审复算，不能凭模型记忆填答；无法确认的题保留源字面并登记 issue。
- 四卷各生成 `试题版.pdf`、`解析版.pdf`、`简答版.pdf`、`印刷版.pdf`；最终每个 `build/` 目录只保留这四个 PDF。
- 所有会写共享 manifest 或生成文件的命令遵循 `RepoLock`，生成/构建命令严格串行；不 push。
- 每完成一个逻辑阶段精确暂存并提交；计划关闭前必须运行批次门禁、全库门禁和完整 816 项测试。
