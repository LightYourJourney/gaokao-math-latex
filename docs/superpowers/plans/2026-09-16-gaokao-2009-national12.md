# 2009 全国大纲卷Ⅰ/Ⅱ文理科 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将固定源中的 2009 全国大纲卷Ⅰ/Ⅱ文理科四套数学试卷整理为可复用、可打印、带逐题来源证据的 LaTeX 项目。

**Architecture:** 沿用已经验收的来源总账驱动链：固定 PDF 元数据进入 `source-manifest.json`，题面/答案/解析保留在 `2009/`，`generate_projects.py` 生成每卷唯一的共享 `questions.tex` 与 `answers.tex`，四个入口壳复用共享内容。所有图形由每卷目录下的 TikZ/PGFPlots `.tex` 源提供，PDF 只作为本地构建产物。

**Tech Stack:** Markdown、Python 3.12 标准库工具、XeLaTeX、TikZ/PGFPlots、Poppler `pdfinfo`/`pdftotext`/`pdftoppm`、Git。


## Global Constraints

- 固定批次：`phase2-b98`；仅处理 2009 全国大纲卷Ⅰ/Ⅱ文理四套，不改公共生成器。
- 固定源来自 `gaokaomath-src/普通高考/2009/`；登记后以 manifest 中的 `source_id`、SHA-256 和页码为唯一来源身份。
- 题面、答案和解析逐题绑定固定源；无法从固定源确认的内容进入 `missing-issues.md`，不凭记忆补写。
- 每卷保留 `questions.tex`、`answers.tex`、`answers_short.tex`、四个入口 `.tex`、`provenance.json`、`receipts/build.json`、`receipts/review.json` 与矢量图源。
- 不提交 PNG/JPEG 等光栅图；构建中间文件、`.work` 和渲染临时文件在收尾时删除，build 目录只保留 PDF。
- 四卷完成后批次状态以实际证据为准；存在开放阻断问题时标为 `closed_with_blockers`，不得伪装为无问题完成。
