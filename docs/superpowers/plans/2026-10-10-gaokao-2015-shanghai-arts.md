# 2015 上海文卷 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. 卷面转录与独立求解由不同角色分头完成，主会话独占规范整合、manifest、回执与提交。Steps use checkbox (`- [ ]`) syntax.

**Goal:** 将固定上游中的 2015 上海文卷整理为可追溯、可编译、可逐页复核的四版本 LaTeX 项目。

**Architecture:** 同 b15–b23、phase3-b00/b01/b02/b03 批次：固定来源 ID 是身份根；转录与盲解角色分离；规范三件套 + TikZ 图源由主会话整合；不提交扫描件与构建中间件。**版式新类型**：源为 **A3 横向（1190.55 × 841.89 pt）三栏书刊合排**（转录双代理实测，初判「双栏」已更正）——印刷页码 979/980 属**合订本书页体系**（位于页面底部正中），phase3 批次首次处理；栏序/栏内坐标映射由转录实测建档。**源制作体系：LaTeX 重排产物**（非扫描件——pdfimages 零命中、全矢量、文本层完整可读无 PUA、16 字体全嵌入），与 b03（Word＋MathType）体系不同。

建模先例：上海卷 3+1 体制（2017 改革前）结构从源实测核定（2016 上海文理 b14 由另一会话在途，**不依赖其未定稿产物**）。
