## 2. 原卷排印与考订说明

1. **第 1 题（圆关于原点对称方程）**：
   - 原圆心 $(-2, 0)$，半径 $\sqrt{5}$，对称圆心 $(2, 0)$，方程 $(x - 2)^2 + y^2 = 5$，选 A。
2. **第 2 题（二倍角与平方差三角求值）**：
   - 展开得 $\cos^2\dfrac{\pi}{12} - \sin^2\dfrac{\pi}{12} = \cos\dfrac{\pi}{6} = \dfrac{\sqrt{3}}{2}$，选 D。
3. **第 3 题（偶函数与单调性不等式）**：
   - $f(x)$ 为偶函数，$f(-2) = f(2) = 0$；负半轴递减推导正半轴递增，解得 $(-2, 2)$，选 D。
4. **第 4 题（平面向量数量积与数乘）**：
   - $\vec{a} \cdot \vec{b} = -4$，$\vec{a} + \vec{b} = (1, 1)$，数乘得 $(-4, -4)$，选 B。
5. **第 5 题（绝对值与对数不等式组解集）**：
   - $|x - 2| < 2 \implies x \in (0, 4)$；$\log_2(x^2 - 1) > 1 \implies x^2 > 3$；交集为 $(\sqrt{3}, 4)$，选 C。
6. **第 6 题（锐角三角函数充分必要条件）**：
   - $q \implies p$ 显然；$p \centernot\implies q$（如 $\alpha = 30^\circ, \beta = 60^\circ$ 时 $p$ 成立但 $q$ 不成立），故为必要而不充分条件，选 B。
7. **第 7 题（空间线面平行判定命题辨析）**：
   - ② 面面平行传递性；④ 异面线分别平行两平面可导出面内相交线平行另一平面；判定平行的条件共 2 个，选 B。
8. **第 8 题（二项式定理系数比例方程）**：
   - $\dfrac{4}{3}n(n-1)(n-2) = 16n \implies (n-1)(n-2) = 12 \implies n = 5$，选 A。
9. **第 9 题（椭圆动点二次函数最值与分段讨论）**：
   - 代换得二次函数 $f(y) = -\dfrac{4}{b^2}\left(y - \dfrac{b^2}{4}\right)^2 + \dfrac{b^2}{4} + 4$；对称轴 $\dfrac{b^2}{4}$ 与边界 $b$ 比较，得 $0 < b < 4$ 时最大值 $\dfrac{b^2}{4} + 4$，$b \geqslant 4$ 时最大值 $2b$，选 A。
10. **第 10 题（正方体几何体塔形表面积与等比数列）**：
    - 边长等比公比 $\dfrac{\sqrt{2}}{2}$，面积公比 $\dfrac{1}{2}$；侧面积和 $16 \times 2(1 - 1/2^n) = 32(1 - 1/2^n)$，水平暴露面积 $2S_1 = 8$；总表面积 $40 - \dfrac{32}{2^n} > 39 \implies 2^n > 32 \implies n \geqslant 6$，选 C。
11. **第 11 题（一元二次不等式交集）**：
    - $A = (1, 3)$，$B = (2, 5)$，$A \cap B = (2, 3)$。
12. **第 12 题（三次曲线切线与三角形面积）**：
    - 切线 $y = 3x - 2$，与 $x$ 轴交于 $(2/3, 0)$，与 $x=2$ 交于 $(2, 4)$；底边长 $4/3$，高 4，面积 $\dfrac{8}{3}$。
13. **第 13 题（锐角三角函数恒等方程）**：
    - 展开得 $\cos\alpha(\cos\beta + \sin\beta) = \sin\alpha(\cos\beta + \sin\beta)$，两边消去正因式得 $\tan\alpha = 1$。
14. **第 14 题（圆上动点线性目标函数最值）**：
    - 三角换元 $x - y = 2\sqrt{2}\cos(\theta + \pi/4)$，最大值为 $2\sqrt{2}$。
15. **第 15 题（抽样开锁对立事件概率）**：
    - 对立事件为 2 把都不能开锁，概率 $1 - \dfrac{\mathrm{C}_8^2}{\mathrm{C}_{10}^2} = 1 - \dfrac{28}{45} = \dfrac{17}{45}$。
16. **第 16 题（垂直平分线与圆半径轨迹方程）**：
    - 点 $A$ 在圆内，$|PA| + |PF| = |BF| = 2 > 1$，椭圆第一定义，$a = 1, c = 1/2, b^2 = 3/4$；方程为 $x^2 + \dfrac{4y^2}{3} = 1$。
17. **第 17 题（三角函数恒等变形与最值参数求解）**：
    - 化简得 $f(x) = (\sqrt{2} + a^2)\sin(x + \pi/4)$；最大值 $\sqrt{2} + a^2 = \sqrt{2} + 3 \implies a = \pm\sqrt{3}$。
18. **第 18 题（独立工序零件合格率与二项分布）**：
    - (1) 零件合格率 $P = \dfrac{9}{10} \times \dfrac{8}{9} \times \dfrac{7}{8} = \dfrac{7}{10} = 0.7$；
    - (2) 恰好取到一件合格品概率 $\mathrm{C}_3^1 (0.7)(0.3)^2 = \dfrac{189}{1000} = 0.189$；至少一件合格品概率 $1 - (0.3)^3 = \dfrac{973}{1000} = 0.973$。
19. **第 19 题（三次多项式极值与单调区间参数范围）**：
    - 导数 $f'(x) = 6(x - 1)(x - a)$；
    - (1) 极值点 $x = 3 \implies a = 3$；
    - (2) 在 $(-\infty, 0)$ 上递增 $\implies (x - 1)(x - a) \geqslant 0 \iff a \geqslant x$ 恒成立 $\implies a \geqslant 0$。
20. **第 20 题（四棱锥公垂线与二面角）**：
    - (1) 三垂线定理逆定理证 $DE \perp EC$，矩形勾股定理列方程求得 $AD = \dfrac{\sqrt{3}}{2}$，公垂线段 $DE = 1$；
    - (2) 建系求平面 $PCD$ 法向量 $(1, 0, 0)$ 与平面 $PCE$ 法向量 $(\sqrt{3}, 1, \sqrt{2})$，二面角余弦 $\dfrac{\sqrt{2}}{2}$，二面角为 $\dfrac{\pi}{4}$（或 $45^\circ$）。
21. **第 21 题（双曲线标准方程与直线割线向量数量积）**：
    - (1) $a = \sqrt{3}, c = 2 \implies b^2 = 1$，方程 $\dfrac{x^2}{3} - y^2 = 1$；
    - (2) 联立消元判别式 $\Delta = 36(1 - k^2) > 0 \implies k^2 < 1$；向量数量积 $\overrightarrow{OA} \cdot \overrightarrow{OB} = \dfrac{-3k^2 - 7}{1 - 3k^2} > 2 \iff \dfrac{3 - k^2}{3k^2 - 1} > 0 \implies k^2 > \dfrac{1}{3}$，范围为 $\left(-1, -\dfrac{\sqrt{3}}{3}\right) \cup \left(\dfrac{\sqrt{3}}{3}, 1\right)$。
22. **第 22 题（分式递推数列、等比转化与错位相减求和）**：
    - (1) 递推 $b_{n+1} = 2b_n - \dfrac{4}{3}$，$b_1 = 2, b_2 = \dfrac{8}{3}, b_3 = 4, b_4 = \dfrac{20}{3}$；
    - (2) 构造等比数列得 $b_n = \dfrac{2^n + 4}{3}$；通项 $a_n b_n = \dfrac{2^{n-1} + 5}{3}$，前 $n$ 项和 $S_n = \dfrac{2^n + 5n - 1}{3}$。
