    - Q8：$A \in (0, 180^\circ)$，$\sin A > \frac{1}{2} \iff 30^\circ < A < 150^\circ \implies A > 30^\circ$，反之 $A = 150^\circ$ 时 $\sin A = \frac{1}{2} \not> \frac{1}{2}$，为必要不充分条件，选 B；

    - Q11：点 $\left(\frac{b}{2}, 0\right)$ 分焦距 $c$ 为 $c + \frac{b}{2}$ 与 $c - \frac{b}{2}$，比值为 $5 : 3 \implies c = 2b$，代入 $b^2 = a^2 - c^2 \implies \frac{5}{4}c^2 = a^2 \implies e = \frac{2\sqrt{5}}{5}$，选 D；
    - Q12：$f[g(x_0)] = x_0 \implies g(f[g(x_0)]) = g(x_0)$，令 $u_0 = g(x_0)$ 则 $g[f(u_0)] = u_0$，要求 $h(x) = x$ 有实根，B 选项 $x^2 + x + \frac{1}{5} = x \iff x^2 + \frac{1}{5} = 0$ 无实数解，不可能，选 B。

    - Q17：(1) $n = 1$ 时 $a_1 = \frac{1}{3}(a_1 - 1) \implies a_1 = -\frac{1}{2}$；$n = 2$ 时 $a_1 + a_2 = \frac{1}{3}(a_2 - 1) \implies a_2 = \frac{1}{4}$；(2) $n \geqslant 2$ 时 $a_n = S_n - S_{n-1} = \frac{1}{3}a_n - \frac{1}{3}a_{n-1} \implies a_n = -\frac{1}{2}a_{n-1}$，公比 $-\frac{1}{2}$ 的等比数列；
    - Q18：(1) $\sin^2\frac{B+C}{2} = \cos^2\frac{A}{2} = \frac{1+\cos A}{2} = \frac{2}{3}$，$\cos 2A = 2\cos^2 A - 1 = -\frac{7}{9}$，和为 $-\frac{1}{9}$；(2) $3 = b^2 + c^2 - \frac{2}{3}bc \geqslant \frac{4}{3}bc \implies bc \leqslant \frac{9}{4}$，最大值为 $\frac{9}{4}$；
    - Q19：(1) 正方形中心 $O$ 与 $EF$ 中点 $M$，在矩形 $ACEF$ 中 $AOEM$ 为平行四边形 $\implies AM \parallel OE \implies AM \parallel$ 面 $BDE$；(2) 建系 $\vec{AM} = (0, 1, 1)$，$\vec{BD} = (-2, 0, 0) \implies \vec{AM}\cdot\vec{BD} = 0$，$\vec{BF} = (-1, -1, 1) \implies \vec{AM}\cdot\vec{BF} = 0$，得 $AM \perp$ 面 $BDF$；(3) 面 $ADF$ 法向量 $(1, 1, 0)$，面 $BDF$ 法向量 $\vec{AM} = (0, 1, 1)$，法向量夹角余弦 $\frac{1}{2}$，二面角为 $60^\circ$（或 $\frac{\pi}{3}$）；
    - Q20：(1) 5 个工厂均选星期日概率 $\left(\frac{1}{7}\right)^5 = \frac{1}{16807}$；(2) 对立事件为 5 个工厂选择互不相同的 5 天，概率为 $\frac{\mathrm{A}_7^5}{7^5} = \frac{2520}{16807} = \frac{360}{2401}$，至少两工厂同一天概率 $1 - \frac{360}{2401} = \frac{2041}{2401}$；
    - Q21：(1) $f'(x) = 3x^2 - 2ax - 4$；(2) $f'(-1) = 0 \implies a = \frac{1}{2}$，$f'(x) = 3x^2 - x - 4 = (3x - 4)(x + 1)$，在 $[-2, 2]$ 上极值点 $-1$ 与 $\frac{4}{3}$，最大值 $f(-1) = \frac{9}{2}$，最小值 $f\left(\frac{4}{3}\right) = -\frac{50}{27}$；(3) 导数二次函数开口向上，$f'(x) \geqslant 0$ 在 $(-\infty, -2]$ 与 $[2, +\infty)$ 恒成立 $\iff$ 两根在 $[-2, 2]$ 内 $\iff f'(-2) \geqslant 0$ 且 $f'(2) \geqslant 0 \iff a \in [-2, 2]$；
    - Q22：(1) 直线 $AP$：$kx - y - k = 0$，距离 $d = \frac{|k(m-1)|}{\sqrt{k^2+1}} = 1 \implies (m-1)^2 = 1 + \frac{1}{k^2}$，由 $k^2 \in [1/3, 3]$ 得 $|m-1| \in [2\sqrt{3}/3, 2]$，解得 $m \in [-1, 1 - 2\sqrt{3}/3] \cup [1 + 2\sqrt{3}/3, 3]$；(2) 内心 $M$ 在 $x$ 轴上表明 $x$ 轴平分 $\angle PAQ$，由对称性 $k = 1$，直线 $PQ$ 垂直于 $x$ 轴，$x_P = m + 1 = \sqrt{2} + 2$，$y_P = \sqrt{2} + 1$，代入双曲线解得 $b^2 = \frac{2\sqrt{2}+1}{7}$，方程为 $x^2 - (2\sqrt{2}-1)y^2 = 1$。
