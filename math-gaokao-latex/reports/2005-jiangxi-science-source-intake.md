## 2. 原卷排印与考订说明

1. **第 1 题（整数集合运算）**：
   - 整数全集 $I = \{x \mid |x| < 3, x \in \mathbf{Z}\} = \{-2, -1, 0, 1, 2\}$；
   - $\complement_I B = \{0, 1\}$；并集 $A \cup (\complement_I B) = \{1, 2\} \cup \{0, 1\} = \{0, 1, 2\}$，选 D。
2. **第 2 题（复数四则运算与代数形式实部虚部）**：
   - $z_1 z_2 = (1+\mathrm{i})(x+2\mathrm{i}) = (x-2) + (x+2)\mathrm{i}$；
   - 乘积为实数 $\implies x + 2 = 0 \implies x = -2$，选 A。
3. **第 3 题（点线相切与充要条件辨析）**：
   - 圆心 $(a, -b)$，半径 $r = \sqrt{2}$；直线 $x - y + 2 = 0$；
   - 相切充要条件是 $d = \dfrac{|a + b + 2|}{\sqrt{2}} = \sqrt{2} \iff a + b = 0$ 或 $a + b = -4$；
   - “$a = b$”推不出相切，相切亦推不出“$a = b$”，互为既不充分又不必要条件，选 D。
4. **第 4 题（二项式定理通项与正整数指数项）**：
   - 通项 $T_{r+1} = \mathrm{C}_{12}^r x^{6 - r/6}$；
   - 指数 $6 - \dfrac{r}{6} \in \mathbf{N}^* \implies r \in \{0, 6, 12\}$，对应指数 $6, 5, 4$，共 3 项，选 B。
5. **第 5 题（含绝对值三角函数周期性辨析）**：
   - $f(x) = \sin 3x + |\sin 3x|$；
   - 当 $\sin 3x \geqslant 0$ 时 $f(x) = 2\sin 3x$；当 $\sin 3x < 0$ 时 $f(x) = 0$；
   - 最小正周期为 $\dfrac{2\pi}{3}$，选 B。
6. **第 6 题（平面向量线性运算与夹角公式）**：
   - $\vec{a} + \vec{b} = -\vec{a} \implies \vec{a} \cdot \vec{c} = -\dfrac{5}{2}$；
   - $\cos\theta = \dfrac{\vec{a}\cdot\vec{c}}{|\vec{a}||\vec{c}|} = -\dfrac{1}{2} \implies \theta = 120^\circ$，选 C。
7. **第 7 题（导数图象与原函数单调性、极值）**：
   - 由 $y = x f'(x)$ 的零点与符号，解得导函数 $f'(x)$ 符号：
     - $x < -1$ 时 $f'(x) > 0$，单调递增；
     - $-1 < x < 0$ 时 $f'(x) < 0$，单调递减；
     - $0 < x < 1$ 时 $f'(x) < 0$，单调递减；
     - $x > 1$ 时 $f'(x) > 0$，单调递增；
   - 极大值在 $x = -1$，极小值在 $x = 1$；选项 (C) 准确对应，选 C。
8. **第 8 题（函数极限换元与倒数计算）**：
   - 换元 $t = x - 1 \to 0$，已知 $\lim_{t \to 0} \dfrac{f(t)}{t} = 1$；
   - 令 $u = -2(x - 1) \to 0$，原式化为 $-\dfrac{1}{2} \lim_{u \to 0} \dfrac{u}{f(u)} = -\dfrac{1}{2}$，选 C。
9. **第 9 题（矩形折叠直二面角与四面体外接球）**：
   - 斜边 $AC = 5$ 的中点到四顶点距离均相等，外接球半径 $R = \dfrac{5}{2}$；
   - 外接球体积 $V = \dfrac{4}{3}\pi R^3 = \dfrac{125}{6}\pi$，选 C。
10. **第 10 题（指数对数关系式不可能成立辨析）**：
    - $(1/2)^a = (1/3)^b = t$；
    - ③ $0 < a < b$ 与 ④ $b < a < 0$ 均不可能成立，共有 2 个不可能成立，选 B。
11. **第 11 题（三角形面积最大值）**：
    - $S_{\triangle OAB} = \dfrac{1}{2}\left(1 - \dfrac{1}{2}\sin 2\theta\right)$；
    - 在 $\theta \in (0, \pi/2]$ 上，当 $\theta = \dfrac{\pi}{2}$ 时 $\sin 2\theta = 0$，面积取得最大值 $\dfrac{1}{2}$，选 D。
12. **第 12 题（有限集划分等差数列概率）**：
    - 9 个数平均分成 3 组，基本事件数为 $\dfrac{\mathrm{C}_9^3 \mathrm{C}_6^3}{3!} = 280$；
    - 每组均成等差数列的划分恰有 5 组；
    - 概率 $P = \dfrac{5}{280} = \dfrac{1}{56}$，选 A。
13. **第 13 题（对数奇函数性质与参数求解）**：
    - 奇函数需满足 $f(0) = 0 \implies \sqrt{2}a = 1 \implies a = \dfrac{\sqrt{2}}{2}$。
14. **第 14 题（线性规划连线斜率最值）**：
    - 可行域边界交点 $(1, 3/2)$ 取得连线斜率最大值 $\dfrac{3}{2}$。
15. **第 15 题（直三棱柱表面最短路径）**：
    - 沿侧面 $ACC_1A_1$ 与顶面展开至同一平面，点 $E(0, -1)$ 到 $F(3/2, 1/2)$ 的直线距离最短；
    - 最短路径长为 $\sqrt{(3/2)^2 + (3/2)^2} = \dfrac{3\sqrt{2}}{2}$。
16. **第 16 题（圆锥曲线真假命题辨析）**：
    - ① 双曲线定义遗漏常数小于两定点距离条件，假；
    - ② 定圆弦中点轨迹为圆非椭圆，假；
    - ③ 方程根为 $1/2$ 与 $2$，可分别作为椭圆和双曲线离心率，真；
    - ④ 焦点均在 $x$ 轴上且 $c = \sqrt{34}$，真；
    - 真命题序号为 ③④。
17. **第 17 题（二次方程根与带参不等式分类讨论）**：
    - (1) 韦达定理确定解析式 $f(x) = \dfrac{x^2}{2-x}$；
    - (2) 移项通分得 $\dfrac{(x-1)(x-k)}{x-2} > 0$；$1 < k < 2$ 时为 $(1, k) \cup (2, +\infty)$；$k = 2$ 时为 $(1, 2) \cup (2, +\infty)$；$k > 2$ 时为 $(1, 2) \cup (k, +\infty)$。
18. **第 18 题（三角函数导数方程与定义域陷阱）**：
    - 数量积化简得 $f(x) = \sin x + \cos x$，定义域要求 $x \neq \dfrac{\pi}{2}$；
    - 方程 $f(x) + f'(x) = 0 \iff 2\cos x = 0 \implies x = \dfrac{\pi}{2}$；
    - 该解不在定义域内，故不存在满足题意的实数 $x$。
19. **第 19 题（随机游走卡片游戏终止步数与数学期望）**：
    - (1) 初始卡片数为奇数，提前终止步数必为奇数，终止步数取值范围为 $\{5, 7, 9\}$；
    - (2) $P(\xi=5) = \dfrac{1}{16}$；$P(\xi=7) = \dfrac{5}{64}$；$P(\xi=9) = \dfrac{55}{64}$；
    - 数学期望 $\mathbf{E}\xi = \dfrac{275}{32}$。
20. **第 20 题（长方体空间线面垂直、点面距离与二面角）**：
    - (1) $A_1D \perp AD_1$ 且 $A_1D \perp AB \implies A_1D \perp \text{面 } AD_1B \implies D_1E \perp A_1D$；
    - (2) 空间坐标法求得点面距离为 $\dfrac{1}{3}$；
    - (3) 二面角方程解得 $AE = 2 - \sqrt{3}$。
21. **第 21 题（非线性递推数列单调有界性与通项公式求解）**：
    - (1) 构造函数 $f(x) = \dfrac{1}{2}x(4-x)$，由数学归纳法证明 $a_n < a_{n+1} < 2$；
    - (2) 换元 $c_n = \dfrac{2 - a_n}{2}$ 得平方递推 $c_{n+1} = c_n^2$，解得 $a_n = 2\left[1 - \left(\dfrac{1}{2}\right)^{2^n}\right]$。
22. **第 22 题（抛物线切线交点、重心轨迹与焦点角相等几何定理）**：
    - (1) 切线方程联立得切点横坐标方程 $t^2 - 2x_0 t + y_0 = 0$，重心轨迹方程为 $y = \dfrac{4}{3}x^2 - \dfrac{1}{3}x + \dfrac{2}{3}$；
    - (2) 由数量积恒等式 $\vec{FA} \cdot \vec{FP} = |FA|\left(y_0 + \dfrac{1}{4}\right)$ 证得 $\cos\angle PFA = \cos\angle PFB = \dfrac{y_0 + 1/4}{|FP|}$，从而 $\angle PFA = \angle PFB$。
