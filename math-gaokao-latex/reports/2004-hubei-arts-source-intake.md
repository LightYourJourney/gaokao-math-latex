Q14 题干为“已知 $(x^{\frac{1}{2}} + x^{-\frac{1}{2}})^n$ 的展开式中各项系数的和是 128，则展开式中 $x^5$ 的系数是______”：赋值 $x = 1$ 得 $2^n = 128 \implies n = 7$；通项公式中 $x$ 的指数为 $\frac{7-2r}{2}$，对 $r \in \{0, 1, \dots, 7\}$，指数均为半奇数（$\pm\frac{7}{2}, \pm\frac{5}{2}, \pm\frac{3}{2}, \pm\frac{1}{2}$），不存在指数为 5 的项，故 $x^5$ 的系数为 0。此题为经典“无对应项系数为零”的高考考题陷阱，官方答案确定为 0；
  4. Q18 二面角 $B - EF - C$ 的大小求解：等腰 $\triangle BEF$ 与 $\triangle CEF$ 共享公共底边 $EF$，中点垂线夹角余弦为 $-\frac{1}{3}$，平面角为钝角，大小为 $\arccos\left(-\frac{1}{3}\right)$（或 $\pi - \arccos\frac{1}{3}$）；
  5. Q19 直角三角形 $\mathrm{Rt}\triangle ABC$ 中 $A$ 为 $PQ$ 中点，由向量分解得 $\vec{BP}\cdot\vec{CQ} = a^2(\cos\theta - 1)$，由于 $\theta \in [0, \pi]$，$\cos\theta \leqslant 1$，当且仅当 $\theta = 0$ 时取得最大值 0；
  6. Q20 双曲线右支相交问题：由判别式 $\Delta > 0$、$2-k^2 < 0$、$x_1+x_2 > 0$ 得 $k \in (-2, -\sqrt{2})$；以 $AB$ 为直径的圆过右焦点 $F(\frac{\sqrt{6}}{2}, 0)$ 得到 $5k^2 + 2\sqrt{6}k - 6 = 0$，解得唯一合格解 $k = \frac{-6-\sqrt{6}}{5} = -\frac{6+\sqrt{6}}{5} \in (-2, -\sqrt{2})$；
  7. Q21 预防方案决策：在费用 $\leqslant 120$ 万元约束下，联合采用乙、丙、丁三种措施的总费用为 100 万元，事件不发生概率为 $1 - 0.2\times 0.3\times 0.4 = 0.976$，优于采用甲、丙（费用 120 万元，概率 0.970）及其他所有组合；
  8. Q22 直线与二次函数相切得 $(b+1)^2 = 4c \implies b = 2\sqrt{c}-1$（由 $c>0, b>-1$）；三次积函数导函数判别式 $\Delta = 4(b^2 - 3c) > 0 \implies (2\sqrt{c}-1)^2 > 3c \implies c - 4\sqrt{c} + 1 > 0$，求得 $c \in (0, 7-4\sqrt{3}) \cup (7+4\sqrt{3}, +\infty)$。

    - Q18：(1) 建系 $\vec{A_1C} = (-1, -1, -1)$，与 $\vec{BD}=(1, -1, 0)$ 及 $\vec{BC_1}=(0, -1, 1)$ 点积均为 0，得证垂直；(2) $EF$ 中点为 $H$，在等腰 $\triangle BEF$ 与 $\triangle CEF$ 中，$BH \perp EF, CH \perp EF$，$\triangle BCH$ 中由余弦定理得 $\cos\angle BHC = -\frac{1}{3}$，二面角大小为 $\arccos(-\frac{1}{3})$；
    - Q19：向量分解 $\vec{BP}\cdot\vec{CQ} = (\vec{BA} - \frac{1}{2}\vec{PQ})\cdot(\vec{CA} + \frac{1}{2}\vec{PQ}) = \frac{1}{2}\vec{PQ}\cdot\vec{BC} - a^2 = a^2(\cos\theta - 1)$；当 $\theta = 0$ 时取最大值 0；
    - Q20：(1) 联立消元得 $(2-k^2)x^2 - 2kx - 2 = 0$，由交于右支得 $\Delta > 0, 2-k^2 < 0, x_1+x_2 > 0$，求得 $k \in (-2, -\sqrt{2})$；(2) 圆过右焦点 $F(\frac{\sqrt{6}}{2}, 0) \iff \vec{FA}\cdot\vec{FB} = 0$，代入韦达定理化简得 $5k^2 + 2\sqrt{6}k - 6 = 0$，解得 $k = \frac{-6-\sqrt{6}}{5} = -\frac{6+\sqrt{6}}{5} \in (-2, -\sqrt{2})$；
    - Q21：不超 120 万元的所有组合中：联合采用乙、丙、丁费用为 100 万元，事件不发生概率为 $1 - 0.2\times 0.3\times 0.4 = 0.976$ 为最大；
    - Q22：(1) 相切 $\Delta = (b-1)^2 - 4(c-b) = (b+1)^2 - 4c = 0$，由 $b>-1, c>0$ 得 $b = 2\sqrt{c}-1$；(2) $F'(x) = 3x^2 + 4bx + (b^2+c)$，极值点存在等价于 $\Delta = 4(b^2-3c) > 0$，代入得 $c - 4\sqrt{c} + 1 > 0$，解得 $c \in (0, 7-4\sqrt{3}) \cup (7+4\sqrt{3}, +\infty)$。
