## 2. 原卷排印与考订说明

1. **第 1 题（整数集合定义域与交并补运算）**：
   - 整数全集 $I = \{x \mid |x| < 3, x \in \mathbf{Z}\} = \{-2, -1, 0, 1, 2\}$；
   - $\complement_I B = \{0, 1\}$；并集 $A \cup (\complement_I B) = \{1, 2\} \cup \{0, 1\} = \{0, 1, 2\}$，选 D。
2. **第 2 题（半角正切万能公式求余弦）**：
   - $\cos\alpha = \dfrac{1 - \tan^2(\alpha/2)}{1 + \tan^2(\alpha/2)} = \dfrac{1 - 9}{1 + 9} = -\dfrac{4}{5}$，选 B。
3. **第 3 题（二项式定理通项与正整数指数项）**：
   - 通项 $T_{r+1} = \mathrm{C}_{12}^r x^{(12-r)/2} x^{r/3} = \mathrm{C}_{12}^r x^{6 - r/6}$；
   - 要求指数 $6 - \dfrac{r}{6} \in \mathbf{N}^*$ 且 $r \in \{0, 1, \dots, 12\}$，故 $r$ 必须是 6 的倍数，即 $r = 0, 6, 12$，对应指数分别为 $6, 5, 4$（均为正整数），共 3 项，选 B。
4. **第 4 题（分式对数型复合函数定义域）**：
   - 分母不为零：$\log_2(-x^2 + 4x - 3) \neq 0 \iff -x^2 + 4x - 3 \neq 1 \iff (x-2)^2 \neq 0 \iff x \neq 2$；
   - 对数真数大于零：$-x^2 + 4x - 3 > 0 \iff (x-1)(x-3) < 0 \iff 1 < x < 3$；
   - 取交集得 $(1, 2) \cup (2, 3)$，选 A。
5. **第 5 题（含绝对值三角函数周期性辨析）**：
   - $f(x) = \sin 3x + |\sin 3x|$；
   - 当 $\sin 3x \geqslant 0$ 时 $f(x) = 2\sin 3x$；当 $\sin 3x < 0$ 时 $f(x) = 0$；
   - 函数在一个周期 $[0, \dfrac{2\pi}{3}]$ 内先为半波正弦拱，后为恒等于 0 的线段，最小正周期为 $\dfrac{2\pi}{3}$，选 B。
6. **第 6 题（平面向量数量积与夹角公式）**：
   - $\vec{a} + \vec{b} = (1-2, 2-4) = (-1, -2) = -\vec{a}$；
   - $(\vec{a} + \vec{b}) \cdot \vec{c} = -\vec{a} \cdot \vec{c} = \dfrac{5}{2} \implies \vec{a} \cdot \vec{c} = -\dfrac{5}{2}$；
   - $|\vec{a}| = \sqrt{1^2+2^2} = \sqrt{5}$，$|\vec{c}| = \sqrt{5}$；
   - $\cos\theta = \dfrac{\vec{a}\cdot\vec{c}}{|\vec{a}||\vec{c}|} = \dfrac{-5/2}{5} = -\dfrac{1}{2} \implies \theta = 120^\circ$，选 C。
7. **第 7 题（有限集合平均分组组合计数）**：
   - 9 人平均分成 3 组，每组 3 人；甲、乙同在某一组；
   - 该组需从剩余 7 人中再选 1 人，有 $\mathrm{C}_7^1 = 7$ 种选法；
   - 剩下 6 人平均分成 2 组（无标号均匀分组），选法为 $\dfrac{\mathrm{C}_6^3 \mathrm{C}_3^3}{2!} = \dfrac{20}{2} = 10$ 种；
   - 总分组数 $7 \times 10 = 70$ 种，选 A。
8. **第 8 题（正弦定理与等边三角形充要条件）**：
   - 在 $\triangle ABC$ 中，由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$；
   - 命题 $p: \dfrac{a}{\sin B} = \dfrac{b}{\sin C} = \dfrac{c}{\sin A}$ 结合正弦定理推得 $\sin A = \sin B = \sin C \iff A = B = C = 60^\circ$；
   - 故 $p \iff q$，互为充分必要条件，选 C。
9. **第 9 题（空间矩形折叠直二面角与四面体外接球）**：
   - 矩形折叠为直二面角 $B-AC-D$，$\triangle ABC$ 与 $\triangle ADC$ 均为以 $AC$ 为斜边的直角三角形；
   - 斜边中点 $O$ 到四顶点距离均等于 $\dfrac{1}{2}AC = \dfrac{5}{2}$；
   - 故外接球心即为 $AC$ 中点，半径 $R = \dfrac{5}{2}$；
   - 体积 $V = \dfrac{4}{3}\pi R^3 = \dfrac{4}{3}\pi \cdot \dfrac{125}{8} = \dfrac{125}{6}\pi$，选 C。
10. **第 10 题（指数方程对数关系式可能情形排除）**：
    - $(1/2)^a = (1/3)^b = t$；
    - 若 $t > 1$，则 $a < 0, b < 0$，$a = -\log_2 t, b = -\log_3 t$，因为 $\log_2 t > \log_3 t > 0 \implies -a > -b > 0 \implies a < b < 0$（②可能成立）；
    - 若 $t = 1$，则 $a = b = 0$（⑤可能成立）；
    - 若 $0 < t < 1$，则 $a = \log_{1/2} t > 0, b = \log_{1/3} t > 0$，因底数 $1/3 < 1/2 < 1$，得 $b < a$（①可能成立）；
    - 故 ③ $0 < a < b$ 与 ④ $b < a < 0$ 均不可能成立，共有 2 个不可能成立，选 B。
11. **第 11 题（坐标向量围成三角形面积最值）**：
    - $S_{\triangle OAB} = \dfrac{1}{2}|x_A y_B - x_B y_A| = \dfrac{1}{2}|1 - \sin\theta\cos\theta| = \dfrac{1}{2}\left(1 - \dfrac{1}{2}\sin 2\theta\right)$；
    - 当 $\theta \in (0, \pi/2]$ 时，$\sin 2\theta \in [0, 1]$；当 $\sin 2\theta = 0$ 即 $\theta = \dfrac{\pi}{2}$ 时，面积取到最大值 $\dfrac{1}{2}$，选 D。
12. **第 12 题（频率分布直方图等差等比数列应用）**：
    - 组距为 0.1，共 10 组；总人数 100；
    - 前 4 组频数成等比数列：$1, 3, 9, 27$（公比为 3，若公比为 1 则前 4 组均为 1，无法与后 6 组等差衔接达到 100）；
    - 第 4 组频数 27 为峰值，后 6 组为等差数列，首项 27，末项 2，公差 $d = -5$；
    - 后续频数依次为 $22, 17, 12, 7, 2$；全部频数和为 $1+3+9+27+22+17+12+7+2 = 100$；
    - 最大频率 $a = \dfrac{27}{100} = 0.27$；视力在 4.6–5.0 之间对应第 4、5、6、7 组，人数 $b = 27 + 22 + 17 + 12 = 78$，选 A。
13. **第 13 题（对数奇函数性质与待定系数求解）**：
    - 奇函数需满足 $f(0) = 0 \implies \log_a(\sqrt{2a^2}) = 0 \implies \sqrt{2}a = 1 \implies a = \dfrac{\sqrt{2}}{2}$。
14. **第 14 题（二元一次不等式组可行域与连线斜率最值）**：
    - 可行域由边界直线 $x - y - 2 \leqslant 0$、$x + 2y - 4 > 0$、$y \leqslant 3/2$ 围成；
    - 目标 $\dfrac{y}{x}$ 为点 $(x, y)$ 与原点连线斜率，在边界交点 $(1, 3/2)$ 处取得最大值 $\dfrac{3}{2}$。
15. **第 15 题（三棱锥线面角与直角三角形外心射影）**：
    - $\triangle ABC$ 为直角三角形，外心为其斜边 $BC$ 中点 $M$；
    - 由 $PA = PB = PC$ 知 $P$ 在底面的射影恰为外心 $M$，故 $PM \perp \text{底面}$；
    - $PA$ 与底面所成角为 $\angle PAM$；$AM = \dfrac{1}{2}BC = \dfrac{1}{2}PA$，$\cos\angle PAM = \dfrac{1}{2} \implies \angle PAM = 60^\circ$（或 $\dfrac{\pi}{3}$）。
16. **第 16 题（圆锥曲线基础定义与真假命题辨析）**：
    - ① 双曲线定义遗漏常数小于两定点距离条件，假；
    - ② 定圆动点弦中点轨迹为同心圆，非椭圆，假；
    - ③ 方程 $2x^2 - 5x + 2 = 0$ 根为 $1/2$ 与 $2$，分别落在 $(0, 1)$ 与 $(1, +\infty)$，可作为椭圆和双曲线离心率，真；
    - ④ 双曲线与椭圆焦点均在 $x$ 轴上，$c^2 = 25+9 = 34$，$c^2 = 35-1 = 34$，焦点同为 $(\pm\sqrt{34}, 0)$，真；
    - 故真命题序号为 ③④。
17. **第 17 题（分式二次方程与带参不等式分类讨论）**：
    - (1) 由 $x_1=3, x_2=4$ 为方程根建立方程组，解得 $a = -1, b = 2 \implies f(x) = \dfrac{x^2}{2-x}$；
    - (2) 移项通分得 $\dfrac{(x-1)(x-k)}{x-2} > 0$；
    - 因 $k > 1$，对 $k$ 与 2 的相对大小进行分类讨论：
      - $1 < k < 2$ 时，解集为 $(1, k) \cup (2, +\infty)$；
      - $k = 2$ 时，不等式化为 $\dfrac{(x-1)(x-2)^2}{x-2} > 0 \iff (x-1)(x-2) > 0$，解集为 $(1, 2) \cup (2, +\infty)$；
      - $k > 2$ 时，解集为 $(1, 2) \cup (k, +\infty)$。
18. **第 18 题（三角诱导公式与复合正弦函数性质）**：
    - $\tan(x/2 + \pi/4)\tan(x/2 - \pi/4) = -\tan(x/2 + \pi/4)\cot(x/2 + \pi/4) = -1$；
    - $f(x) = 2\sqrt{2}\cos(x/2)\sin(x/2 + \pi/4) - 1 = \sqrt{2}\sin(x + \pi/4)$（定义域 $x \neq \pi + 2k\pi$ 且 $x \neq \pi/2 + k\pi$）；
    - 最大值为 $\sqrt{2}$，最小正周期为 $2\pi$；
    - 在 $[0, \pi]$ 上递增区间为 $[0, \pi/4]$，递减区间为 $[\pi/4, \pi/2)$ 和 $(\pi/2, \pi]$。
19. **第 19 题（一维随机游走终止概率模型）**：
    - 双方各有 5 张，净胜 5 局游戏终止；
    - 7 次以内终止的步数只可能是 5 步或 7 步；
    - 5 步全胜或全负概率：$2 \times (1/2)^5 = \dfrac{1}{16}$；
    - 7 步终止要求前 6 步净胜 4 局（5 胜 1 负，且中间任何前缀不能提前达到净胜 5），有效路径数为 $2 \times 5 = 10$ 条，概率 $10 \times (1/2)^7 = \dfrac{5}{64}$；
    - 总概率为 $\dfrac{1}{16} + \dfrac{5}{64} = \dfrac{9}{64}$。
20. **第 20 题（长方体空间线面垂直、点面距离与二面角）**：
    - 原卷题干文字印刷存在轻微勘误（题干误写为“在棱 $AD$ 上移动”，配图及第(2)(3)问均证实点 $E$ 在棱 $AB$ 上）；
    - (1) 侧面为正方形得 $A_1D \perp AD_1$，又 $A_1D \perp AB$，故 $A_1D \perp \text{面 } AD_1B \implies A_1D \perp D_1E$；
    - (2) 向量法建立空间直角坐标系，点面距离为 $\dfrac{1}{3}$；
    - (3) 设 $AE = t$，建立二面角法向量方程，求得 $AE = 2 - \sqrt{3}$。
21. **第 21 题（抛物线动弦斜率定值与重心轨迹方程）**：
    - (1) 由 $MA = MB$ 知直线的倾斜角互补，斜率互为相反数；
    - 设 $M(y_0^2, y_0)$，直线 $EF$ 斜率化简后恒为定值 $-\dfrac{1}{2y_0}$；
    - (2) 当 $\angle EMF = 90^\circ$ 时，利用斜率垂直关系与韦达定理求得 $\triangle EMF$ 重心坐标满足 $y^2 = \dfrac{1}{9}\left(x - \dfrac{2}{3}\right)\ (y \neq 0)$。
22. **第 22 题（差分递推关系数列通项求解）**：
    - 奇偶项差分转化为 $a_n + a_{n-1} = 3\left(-\dfrac{1}{2}\right)^{n-1}$；
    - 两边同乘 $(-1)^n$ 构造累加递推，解得通项 $a_n = 4(-1)^{n-1} + 6\left(-\dfrac{1}{2}\right)^n$。
