# 湖南考生历年高考数学真题库（2017–2026）

面向 **2027 届湖南考生** 的备考资料库，与同目录的[物理真题库](README.md)并列存放。
每年提供**三份文档 × 三种格式**（`.md` 供 Obsidian 阅读、`.pdf` 供打印、`.docx` 供编辑重排），原卷影印件统一放在 `_raw/`。

---

## 一、先看这个：数学卷的两次「断代」

与物理不同，湖南数学**始终使用全国统一命题**（从未自主命题），但卷种名称与题型结构变过两次：

| 时期 | 卷种 | 题型结构 | 与 2027 高考的关系 |
|:---|:---|:---|:---|
| 2017–2020 | **全国 I 卷**（文/理**分科**） | 12 单选 + 4 填空 + 6 解答，**含选做题 2 选 1**（极坐标参数方程／不等式选讲） | ⚠️ 结构已废止、选做题已取消，**仅供按考点抽题** |
| 2021–2023 | **新高考 I 卷**（文理合卷） | 8 单选 + 4 多选 + 4 填空 + 6 解答 | ✅ 结构接近，可用 |
| 2024–2026 | 新高考 I 卷 → **全国 1 卷**（2025 起更名，结构不变） | 8 单选 + **3 多选** + **3 填空** + **5 解答** | ✅ **这三份才是真正的对标真题** |

**两条实操结论**

1. **2024 年是分水岭**：题量由 22 题减到 19 题，多选、填空、解答各减一题，单题分值提高、压轴更难（如 2024 第 19 题「可分数列」、2026 第 19 题新定义抽象函数）。**限时套卷训练请优先用 2024–2026 三年。**
2. **2017–2020 是文理分科卷**，每年文、理各一套（本库两套都收）。这四年适合按知识点抽题练习，不适合整套限时。

## 六、重新生成 PDF / Word

修改任何数学真题 Markdown 后运行：

```bash
bash _convert_math.sh          # 转换全部年份
bash _convert_math.sh 2025     # 只转换某一年
```

依赖 `pandoc` + `xelatex`（字体用 macOS 自带 Songti SC / PingFang SC）。
物理真题由 `_build.py` 从 docx 构建，两条流水线互不干扰。

> **LaTeX 兼容性提醒**：写 Markdown 时避免 `\xlongequal`、`\xrightarrow[]{}` 等需额外宏包的命令，否则 PDF 转换失败（Word 与 Obsidian 预览不受影响）。改用文字描述即可。
